# 자작문제 🎤 아이돌 서바이벌 — 관대화 지수

## 문제 요약
> 아이돌 오디션에서 팀별로 "같은 팀끼리 점수를 후하게 주는지"를 검증하기 위해, 팀내평가 평균 / 팀외평가 평균으로 관대화 지수를 구하는 문제. 예외 처리(내부/외부 평가 없음)와 혼합 정렬 포함.

### 문제링크
https://velog.io/@tesabel/SQL-자작문제-아이돌-서바이벌

## 느낀점
>
- 배울 점 많은 문제였다.
- 시험 전 다시 풀어보기

## 흐름
1. PEER_EVALUATION에 TRAINEE를 두 번 JOIN (평가자 팀, 피평가자 팀 확인)
2. 평가자와 피평가자의 팀이 같으면 SAME, 다르면 DIFF로 분류
3. 피평가자 팀 기준으로 GROUP BY → CASE WHEN 피벗으로 SAME_AVG / DIFF_AVG 컬럼 생성
4. NULL 여부에 따라 예외 문자열 또는 ROUND(SAME / DIFF, 2) 출력
5. 숫자 결과 내림차순 → 예외 문자열은 팀 이름 오름차순 정렬

## 코드
```sql
WITH J AS (
    SELECT EVALUATEE_ID, SCORE, T2.TEAM_NAME,
        CASE
            WHEN T1.TEAM_NAME = T2.TEAM_NAME THEN 'SAME'
            ELSE 'DIFF'
        END AS TEAM
    FROM PEER_EVALUATION E
    JOIN TRAINEE T1 ON T1.TRAINEE_ID = E.EVALUATOR_ID
    JOIN TRAINEE T2 ON T2.TRAINEE_ID = E.EVALUATEE_ID
), G AS (
    SELECT TEAM_NAME, TEAM,
        ROUND(
            AVG(SCORE),
            2
        ) AS A
    FROM J
    GROUP BY TEAM_NAME, TEAM
), R AS (
    SELECT TEAM_NAME, 
        MAX(
            CASE
                WHEN TEAM = 'SAME' THEN A
            END
        ) AS SAME_AVG,
        MAX(
            CASE
                WHEN TEAM = 'DIFF' THEN A
            END
        ) AS DIFF_AVG
    FROM G
    GROUP BY TEAM_NAME
)
SELECT TEAM_NAME,
    CASE
        WHEN SAME_AVG IS NULL AND DIFF_AVG IS NULL THEN '둘 다 없음'
        WHEN DIFF_AVG IS NULL THEN '외부 평가 없음'
        WHEN SAME_AVG IS NULL THEN '내부 평가 없음'
        ELSE ROUND(
            SAME_AVG / DIFF_AVG,
            2
            )
    END AS LENIENCY_INDEX 
FROM R
ORDER BY 
    CASE WHEN SAME_AVG IS NOT NULL AND DIFF_AVG IS NOT NULL THEN 0 ELSE 1 END,
    ROUND(SAME_AVG / DIFF_AVG, 2) DESC,
    TEAM_NAME ASC
```

## 질문 & 실수 정리

### 새로 배운 것

#### 관대화 지수(Leniency Bias)의 실제 의미
실제 인사/동료평가 분야에서 "leniency bias"는 널리 쓰이는 개념이다. 개인 수준(특정 평가자가 전체 평균보다 높게 주는 정도)과 집단 수준(in-group vs out-group 점수 비교)이 있으며, 이 문제에서 쓴 방식은 **in-group leniency** — 피평가자 기준으로 내부/외부 점수를 비율로 비교하는 전형적인 접근이다.
- **핵심 원리**: 비율이 1보다 크면 내부에서 후하게 줬다는 의미

#### 혼합 정렬 (숫자 + 문자열 분리 정렬)
CASE WHEN 결과에 숫자와 문자열이 섞여 있을 때, 단순 ORDER BY로는 기대 순서가 나오지 않는다. 숫자 그룹을 먼저 올리는 0/1 플래그를 첫 번째 정렬 기준으로 두고, 두 번째로 숫자 내림차순, 세 번째로 문자열 그룹 내 팀 이름 오름차순으로 정렬하면 된다.
- **핵심 원리**: `CASE WHEN 조건 THEN 0 ELSE 1 END`로 그룹을 나눈 뒤 각 그룹 내부에서 별도 기준 적용

#### CTE 피벗에서 AVG를 직접 사용하면 중간 집계 생략 가능
`GROUP BY 팀 + CASE WHEN 피벗`에서, 중간에 별도로 AVG를 구한 뒤 MAX로 피벗할 필요 없이, `AVG(CASE WHEN ... THEN SCORE END)`로 한 번에 처리할 수 있다. 조건에 해당하지 않는 행은 NULL이 되어 AVG에서 자동 제외된다.
- **핵심 원리**: `AVG(CASE WHEN 조건 THEN 값 END)` = 조건부 평균, NULL은 집계에서 무시됨

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| EVALUATOR_ID 기준으로 집계 (평가자 관점) | EVALUATEE_ID의 팀 기준으로 집계 (피평가자 관점) |
| `SELECT *`에 GROUP BY 미포함 컬럼 포함 | GROUP BY에 있는 컬럼만 SELECT하거나 집계함수 사용 |
| 중간 CTE(G)에서 ROUND 후 나눗셈 | ROUND는 최종 출력에서만 적용 (정밀도 보존) |

## AI 코드 리뷰

### 개선할 점

1. **불필요한 중간 CTE 제거**: G에서 팀+EVAL_TYPE별 평균을 구한 뒤 R에서 피벗하는 2단계를, `AVG(CASE WHEN ...)` 패턴으로 1단계로 축소 가능
2. **ROUND 위치**: 중간 집계에서 반올림하면 나눗셈 정밀도가 떨어질 수 있음. 최종 SELECT에서만 ROUND 적용
3. **별칭 네이밍**: `A`, `TEAM` → `AVG_SCORE`, `EVAL_TYPE` 등 의미가 명확한 이름 사용

## 수정된 코드
```sql
WITH J AS (
    SELECT T2.TEAM_NAME,
        CASE
            WHEN T1.TEAM_NAME = T2.TEAM_NAME THEN 'SAME'
            ELSE 'DIFF'
        END AS EVAL_TYPE,
        SCORE
    FROM PEER_EVALUATION E
    JOIN TRAINEE T1 ON T1.TRAINEE_ID = E.EVALUATOR_ID
    JOIN TRAINEE T2 ON T2.TRAINEE_ID = E.EVALUATEE_ID
), R AS (
    SELECT TEAM_NAME,
        AVG(CASE WHEN EVAL_TYPE = 'SAME' THEN SCORE END) AS SAME_AVG,
        AVG(CASE WHEN EVAL_TYPE = 'DIFF' THEN SCORE END) AS DIFF_AVG
    FROM J
    GROUP BY TEAM_NAME
)
SELECT TEAM_NAME,
    CASE
        WHEN SAME_AVG IS NULL AND DIFF_AVG IS NULL THEN '둘 다 없음'
        WHEN DIFF_AVG IS NULL THEN '외부 평가 없음'
        WHEN SAME_AVG IS NULL THEN '내부 평가 없음'
        ELSE ROUND(SAME_AVG / DIFF_AVG, 2)
    END AS LENIENCY_INDEX
FROM R
ORDER BY
    CASE WHEN SAME_AVG IS NOT NULL AND DIFF_AVG IS NOT NULL THEN 0 ELSE 1 END,
    ROUND(SAME_AVG / DIFF_AVG, 2) DESC,
    TEAM_NAME ASC
```
