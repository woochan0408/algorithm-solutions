# 자작문제 🎤 배틀 래퍼 디스전 - 관대화 지수

## 문제 요약
> 래퍼별로 같은 크루원에게 준 점수 평균 / 다른 크루원에게 준 점수 평균을 구해 관대화 지수를 계산. 크루 내/외 평가가 없는 경우 예외 문자열 출력.

### 문제링크
https://velog.io/@tesabel/자작문제-아이돌-서바이벌-관대화-지수-문제-풀이

## 느낀점
>
- 피벗이 항상 헷갈린다.
- 내일 시험 전에 마지막으로 한번 더 풀어보기

## 흐름
1. BATTLE_EVALUATION에 RAPPER를 두 번 JOIN해서 평가자/피평가자의 크루가 같은지 판별 (SAME/DIFF)
2. EVALUATOR_ID + IS_SAME 기준으로 GROUP BY하여 평균 점수 계산
3. 피벗: EVALUATOR_ID 기준으로 SAME_AVG / DIFF_AVG를 한 행에 정리
4. SAME_AVG / DIFF_AVG 나눠서 관대화 지수 계산, NULL인 경우 예외 문자열 출력
5. 숫자 결과는 내림차순, 예외는 래퍼 이름 오름차순 정렬

## 코드
```sql
WITH E AS (
    SELECT EVALUATOR_ID, SCORE,
        CASE
            WHEN R1.CREW_ID = R2.CREW_ID THEN 'SAME'
            ELSE 'DIFF'
        END AS IS_SAME
    FROM BATTLE_EVALUATION E
    JOIN RAPPER R1 ON R1.RAPPER_ID = E.EVALUATOR_ID
    JOIN RAPPER R2 ON R2.RAPPER_ID = E.EVALUATEE_ID
), G AS (
    SELECT EVALUATOR_ID, IS_SAME, AVG(SCORE) AS AVG_SCORE
    FROM E
    GROUP BY EVALUATOR_ID, IS_SAME
), GG AS (
    SELECT EVALUATOR_ID,
        MAX(
            CASE
                WHEN IS_SAME = 'SAME' THEN AVG_SCORE
            END
        ) AS SAME_AVG,
        MAX(
            CASE
                WHEN IS_SAME = 'DIFF' THEN AVG_SCORE
            END
        ) AS DIFF_AVG
    FROM G
    GROUP BY EVALUATOR_ID
)
SELECT R.RAPPER_NAME,
    CASE
        WHEN GG.SAME_AVG IS NULL THEN '크루 내 평가 없음'
        WHEN GG.DIFF_AVG IS NULL THEN '크루 외 평가 없음'
        ELSE ROUND(GG.SAME_AVG / GG.DIFF_AVG, 2)
    END AS LENIENCY_INDEX
FROM GG
JOIN RAPPER R ON R.RAPPER_ID = GG.EVALUATOR_ID
ORDER BY 
    CASE
        WHEN GG.SAME_AVG IS NULL THEN 2
        WHEN GG.DIFF_AVG IS NULL THEN 1
        ELSE 0
    END, LENIENCY_INDEX DESC
```

## 질문 & 실수 정리

### 새로 배운 것

#### MySQL 집계 함수 중첩 불가
MySQL에서 `MAX(AVG(...))`처럼 집계 함수 안에 집계 함수를 넣으면 `Invalid use of group function` 에러가 발생한다. 집계 결과를 다시 집계해야 할 때는 반드시 서브쿼리나 CTE로 단계를 분리해야 한다.
- **핵심 원리**: 집계 함수는 GROUP BY된 그룹 내 행들을 하나로 축약하는 연산인데, 이미 축약된 결과를 같은 단계에서 다시 축약할 수 없음. 한 단계에서 AVG로 평균을 구한 뒤, 다음 단계에서 MAX로 피벗하는 식으로 나눠야 함.

#### GROUP BY + CASE WHEN 피벗 패턴
여러 행으로 나뉜 카테고리별 값을 한 행의 여러 컬럼으로 변환하는 피벗 기법. `MAX(CASE WHEN 조건 THEN 값 END)`로 각 카테고리의 값을 별도 컬럼으로 꺼낸다. MAX는 그룹 내 하나의 non-NULL 값만 존재하므로 실질적으로 값을 꺼내는 역할.
- **핵심 원리**: GROUP BY로 묶인 그룹에서 CASE WHEN이 조건에 맞지 않으면 NULL을 반환하고, MAX는 NULL을 무시하므로 조건에 맞는 유일한 값이 선택됨.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `CASE WHEN ... (END 누락)` | `CASE WHEN ... END` 반드시 닫아야 함 |
| `MAX(AVG(...))` 집계 중첩 | CTE로 단계 분리 후 각각 집계 |
| `CASE IS_SAME = 'SAME' THEN` | `CASE WHEN IS_SAME = 'SAME' THEN` (WHEN 누락) |
| `FROM` 절 누락 | CTE 참조 시 `FROM G` 명시 |
| GG에서 `SCORE` 참조 | G CTE에는 `AVG_SCORE`로 정의됨 |

## AI 코드 리뷰

### 개선할 점

1. **CTE 이름 가독성**: `E`, `G`, `GG`는 의미가 불분명. `eval_classified`, `avg_by_group`, `pivoted` 등 역할이 드러나는 이름으로 변경
2. **ORDER BY 예외 정렬 보완**: 문제 요구사항은 예외를 "래퍼 이름 오름차순"인데, 현재는 타입별 우선순위(1, 2)로만 분리. 예외가 여러 명일 때 이름순 정렬이 보장되지 않으므로 `RAPPER_NAME ASC` 추가 필요
3. **혼합 타입 정렬 위험**: `LENIENCY_INDEX` 컬럼에 숫자와 문자열이 섞여 있어 ORDER BY 시 문자열 비교가 될 수 있음. 정렬은 원본 숫자 컬럼(`SAME_AVG / DIFF_AVG`)으로 하는 게 안전

## 수정된 코드
```sql
WITH eval_classified AS (
    SELECT E.EVALUATOR_ID, E.SCORE,
        CASE
            WHEN R1.CREW_ID = R2.CREW_ID THEN 'SAME'
            ELSE 'DIFF'
        END AS IS_SAME
    FROM BATTLE_EVALUATION E
    JOIN RAPPER R1 ON R1.RAPPER_ID = E.EVALUATOR_ID
    JOIN RAPPER R2 ON R2.RAPPER_ID = E.EVALUATEE_ID
),
avg_by_group AS (
    SELECT EVALUATOR_ID, IS_SAME, AVG(SCORE) AS AVG_SCORE
    FROM eval_classified
    GROUP BY EVALUATOR_ID, IS_SAME
),
pivoted AS (
    SELECT EVALUATOR_ID,
        MAX(CASE WHEN IS_SAME = 'SAME' THEN AVG_SCORE END) AS SAME_AVG,
        MAX(CASE WHEN IS_SAME = 'DIFF' THEN AVG_SCORE END) AS DIFF_AVG
    FROM avg_by_group
    GROUP BY EVALUATOR_ID
)
SELECT R.RAPPER_NAME,
    CASE
        WHEN P.SAME_AVG IS NULL THEN '크루 내 평가 없음'
        WHEN P.DIFF_AVG IS NULL THEN '크루 외 평가 없음'
        ELSE ROUND(P.SAME_AVG / P.DIFF_AVG, 2)
    END AS LENIENCY_INDEX
FROM pivoted P
JOIN RAPPER R ON R.RAPPER_ID = P.EVALUATOR_ID
ORDER BY 
    CASE
        WHEN P.SAME_AVG IS NOT NULL AND P.DIFF_AVG IS NOT NULL THEN 0
        ELSE 1
    END,
    P.SAME_AVG / P.DIFF_AVG DESC,
    R.RAPPER_NAME ASC
```
