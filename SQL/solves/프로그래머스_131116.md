# 식품분류별 가장 비싼 식품의 정보 조회하기

## 문제 요약
> 식품분류별로 가장 비싼 식품의 분류, 가격, 이름을 조회하되, '과자', '국', '김치', '식용유' 카테고리만 출력하고 가격 내림차순 정렬

## 느낀점
>
- 실력이 많이 늘은 것 같다.
- 요구사항만 잘 읽자.

## 코드
```sql
WITH M AS (
    SELECT CATEGORY, MAX(PRICE) AS MAX_PRICE
    FROM FOOD_PRODUCT
    GROUP BY CATEGORY
)
SELECT F.CATEGORY, M.MAX_PRICE, F.PRODUCT_NAME
FROM FOOD_PRODUCT F
JOIN M ON M.CATEGORY = F.CATEGORY
WHERE F.PRICE = M.MAX_PRICE AND F.CATEGORY IN ('과자', '국', '김치', '식용유')
ORDER BY F.PRICE DESC
```

## AI 코드 리뷰

### 개선할 점

1. **필터링 순서 최적화**: `WHERE` 절의 카테고리 필터를 CTE 내부로 이동하면 불필요한 카테고리의 MAX 계산을 줄일 수 있습니다. 데이터가 많을 경우 성능 향상 효과가 있습니다.

2. **JOIN 조건 명확화**: 가격 비교 조건을 JOIN 절로 이동하면 의도가 더 명확해집니다.

3. **정렬 기준 명시**: `F.PRICE`와 `M.MAX_PRICE`는 같은 값이지만, 정렬 시 `M.MAX_PRICE`를 사용하면 "최대값 기준 정렬"이라는 의도가 더 명확합니다.

## 수정된 코드
```sql
-- 방법 1: 필터링 위치 최적화 (권장)
WITH M AS (
    SELECT CATEGORY, MAX(PRICE) AS MAX_PRICE
    FROM FOOD_PRODUCT
    WHERE CATEGORY IN ('과자', '국', '김치', '식용유')  -- 이른 필터링
    GROUP BY CATEGORY
)
SELECT F.CATEGORY, M.MAX_PRICE, F.PRODUCT_NAME
FROM FOOD_PRODUCT F
JOIN M ON M.CATEGORY = F.CATEGORY AND F.PRICE = M.MAX_PRICE
ORDER BY M.MAX_PRICE DESC;
```

```sql
-- 방법 2: 서브쿼리 사용 (CTE 없이)
SELECT F.CATEGORY, F.PRICE AS MAX_PRICE, F.PRODUCT_NAME
FROM FOOD_PRODUCT F
WHERE F.CATEGORY IN ('과자', '국', '김치', '식용유')
  AND F.PRICE = (
      SELECT MAX(PRICE)
      FROM FOOD_PRODUCT
      WHERE CATEGORY = F.CATEGORY
  )
ORDER BY F.PRICE DESC;
```

**핵심 개선점**
- 이른 필터링으로 불필요한 연산 감소 (전체 카테고리 → 4개만 집계)
- JOIN 조건에 가격 비교 포함으로 로직 명확화
- 상관 서브쿼리 대안도 고려 가능
