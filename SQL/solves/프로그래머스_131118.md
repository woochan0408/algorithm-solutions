# 서울에 위치한 식당 목록 출력하기

## 문제 요약
> REST_INFO와 REST_REVIEW 테이블을 JOIN하여 서울 소재 식당의 정보와 리뷰 평균 점수를 조회하고, 평균점수 → 즐겨찾기수 순으로 내림차순 정렬

## 느낀점
>
- 서울% -> 서울특별시% 라고해서 틀렸다.
(서울이면 서울특별시 아닌가..)
- 나머지는 굳

## 코드
```sql
SELECT RI.REST_ID, RI.REST_NAME, RI.FOOD_TYPE, RI.FAVORITES, RI.ADDRESS, 
       ROUND(AVG(RR.REVIEW_SCORE), 2) AS SCORE
FROM REST_INFO RI
JOIN REST_REVIEW RR ON RI.REST_ID = RR.REST_ID
WHERE RI.ADDRESS LIKE '서울%'
GROUP BY RI.REST_ID
ORDER BY SCORE DESC, RI.FAVORITES DESC
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| SQL에서 따옴표는 언제 어떻게 쓰나요? | 문자열 값은 작은따옴표(`'서울%'`), 식별자(컬럼명, 별칭)는 큰따옴표(`"SCORE"`) 사용. SQL 표준은 작은따옴표이므로 프로그래머스에서는 작은따옴표 권장 |

### 실수했던 부분

**1. LIKE 패턴 범위 설정**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `'서울특별시%'` | `'서울%'` |

→ 데이터에 "서울시", "서울특별시" 등 다양한 형태가 있을 수 있어 넓은 패턴이 안전함

## AI 코드 리뷰

### 개선할 점

1. **GROUP BY 명시성**: MySQL은 `REST_ID`만으로 동작하지만, 다른 DBMS 호환성을 위해 SELECT의 비집계 컬럼을 모두 명시하는 것도 좋은 습관

## 수정된 코드

```sql
SELECT RI.REST_ID, RI.REST_NAME, RI.FOOD_TYPE, RI.FAVORITES, RI.ADDRESS,

WHERE RI.ADDRESS LIKE '서울%'
GROUP BY RI.REST_ID
ORDER BY SCORE DESC, RI.FAVORITES DESC
```
