# 즐겨찾기가 가장 많은 식당 정보 출력하기

## 문제 요약
> 음식종류별로 즐겨찾기수가 가장 많은 식당의 음식 종류, ID, 식당 이름, 즐겨찾기수를 조회하고, 음식 종류 기준 내림차순 정렬

## 느낀점
>
- 요즘 모든 문제를 CTE로 풀고 있다.
- 서브쿼리 연습하자

## 코드
```sql
WITH F AS (
    SELECT FOOD_TYPE, MAX(FAVORITES) AS MAX_FAVORITE
    FROM REST_INFO
    GROUP BY FOOD_TYPE
)
SELECT I.FOOD_TYPE, I.REST_ID, I.REST_NAME, I.FAVORITES
FROM REST_INFO I
JOIN F ON F.FOOD_TYPE = I.FOOD_TYPE
WHERE I.FAVORITES = F.MAX_FAVORITE
ORDER BY FOOD_TYPE DESC
```

## AI 코드 리뷰

### 개선할 점

1. **별칭 통일**: CTE에서 `MAX_FAVORITE`로 별칭을 지었지만, 최종 SELECT에서는 원본 컬럼 `I.FAVORITES`를 사용. 일관성 면에서 문제는 없지만, 의도가 명확하게 드러남
2. **대안 접근법 참고**: 상관 서브쿼리 방식은 CTE 없이 한 문장으로 작성 가능하지만, 대규모 데이터에서는 CTE + JOIN이 일반적으로 더 효율적

## 수정된 코드
```sql
WITH MAX_FAVORITES AS (
    SELECT FOOD_TYPE, MAX(FAVORITES) AS MAX_FAVORITE
    FROM REST_INFO
    GROUP BY FOOD_TYPE
)
SELECT R.FOOD_TYPE, R.REST_ID, R.REST_NAME, R.FAVORITES
FROM REST_INFO R
JOIN MAX_FAVORITES M ON R.FOOD_TYPE = M.FOOD_TYPE
                     AND R.FAVORITES = M.MAX_FAVORITE
ORDER BY R.FOOD_TYPE DESC
```
