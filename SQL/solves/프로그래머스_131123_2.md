# 즐겨찾기가 가장 많은 식당 정보 출력하기

## 문제 요약
> REST_INFO 테이블에서 음식종류별로 즐겨찾기수가 가장 많은 식당의 음식 종류, ID, 식당 이름, 즐겨찾기수를 조회하고, 음식종류 기준 내림차순 정렬

## 느낀점
>
- 잘 풀었다.

## 코드
```sql
SELECT F.FOOD_TYPE, F.REST_ID, F.REST_NAME, F.FAVORITES
FROM REST_INFO F
JOIN (
    SELECT FOOD_TYPE, MAX(FAVORITES) AS MAX_FAVORITES
    FROM REST_INFO
    GROUP BY FOOD_TYPE
) S ON F.FOOD_TYPE = S.FOOD_TYPE
WHERE F.FAVORITES = S.MAX_FAVORITES
ORDER BY F.FOOD_TYPE DESC
```

## AI 코드 리뷰

### 개선할 점

1. **JOIN 조건 통합**: `FAVORITES` 매칭 조건이 `WHERE`에 분리되어 있는데, `ON` 절에 함께 작성하면 JOIN의 연결 의미가 명확해지고 가독성이 향상된다.

## 수정된 코드
```sql
SELECT F.FOOD_TYPE, F.REST_ID, F.REST_NAME, F.FAVORITES
FROM REST_INFO F
JOIN (
    SELECT FOOD_TYPE, MAX(FAVORITES) AS MAX_FAVORITES
    FROM REST_INFO
    GROUP BY FOOD_TYPE
) S ON F.FOOD_TYPE = S.FOOD_TYPE AND F.FAVORITES = S.MAX_FAVORITES
ORDER BY F.FOOD_TYPE DESC
```
