# 그룹별 조건에 맞는 식당 목록 출력하기

## 문제 요약
> 리뷰를 가장 많이 작성한 회원의 리뷰들을 조회하고, 리뷰 작성일 오름차순 → 리뷰 텍스트 오름차순 정렬

## 느낀점
>
- 각 문제 별 풀이방식이 중구난방이라 계속 갈피를 못 잡는다
(어려운 문제 아닌데;;)
- 한번 개념을 정리해보자 어떤 유형은 어떤 스킬을 쓸 지
---

## 흐름
1. "가장 많이 리뷰한 회원"을 `ORDER BY COUNT(*) DESC LIMIT 1`로 간단히 추출
2. 해당 회원의 리뷰를 JOIN으로 조회
3. DATE_FORMAT으로 날짜 포맷 맞춤

## 코드
```sql
SELECT P.MEMBER_NAME, R.REVIEW_TEXT, DATE_FORMAT(R.REVIEW_DATE, "%Y-%m-%d") AS REVIEW_DATE
FROM REST_REVIEW R
JOIN MEMBER_PROFILE P ON P.MEMBER_ID = R.MEMBER_ID
WHERE P.MEMBER_ID = (
                SELECT MEMBER_ID
                FROM REST_REVIEW
                GROUP BY MEMBER_ID
                ORDER BY COUNT(*) DESC
                LIMIT 1
                )
ORDER BY REVIEW_DATE, REVIEW_TEXT
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| MAX(COUNT(*))처럼 집계 함수를 중첩할 수 있는지 | MySQL에서는 집계 함수 안에 집계 함수 중첩 불가. 인라인 뷰 또는 ORDER BY + LIMIT로 우회해야 함 |

### 실수했던 부분

**1. 집계 함수 중첩 시도**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `HAVING COUNT(*) = MAX(COUNT(*))` | `ORDER BY COUNT(*) DESC LIMIT 1` 또는 인라인 뷰에서 MAX 사용 |

**2. 같은 실수 반복 (서브쿼리 안에서도 중첩)**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `SELECT MAX(COUNT(*)) FROM ... GROUP BY ...` | `SELECT MAX(cnt) FROM (SELECT COUNT(*) AS cnt FROM ... GROUP BY ...) t` |

## AI 코드 리뷰

### "가장 많은" 값을 찾는 두 가지 패턴

MySQL에서 GROUP BY 결과 중 최대값을 가진 행을 찾을 때, 집계 함수는 중첩할 수 없으므로 다음 두 가지 방법을 사용한다.

**방법 1: ORDER BY + LIMIT (간결한 방법)**

단순히 정렬 후 1건만 가져오는 방식이다. 코드가 짧고 직관적이어서 코딩테스트에서 자주 쓰인다. 단, `LIMIT`은 MySQL 전용이므로 Oracle 등에서는 사용할 수 없다.

```sql
SELECT MEMBER_ID
FROM REST_REVIEW
GROUP BY MEMBER_ID
ORDER BY COUNT(*) DESC
LIMIT 1
```

**방법 2: 인라인 뷰 + MAX (범용적인 방법)**

COUNT 결과를 먼저 서브쿼리(인라인 뷰)로 만든 뒤, 그 결과에서 MAX를 구하는 방식이다. 집계 함수 중첩이 불가능하기 때문에, 중간 결과를 테이블화하는 것이 핵심이다.

```sql
SELECT MEMBER_ID
FROM REST_REVIEW
GROUP BY MEMBER_ID
HAVING COUNT(*) = (
    SELECT MAX(cnt)
    FROM (
        SELECT COUNT(*) AS cnt
        FROM REST_REVIEW
        GROUP BY MEMBER_ID
    ) t
)
```

이 방법은 동점자가 여러 명일 때 모두 반환한다는 장점이 있다. `LIMIT 1`은 한 명만 반환하므로, 문제 조건에 따라 적절한 방법을 선택해야 한다.

### DATE_FORMAT 습관화

날짜 포맷 조건이 명시된 문제에서는 `DATE_FORMAT`을 적용하는 것이 안전하다. MySQL의 DATE 타입이 기본적으로 `YYYY-MM-DD`로 출력되더라도, 출력 포맷이 명시되어 있다면 `DATE_FORMAT(컬럼, "%Y-%m-%d")`을 습관적으로 적용하는 것이 좋다.

## 수정된 코드
```sql
SELECT P.MEMBER_NAME,
       R.REVIEW_TEXT,
       DATE_FORMAT(R.REVIEW_DATE, "%Y-%m-%d") AS REVIEW_DATE
FROM REST_REVIEW R
JOIN MEMBER_PROFILE P ON P.MEMBER_ID = R.MEMBER_ID
WHERE P.MEMBER_ID = (
    SELECT MEMBER_ID
    FROM REST_REVIEW
    GROUP BY MEMBER_ID
    ORDER BY COUNT(*) DESC
    LIMIT 1
)
ORDER BY REVIEW_DATE, REVIEW_TEXT
```
