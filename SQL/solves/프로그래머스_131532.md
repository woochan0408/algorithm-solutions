# 년, 월, 성별 별 상품 구매 회원 수 구하기

## 문제 요약
> USER_INFO와 ONLINE_SALE 테이블을 JOIN하여 년, 월, 성별 별로 상품을 구매한 회원 수를 집계하고, 성별이 NULL인 경우 제외

## 느낀점
>
- DISTINCT는 칼럼에 감싸는 것이다. 
COUNT(DISTINCT I.USER_ID)
- 니머진 모두 실수.. 실수를 좀 줄이자!

## 코드
```sql
SELECT YEAR(S.SALES_DATE) AS YEAR, MONTH(S.SALES_DATE) AS MONTH, I.GENDER, COUNT(DISTINCT I.USER_ID) AS USERS
FROM ONLINE_SALE S
JOIN USER_INFO I ON I.USER_ID = S.USER_ID
WHERE I.GENDER IS NOT NULL
GROUP BY YEAR(S.SALES_DATE), MONTH(S.SALES_DATE), I.GENDER
ORDER BY YEAR, MONTH, GENDER
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| COUNT 안에서 DISTINCT는 어떻게 쓰는지? | `COUNT(DISTINCT 컬럼명)` 형태로 집계 함수 안에 직접 넣어 중복 제거 후 카운트 |

### 실수했던 부분

**1. SALES_DATE가 아닌 JOINED에서 년/월 추출**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `YEAR(I.JOINED)`, `MONTH(I.JOINED)` | `YEAR(S.SALES_DATE)`, `MONTH(S.SALES_DATE)` |

**2. COUNT(*)로 회원 수 집계**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `COUNT(*)` — 같은 달 중복 구매 시 중복 카운트 | `COUNT(DISTINCT I.USER_ID)` — 회원 단위로 중복 제거 |
