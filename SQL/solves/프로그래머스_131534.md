# 상품을 구매한 회원 비율 구하기

## 문제 요약
> 2021년에 가입한 전체 회원 중 상품을 구매한 회원수와 구매 비율을 년, 월별로 구하기

## 느낀점
>
- 먼가 억지로 어렵게 낸 문제..?
쿼리가 참 복잡해졌다.
- 연습용으로 좋고 겹치는 정보를 어떻게 병합할 지 다시 한번 생각해보자.

## 코드
```sql
SELECT YEAR(O.SALES_DATE) AS YEAR, 
        MONTH(O.SALES_DATE) AS MONTH, 
        COUNT(DISTINCT O.USER_ID),
        ROUND(COUNT(DISTINCT O.USER_ID) / 
              (SELECT COUNT(DISTINCT USER_ID)
                FROM USER_INFO
                WHERE YEAR(JOINED) = 2021
              ), 1
             ) AS PURCHASED_RATIO
FROM USER_INFO UI
JOIN ONLINE_SALE O ON UI.USER_ID = O.USER_ID
WHERE YEAR(UI.JOINED) = 2021
GROUP BY YEAR(O.SALES_DATE), MONTH(O.SALES_DATE)
ORDER BY YEAR, MONTH
```

## 질문 & 실수 정리

### 실수했던 부분

**1. 함수 호출 문법 오류**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `O.YEAR(SALES_DATE)` | `YEAR(O.SALES_DATE)` |

> `YEAR()`는 테이블의 메서드가 아니라 SQL 함수이므로, 함수 안에 `테이블.컬럼`을 넣어야 한다.

**2. COUNT(*) vs COUNT(DISTINCT)**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `COUNT(*)` | `COUNT(DISTINCT O.USER_ID)` |

> 한 회원이 같은 달에 여러 번 구매할 수 있으므로, 구매 **회원수**를 구할 때는 `COUNT(DISTINCT)`를 사용해야 한다.

**3. PURCHASED_USERS를 전체 회원수로 잘못 계산**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| 서브쿼리(전체 회원수)를 `PURCHASED_USERS`로 사용 | 메인 쿼리의 `COUNT(DISTINCT O.USER_ID)`를 `PURCHASED_USERS`로 사용 |

> "구매한 회원수"는 JOIN 결과에서 구해야 하고, 서브쿼리의 전체 회원수는 비율 계산의 분모로만 쓰여야 한다.

**4. SELECT절 콤마 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `...) AS PURCHASED_USERS ROUND(...)` | `...) AS PURCHASED_USERS, ROUND(...)` |

## AI 코드 리뷰

### 개선할 점

1. **컬럼 별칭 누락**: `COUNT(DISTINCT O.USER_ID)`에 `AS PURCHASED_USERS` 별칭이 빠져있다. 문제에서 요구하는 출력 컬럼명을 맞춰주는 습관이 중요하다.

2. **반복 서브쿼리 제거**: SELECT절의 서브쿼리는 GROUP BY의 각 그룹마다 반복 실행된다. CTE나 변수로 한 번만 계산하면 가독성과 성능 모두 개선된다.

3. **SARGable 조건**: `YEAR(JOINED) = 2021`은 컬럼에 함수를 씌워 인덱스를 활용할 수 없다. `JOINED >= '2021-01-01' AND JOINED < '2022-01-01'` 범위 조건이 더 효율적이다.

## 수정된 코드
```sql
SET @total = (SELECT COUNT(*)
              FROM USER_INFO
              WHERE JOINED >= '2021-01-01' AND JOINED < '2022-01-01');

SELECT YEAR(O.SALES_DATE) AS YEAR,
       MONTH(O.SALES_DATE) AS MONTH,
       COUNT(DISTINCT O.USER_ID) AS PURCHASED_USERS,
       ROUND(COUNT(DISTINCT O.USER_ID) / @total, 1) AS PURCHASED_RATIO
FROM USER_INFO UI
JOIN ONLINE_SALE O ON UI.USER_ID = O.USER_ID
WHERE UI.JOINED >= '2021-01-01' AND UI.JOINED < '2022-01-01'
GROUP BY YEAR(O.SALES_DATE), MONTH(O.SALES_DATE)
ORDER BY YEAR, MONTH;
```
