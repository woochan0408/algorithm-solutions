# 프로그래머스 132204 🏥 취소되지 않은 진료 예약 조회하기

## 문제 요약
> PATIENT, DOCTOR, APPOINTMENT 테이블에서 2022년 4월 13일 취소되지 않은 흉부외과(CS) 진료 예약 내역을 조회하는 문제. 3개 테이블 JOIN + 날짜/취소 조건 필터링.

## 느낀점
>
- 다 풀고 계속 틀렸다고 나왔다.
- 디버깅 30분했는데 실패
- `취소 날짜 IS null == 취소되지 않음` 이라고 생각했다.
- 조심하면서 풀자.

## 흐름
1. APPOINTMENT에서 2022-04-13, 취소되지 않은(APNT_CNCL_YN = 'N'), 흉부외과(CS) 조건으로 필터링
2. PATIENT 테이블과 JOIN하여 환자 이름 조회
3. DOCTOR 테이블과 JOIN하여 의사 이름 조회
4. 진료예약일시 기준 오름차순 정렬

## 코드
```sql
WITH A AS (
    SELECT APNT_YMD, APNT_NO, MCDP_CD, MDDR_ID, PT_NO
    FROM APPOINTMENT
    WHERE DATE_FORMAT(APNT_YMD, '%Y-%m-%d') = '2022-04-13' AND APNT_CNCL_YN = 'N' AND MCDP_CD = 'CS'
)
SELECT A.APNT_NO, P.PT_NAME, P.PT_NO, A.MCDP_CD, D.DR_NAME, A.APNT_YMD
FROM PATIENT P
JOIN A ON A.PT_NO = P.PT_NO
JOIN DOCTOR D ON A.MDDR_ID = D.DR_ID
ORDER BY APNT_YMD
```

## 질문 & 실수 정리

### 새로 배운 것

#### 취소 여부 판단 컬럼 선택
"취소되지 않은"이라는 조건을 필터링할 때, 취소 날짜(`APNT_CNCL_YMD IS NULL`)가 아닌 취소 여부 전용 컬럼(`APNT_CNCL_YN = 'N'`)을 사용해야 한다. 취소 날짜가 NULL인 것과 취소되지 않은 것이 항상 동치라는 보장이 없기 때문에, 의미적으로 정확한 컬럼을 선택하는 것이 중요하다.
- **핵심 원리**: 비즈니스 로직을 표현할 때는 해당 의미를 직접적으로 나타내는 컬럼을 사용할 것

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `APNT_CNCL_YMD IS NULL`로 취소 여부 판단 | `APNT_CNCL_YN = 'N'`으로 취소 여부 판단 |

## AI 코드 리뷰

### 개선할 점

1. **날짜 비교 방식 (SARGable)**: `DATE_FORMAT(APNT_YMD, '%Y-%m-%d') = '2022-04-13'`은 컬럼에 함수를 적용하여 인덱스를 활용하지 못한다. `APNT_YMD >= '2022-04-13' AND APNT_YMD < '2022-04-14'` 범위 비교가 성능상 더 좋다.

## 수정된 코드
```sql
WITH A AS (
    SELECT APNT_YMD, APNT_NO, MCDP_CD, MDDR_ID, PT_NO
    FROM APPOINTMENT
    WHERE APNT_YMD >= '2022-04-13'
      AND APNT_YMD < '2022-04-14'
      AND APNT_CNCL_YN = 'N'
      AND MCDP_CD = 'CS'
)
SELECT A.APNT_NO, P.PT_NAME, P.PT_NO, A.MCDP_CD, D.DR_NAME, A.APNT_YMD
FROM PATIENT P
JOIN A ON A.PT_NO = P.PT_NO
JOIN DOCTOR D ON A.MDDR_ID = D.DR_ID
ORDER BY A.APNT_YMD
```
