# 저자 별 카테고리 별 매출액 집계하기

## 문제 요약
> 2022년 1월 기준, 저자별/카테고리별 매출액을 집계하여 저자 ID 오름차순, 카테고리 내림차순으로 정렬

## 느낀점
>
- 

## 코드
```sql
SELECT B.AUTHOR_ID, A.AUTHOR_NAME, B.CATEGORY, SUM(BS.SALES * B.PRICE) AS TOTAL_SALES
FROM BOOK B
JOIN AUTHOR A ON B.AUTHOR_ID = A.AUTHOR_ID
JOIN BOOK_SALES BS ON BS.BOOK_ID = B.BOOK_ID
WHERE SALES_DATE >= '2022-01-01' and SALES_DATE <= '2022-01-31'
GROUP BY B.AUTHOR_ID, B.CATEGORY
ORDER BY AUTHOR_ID, CATEGORY DESC
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| `0 <= x <= 100` 문법 가능한지 | SQL에서는 불가. `AND`로 연결하거나 `BETWEEN` 사용 |

### 실수했던 부분

**1. GROUP BY 괄호 사용**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `GROUP BY (A, B)` | `GROUP BY A, B` |

## AI 코드 리뷰

### 개선할 점

1. **날짜 조건 간결화**: `>= AND <=` 대신 `BETWEEN` 사용 가능
2. **GROUP BY에 AUTHOR_NAME 추가 권장**: MySQL에서는 동작하지만, 표준 SQL에서는 SELECT에 있는 비집계 컬럼은 GROUP BY에 포함해야 함

## 수정된 코드
```sql
SELECT B.AUTHOR_ID, A.AUTHOR_NAME, B.CATEGORY, SUM(BS.SALES * B.PRICE) AS TOTAL_SALES
FROM BOOK B
JOIN AUTHOR A ON B.AUTHOR_ID = A.AUTHOR_ID
JOIN BOOK_SALES BS ON BS.BOOK_ID = B.BOOK_ID
WHERE BS.SALES_DATE BETWEEN '2022-01-01' AND '2022-01-31'
GROUP BY B.AUTHOR_ID, A.AUTHOR_NAME, B.CATEGORY
ORDER BY B.AUTHOR_ID, B.CATEGORY DESC
```
