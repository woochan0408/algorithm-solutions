# 자동차 대여 기록에서 장기/단기 대여 구분하기

## 문제 요약
> 2022년 9월 대여 기록에서 대여 기간 30일 이상이면 '장기 대여', 미만이면 '단기 대여'로 구분하는 RENT_TYPE 컬럼을 추가하여 HISTORY_ID 내림차순 출력

## 느낀점
>
- 

## 코드
```sql
SELECT HISTORY_ID, CAR_ID, DATE_FORMAT(START_DATE, "%Y-%m-%d") AS START_DATE, DATE_FORMAT(END_DATE, "%Y-%m-%d") AS END_DATE, 
    CASE
        WHEN DATEDIFF(END_DATE,START_DATE) >= 29 THEN '장기 대여'
        ELSE '단기 대여'
    END AS RENT_TYPE
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE START_DATE BETWEEN '2022-09-01' AND '2022-09-30'
ORDER BY HISTORY_ID DESC
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| `END_DATE - START_DATE`로 날짜 차이를 구할 수 있는가? | MySQL에서 DATE끼리 `-` 연산하면 YYYYMMDD 숫자로 변환 후 빼기 때문에 정확한 일수 차이가 아님. 반드시 `DATEDIFF()` 사용 |

### 실수했던 부분

**1. 날짜 뺄셈 연산 사용**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `END_DATE - START_DATE >= 30` | `DATEDIFF(END_DATE, START_DATE) >= 29` |

**2. DATEDIFF 결과와 실제 대여일수 차이**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `DATEDIFF() >= 30` (대여일수 31일 이상만 장기) | `DATEDIFF() >= 29` (시작일 포함하면 30일 = DATEDIFF 29) |

## AI 코드 리뷰

### 개선할 점

1. **대여 기간 조건 가독성**: `DATEDIFF() >= 29`는 "30일 이상"이라는 문제 조건과 숫자가 달라 의도 파악이 어려움. `DATEDIFF() + 1 >= 30`으로 작성하면 실제 대여일수 계산 의도가 명확해짐

## 수정된 코드
```sql
SELECT 
    HISTORY_ID, 
    CAR_ID, 
    DATE_FORMAT(START_DATE, "%Y-%m-%d") AS START_DATE, 
    DATE_FORMAT(END_DATE, "%Y-%m-%d") AS END_DATE, 
    CASE
        WHEN DATEDIFF(END_DATE, START_DATE) + 1 >= 30 THEN '장기 대여'
        ELSE '단기 대여'
    END AS RENT_TYPE
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE START_DATE BETWEEN '2022-09-01' AND '2022-09-30'
ORDER BY HISTORY_ID DESC
```
