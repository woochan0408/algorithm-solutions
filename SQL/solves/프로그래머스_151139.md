# 대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기

## 문제 요약
> 2022년 8~10월 총 대여 횟수가 5회 이상인 자동차에 대해, 해당 기간의 월별 자동차 ID별 대여 횟수를 구하기 (월 오름차순, 같은 월이면 CAR_ID 내림차순)

## 느낀점
>
- 다중 칼럼 집계는 처음이라 좀 헤맸다.

## 코드
```sql
SELECT MONTH(START_DATE) AS MONTH, CAR_ID, COUNT(CAR_ID) AS RECORDS
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE CAR_ID IN (
    SELECT CAR_ID
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
    GROUP BY CAR_ID
    HAVING COUNT(CAR_ID) >= 5
) AND START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
GROUP BY MONTH(START_DATE), CAR_ID
ORDER BY MONTH, CAR_ID DESC
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

#### COUNT 함수의 인자 개수
`COUNT`는 인자를 **1개만** 받는다. `COUNT(*)`, `COUNT(컬럼명)`, `COUNT(DISTINCT 컬럼명)` 세 가지 형태만 가능하며, `COUNT(A, B)`처럼 2개 이상의 인자를 넣으면 문법 오류가 발생한다. 다중 컬럼 기준 집계가 필요하면 `GROUP BY`로 그룹을 나눈 뒤 `COUNT(*)`를 사용한다.

#### GROUP BY에서 SELECT 별칭 사용
MySQL에서는 GROUP BY에서 SELECT의 별칭을 사용할 수 있다 (비표준 확장). 하지만 표준 SQL(Oracle, PostgreSQL 등)에서는 GROUP BY가 SELECT보다 먼저 실행되므로 별칭을 인식하지 못한다. 이식성을 위해 `MONTH(START_DATE)`처럼 원본 표현식을 직접 쓰는 것이 안전하다.

#### 다중 컬럼 GROUP BY와 SELECT 규칙
`GROUP BY`에 명시한 컬럼 또는 집계 함수만 `SELECT`에 쓸 수 있다. `GROUP BY A, B`이면 SELECT에는 `A`, `B`, 집계 함수만 허용된다. GROUP BY에 없는 컬럼을 SELECT에 쓰면, 그룹 내 여러 값 중 어떤 것을 보여줄지 결정할 수 없어 오류가 발생한다.

### 실수했던 부분

**1. COUNT에 인자 2개 전달**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `COUNT(CAR_ID, MONTH(START_DATE))` | `COUNT(CAR_ID)` 또는 `COUNT(*)` |

**2. GROUP BY에 CAR_ID 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `GROUP BY MONTH(START_DATE), MONTH` (같은 컬럼 중복) | `GROUP BY MONTH(START_DATE), CAR_ID` |

**3. 외부 쿼리에 기간 필터링 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| 서브쿼리에만 `WHERE` 기간 조건 | 외부 쿼리에도 `AND START_DATE BETWEEN '2022-08-01' AND '2022-10-31'` 추가 |

**4. 날짜 범위 끝값 오류**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `'2022-10-30'` (10/31 누락) | `'2022-10-31'` |

## AI 코드 리뷰

### 개선할 점

1. **COUNT(*) 사용 권장**: `COUNT(CAR_ID)`는 NOT NULL 컬럼이라 `COUNT(*)`와 결과가 동일하다. `COUNT(*)`가 "행 수를 센다"는 의도를 더 명확히 전달하고, 컬럼 의존성도 없어 가독성이 좋다.

2. **서브쿼리 중복 조건 → CTE로 개선**: 동일한 테이블에 같은 기간 조건을 서브쿼리와 외부 쿼리에서 반복하고 있다. CTE를 사용하면 기간 필터링을 한 번만 작성하고 재사용할 수 있어 유지보수성이 높아진다.

## 수정된 코드
```sql
WITH RENTAL_8_10 AS (
    SELECT CAR_ID, MONTH(START_DATE) AS MONTH
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
)
SELECT MONTH, CAR_ID, COUNT(*) AS RECORDS
FROM RENTAL_8_10
WHERE CAR_ID IN (
    SELECT CAR_ID
    FROM RENTAL_8_10
    GROUP BY CAR_ID
    HAVING COUNT(*) >= 5
)
GROUP BY MONTH, CAR_ID
ORDER BY MONTH, CAR_ID DESC
```
