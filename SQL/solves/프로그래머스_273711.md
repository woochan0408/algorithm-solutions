### 1. 문제 요약

> 'RARE' 등급인 아이템을 부모(PARENT)로 둔 모든 '다음 단계 아이템'들의 상세 정보를 조회하는 문제

### 2. 느낀점
> 
- 근래 푼 것 중 제일 어려웠다.
- 꼭 다시 풀어보기 (+ JOIN으로 풀어보기)

### 3. 코드

```sql
-- 사용자 제출 코드
SELECT ITEM_ID, ITEM_NAME, RARITY
FROM ITEM_INFO
WHERE ITEM_ID IN (
    SELECT ITEM_ID
    FROM ITEM_TREE 
    WHERE PARENT_ITEM_ID IN (SELECT ITEM_ID FROM ITEM_INFO WHERE RARITY = 'RARE')
)
ORDER BY ITEM_ID DESC

```

## 🛠 AI 코드 리뷰

### 개선할 점

1. **가독성 (JOIN 활용)**: 현재 3중 서브쿼리 방식도 정확하지만, `JOIN`을 활용하면 테이블 간의 관계가 더 명확하게 보일 수 있습니다. 특히 대용량 데이터에서는 인덱스 활용 측면에서 `JOIN`이 유리할 수 있습니다.

### 수정된 코드 (JOIN 버전)

```sql
SELECT 
    T.ITEM_ID, 
    I_CHILD.ITEM_NAME, 
    I_CHILD.RARITY
FROM ITEM_TREE T
JOIN ITEM_INFO I_PARENT ON T.PARENT_ITEM_ID = I_PARENT.ITEM_ID
JOIN ITEM_INFO I_CHILD ON T.ITEM_ID = I_CHILD.ITEM_ID
WHERE I_PARENT.RARITY = 'RARE'
ORDER BY T.ITEM_ID DESC;

```

* `I_PARENT`: 부모의 RARITY를 체크하기 위한 용도
* `I_CHILD`: 출력할 자식 아이템의 정보를 가져오기 위한 용도
