# 프로그래머스 284527 🏆 조건에 맞는 사원 정보 조회하기

## 문제 요약
> 2022년 상/하반기 점수 합계가 가장 높은 사원의 정보를 조회

## 느낀점
>
- 잘 풀었다.
- 삥 돌아 푼 줄 알았는데 정석 풀이었다.
- 운 좋게 LIMIT를 활용한 최댔값이 떠올랐는데 자주 활용하자.
(서브쿼리 하나 줄일 수 있다.)

## 흐름
1. `HR_GRADE` 테이블에서 2022년 데이터만 필터링하여 사원별로 `SCORE` 합계를 구함.
2. 합계 점수를 내림차순 정렬하여 가장 높은 1명의 사번과 점수를 추출 (CTE 활용).
3. 추출된 사번을 바탕으로 `HR_EMPLOYEES` 테이블과 조인하여 상세 정보 출력.

## 코드
```sql
WITH H AS (
    SELECT EMP_NO, SUM(SCORE) AS SCORE
    FROM HR_GRADE
    GROUP BY EMP_NO
    ORDER BY SCORE DESC
    LIMIT 1
)
SELECT H.SCORE, E.EMP_NO, E.EMP_NAME, E.POSITION, E.EMAIL
FROM HR_EMPLOYEES E
LEFT JOIN H ON E.EMP_NO = H.EMP_NO
WHERE H.SCORE IS NOT NULL
```

## AI 코드 리뷰

### 개선할 점

* **항목**: 명시적 필터링 및 조인 최적화
* **설명**: `YEAR = 2022` 조건을 명시하여 데이터 무결성을 확보하고, `INNER JOIN`을 사용하여 쿼리 의도를 명확히 했습니다.

### 수정된 코드

```sql
WITH H AS (
    SELECT EMP_NO, SUM(SCORE) AS SCORE
    FROM HR_GRADE
    WHERE YEAR = 2022
    GROUP BY EMP_NO
    ORDER BY SCORE DESC
    LIMIT 1
)
SELECT H.SCORE, E.EMP_NO, E.EMP_NAME, E.POSITION, E.EMAIL
FROM HR_EMPLOYEES E
INNER JOIN H ON E.EMP_NO = H.EMP_NO;

```
