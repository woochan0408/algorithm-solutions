# 노선별 평균 역 사이 거리 조회하기

## 문제 요약
> SUBWAY_DISTANCE 테이블에서 노선별 총 누계 거리와 평균 역 사이 거리를 구하고, 단위(km)를 붙여 출력하기

## 느낀점
>
- 문자열이 너무 약하다..
- 실수포인트 한번 읽어보기

## 코드
```sql
SELECT ROUTE, 
    CONCAT(ROUND(SUM(D_BETWEEN_DIST), 1), 'km') AS TOTAL_DISTANCE,
    CONCAT(ROUND(AVG(D_BETWEEN_DIST), 2), 'km') AS AVERAGE_DISTANCE
FROM SUBWAY_DISTANCE
GROUP BY ROUTE
ORDER BY ROUND(SUM(D_BETWEEN_DIST), 1) DESC
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| MySQL에서 문자열을 어떻게 붙이는지 | `CONCAT()` 함수를 사용. `+`는 숫자 덧셈 연산자이므로 문자열 결합에 사용할 수 없음 |

### 실수했던 부분

**1. `+` 연산자로 문자열 결합 시도**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `ROUND(SUM(...), 1) + 'km'` | `CONCAT(ROUND(SUM(...), 1), 'km')` |

**2. AS 별칭 뒤에 연산자 붙임**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `AS AVERAGE_DISTANCE + 'km'` | `CONCAT(ROUND(...), 'km') AS AVERAGE_DISTANCE` |

**3. 문자열 컬럼으로 정렬**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `ORDER BY TOTAL_DISTANCE DESC` (문자열 사전순 정렬) | `ORDER BY SUM(D_BETWEEN_DIST) DESC` (숫자 기준 정렬) |

## AI 코드 리뷰

### 개선할 점

1. **ORDER BY에서 불필요한 ROUND 제거**: `ROUND(SUM(D_BETWEEN_DIST), 1)`로 정렬하고 있지만, ROUND는 표시용이지 정렬 순서에 영향을 주지 않으므로 `SUM(D_BETWEEN_DIST)`만으로 충분

## 수정된 코드
```sql
SELECT ROUTE, 
    CONCAT(ROUND(SUM(D_BETWEEN_DIST), 1), 'km') AS TOTAL_DISTANCE,
    CONCAT(ROUND(AVG(D_BETWEEN_DIST), 2), 'km') AS AVERAGE_DISTANCE
FROM SUBWAY_DISTANCE
GROUP BY ROUTE
ORDER BY SUM(D_BETWEEN_DIST) DESC
```
