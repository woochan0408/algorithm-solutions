# 물고기 종류 별 잡은 수 구하기

## 문제 요약
> FISH_INFO와 FISH_NAME_INFO를 JOIN하여 물고기 종류별 이름과 잡은 수를 출력 (잡은 수 내림차순)

## 느낀점
>
- 비집계 + 1대1이라고 해서 컴퓨터가 알아차리는 것은 아니다.

## 코드
```sql
SELECT COUNT(*) AS FISH_COUNT, FN.FISH_NAME
FROM FISH_INFO FI
JOIN FISH_NAME_INFO FN ON FN.FISH_TYPE = FI.FISH_TYPE
GROUP BY FN.FISH_NAME
ORDER BY FISH_COUNT DESC
```

## 질문 & 실수 정리

### 실수했던 부분

**1. 정렬 방향 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `ORDER BY FISH_COUNT` | `ORDER BY FISH_COUNT DESC` |

**2. GROUP BY 컬럼 불일치**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `GROUP BY FI.FISH_TYPE` (SELECT엔 `FN.FISH_NAME`) | `GROUP BY FN.FISH_NAME` |

> 💡 `FISH_TYPE`과 `FISH_NAME`이 1:1 관계라도, SELECT에 있는 비집계 컬럼은 반드시 GROUP BY에 명시해야 한다.
