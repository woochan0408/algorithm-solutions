# 대장균의 크기에 따라 분류하기 1

## 문제 요약
> 대장균 개체의 크기(SIZE_OF_COLONY)를 기준으로 100 이하 'LOW', 100 초과 1000 이하 'MEDIUM', 1000 초과 'HIGH'로 분류하여 ID와 함께 출력

## 느낀점
> 
- CASE 문 복습하라고 !!!
- 다음엔 꼭 틀리지 말자.

## 코드
```sql
SELECT ID, CASE 
    WHEN SIZE_OF_COLONY <= 100 THEN 'LOW'
    WHEN SIZE_OF_COLONY <= 1000 THEN 'MEDIUM'
    WHEN SIZE_OF_COLONY > 1000 THEN 'HIGH'
END AS SIZE
FROM ECOLI_DATA
ORDER BY ID
```

## 질문 & 실수 정리

### 실수했던 부분

**1. CASE WHEN에 불필요한 괄호 사용**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `CASE (WHEN ... END)` | `CASE WHEN ... END` (괄호 없이) |

## AI 코드 리뷰

### 개선할 점

1. **마지막 조건을 ELSE로 대체**: 앞의 두 WHEN에서 100 이하, 1000 이하를 이미 걸렀으므로 나머지는 자동으로 1000 초과. `ELSE`를 사용하면 조건 누락 위험 없이 안전하고 가독성도 향상됨

## 수정된 코드
```sql
SELECT ID, CASE 
    WHEN SIZE_OF_COLONY <= 100 THEN 'LOW'
    WHEN SIZE_OF_COLONY <= 1000 THEN 'MEDIUM'
    ELSE 'HIGH'
END AS SIZE
FROM ECOLI_DATA
ORDER BY ID
```
