# 잡은 물고기 중 가장 큰 물고기의 길이 구하기

## 문제 요약
> FISH_INFO 테이블에서 가장 큰 물고기의 길이를 구하고 'cm'를 붙여 출력

## 느낀점
>
- 

## 코드
```sql
SELECT CONCAT(FORMAT(MAX(LENGTH), 2), 'cm') AS MAX_LENGTH
FROM FISH_INFO
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| FORMAT(price, 0)이 뭐야? | 숫자를 지정한 소수점 자릿수로 포맷팅하는 함수. 천단위 콤마도 자동으로 붙음 |

### 실수했던 부분

**1. 문자열 따옴표 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `CONCAT(..., cm)` | `CONCAT(..., 'cm')` |

## AI 코드 리뷰

### 개선할 점

1. **FORMAT 불필요**: LENGTH가 FLOAT 타입으로 이미 `50.00` 형태로 저장되어 있어 FORMAT 없이도 통과 가능

## 수정된 코드
```sql
SELECT CONCAT(MAX(LENGTH), 'cm') AS MAX_LENGTH
FROM FISH_INFO
```
