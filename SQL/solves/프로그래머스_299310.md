# 연도별 대장균 크기의 편차 구하기

## 문제 요약
> 연도별 가장 큰 대장균 크기에서 각 대장균 크기를 뺀 편차(YEAR_DEV)를 구하기

## 느낀점
>
- 배운거 다시 복습하기
- 복잡해지면 WITH문 사용하기
- SQL 평가순서 조심하기

## 코드
```sql
WITH M AS (
    SELECT YEAR(DIFFERENTIATION_DATE) AS YEAR, MAX(SIZE_OF_COLONY) AS YEAR_MAX
    FROM ECOLI_DATA
    GROUP BY YEAR
)
SELECT YEAR(E.DIFFERENTIATION_DATE) AS YEAR, M.YEAR_MAX - E.SIZE_OF_COLONY AS YEAR_DEV, E.ID
FROM ECOLI_DATA E
JOIN M ON YEAR(E.DIFFERENTIATION_DATE) = M.YEAR
ORDER BY YEAR, YEAR_DEV
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| CTE란? | WITH 절로 임시 테이블을 정의하는 방식, 서브쿼리의 가독성 좋은 버전 |
| 서브쿼리 = CTE? | 거의 동일, CTE는 재사용 가능하다는 장점 |
| ORDER BY에서 별칭 사용 가능? | 가능 (SELECT 이후 실행되므로) |

### 실수했던 부분

**1. JOIN 조건에서 SELECT 별칭 사용**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `JOIN M ON E.YEAR = M.YEAR` | `JOIN M ON YEAR(E.DIFFERENTIATION_DATE) = M.YEAR` |

SQL 실행 순서: FROM/JOIN → WHERE → SELECT → ORDER BY
JOIN은 SELECT 전에 실행되므로 SELECT 별칭 사용 불가

## AI 코드 리뷰

### 개선할 점

1. **윈도우 함수로 더 간결하게 가능**: CTE + JOIN 없이 `MAX() OVER(PARTITION BY ...)` 사용

## 수정된 코드
```sql
SELECT 
    YEAR(DIFFERENTIATION_DATE) AS YEAR,
    MAX(SIZE_OF_COLONY) OVER(PARTITION BY YEAR(DIFFERENTIATION_DATE)) - SIZE_OF_COLONY AS YEAR_DEV,
    ID
FROM ECOLI_DATA
ORDER BY YEAR, YEAR_DEV
```
