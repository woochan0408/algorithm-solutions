# 동명 동물 수 찾기

## 문제 요약
> 동물 이름 중 두 번 이상 쓰인 이름과 횟수를 조회 (NULL 제외, 이름순 정렬)

## 느낀점
>
- 

## 코드
```sql
SELECT NAME, COUNT(*) AS COUNT
FROM ANIMAL_INS
WHERE NAME IS NOT NULL
GROUP BY NAME
HAVING COUNT >= 2
ORDER BY NAME
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| WHERE에서 할 수 있는 작업은 HAVING에서도 가능한가? | 기능적으로는 가능하지만, WHERE는 GROUP BY 이전에 실행되어 성능상 유리함 |

### 실수했던 부분

**1. NULL 필터링 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `NAME IS NOT NULL` 조건 없음 | `WHERE NAME IS NOT NULL` 추가 필요 |

## AI 코드 리뷰

### 개선할 점

1. **NULL 필터링 위치**: `HAVING`에서도 동작하지만, `WHERE`에서 필터링하면 그룹화 전에 불필요한 행을 제외하여 성능 향상

## 수정된 코드
```sql
SELECT NAME, COUNT(*) AS COUNT
FROM ANIMAL_INS
WHERE NAME IS NOT NULL
GROUP BY NAME
HAVING COUNT >= 2
ORDER BY NAME
```
