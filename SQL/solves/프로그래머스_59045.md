# 보호소에서 중성화한 동물

## 문제 요약
> 보호소에 들어올 때는 중성화되지 않았지만(`Intact`), 나갈 때는 중성화된(`Spayed`/`Neutered`) 동물의 아이디, 생물 종, 이름을 아이디 순으로 조회

## 느낀점
>
- 

## 코드
```sql
SELECT AI.ANIMAL_ID, AI.ANIMAL_TYPE, AI.NAME
FROM ANIMAL_INS AI
JOIN ANIMAL_OUTS AO ON AO.ANIMAL_ID = AI.ANIMAL_ID
WHERE AI.SEX_UPON_INTAKE LIKE 'Intact%' AND
    AO.SEX_UPON_OUTCOME NOT LIKE 'Intact%'
ORDER BY AI.ANIMAL_ID
```

## 질문 & 실수 정리

### 실수했던 부분

**1. 조건 방향 반대로 작성**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `SEX_UPON_INTAKE LIKE 'Spayed%'` | `SEX_UPON_INTAKE LIKE 'Intact%'` |
| 들어올 때 중성화된 동물을 찾음 | 들어올 때 중성화 안 된 동물을 찾아야 함 |

**2. 나갈 때 조건에서 Spayed 누락**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `SEX_UPON_OUTCOME LIKE 'Neutered%'` | `SEX_UPON_OUTCOME NOT LIKE 'Intact%'` |
| Neutered만 잡아서 Spayed Female 누락 | NOT LIKE로 Intact가 아닌 모든 경우를 포함 |
