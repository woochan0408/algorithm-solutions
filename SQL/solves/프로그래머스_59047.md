# 프로그래머스 59047 🐶 이름에 el이 들어가는 동물 찾기

## 문제 요약
> 동물 보호소에 들어온 동물 중, 이름에 "EL"이 들어가는 **개**의 아이디와 이름을 대소문자 구분 없이 조회 (이름순 정렬)

## 느낀점
>
- 문자열 공부하기
(뻘짓하지 말기)

## 흐름
1. ANIMAL_INS 테이블에서 ANIMAL_TYPE = 'Dog' 필터링
2. NAME에 'el'이 포함된 행 필터링 (LIKE)
3. NAME 기준 오름차순 정렬

## 코드
```sql
SELECT ANIMAL_ID, NAME
FROM ANIMAL_INS
WHERE (NAME LIKE '%EL%' OR NAME LIKE '%el%' OR NAME LIKE '%El%' OR NAME LIKE '%el%')
  AND ANIMAL_TYPE = 'Dog'
ORDER BY NAME
```

## 질문 & 실수 정리

### 새로 배운 것

#### MySQL LIKE의 대소문자 처리
MySQL의 기본 collation(`utf8_general_ci`)에서 `LIKE`는 대소문자를 구분하지 않는다. `ci`는 **Case Insensitive**의 약자로, 별도 설정 없이 `'%el%'` 하나로 `EL`, `El`, `eL`, `el` 모두 매칭된다.
- **핵심 원리**: collation이 `_ci`로 끝나면 대소문자 무시, `_cs` 또는 `_bin`이면 구분

#### BINARY 키워드로 대소문자 구분하기
대소문자를 구분해야 할 때는 `BINARY` 키워드를 사용한다. `LIKE BINARY '%el%'`은 정확히 소문자 `el`만 매칭하며, 바이트 단위 비교를 수행한다.
- **핵심 원리**: `BINARY`는 비교를 바이트 단위로 바꿔서 대소문자 구분을 강제함

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| LIKE 조건을 대소문자 조합별로 4개 OR 나열 | MySQL 기본 collation에서 `LIKE '%el%'` 하나면 충분 |
| `'%el%'` 조건이 중복으로 2번 작성됨 | 중복 제거 필요 |

## AI 코드 리뷰

### 개선할 점

1. **불필요한 OR 제거**: MySQL 기본 설정에서 LIKE는 대소문자를 구분하지 않으므로 조건 하나로 충분
2. **괄호 정리**: OR 조건이 사라지면 괄호도 불필요
