# 상위 n개 레코드

## 문제 요약
> 동물 보호소에 가장 먼저 들어온 동물의 이름을 조회

## 느낀점
>
- 

## 코드
```sql
SELECT NAME
FROM ANIMAL_INS
WHERE DATETIME = (SELECT MIN(DATETIME) FROM ANIMAL_INS)
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| WHERE 절에서 MIN() 직접 사용 가능? | 불가능. 서브쿼리로 감싸야 함 |

### 실수했던 부분

**1. WHERE 절에 집계 함수 직접 사용**

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `WHERE DATETIME = MIN(DATETIME)` | `WHERE DATETIME = (SELECT MIN(DATETIME) FROM 테이블)` |

## AI 코드 리뷰

### 개선할 점

1. **대안 쿼리**: 서브쿼리 방식도 좋지만, `ORDER BY + LIMIT` 방식이 더 직관적이고 성능상 유리할 수 있음

## 수정된 코드
```sql
-- 방법 1: 서브쿼리 (현재 코드 - 정상)
SELECT NAME
FROM ANIMAL_INS
WHERE DATETIME = (SELECT MIN(DATETIME) FROM ANIMAL_INS)

-- 방법 2: ORDER BY + LIMIT (대안)
SELECT NAME
FROM ANIMAL_INS
ORDER BY DATETIME
LIMIT 1
```
