## 실패한 코드 흐름

1. 상태를 `deque`(문자열 리스트)로 관리
2. 매번 `listToInt()`, `intToList()`로 숫자 ↔ 리스트 변환
3. 경로 문자열을 BFS 큐에 함께 저장하며 매번 문자열 연결

**문제점**: 변환 오버헤드 + 문자열 연결 오버헤드로 시간초과

## 실패한 코드

```python
from collections import deque
import sys
input = sys.stdin.readline

def listToInt(arr):
    result = ""
    for c in arr:
        result += c
    return int(result)
    
def intToList(n):
    arr = deque()
    n = str(n)
    for i in n:
        arr.append(i)
    while len(arr) < 4:
        arr.appendleft("0")
    return arr

def d(arr):
    n = listToInt(arr)
    result = (n*2)%10000
    return intToList(result)

def s(arr):
    n = listToInt(arr)
    result = (n-1)%10000
    return intToList(result)
    
def l(arr):
    dq = deque(arr)
    dq.rotate(-1)
    return dq

def r(arr):
    dq = deque(arr)
    dq.rotate(1)
    return dq

N = int(input())
for _ in range(N):
    a, b = map(int, input().split())
    a = intToList(a)
    dq = deque()
    dq.append([a, ""])
    visited = {tuple(a)}
    while dq:
        cur = dq.popleft()
        curArr = cur[0]
        curStat = cur[1]
        if(listToInt(curArr) == b):
            print(curStat)
            break
        # D 사용
        useD = tuple(d(curArr))
        if(useD not in visited):
            visited.add(useD)
            dq.append([deque(useD), curStat+"D"])
        # S 사용
        useS = tuple(s(curArr))
        if(useS not in visited):
            visited.add(useS)
            dq.append([deque(useS), curStat+"S"])
        # L 사용
        useL = tuple(l(curArr))
        if(useL not in visited):
            visited.add(useL)
            dq.append([deque(useL), curStat+"L"])
        # R 사용
        useR = tuple(r(curArr))
        if(useR not in visited):
            visited.add(useR)
            dq.append([deque(useR), curStat+"R"])
```

## 성공한 코드 흐름

1. 상태를 **정수**로 관리 (변환 오버헤드 제거)
2. L, R 연산을 정수 계산으로 처리
   - L: `(n % 1000) * 10 + n // 1000`
   - R: `(n % 10) * 1000 + n // 10`
3. **역추적 방식**: `prev[다음상태] = (이전상태, 명령어)`로 기록
4. 목표 도달 시 역추적하여 경로 생성 (문자열 연결 오버헤드 제거)

## 성공한 코드

```python
from collections import deque
import sys
input = sys.stdin.readline

def bfs(a, b):
    if a == b:
        return ""
    
    prev = {a: (None, None)}
    dq = deque([a])
    
    while dq:
        cur = dq.popleft()
        
        # D, S, L, R 연산
        next_states = [
            ((cur * 2) % 10000, 'D'),
            ((cur - 1) % 10000, 'S'),
            ((cur % 1000) * 10 + cur // 1000, 'L'),
            ((cur % 10) * 1000 + cur // 10, 'R')
        ]
        
        for nxt, cmd in next_states:
            if nxt not in prev:
                prev[nxt] = (cur, cmd)
                if nxt == b:
                    # 역추적
                    result = []
                    while prev[nxt][0] is not None:
                        result.append(prev[nxt][1])
                        nxt = prev[nxt][0]
                    return ''.join(reversed(result))
                dq.append(nxt)
    
    return ""

T = int(input())
for _ in range(T):
    a, b = map(int, input().split())
    print(bfs(a, b))
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

|질문|답변|
|---|---|
|`deque.rotate()`를 return하면 되지 않나?|`rotate()`는 in-place로 동작하고 **None을 반환**함|
|L, R에서 원본이 변경되는 문제 해결법?|`deque(원본)`으로 **복사**해서 사용|
|문자열 연결 오버헤드 해결법?|`prev` 딕셔너리로 **(이전상태, 명령어)** 기록 후 역추적|

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|S 사용 부분에서 `curStat+"D"`|`curStat+"S"`|
|R 사용 부분에서 `d(curNum)` 호출|`r(curNum)` 호출|
|`l(curArr)` 호출 후 `r(curArr)` 호출 시 원본 변경됨|각 연산마다 복사본 사용|

## AI 코드 리뷰

### 개선할 점

1. **상태를 정수로 관리**: 문자열/리스트 변환 없이 정수 연산만으로 D, S, L, R 처리
2. **역추적 방식 사용**: 경로 문자열을 매번 들고 다니지 않고, `prev` 딕셔너리에 (이전상태, 명령어)만 기록하여 메모리와 시간 절약
