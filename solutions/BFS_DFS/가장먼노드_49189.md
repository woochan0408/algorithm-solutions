# 프로그래머스 49189 🌐 가장 먼 노드 파이썬

## 느낀점
>
- BFS는 현재 레벨 처리 후 dq가 비어있으면 그게 리프다.

## 흐름

1. 인접 리스트로 그래프 구성
2. BFS로 레벨별 탐색 수행
3. 더 이상 확장할 노드가 없을 때의 레벨 크기가 정답

## 코드

```python
"""
목표는 1번 노드와 가장 먼 노드
"""
from collections import defaultdict, deque
grid = defaultdict(list)
def solution(n, edge):
    for u, v in edge:
        grid[u].append(v)
        grid[v].append(u)
    # 가장 먼 노드? 어짜피 완전탐색?
    dq = deque([1])
    visited = set([1])
    while dq:
        # 현재 레벨 모두 작업
        expanded = False
        levelLen = len(dq)
        for i in range(levelLen):
            cur = dq.popleft()
            for next in grid[cur]:
                if(next not in visited):
                    expanded = True
                    dq.append(next)
                    visited.add(next)
        if(not expanded):
            answer = levelLen
            break
            
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### BFS 레벨 탐색
BFS는 시작점에서 가까운 노드부터 방문하므로, 레벨별로 탐색하면 각 노드까지의 최단 거리를 자연스럽게 구할 수 있다. 모든 간선의 가중치가 동일할 때 BFS가 최단경로를 보장한다.
- **핵심 원리**: 큐의 현재 크기만큼만 처리하면 한 레벨씩 탐색 가능
- **시간복잡도**: O(V + E)

## AI 코드 리뷰

### 개선할 점

1. **전역 변수 `grid`**: 함수 외부에 선언되어 프로그래머스에서 여러 테스트케이스 실행 시 이전 데이터가 남아 오답 가능. 함수 내부로 이동 필요.

2. **`next` 변수명**: 파이썬 내장 함수 이름과 충돌. `nxt` 또는 `neighbor`로 변경 권장.

3. **`expanded` 플래그 불필요**: 마지막 레벨 노드들을 별도로 추적하면 더 간결하게 처리 가능.

## 수정된 코드

```python
from collections import defaultdict, deque

def solution(n, edge):
    graph = defaultdict(list)
    for u, v in edge:
        graph[u].append(v)
        graph[v].append(u)
    
    dq = deque([1])
    visited = set([1])
    last_level = []
    
    while dq:
        last_level = list(dq)  # 현재 레벨 저장
        for _ in range(len(dq)):
            cur = dq.popleft()
            for nxt in graph[cur]:
                if nxt not in visited:
                    dq.append(nxt)
                    visited.add(nxt)
    
    return len(last_level)
```
