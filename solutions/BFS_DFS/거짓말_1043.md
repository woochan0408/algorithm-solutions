# 백준 1043 🤥 거짓말 파이썬

## 느낀점
>
- 처음으로 골4 원큐에 성공!
- 근데 AI 코드 보니 수정할 부분은 많아보인다..

## 흐름

1. 진실을 아는 사람들을 set에 저장
2. 각 파티 참석자를 리스트에 저장
3. 각 사람이 어느 파티에 참석하는지 딕셔너리로 매핑
4. BFS로 진실 전파: 진실을 아는 사람과 같은 파티에 있으면 그 사람도 진실을 알게 됨
5. 진실을 아는 사람이 한 명도 없는 파티 개수 카운트

## 코드

```python
"""
4 1
1 1
4 1 2 3 4
우리는 각 사람들이 어디 파티에 있는 지 가진 dic 을 만들자.
"""
import sys
from collections import deque
input = sys.stdin.readline
N, M = map(int, input().split())
knowReal = set()
arr = list(map(int, input().split()))
for i in range(1, len(arr)):
    knowReal.add(arr[i])
result = 0
party = []
for i in range(M):
    p = set()
    arr = list(map(int, input().split()))
    for i in range(1, len(arr)):
        p.add(arr[i])
    party.append(p)
# dic 초기화
dic = {}
for i in range(1, N+1):
    dic[i] = set()
# 파티는 0번부터 시작
for i in range(len(party)):
    cur = party[i]
    for m in cur:
        dic[m].add(i)
# 자 이제 각 파티에 누가 왔는 지 dic으로 저장했어.
# 이제 BFS로 어디까지 오염됐는 지 찾아보자
dq = deque()
# 처음 알고 있던 놈 먼저 add
for m in knowReal:
    dq.append(m)
    knowReal.add(m)
while dq:
    cur = dq.popleft()
    for nextParty in dic[cur]:
        for m in party[nextParty]:
            if(m not in knowReal):
                dq.append(m)
                knowReal.add(m)
result = 0
# 결과출력
for cur in party:
    know = False
    for m in cur:
        if(m in knowReal):
            know = True
            break
    if(not know):
        result += 1
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### BFS를 활용한 상태 전파
그래프 탐색뿐 아니라 "연결된 요소들에게 상태를 전파"하는 문제에도 BFS를 활용할 수 있다. 이 문제에서는 진실을 아는 사람 → 같은 파티 참석자 → 그 사람이 참석한 다른 파티 순으로 전파된다.
- **핵심 원리**: 초기 상태를 가진 노드들을 큐에 넣고, 연결된 노드들에게 상태를 퍼뜨림
- **시간복잡도**: O(N × M) - 각 사람과 파티의 연결 관계를 한 번씩 탐색

## AI 코드 리뷰

### 개선할 점

1. **변수 `i` 중첩 사용**: 외부 루프와 내부 루프에서 동일한 변수명 `i`를 사용. 잠재적 버그 원인.

2. **변수명 명확화**: `dic` → `person_to_parties`, `knowReal` → `knows_truth` 등 의미 전달이 더 명확한 이름 권장.

3. **입력 처리 간소화**: `arr[1:]` 슬라이싱으로 반복문 없이 처리 가능.

4. **결과 계산 간소화**: set 교집합 연산(`&`)을 활용하면 더 간결하게 표현 가능.

## 수정된 코드

```python
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())

truth_input = list(map(int, input().split()))
knows_truth = set(truth_input[1:])

parties = []
for _ in range(M):
    party_input = list(map(int, input().split()))
    parties.append(set(party_input[1:]))

# 각 사람이 참석하는 파티 번호 저장
person_to_parties = {i: set() for i in range(1, N + 1)}
for party_idx, members in enumerate(parties):
    for person in members:
        person_to_parties[person].add(party_idx)

# BFS로 진실 전파
dq = deque(knows_truth)
while dq:
    cur = dq.popleft()
    for party_idx in person_to_parties[cur]:
        for person in parties[party_idx]:
            if person not in knows_truth:
                knows_truth.add(person)
                dq.append(person)

# 진실 아는 사람이 없는 파티 카운트
result = sum(1 for party in parties if not party & knows_truth)
print(result)
```
