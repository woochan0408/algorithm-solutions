## 흐름

1. 사람별로 참여한 파티 목록(`rooms`), 파티별 참가자 목록(`members`) 구성
2. 진실을 아는 사람이 참여한 파티를 시작점으로 설정
3. BFS로 해당 파티의 참가자들이 참여한 다른 파티까지 전파
4. 방문된 파티 수를 전체에서 빼서 과장 가능한 파티 수 계산

## 코드

```python
import sys
from collections import deque
input = sys.stdin.readline
N, M = map(int, input().split())
know_truth = list(map(int, input().split()))
know_truth = know_truth[1:]
# rooms[i] = i번 사람이 들어간 방 번호들 (1번부터)
rooms = [set() for i in range(N+1)]
# members[i] : i방에 들어간 멤버들 (0번부터)
members = [set() for i in range(M)]
for i in range(M):
    arr = list(map(int, input().split()))
    for j in range(1, len(arr)):
        cur = arr[j]
        rooms[cur].add(i)
        members[i].add(cur)
        
first_room = set()
for cur in know_truth:
    first_room.update(rooms[cur])
dq = deque(list(first_room))
visited = first_room
while dq:
    cur = dq.popleft()
    for next_mem in members[cur]:
        for next_room in rooms[next_mem]:
            if(next_room in visited):
                continue
            dq.append(next_room)
            visited.add(next_room)
print(M - len(visited))
```

## 질문 & 실수 정리

### 새로 배운 것

#### BFS를 활용한 그래프 전파
파티와 사람의 관계를 양방향 그래프로 모델링하여, 진실을 아는 사람으로부터 연결된 모든 파티를 탐색하는 기법. 같은 파티에 참석한 사람은 같은 이야기를 들으므로, 한 명이라도 진실을 알면 그 파티 전체가 전파 대상이 된다. 이를 BFS로 파티→사람→파티 순으로 확장하면 모든 제약 파티를 찾을 수 있다.
- **핵심 원리**: 이분 그래프(사람-파티) 구조에서 BFS 전파
- **시간복잡도**: O(N × M)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `members`를 빈 set M개로 초기화 후 `append` → 데이터가 인덱스 M부터 저장됨 | 초기화된 `members[i]`에 직접 `add`하거나, 빈 리스트에서 `append` 중 하나만 사용 |
| `for cur in range(1, len(arr))`에서 `cur`(인덱스)를 `rooms[cur]`에 사람 번호로 사용 | `cur = arr[j]`로 실제 사람 번호를 꺼내서 사용 |
| `for cur in arr`로 첫 원소(사람 수)도 사람 번호로 처리 | `arr[1:]` 슬라이싱 또는 `range(1, len(arr))`로 첫 원소 제외 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 명확화**: `rooms`보다 `person_parties`, `members`보다 `party_members`가 역할을 더 명확히 드러냄
2. **`first_room`과 `visited` 통합**: `first_room`은 `visited` 초기값으로만 쓰이므로 별도 변수 없이 바로 `visited`에 구성 가능
3. **입력 파싱 간소화**: `know_truth` 두 줄 처리 대신 슬라이싱으로 한 줄 처리 가능
4. **`_` 사용**: 사용하지 않는 반복 변수에 `_` 관례 적용

## 수정된 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

N, M = map(int, input().split())
know_truth = list(map(int, input().split()))[1:]

person_parties = [set() for _ in range(N + 1)]
party_members = [set() for _ in range(M)]

for i in range(M):
    arr = list(map(int, input().split()))
    for j in range(1, len(arr)):
        person = arr[j]
        person_parties[person].add(i)
        party_members[i].add(person)

visited = set()
for person in know_truth:
    visited.update(person_parties[person])

dq = deque(visited)
while dq:
    party = dq.popleft()
    for member in party_members[party]:
        for next_party in person_parties[member]:
            if next_party in visited:
                continue
            dq.append(next_party)
            visited.add(next_party)

print(M - len(visited))
```
