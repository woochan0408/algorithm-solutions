## 흐름

1. N×M 크기의 도화지를 입력받고 visited 배열 초기화
2. 모든 칸을 순회하면서 아직 방문하지 않은 1을 발견하면 BFS 시작
3. BFS에서 상하좌우 인접한 1을 탐색하며 넓이(count)를 계산
4. 그림 개수와 최대 넓이를 갱신하며 결과 출력

## 코드

```python
from collections import deque
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
grid = []
visited = [[False]*M for i in range(N)]
for i in range(N):
    grid.append(list(map(int, input().split())))
def bfs(x, y):
    visited[x][y] = True
    dq = deque([(x, y)])
    count = 1
    while dq:
        x, y = dq.popleft()
        for dx, dy in [[1, 0], [-1, 0], [0, 1], [0, -1]]:
            nx = x + dx
            ny = y + dy
            if(0 <= nx < N and 0 <= ny < M and not visited[nx][ny] and grid[nx][ny] == 1):
                visited[nx][ny] = True
                dq.append((nx, ny))
                count += 1
    return count
count = 0
answer = 0
for i in range(N):
    for j in range(M):
        if(grid[i][j] == 1 and not visited[i][j]):
            count += 1
            answer = max(answer, bfs(i, j))
print(count)
print(answer)
```

## AI 코드 리뷰

### 개선할 점

1. **방향 벡터를 상수 튜플로 분리**: `[[1,0],[-1,0],...]`은 BFS 호출마다 리스트를 새로 생성한다. 함수 밖에 튜플로 선언하면 불필요한 객체 생성을 줄일 수 있다.

2. **변수 섀도잉 방지**: `bfs(x, y)`의 파라미터 `x, y`를 while 루프 안에서 `x, y = dq.popleft()`로 덮어쓰고 있다. 동작에는 문제없지만 `cx, cy` 같은 이름으로 구분하면 가독성이 좋아진다.

3. **변수명 충돌 해소**: 외부 `count`(그림 개수)와 BFS 내부 `count`(넓이)가 같은 이름이라 혼동될 수 있다. 외부는 `picture_count`, 내부는 `area` 등으로 구분하면 명확하다.

## 수정된 코드

```python
from collections import deque
import sys
input = sys.stdin.readline

DIRS = ((1, 0), (-1, 0), (0, 1), (0, -1))

N, M = map(int, input().split())
grid = []
visited = [[False] * M for _ in range(N)]
for _ in range(N):
    grid.append(list(map(int, input().split())))

def bfs(x, y):
    visited[x][y] = True
    dq = deque([(x, y)])
    area = 1
    while dq:
        cx, cy = dq.popleft()
        for dx, dy in DIRS:
            nx = cx + dx
            ny = cy + dy
            if 0 <= nx < N and 0 <= ny < M and not visited[nx][ny] and grid[nx][ny] == 1:
                visited[nx][ny] = True
                dq.append((nx, ny))
                area += 1
    return area

picture_count = 0
max_area = 0
for i in range(N):
    for j in range(M):
        if grid[i][j] == 1 and not visited[i][j]:
            picture_count += 1
            max_area = max(max_area, bfs(i, j))

print(picture_count)
print(max_area)
```
