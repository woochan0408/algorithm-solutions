# 프로그래머스 43162 🔗 네트워크 파이썬

## 느낀점
>
- 인접행렬 숙련도 이슈로 그냥 인접리스트 변환 후 구현
- 한번정도 읽어보자.

## 흐름

1. 인접행렬 `computers`를 인접리스트 `graph`로 변환
2. 모든 노드를 순회하며, 방문하지 않은 노드를 발견하면 `answer += 1`
3. 해당 노드에서 BFS로 연결된 모든 노드를 방문 처리
4. 최종적으로 BFS가 시작된 횟수 = 네트워크 개수

## 코드
```python
"""
네트워크의 개수?
expand 시도 후 글로벌 visited에 저장.
"""
from collections import deque, defaultdict
def solution(n, computers):
    answer = 0
    visited = set()
    
    graph = defaultdict(list)
    for i in range(n-1):
        for j in range(i+1, n):
            if(computers[i][j] == 1):
                graph[i].append(j)
                graph[j].append(i)
    
    for cur in range(n):
        # 방문했음
        if(cur in visited):
            continue
            
        dq = deque([cur])
        visited.add(cur)
        answer += 1
        while dq:
            c = dq.popleft()
            for next in graph[c]:
                if(next not in visited):
                    visited.add(next)
                    dq.append(next)
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### 인접행렬 직접 활용
`computers`는 이미 인접행렬 형태로 주어지기 때문에, 굳이 인접리스트로 변환하지 않아도 된다. BFS 탐색 시 `computers[node]`를 순회하면서 값이 1이고 아직 방문하지 않은 노드를 큐에 넣으면 동일한 결과를 얻을 수 있다.
- **핵심 원리**: 인접행렬에서 `computers[i][j] == 1`이면 i와 j가 연결된 것이므로, 별도 변환 없이 행 전체를 순회하며 연결 노드를 찾는다.
- **시간복잡도**: 인접리스트 변환도 O(N²), 인접행렬 직접 탐색도 O(N²)로 동일하지만, 변환 과정이 생략되어 코드가 간결해진다.

## AI 코드 리뷰

### 개선할 점

1. **`next`는 파이썬 내장 함수명**: `next()`는 이터레이터의 다음 값을 가져오는 내장 함수다. 변수명으로 사용하면 해당 스코프에서 내장 함수가 가려지므로 `neighbor` 등으로 변경하는 것이 안전하다.

2. **인접리스트 변환 불필요**: `computers`가 이미 인접행렬이므로, `defaultdict`로 변환하는 과정을 생략하고 직접 행렬을 탐색하면 코드가 훨씬 간결해진다.

3. **변수명 `c` → `node`**: BFS에서 현재 탐색 중인 노드를 나타내므로, 의미가 드러나는 이름이 좋다.

## 수정된 코드
```python
from collections import deque

def solution(n, computers):
    answer = 0
    visited = set()

    for cur in range(n):
        if cur in visited:
            continue

        dq = deque([cur])
        visited.add(cur)
        answer += 1

        while dq:
            node = dq.popleft()
            for neighbor in range(n):
                if computers[node][neighbor] == 1 and neighbor not in visited:
                    visited.add(neighbor)
                    dq.append(neighbor)

    return answer
```
