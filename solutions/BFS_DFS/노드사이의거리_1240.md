## 흐름
- 트리는 두 노드 사이의 경로가 **유일**하므로, 매 쿼리마다 BFS/DFS로 시작 노드에서 목표 노드까지 탐색하면서 **거리 누적**.
- 목표 노드에 도달하는 순간 누적 거리 출력 후 종료.

## 코드
```python
"""
트리 특징 : 시작 -> 끝 어디든 도달 가능하다
각각 계산은 또 시간초과가 나겠지?
안날 것 같은데?
바로 구현 시작

4 2
2 1 2
4 3 2
1 4 3
1 2
3 2
"""

import sys
from collections import defaultdict,deque

input = sys.stdin.readline

N, M = map(int, input().split())
target = []

grid = defaultdict(list)

for _ in range(N-1):
    u, v, w = map(int, input().split())
    grid[u].append((v, w))
    grid[v].append((u, w))

for _ in range(M):
    u, v = map(int, input().split())
    dq = deque()
    visited = set()
    dq.append((u, 0))

    while dq:
        cur = dq.popleft()
        curNode = cur[0]
        d = cur[1]

        if(curNode == v):
            print(d)
            break
        for next in grid[curNode]:
            if(next not in visited):
                visited.add(next)
                dq.append((next[0], d + next[1])) 
```

## AI 코드 리뷰

### 개선할 점

1. **방문 처리 버그 (정답/무한루프 원인)**  
   현재 `visited`가 노드가 아니라 `(node, weight)`를 저장하고 있어서, 이웃으로 갔다가 다시 되돌아오는 걸 막지 못합니다. 트리에서는 반드시 **노드 방문 체크**로 막아야 합니다.

2. **가독성 개선**
   - `cur = dq.popleft()` 후 `cur[0]`, `cur[1]`로 쓰기보다 `cur_node, dist = ...`로 언패킹이 더 읽기 쉽습니다.
   - `next`는 파이썬 예약어는 아니지만 내장 함수 `next()`가 있어서 변수명으로는 `nxt`/`to` 같은 이름을 추천합니다.

3. **중복 제거**
   - 매 쿼리마다 BFS가 반복되므로 `bfs(start, end)` 함수로 빼면 코드가 깔끔해집니다.

## 수정된 코드
```python
import sys
from collections import defaultdict, deque

input = sys.stdin.readline

N, M = map(int, input().split())
graph = defaultdict(list)

for _ in range(N - 1):
    u, v, w = map(int, input().split())
    graph[u].append((v, w))
    graph[v].append((u, w))

def bfs(start: int, target: int) -> int:
    dq = deque([(start, 0)])
    visited = [False] * (N + 1)
    visited[start] = True

    while dq:
        node, dist = dq.popleft()
        if node == target:
            return dist

        for nxt, w in graph[node]:
            if not visited[nxt]:
                visited[nxt] = True
                dq.append((nxt, dist + w))

    return -1  # 트리에서는 도달 불가능 케이스가 없음

for _ in range(M):
    a, b = map(int, input().split())
    print(bfs(a, b))
```
