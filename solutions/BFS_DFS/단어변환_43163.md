## 느낀점
>
- level 업데이트 시점이 왤캐 헷갈릴까..
- 잘 정리해두었으니 틀리지 말자

## 흐름
1. begin에서 시작, BFS로 레벨 단위 탐색
2. 현재 단어와 1글자만 다른 단어를 큐에 추가
3. visited로 중복 방문 방지
4. target 발견 시 현재 레벨 반환, 못 찾으면 0 반환

## 코드
```python
"""
한번에 1개 바꿈
word에 있는 단어로만 바꿈
"""
from collections import deque
def solution(begin, target, words):
    def canSpread(a, b):
        diff = 0
        
        for i in range(len(a)):
            if(a[i] != b[i]):
                if(diff == 1):
                    return False
                diff += 1
        if(diff == 0):
            return False
            
        return True
    
    dq = deque([begin])
    visited = set()
    visited.add(begin)
    level = 0
    while dq:
        print('level : ', level)
        spreaded = False
        for i in range(len(dq)):
            cur = dq.popleft()
            for i in range(len(words)):
                if(words[i] not in visited and canSpread(cur, words[i])):
                    spreaded = True
                    visited.add(words[i])
                    dq.append(words[i])
        
        level += 1
        print(visited)
        if(not spreaded and target not in visited):
            return 0
        elif(target in visited):
            return level
    return 0
```

## 질문 & 실수 정리

### 새로 배운 것

#### BFS 레벨 카운트 시작 기준
BFS에서 level(단계 수)을 세는 핵심은 **시작점의 의미를 먼저 정의**하는 것이다. 시작점(begin)은 아직 변환을 하지 않은 상태이므로 **0단계**로 설정해야 한다. level을 루프 하단에서 증가시키면 "이번 레벨의 탐색이 끝난 뒤 +1"이 되어 직관적이다.
- **핵심 원리**: 시작점 = 0단계, 탐색 완료 후 level 증가 → 자연스럽게 "몇 번 변환했는가"를 카운트
- **흔한 실수**: level = 1로 시작하거나 루프 상단에서 증가시키면 1단계가 밀림

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`diff >= 2` 조건 (2글자 차이도 통과)|`diff == 1`일 때 즉시 `return False`|
|diff == 0 체크 누락 (동일 단어도 True)|`diff == 0`이면 `return False` 추가|
|`level = 1` + 루프 상단 증가 (1단계 밀림)|`level = 0` + 루프 하단 증가|
|`return answer` (미정의 변수)|`return 0`|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `canSpread` → `can_change` (변환 가능 여부를 명확히), `spreaded` → `spread` (spread의 과거형은 spread)
2. **변수 섀도잉**: 외부 for문과 내부 for문 모두 `i` 사용 → 외부 `_`, 내부 `j`로 분리
3. **조기 반환 추가**: `target not in words`이면 즉시 0 반환 (불필요한 탐색 방지)
4. **`can_change` 간결화**: `sum(c1 != c2 for c1, c2 in zip(a, b)) == 1`로 한 줄 처리
5. **종료 조건 단순화**: `spreaded` 플래그 없이, 큐가 비면 자연스럽게 while 종료 → `return 0`
6. **디버깅용 print 제거**

## 수정된 코드
```python
from collections import deque

def solution(begin, target, words):
    if target not in words:
        return 0

    def can_change(a, b):
        return sum(c1 != c2 for c1, c2 in zip(a, b)) == 1

    dq = deque([begin])
    visited = set([begin])
    level = 0

    while dq:
        level += 1
        for _ in range(len(dq)):
            cur = dq.popleft()
            for word in words:
                if word not in visited and can_change(cur, word):
                    if word == target:
                        return level
                    visited.add(word)
                    dq.append(word)

    return 0
```
