## 흐름

1. `maps` 문자열 배열을 2차원 리스트로 변환
2. 전체 격자를 순회하며 숫자(땅)를 발견하면 BFS 시작
3. BFS로 연결된 모든 땅의 식량 합산, 방문한 칸은 `'X'`로 변경
4. 각 섬의 식량 합을 리스트에 저장 후 오름차순 정렬
5. 섬이 없으면 `[-1]` 반환

```python
def solution(maps):
    arr = []
    for i in range(len(maps)):
        arr.append(list(maps[i]))
    N = len(arr)
    M = len(arr[0])
    
    print(arr)
        
    
    def bfs(x, y):
        result = int(arr[x][y])
        arr[x][y] = 'X'
        dq = deque()
        dq.append((x, y))
        while dq:
            x, y = dq.popleft()
            for dx, dy in move:
                nx = x + dx
                ny = y + dy
                
                if(0 <= nx < N and 0 <= ny < M and arr[nx][ny] != 'X'):
                    result += int(arr[nx][ny])
                    arr[nx][ny] = 'X'
                    dq.append((nx, ny))
        
        return result
    answer = []
    for i in range(N):
        for j in range(M):
            if(arr[i][j] != 'X'):
                answer.append(bfs(i, j))
    if(len(answer) == 0):
        answer.append(-1)
    answer.sort()
    return answer
```
## AI 코드 리뷰

### 개선할 점

1. **디버깅 print 제거**: `print(arr)`가 남아있어 불필요한 출력 발생
2. **리스트 변환 간소화**: `for` 루프 대신 list comprehension 사용
3. **변수 shadowing 해소**: `bfs` 파라미터 `x, y`와 `while` 내부 `x, y`가 같은 이름이라 혼동 가능. 내부 변수를 `cx, cy`로 구분
4. **변수명 개선**: `dq` → `queue`로 변경하여 의미 명확화
5. **빈 결과 처리 간소화**: `if len(answer) == 0` 대신 `return answer or [-1]` 패턴 활용

## 수정된 코드
```python
from collections import deque

def solution(maps):
    arr = [list(row) for row in maps]
    N, M = len(arr), len(arr[0])
    move = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    def bfs(sx, sy):
        result = int(arr[sx][sy])
        arr[sx][sy] = 'X'
        queue = deque([(sx, sy)])

        while queue:
            cx, cy = queue.popleft()
            for dx, dy in move:
                nx, ny = cx + dx, cy + dy
                if 0 <= nx < N and 0 <= ny < M and arr[nx][ny] != 'X':
                    result += int(arr[nx][ny])
                    arr[nx][ny] = 'X'
                    queue.append((nx, ny))

        return result

    answer = []
    for i in range(N):
        for j in range(M):
            if arr[i][j] != 'X':
                answer.append(bfs(i, j))

    answer.sort()
    return answer or [-1]
```
