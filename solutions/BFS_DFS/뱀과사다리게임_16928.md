# 백준 16928 🎲 뱀과 사다리 게임 파이썬

## 느낀점
>
- 단순 구현문제

## 흐름

1. 사다리와 뱀 정보를 딕셔너리에 저장 (시작점 → 도착점)
2. BFS로 1번 칸에서 시작하여 100번 칸까지 최단 거리 탐색
3. 주사위 1~6 굴려서 이동 가능한 칸 계산
4. 사다리/뱀 칸이면 해당 위치로 이동
5. 100번 칸 도착 시 주사위 굴린 횟수 출력

## 코드

```python
"""
3 7
32 62
42 68
12 98
95 13
97 25
93 37
79 27
75 19
49 47
67 17
일단 dic로 저장하자
흠...
visited는 set로 저장
"""
import sys
from collections import deque
input = sys.stdin.readline
N, M = map(int, input().split())
go = {}
for _ in range(N+M):
    start, end = map(int, input().split())
    go[start] = end
dq = deque([1])
visited = {1}
level = 1
while dq:
    for _ in range(len(dq)):
        cur = dq.popleft()
        next = [cur+i for i in range(1, 7)]
        stack = []
        for n in next:
            if(n in go):
                stack.append(go[n])
            else:
                stack.append(n)
        next = stack
        for n in next:
            if(n not in visited and n <= 100):
                visited.add(n)
                dq.append(n)
    if(100 in visited):
        break
    level += 1
print(level)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 리스트 순회 중 수정 금지
파이썬에서 `for n in list`로 순회하면서 동시에 해당 리스트를 `append`/`remove`하면 인덱스가 꼬여서 일부 원소를 건너뛰거나 예상치 못한 동작이 발생한다. 별도 리스트에 결과를 담거나, 리스트 컴프리헨션으로 새 리스트를 생성해야 한다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 사다리/뱀 칸 도착 시 원래 칸도 next에 유지 | 사다리/뱀 칸은 **반드시** 이동, 원래 칸 제거 |
| 100 초과 체크 누락 | `n <= 100` 조건 추가 |
| 순회 중인 리스트를 `append`/`remove`로 수정 | 별도 리스트에 결과 저장 |

## AI 코드 리뷰

### 개선할 점

1. **`next`는 파이썬 내장 함수명**: 다른 변수명 사용 권장 (예: `next_positions`)
2. **`stack` 변수명이 용도와 불일치**: 실제로는 "이동 후 위치 리스트"이므로 `moved` 또는 별도 변수 없이 바로 처리 가능
3. **중복 리스트 생성 제거**: `next` 리스트를 만들고 다시 `stack`으로 변환하는 과정을 한 번에 처리 가능
4. **100 도착 체크 위치**: 큐에 넣을 때 바로 체크하면 불필요한 반복 없이 즉시 종료 가능

## 수정된 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

N, M = map(int, input().split())

warp = {}
for _ in range(N + M):
    start, end = map(int, input().split())
    warp[start] = end

dq = deque([1])
visited = {1}
level = 0

while dq:
    level += 1
    for _ in range(len(dq)):
        cur = dq.popleft()
        for dice in range(1, 7):
            nxt = cur + dice
            if nxt > 100:
                continue
            if nxt in warp:
                nxt = warp[nxt]
            if nxt == 100:
                print(level)
                sys.exit()
            if nxt not in visited:
                visited.add(nxt)
                dq.append(nxt)
```
