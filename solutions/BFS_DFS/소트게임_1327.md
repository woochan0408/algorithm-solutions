## 실패한 코드 흐름
1. 뒤집기를 시작할 위치들을 combinations로 뽑아서, 각 조합마다 한 번에 적용
2. 유효한 조합을 찾으면 조합의 길이를 반환

## 실패한 코드
```python
from itertools import combinations
def re(arr, i, k):
    sub = arr[i, i+k+1]
    sub.reverse()
    
    return arr[0:i] + sub + (arr[i+1:] if i+1 < len(arr) else [])
def valid(sub):
    for i in range(len(target)):
        if(sub[i] != target[i]):
            return False
    return True
            
def solve(N, K):
    arr = [i for i in range(1, N+1)]
    for i in range(N-K):
        for comb in combinations([j for j in range(N-K)], i):
            for idx in comb:
                sub = re(list(arr), idx, K)
                if(valid(sub)):
                    return len(comb)
    return -1
N, K = map(int, input().split())
target = list(map(int, input().split()))
print(solve(N, K))
```

**문제점**: 뒤집기 연산은 순서에 따라 결과가 달라지는 순차적 상태 변화인데, combinations는 순서를 무시하고 같은 위치를 여러 번 선택할 수도 없어 올바른 탐색이 불가능하다.

## 성공한 코드 흐름

1. 순열의 각 상태를 노드, 뒤집기 연산을 간선으로 보는 BFS
2. 시작 상태 `[1, 2, ..., N]`에서 목표 상태(입력 순열)까지의 최단 거리를 구함
3. 각 레벨에서 가능한 모든 뒤집기 위치(0 ~ N-K)를 시도
4. visited set으로 중복 상태 방문 방지
5. 목표 상태에 도달하면 레벨(뒤집기 횟수) 출력, 도달 불가하면 -1 출력

## 성공한 코드
```python
from collections import deque
def re(arr, l, r):
    while l < r:
        arr[l], arr[r] = arr[r], arr[l]
        l += 1
        r -= 1
N, K = map(int, input().split())
target = tuple(map(int, input().split()))
base = [i for i in range(1, N+1)]
dq = deque()
dq.append(base)
visited = set()
visited.add(tuple(base))
level = 0
while dq:
    if(target in visited):
        print(level)
        break
    level += 1
    for i in range(len(dq)):
        cur = dq.popleft()
        next = []
        for j in range(0, N-K+1):
            sub = list(cur)
            re(sub, j, j+K-1)
            next.append(tuple(sub))
        for n in next:
            if(n not in visited):
                visited.add(tuple(n))
                dq.append(n)
                
if(target not in visited):
    print(-1)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 상태 공간 BFS
순열이나 퍼즐처럼 상태가 변화하는 문제에서, 각 상태를 그래프의 노드로, 연산 한 번을 간선으로 모델링하면 BFS로 최소 연산 횟수를 구할 수 있다. 핵심은 상태를 tuple 같은 해시 가능한 자료형으로 변환해서 visited에 넣는 것이다.
- **핵심 원리**: 모든 간선의 가중치가 1일 때 BFS가 최단 거리를 보장
- **시간복잡도**: O(N! × N) — 가능한 순열 수 × 각 상태에서 연산 수

#### 슬라이싱을 이용한 구간 뒤집기
`arr[l:r+1] = arr[l:r+1][::-1]`로 특정 구간을 간결하게 뒤집을 수 있다. 수동으로 while 루프를 돌며 swap하는 것보다 파이썬답고 가독성이 좋다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| combinations로 뒤집기 위치 조합 시도 | 순차적 상태 변화이므로 BFS가 적합 |
| permutations로 변경 시도 | 같은 위치를 여러 번 선택할 수 있어야 함 |
| `re` 함수에 return 없이 결과 사용 | in-place 수정 후 수정된 배열을 사용하거나 return 추가 |
| 바깥/안쪽 루프 변수명 `i` 충돌 | 안쪽 루프를 `j`로 변경 |
| `level` 증가 코드 누락 | 레벨 처리 후 `level += 1` 추가 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 충돌**: `re`는 파이썬 정규표현식 모듈, `next`는 파이썬 내장 함수와 이름이 겹침. `reverse_section`, `next_states` 등으로 변경 권장

2. **불필요한 리스트 컴프리헨션**: `[i for i in range(1, N+1)]`은 `list(range(1, N+1))`로 충분

3. **수동 reverse 함수**: 슬라이싱 `sub[j:j+K] = sub[j:j+K][::-1]`로 대체하면 별도 함수 불필요

4. **조기 종료 최적화**: 큐에 넣을 때 target 체크하면 한 레벨의 불필요한 탐색을 줄일 수 있음

5. **함수 분리**: 전체 로직을 함수로 감싸면 `return`으로 깔끔하게 종료 가능 (while문 밖의 `-1` 처리 간소화)

## 수정된 코드
```python
from collections import deque

def solve():
    N, K = map(int, input().split())
    target = tuple(map(int, input().split()))
    start = tuple(range(1, N + 1))

    if start == target:
        print(0)
        return

    visited = {start}
    dq = deque([(start, 0)])

    while dq:
        cur, level = dq.popleft()
        for j in range(N - K + 1):
            sub = list(cur)
            sub[j:j+K] = sub[j:j+K][::-1]
            next_state = tuple(sub)
            if next_state == target:
                print(level + 1)
                return
            if next_state not in visited:
                visited.add(next_state)
                dq.append((next_state, level + 1))

    print(-1)

solve()
```
