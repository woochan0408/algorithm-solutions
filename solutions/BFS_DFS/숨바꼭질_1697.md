## 흐름

1. BFS를 사용하여 최단 거리를 탐색한다.
2. 시작 위치 N에서 출발하여 X-1, X+1, 2*X 세 가지 이동을 시도한다.
3. visited로 방문 체크하며 목표 위치 K에 도달하면 이동 횟수를 출력한다.
4. 범위는 0 이상 100,000 이하로 제한한다.

## 코드
```python
from collections import deque
N, M = map(int, input().split())
dq = deque([N])
visited = set()
visited.add(N)
level = 1
if(N == M):
    print(0)
else:
    while dq:
        for i in range(len(dq)):
            cur = dq.popleft()
            next = [cur+1, cur-1, cur*2]
            for n in next:
                if(n not in visited and n >= 0 and n <= 100000):
                    visited.add(n)
                    dq.append(n)
        if M in visited:
            print(level)
            break
        level += 1
```

## 질문 & 실수 정리

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|탐색 상한 범위 제한 없음|`n <= 100000` 조건을 추가하여 불필요한 탐색 방지|

## AI 코드 리뷰

### 개선할 점

1. **변수명 `M` → `K`**: 문제에서 동생 위치를 K로 정의했으므로 변수명을 일치시키면 가독성이 좋아진다.
2. **`next` 변수명 충돌**: `next`는 파이썬 내장 함수 이름이므로 `nxt` 등으로 변경하는 것이 안전하다.
3. **튜플 방식 BFS**: 큐에 `(위치, 시간)`을 저장하면 `level` 변수와 `for` 루프가 불필요해지고 코드가 간결해진다.
4. **조기 종료**: 큐에 넣을 때 목표 도달 여부를 체크하면 해당 레벨의 나머지 노드를 탐색하지 않아 더 효율적이다.
5. **입력 최적화**: `sys.stdin.readline`을 사용하면 입력 속도가 빨라진다.

## 수정된 코드
```python
from collections import deque
import sys
input = sys.stdin.readline

N, K = map(int, input().split())

def bfs():
    if N == K:
        return 0
    visited = set([N])
    dq = deque([(N, 0)])

    while dq:
        cur, time = dq.popleft()
        for nxt in (cur - 1, cur + 1, cur * 2):
            if nxt == K:
                return time + 1
            if 0 <= nxt <= 100000 and nxt not in visited:
                visited.add(nxt)
                dq.append((nxt, time + 1))

print(bfs())
```
