# 백준 16236 🦈 아기 상어 파이썬

## 느낀점
>
- 레벨 단위 BFS 방식 알아두기
- 파이썬 for문 평가 시 range(dq) 사용하면 for문 시작 시 한번만 평가
(즉 레벨 단위 BFS 구현 시 for문으로 len(dq) 만큼 돌리기)
- for cur in dq: 는 iterator 방식이라 중간에 변경되면 Error남
- 머리가 정리 안되면 메모하면서 풀기
(너 수학 암산 못하잖아.)
- 제발!!! 문제 좀 잘 읽자 책좀 읽고 살고.. 삽질하지 말자

## 흐름

1. 입력 처리 및 상어 초기 위치 파악
2. 메인 루프: 먹을 물고기가 없을 때까지 반복
3. BFS로 먹을 수 있는 가장 가까운 물고기 탐색
   - 레벨 단위 BFS로 같은 거리의 후보들 수집
   - 후보 발견 시 탐색 종료
4. 후보가 없으면 루프 탈출
5. 후보 정렬 (행, 열 순) → 가장 위, 가장 왼쪽 물고기 선택
6. 상어 위치 이동, 시간 누적, 물고기 제거
7. 먹은 횟수 체크 → 크기 증가 조건 확인

## 코드

```python
import sys
from collections import deque
input = sys.stdin.readline
N = int(input())
grid = []
sharkX = -1
sharkY = -1
sharkSize = 2
curEaten = 0
for i in range(N):
    grid.append(list(map(int, input().split())))
    
    for j in range(N):
        if(grid[i][j] == 9):
            sharkX = i
            sharkY = j
# solve
result = 0
eatTime = 0
while True:
    
    # 다음 먹을 것을 찾자~~~~~
    dq = deque()
    dq.append((sharkX, sharkY, eatTime))
    visited = {(sharkX, sharkY) : eatTime}
    grid[sharkX][sharkY] = 0
    answerList = []
    # expand 끝날 떄까지 expand할거야.
    while dq:
        # 먼저 현재 레벨 모두 작업하고
        for _ in range(len(dq)):
            curX, curY, curTime = dq.popleft()
            if(0 < grid[curX][curY] < sharkSize):
                answerList.append((curX, curY, curTime))
            for dx, dy in ((1, 0), (0, 1), (0, -1), (-1, 0)):
                nx = curX + dx
                ny = curY + dy
                if(0 <= nx < N and 0 <= ny < N):
                    if(grid[nx][ny] <= sharkSize):
                        if((nx, ny) not in visited or visited[(nx, ny)] > curTime+1):
                            visited[(nx, ny)] = curTime+1
                            dq.append((nx, ny, curTime+1))
        # 뭘 먹었네? BFS 종료
        if(answerList):
            break
    # 아무것도 못먹었네 출력?
    if(not answerList):
        break
    # 뭐라도 먹었네? 위치 정렬 후 위치 저장
    answerList.sort()
    sharkX = answerList[0][0]
    sharkY = answerList[0][1]
    eatTime = answerList[0][2]
    grid[sharkX][sharkY] = 0
    
    # 사이즈 갱신
    curEaten += 1
    if(curEaten == sharkSize):
        curEaten = 0
        sharkSize += 1
    
print(eatTime)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 레벨 단위 BFS
같은 거리에 있는 모든 노드를 한 번에 처리해야 할 때 사용하는 BFS 패턴. 일반 BFS는 노드를 하나씩 처리하지만, 레벨 단위 BFS는 **현재 거리의 모든 노드를 처리한 후** 다음 거리로 넘어간다.
- **핵심 원리**: `for _ in range(len(dq))`로 현재 레벨 노드 수를 고정하고, 그 안에서 append된 노드들은 다음 레벨에서 처리
- **주의점**: `for cur in dq:`는 반복 중 수정 시 에러 발생, 반드시 `range(len(dq))` 사용


### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `sharkSize += grid[curX][curY]` (물고기 크기만큼 증가) | 먹은 마릿수 카운트 후 조건 충족 시 +1 |
| BFS push 순서로 우선순위 보장 | 같은 거리 후보 모두 수집 → 정렬 |
| `grid[curX][curY] = 0` (for문 마지막 좌표) | `grid[sharkX][sharkY] = 0` (실제 먹은 좌표) |
| 상어 시작 위치(9) 미처리 | BFS 시작 전 `grid[sharkX][sharkY] = 0` |

## AI 코드 리뷰

### 개선할 점

1. **누적 시간 방식 단순화**: 현재 `eatTime`을 BFS 시작점에 넣고 누적하는 방식인데, 매 BFS마다 0부터 시작해서 거리를 구한 뒤 `result`에 더하는 방식이 더 직관적입니다.

2. **visited 조건 단순화**: `visited[(nx, ny)] > curTime+1` 조건은 불필요합니다. BFS 특성상 먼저 방문한 곳이 항상 최단거리이므로 `not in visited`만 체크하면 됩니다.

3. **불필요한 변수**: `result`가 선언만 되고 사용되지 않습니다.

4. **변수명 개선**: `curEaten` → `eaten_count`, `eatTime` → `total_time` 등 역할이 명확한 이름 권장

## 수정된 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

n = int(input())
grid = []
shark_x, shark_y = -1, -1
shark_size = 2
eaten_count = 0

for i in range(n):
    grid.append(list(map(int, input().split())))
    for j in range(n):
        if grid[i][j] == 9:
            shark_x, shark_y = i, j
            grid[i][j] = 0

total_time = 0

while True:
    # BFS로 먹을 수 있는 가장 가까운 물고기 찾기
    dq = deque([(shark_x, shark_y, 0)])
    visited = {(shark_x, shark_y)}
    candidates = []
    
    while dq:
        # 현재 레벨 전체 탐색
        for _ in range(len(dq)):
            cur_x, cur_y, cur_dist = dq.popleft()
            
            # 먹을 수 있는 물고기 발견
            if 0 < grid[cur_x][cur_y] < shark_size:
                candidates.append((cur_x, cur_y, cur_dist))
                continue
            
            # 인접 칸 탐색
            for dx, dy in ((-1, 0), (0, -1), (0, 1), (1, 0)):
                nx, ny = cur_x + dx, cur_y + dy
                if 0 <= nx < n and 0 <= ny < n:
                    if (nx, ny) not in visited and grid[nx][ny] <= shark_size:
                        visited.add((nx, ny))
                        dq.append((nx, ny, cur_dist + 1))
        
        # 이번 레벨에서 후보 발견 시 탐색 종료
        if candidates:
            break
    
    # 먹을 물고기 없으면 종료
    if not candidates:
        break
    
    # 가장 위, 가장 왼쪽 물고기 선택
    candidates.sort()
    shark_x, shark_y, dist = candidates[0]
    total_time += dist
    grid[shark_x][shark_y] = 0
    
    # 크기 증가 체크
    eaten_count += 1
    if eaten_count == shark_size:
        shark_size += 1
        eaten_count = 0

print(total_time)
```
