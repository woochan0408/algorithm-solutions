# 백준 16236 🦈 아기 상어 파이썬

## 느낀점
>
- 과거 1시간 반 부여잡고 못 풀었던 문제
(https://velog.io/@tesabel/백준-16236-아기-상어-파이썬)
- 이번엔 오답노트 잘 했다.
- 실력이 많이 늘은 것 같다.
- 잔실수 조심하자.
   - 아기상어 이전 위치(9) 제거하기
   - 다음 BFS 전에 아기상어 현재위치 갱신

## 흐름

1. N×N 격자에서 아기 상어 위치(9) 찾기
2. BFS를 레벨 단위로 실행하여 최단 거리의 먹을 수 있는 물고기 탐색
3. 먹을 수 있는 물고기가 여러 마리면 (행, 열) 기준 정렬 → 가장 위, 가장 왼쪽 우선
4. 물고기를 먹으면 먹은 횟수 카운트, 크기만큼 먹으면 크기 +1
5. 더 이상 먹을 수 있는 물고기가 없으면 종료, 총 이동 시간 출력

## 코드
```python
import sys
input= sys.stdin.readline
from collections import deque
N = int(input())
grid = []
shark = []
curSize = 2
curCount = 2
move = [[-1, 0], [1, 0], [0, -1], [0, 1]]
for i in range(N):
    grid.append(list(map(int, input().split())))
    for j in range(N):
        if(grid[i][j] == 9):
            shark = [i, j]
answer = 0
while True:
    dq = deque()
    dq.append(shark)
    visited = [[False]*N for i in range(N)]
    visited[shark[0]][shark[1]] = True
    canEat = []
    time = 0
    while dq:
        time += 1
        for _ in range(len(dq)):
            x, y = dq.popleft()
            for dx, dy in move:
                nx = dx + x
                ny = dy + y
                if not (0 <= nx < N and 0 <= ny < N and not visited[nx][ny]):
                    continue
                if(grid[nx][ny] == curSize or grid[nx][ny] == 0):
                    dq.append((nx, ny))
                    visited[nx][ny] = True
                # 먹을 수 있는 물고기를 발견함
                # 위치만 저장하고 dq push X, visited = True
                elif(curSize > grid[nx][ny]):
                    canEat.append((nx, ny))
                    visited[nx][ny] = True
        if(canEat):
            canEat.sort()
            break
    # BFS 사이클 끝
    if(not canEat):
        break
    else:
        ex, ey = canEat[0][0], canEat[0][1]
        answer += time
        curCount -= 1
        grid[shark[0]][shark[1]] = 0
        shark = [ex, ey]
        if(curCount == 0):
            curSize += 1
            curCount = curSize
print(answer)
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `curSize` → `shark_size`, `curCount` → `eat_remaining`, `canEat` → `edible_fish` 등 의미가 명확한 이름 사용
2. **먹은 물고기 위치 명시적 초기화**: `grid[ex][ey] = 0`을 먹은 직후 처리하여 의도를 명확하게 표현
3. **크기 초과 물고기 명시적 스킵**: `elif grid[nx][ny] > shark_size: continue`를 추가하여 모든 경우를 명시적으로 처리
4. **상어 좌표를 튜플로 관리**: 좌표는 재할당 방식으로 사용하므로 리스트보다 튜플이 의미상 적절
5. **언패킹 간소화**: `ex, ey = canEat[0][0], canEat[0][1]` → `ex, ey = canEat[0]`

## 수정된 코드
```python
import sys
input = sys.stdin.readline
from collections import deque

N = int(input())
grid = []
shark_pos = (0, 0)
shark_size = 2
eat_remaining = 2
directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

for i in range(N):
    grid.append(list(map(int, input().split())))
    for j in range(N):
        if grid[i][j] == 9:
            shark_pos = (i, j)

total_time = 0

while True:
    dq = deque([shark_pos])
    visited = [[False] * N for _ in range(N)]
    visited[shark_pos[0]][shark_pos[1]] = True
    edible_fish = []
    time = 0

    while dq:
        time += 1
        for _ in range(len(dq)):
            x, y = dq.popleft()
            for dx, dy in directions:
                nx, ny = x + dx, y + dy
                if not (0 <= nx < N and 0 <= ny < N and not visited[nx][ny]):
                    continue
                visited[nx][ny] = True
                cell = grid[nx][ny]
                if cell > shark_size:
                    continue
                if cell == 0 or cell == shark_size:
                    dq.append((nx, ny))
                else:
                    edible_fish.append((nx, ny))
        if edible_fish:
            edible_fish.sort()
            break

    if not edible_fish:
        break

    ex, ey = edible_fish[0]
    total_time += time
    grid[shark_pos[0]][shark_pos[1]] = 0
    grid[ex][ey] = 0
    shark_pos = (ex, ey)
    eat_remaining -= 1
    if eat_remaining == 0:
        shark_size += 1
        eat_remaining = shark_size

print(total_time)
```
