# 백준 2468 🌧️ 안전 영역 파이썬

## 느낀점
>
- 구현 시간 너무 오래걸림
- 계속 첫 노트 visited에 추가 안한다.. 실수하지 말자.
- 2차원 이상 복사는 copy.deepcopy

## 흐름

1. N×N 격자의 높이 정보를 입력받음
2. 비의 양(0 ~ 최대 높이)에 따라 잠기지 않는 영역 개수를 각각 구함
3. 각 비의 양에서 DFS/BFS로 연결된 안전 영역(높이 > 비의 양) 개수를 카운트
4. 모든 경우 중 최대 영역 개수를 출력

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
grid = []
move = [(0, 1), (0, -1), (1, 0), (-1, 0)]
for _ in range(N):
    grid.append(list(map(int, input().split())))
def findArea(cur):
    global visited
    x = cur[0]
    y = cur[1]
    if(grid[x][y] == 0):
        return 0
    stack = [cur]
    visited.add((x, y))
    while stack:
        cur = stack.pop()
        x = cur[0]
        y = cur[1]
        for dx, dy in move:
            nx = x + dx
            ny = y + dy
            if(nx < 0 or nx >= N): continue
            if(ny < 0 or ny >= N): continue
            if(grid[nx][ny] == 0): continue
            if((nx, ny) in visited): continue
            stack.append((nx, ny))
            visited.add((nx, ny))
    return 1
    
def count():
    result = 0
    for i in range(N):
        for j in range(N):
            if((i, j) not in visited and grid[i][j] != 0):
                result += findArea((i, j))
    return result
# 답 도출
maxNum = -1
for i in range(N):
    for j in range(N):
        if(maxNum < grid[i][j]):
            maxNum = grid[i][j]
result = []
for _ in range(maxNum):
    visited = set()
    result.append(count())
    for i in range(N):
        for j in range(N):
            if(grid[i][j] != 0):
                grid[i][j] -= 1
print(max(result))
```

## AI 코드 리뷰

### 개선할 점

1. **`global` 사용 지양**: `visited`를 전역으로 쓰는 대신 파라미터나 함수 내부에서 관리하면 더 깔끔함

2. **최댓값 구하기 간소화**: 이중 for문 대신 `max(max(row) for row in grid)` 활용

3. **grid 직접 수정 방식의 비효율**: 매번 grid를 1씩 빼는 대신, 비의 높이를 기준으로 비교하면 grid 수정 없이 처리 가능

4. **범위 체크 간소화**: `0 <= nx < N` 형태로 한 줄로 작성 가능

## 수정된 코드

```python
import sys
from collections import deque
input = sys.stdin.readline

def bfs(start_x, start_y, rain, visited):
    queue = deque([(start_x, start_y)])
    visited[start_x][start_y] = True
    
    while queue:
        x, y = queue.popleft()
        for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nx, ny = x + dx, y + dy
            if (0 <= nx < N and 0 <= ny < N 
                and not visited[nx][ny] 
                and grid[nx][ny] > rain):
                visited[nx][ny] = True
                queue.append((nx, ny))

def count_area(rain):
    visited = [[False] * N for _ in range(N)]
    count = 0
    
    for i in range(N):
        for j in range(N):
            if not visited[i][j] and grid[i][j] > rain:
                bfs(i, j, rain, visited)
                count += 1
    return count

N = int(input())
grid = [list(map(int, input().split())) for _ in range(N)]
max_height = max(max(row) for row in grid)

result = 0
for rain in range(max_height + 1):  # 비가 0일 때(아무것도 안 잠김)도 포함
    result = max(result, count_area(rain))

print(result)
```
