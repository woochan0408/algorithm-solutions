# 백준 10026 🎨 적록색약 파이썬

## 느낀점
>
- 기본 BFS 문제
- 잘 풀었다.
- 변수명 대충 짓다가 꼬일 뻔했다.

## 흐름

1. N×N 그리드를 입력받는다
2. BFS로 같은 색 구역을 탐색하며 구역 수를 센다
3. 일반인 시점: R, G, B 각각 구분하여 BFS
4. 적록색약 시점: R과 G를 같은 색으로 취급하여 BFS
5. 두 결과를 공백으로 구분하여 출력

## 코드
```python
import sys
from collections import deque
input = sys.stdin.readline
move = [[-1, 0], [1, 0], [0, -1], [0, 1]]
N = int(input())
arr = []
for i in range(N):
    arr.append(list(input().strip()))
def bfs(i, j, ju):
    dq = deque()
    dq.append((i, j))
    visited[i][j] = True
    cur_color = set()
    if(ju):
        if(arr[i][j] == 'R' or arr[i][j] == 'G'):
            cur_color.add('R')
            cur_color.add('G')
        else:
            cur_color.add('B')
    else:
        cur_color.add(arr[i][j])
    
    while dq:
        x, y = dq.popleft()
        for dx, dy in move:
            nx = x + dx
            ny = y + dy
            if not (0 <= nx < N and 0 <= ny < N):
                continue
            if not (arr[nx][ny] in cur_color):
                continue
            if(visited[nx][ny]):
                continue
            dq.append((nx, ny))
            visited[nx][ny] = True
    
# 일반인
visited = [[False] * N for i in range(N)]
g = 0
for i in range(N):
    for j in range(N):
        if not (visited[i][j]):
            g += 1
            bfs(i, j, False)
# 적록
visited = [[False] * N for i in range(N)]
ju = 0
for i in range(N):
    for j in range(N):
        if not (visited[i][j]):
            ju += 1
            bfs(i, j, True)
print(g, ju)
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 불명확**: `g`, `ju`는 의미 파악이 어렵다. `normal_count`, `blind_count`처럼 역할이 드러나는 이름이 좋다.
2. **BFS 내 분기 로직 제거 가능**: 적록색약 처리를 위해 매 BFS 호출마다 `cur_color` set을 만드는 대신, 그리드 자체를 복사하여 `G`→`R`로 치환하면 BFS 함수가 단순해진다.
3. **`move` 상수화**: `move`는 변경되지 않으므로 튜플로 선언하는 것이 의도에 맞다.

## 수정된 코드
```python
import sys
from collections import deque

input = sys.stdin.readline
DIRECTIONS = ((-1, 0), (1, 0), (0, -1), (0, 1))

N = int(input())
grid = [list(input().strip()) for _ in range(N)]


def count_regions(board):
    visited = [[False] * N for _ in range(N)]
    count = 0

    for i in range(N):
        for j in range(N):
            if not visited[i][j]:
                count += 1
                bfs(board, visited, i, j)

    return count


def bfs(board, visited, i, j):
    dq = deque([(i, j)])
    visited[i][j] = True
    color = board[i][j]

    while dq:
        x, y = dq.popleft()
        for dx, dy in DIRECTIONS:
            nx, ny = x + dx, y + dy
            if 0 <= nx < N and 0 <= ny < N and not visited[nx][ny] and board[nx][ny] == color:
                visited[nx][ny] = True
                dq.append((nx, ny))


# 일반인 시점
normal_count = count_regions(grid)

# 적록색약 시점: G를 R로 치환한 그리드
blind_grid = [['R' if c == 'G' else c for c in row] for row in grid]
blind_count = count_regions(blind_grid)

print(normal_count, blind_count)
```
