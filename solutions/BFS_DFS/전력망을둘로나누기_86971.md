# 프로그래머스 86971 ⚡ 전력망을 둘로 나누기 파이썬

## 느낀점
>
- visited에 root 추가 꼭 하자
(매번하는 실수.. 삽질 + 15분)

## 흐름

1. 간선을 하나씩 끊어보며 완전탐색
2. 끊은 간선을 제외하고 인접 리스트 생성
3. 끊어진 두 노드 각각에서 DFS로 컴포넌트 크기 계산
4. 두 컴포넌트 크기 차이의 절댓값을 구하고 최솟값 갱신

## 코드
```python
def solution(n, wires):
    # 모두 계산해본다..? -> 완탐?
    
    answer = n
    for cur in wires:
        # 끊을 간선 하나 선택 및 wires -> dic으로 변경
        sub = list(wires)
        sub.remove(cur)
        graph = [[] for i in range(n+1)]
        
        for u, v in sub:
            graph[u].append(v)
            graph[v].append(u)
        # 그래프에 대한 완탐
        subResult = []
        for root in cur:
            result = 1
            visited = set()
            visited.add(root)
            stack = [root]
            
            while stack:
                curNode = stack.pop()
                for nextNode in graph[curNode]:
                    if(nextNode not in visited):
                        result += 1
                        stack.append(nextNode)
                        visited.add(nextNode)
            subResult.append(result)
        value = abs(subResult[1] - subResult[0])
        answer = min(value, answer)
    return answer
```

## AI 코드 리뷰

### 개선할 점

1. **그래프 매번 재생성 불필요**: 그래프는 한 번만 만들고, DFS 시 끊을 간선만 스킵하면 된다. 현재는 매 반복마다 `list(wires)` 복사 + `remove` + 인접 리스트 재구성을 하고 있어 불필요한 연산이 반복된다.

2. **DFS 두 번 불필요**: 한쪽 컴포넌트 크기를 `size`로 구하면 다른 쪽은 `n - size`이므로, DFS는 한 번이면 충분하다.

3. **변수명 개선**: `cur`, `sub`, `subResult`, `value` 등이 의미를 명확히 전달하지 못한다. `edge`, `component_size`, `diff` 등으로 개선 가능하다.

## 수정된 코드
```python
def solution(n, wires):
    # 그래프 한 번만 생성
    graph = [[] for _ in range(n + 1)]
    for u, v in wires:
        graph[u].append(v)
        graph[v].append(u)
    
    answer = n
    for cut_u, cut_v in wires:
        # 끊은 간선의 한쪽 노드에서 DFS (끊은 간선 스킵)
        visited = set([cut_u])
        stack = [cut_u]
        count = 1
        
        while stack:
            node = stack.pop()
            for neighbor in graph[node]:
                if neighbor not in visited:
                    # 끊은 간선이면 스킵
                    if (node == cut_u and neighbor == cut_v) or (node == cut_v and neighbor == cut_u):
                        continue
                    visited.add(neighbor)
                    stack.append(neighbor)
                    count += 1
        
        diff = abs(count - (n - count))
        answer = min(answer, diff)
    
    return answer
```
