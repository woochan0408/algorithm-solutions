## 흐름

1. 격자를 2D 리스트로 변환하고, 테두리를 `"0"`(외부)으로 패딩
2. 각 요청 처리:
   - **크레인** (길이 2): 해당 문자 전부 `"1"`(내부 빈 칸)로 변경
   - **지게차** (길이 1): `update()`로 외부와 연결된 `"1"` → `"0"` 갱신 후, `"0"`에 인접한 해당 문자 제거
3. `update()`: 모든 `"1"` 칸에서 BFS로 `"0"` 연결 여부 확인, 연결되면 경로상 `"1"` 전부 `"0"`으로 변환
4. 남은 컨테이너 수 반환

def solution(storage, requests):
    def isOut(x, y):
        for dx, dy in move:
            nx = dx + x
            ny = dy + y
            
            if(grid[nx][ny] == '0'):
                return True
        return False

        nonlocal count
        update()
        result = []
        for i in range(1, N-1):

                if(grid[i][j] == c and isOut(i, j)):
                    result.append((i, j))
        ans = len(result)
        for x, y in result:
            grid[x][y] = '0'
        count += ans
        return
    
    def expand(x, y):
        dq = deque()
        dq.append((x, y))
        visited = set()
        visited.add((x, y))
        while dq:
            x, y = dq.popleft()
            
            for dx, dy in move:
                nx = x + dx
                ny = y + dy
                
                if(grid[nx][ny] == '0' and (nx, ny) not in visited):
                    for vx, vy in visited:  # 거쳐온 "1" 전부 "0"으로

                    return
                if(grid[nx][ny] == '1' and (nx, ny) not in visited):
                    visited.add((nx, ny))
                    dq.append((nx, ny))
    
    def update():
        for i in range(1, N-1):

                if(grid[i][j] == '1'):

        nonlocal count

                if(grid[i][j] == c):
                    grid[i][j] = '1'
                    count += 1

        for i in range(1, N-1):

                print(grid[i][j], end = ' ')
            print()
        print('---------')

## 질문 & 실수 정리

### 새로 배운 것

#### 패딩 기법 (격자 확장)
격자 문제에서 외부 공간을 판별해야 할 때, 격자 둘레에 빈 칸 한 겹을 추가하면 "외부"를 하나의 연결된 공간으로 통합할 수 있다. 패딩 없이 가장자리만 확인하면, 컨테이너가 빠져서 생긴 내부 빈 칸이 외부와 연결되는 케이스를 놓칠 수 있다.
- **핵심 원리**: `(n+2) x (m+2)` 격자를 만들고, 원본을 `(1,1)`부터 채우면 둘레가 자연스럽게 빈 칸이 됨
- **시간복잡도**: 패딩 생성 O(N×M)

#### 외부 연결 상태 추적 ("0" / "1" 구분)
빈 칸을 외부 연결(`"0"`)과 내부 고립(`"1"`)로 구분해서 관리하면, 매번 전체 BFS를 돌리지 않고 점진적으로 갱신할 수 있다. 컨테이너 제거 시 `"1"`로 표시해두고, 이후 `"0"`과 연결 여부를 BFS로 확인하면 된다.
- **핵심 원리**: 크레인 제거 → `"1"`, 지게차 제거 → `"0"` (외부에서 접근했으므로), `update()`에서 `"1"` → `"0"` 전파

#### BFS로 연결 영역 전파
`expand` 함수에서 `"1"` 칸들을 BFS로 탐색하다가 `"0"`을 만나면, 경로상 모든 `"1"`을 `"0"`으로 일괄 변환한다. `visited` set에 경로를 저장해두면 한 번에 처리 가능하다.
- **핵심 원리**: BFS 탐색 중 `visited`에 경로 저장 → 외부 연결 발견 시 전체 변환

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `expand`에서 visited 체크 없이 큐에 추가 | `(nx, ny) not in visited` 조건 추가 필요 (무한루프 방지) |
| `expand`에서 `"0"` 발견 시 현재 칸만 변환 | `visited`에 있는 모든 `"1"` 칸을 `"0"`으로 일괄 변환 |

## AI 코드 리뷰

### 개선할 점

1. **함수명 오타**: `crain` → `crane`으로 수정. 영어 철자를 맞추면 가독성이 올라간다.

2. **디버그 코드 제거**: `printGrid` 함수는 제출 시 불필요하므로 삭제.

3. **count 추적 방식 단순화**: `nonlocal count`로 제거 수를 추적하는 대신, 마지막에 남은 컨테이너를 직접 세는 방식이 더 직관적이고 오류 가능성이 줄어든다.

4. **fork에서 불필요한 변수**: `ans = len(result)` → `count += len(result)`로 직접 처리 가능.

5. **move 상수를 튜플로**: 리스트보다 튜플이 불변이라 의도가 명확하고, 약간의 성능 이점도 있다.

## 수정된 코드

```python
from collections import deque

def solution(storage, requests):
    N = len(storage) + 2
    M = len(storage[0]) + 2
    MOVE = ((-1, 0), (1, 0), (0, 1), (0, -1))

    grid = [['0'] * M for _ in range(N)]
    for i in range(N - 2):
        for j in range(M - 2):
            grid[i + 1][j + 1] = storage[i][j]

    def is_outside(x, y):
        for dx, dy in MOVE:
            if grid[x + dx][y + dy] == '0':
                return True
        return False

    def expand(x, y):
        dq = deque([(x, y)])
        visited = {(x, y)}
        while dq:
            cx, cy = dq.popleft()
            for dx, dy in MOVE:
                nx, ny = cx + dx, cy + dy
                if (nx, ny) in visited:
                    continue
                if grid[nx][ny] == '0':
                    for vx, vy in visited:
                        grid[vx][vy] = '0'
                    return
                if grid[nx][ny] == '1':
                    visited.add((nx, ny))
                    dq.append((nx, ny))

    def update():
        for i in range(1, N - 1):
            for j in range(1, M - 1):
                if grid[i][j] == '1':
                    expand(i, j)

    def forklift(ch):
        update()
        targets = []
        for i in range(1, N - 1):
            for j in range(1, M - 1):
                if grid[i][j] == ch and is_outside(i, j):
                    targets.append((i, j))
        for x, y in targets:
            grid[x][y] = '0'

    def crane(ch):
        for i in range(1, N - 1):
            for j in range(1, M - 1):
                if grid[i][j] == ch:
                    grid[i][j] = '1'

    for req in requests:
        if len(req) == 2:
            crane(req[0])
        else:
            forklift(req[0])

    return sum(
        grid[i][j] not in ('0', '1')
        for i in range(1, N - 1)
        for j in range(1, M - 1)
    )
```
