## 실패한 코드 흐름
1. 키 비교 관계를 무방향 그래프로 구성하고, 각 학생에서 BFS로 도달 가능한 노드 수가 N이면 순위를 알 수 있다고 판단
2. 방향 정보를 무시했기 때문에, "나보다 큰 사람"과 "나보다 작은 사람"을 구분하지 못함 → 단순 연결만으로는 순위 확정 불가

## 실패한 코드
```python
import sys
from collections import deque
N, M = map(int, input().split())
graph = [[] for _ in range(N+1)]
for _ in range(M):
    u, v = map(int, input().split())
    graph[u].append(v)
    graph[v].append(u)
def solve(n):
    dq = deque([n])
    visited = set()
    visited.add(n)
    while dq:
        cur = dq.popleft()
        for nxt in graph[cur]:
            if(nxt not in visited):
                visited.add(nxt)
                dq.append(nxt)
    if(len(visited) == N):
        return 1
    else:
        return 0
answer = 0
for i in range(1, N+1):
    answer += solve(i)
print(answer)
```

**문제점**: 방향 그래프를 무방향으로 처리하여 대소 관계를 구분하지 못함

## 성공한 코드 흐름
1. 정방향 그래프(나보다 작은 사람 → 나)와 역방향 그래프(나 → 나보다 큰 사람)를 분리하여 구성
2. 각 학생에 대해 정방향 BFS(나보다 작은 사람 탐색)와 역방향 BFS(나보다 큰 사람 탐색)를 각각 수행
3. 두 집합을 합쳤을 때 크기가 N이면, 모든 학생과의 대소 관계를 알 수 있으므로 순위 확정 가능

## 성공한 코드
```python
import sys
from collections import deque
N, M = map(int, input().split())
graph = [[] for _ in range(N+1)]
graph_re = [[] for _ in range(N+1)]
for _ in range(M):
    u, v = map(int, input().split())
    graph[v].append(u)
    graph_re[u].append(v)
def bfs(graph, n):
    dq = deque([n])
    visited = set()
    visited.add(n)
    while dq:
        cur = dq.popleft()
        for nxt in graph[cur]:
            if(nxt not in visited):
                visited.add(nxt)
                dq.append(nxt)
    return visited
def solve(n):
    s1 = bfs(graph, n)
    s2 = bfs(graph_re, n)
    s1.update(s2)
    if(len(s1) == N):
        return True
    return False
    
answer = 0
for i in range(1, N+1):
    answer += solve(i)
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 방향 그래프에서의 도달 가능성과 순위 확정
어떤 학생의 순위를 확정하려면, 자기 자신을 제외한 N-1명 모두와 대소 관계를 알 수 있어야 한다. 방향 그래프에서 정방향 BFS(나보다 작은 사람)와 역방향 BFS(나보다 큰 사람)를 따로 수행하고, 두 결과의 합집합 크기로 판단한다.
- **핵심 원리**: 정방향 도달 가능 노드 + 역방향 도달 가능 노드 = N이면 순위 확정
- **시간복잡도**: O(N × (N + M)) — 각 학생마다 BFS 2회


### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|키 비교를 무방향 그래프로 처리|방향 그래프로 정방향/역방향 분리 필요|
|역방향은 직접 이웃만 추가 (`visited.update(graph_re[n])`)|역방향도 BFS로 도달 가능한 모든 노드 탐색 필요|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `graph`와 `graph_re`보다 `smaller`(나보다 작은 사람)와 `bigger`(나보다 큰 사람)처럼 의미가 드러나는 이름이 가독성에 좋다.

2. **불필요한 집합 합치기 제거**: `s1.update(s2)` 후 길이를 비교하는 대신, `len(s1) + len(s2) - 1 == N`으로 계산하면 집합 합치기 비용을 줄일 수 있다. 자기 자신이 양쪽에 포함되므로 1을 빼준다.

3. **대안 알고리즘 — 플로이드 워셜**: N ≤ 500이므로 O(N³)인 플로이드 워셜로 모든 쌍의 도달 가능 여부를 한 번에 구할 수 있다. 각 학생에 대해 도달 가능한 관계 수가 N-1이면 순위 확정.

## 수정된 코드
```python
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())
smaller = [[] for _ in range(N + 1)]  # smaller[i]: i보다 작은 사람 방향
bigger = [[] for _ in range(N + 1)]   # bigger[i]: i보다 큰 사람 방향

for _ in range(M):
    a, b = map(int, input().split())
    smaller[b].append(a)  # a < b이므로, b 기준 a는 작은 사람
    bigger[a].append(b)   # a < b이므로, a 기준 b는 큰 사람

def bfs(graph, start):
    queue = deque([start])
    visited = set([start])
    while queue:
        cur = queue.popleft()
        for nxt in graph[cur]:
            if nxt not in visited:
                visited.add(nxt)
                queue.append(nxt)
    return len(visited)

answer = 0
for i in range(1, N + 1):
    small_count = bfs(smaller, i)
    big_count = bfs(bigger, i)
    if small_count + big_count - 1 == N:
        answer += 1

print(answer)
```

## 풀이2 : 플로이드 워셜

`reach[i][j] = True`이면 i에서 j로 도달 가능, 즉 i < j 관계를 알 수 있다는 뜻이다. 모든 중간 노드 k를 거쳐 도달 가능 여부를 전파한 뒤, 각 학생에 대해 자신과 관계를 알 수 있는 상대(`reach[i][j]` 또는 `reach[j][i]`)가 N-1명이면 순위 확정.

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
reach = [[False] * (N + 1) for _ in range(N + 1)]

for _ in range(M):
    a, b = map(int, input().split())
    reach[a][b] = True

# 플로이드 워셜: 도달 가능 여부 전파
for k in range(1, N + 1):
    for i in range(1, N + 1):
        for j in range(1, N + 1):
            if reach[i][k] and reach[k][j]:
                reach[i][j] = True

answer = 0
for i in range(1, N + 1):
    known = 0
    for j in range(1, N + 1):
        if i != j and (reach[i][j] or reach[j][i]):
            known += 1
    if known == N - 1:
        answer += 1

print(answer)
```
- **시간복잡도**: O(N³)
- **공간복잡도**: O(N²)
