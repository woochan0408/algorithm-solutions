# 프로그래머스 43165 🎯 타겟 넘버 파이썬

## 느낀점
>
- 풀다가 실수했을까봐 중간에 그만두는 아주 나쁜 습관이 있다
- 그냥 끝까지 믿고 풀자.

## 흐름

1. defaultdict로 현재까지 만들 수 있는 합과 경우의 수를 관리
2. 첫 번째 숫자는 +, - 두 가지로 초기 상태 설정
3. 이후 숫자를 하나씩 추가하면서, 기존 상태의 모든 합에 현재 숫자를 더하거나 빼서 새로운 상태 갱신
4. 모든 숫자를 처리한 후 target에 해당하는 경우의 수 반환

## 코드
```python
"""
순서 바꿀 수 없다,
더하기 빼기는 바뀌기 가능
"""
from collections import deque, defaultdict
def solution(numbers, target):
    state = defaultdict(int)
    state[numbers[0]] += 1
    state[-numbers[0]] += 1
    
    # 하나씩 추가할거야.
    for i in range(1, len(numbers)):
        cur = numbers[i]
        nextState = defaultdict(int)
        for key in state:
            nextState[key + cur] += state[key]
            nextState[key - cur] += state[key]
        
        state = nextState
    
    answer = state[target]
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### DP 상태 초기화의 중요성
DP에서 초기 상태를 어떻게 설정하느냐에 따라 전체 로직이 달라진다. 이 문제에서는 첫 번째 숫자의 +/-를 초기 상태로 잡는 방법과, `state[0] = 1`로 "아무것도 선택하지 않은 상태"를 잡고 루프를 전체로 돌리는 방법 두 가지가 가능하다. 후자가 초기화와 반복 로직을 분리하지 않아도 되어 더 깔끔하다.
- **핵심 원리**: 초기 상태를 "아무것도 없는 상태 1가지"로 설정하면 루프 내에서 모든 원소를 동일하게 처리 가능

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`return target` — 변수명 오타로 정답 대신 target 자체를 반환|`return answer`|
|루프 안에서 `nextState[cur] += 1`, `nextState[-cur] += 1`로 매번 단독 경로 추가|초기 상태는 루프 시작 전에 한 번만 설정|
|첫 번째 숫자 초기화 시 `state[numbers[0]] += 1`만 설정|`state[-numbers[0]] += 1`도 함께 설정 (빼는 경우 포함)|

## AI 코드 리뷰

### 개선할 점

1. **미사용 import 제거**: `deque`를 import했지만 사용하지 않으므로 제거
2. **변수명 PEP8 준수**: `nextState` → `next_state` (파이썬은 snake_case가 관례)
3. **초기화 방식 단순화**: 첫 번째 원소를 별도 처리하는 대신 `state[0] = 1`로 시작하면 루프를 전체 순회할 수 있어 코드가 간결해짐

## 수정된 코드
```python
from collections import defaultdict

def solution(numbers, target):
    state = defaultdict(int)
    state[0] = 1

    for cur in numbers:
        next_state = defaultdict(int)
        for key in state:
            next_state[key + cur] += state[key]
            next_state[key - cur] += state[key]
        state = next_state

    return state[target]
```

## 다른 풀이 (DFS)
```python
def solution(numbers, target):
    answer = 0

    def dfs(idx, total):
        nonlocal answer
        if idx == len(numbers):
            if total == target:
                answer += 1
            return
        dfs(idx + 1, total + numbers[idx])
        dfs(idx + 1, total - numbers[idx])

    dfs(0, 0)
    return answer
```
