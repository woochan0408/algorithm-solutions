# 백준 7576 🍅 토마토 파이썬

## 느낀점
>
- BFS 구현
- 단위 스탭 계산을 위한 list 두개 활용 (머리 잘 쓴듯 ㅋ)

## 흐름

1. field 파싱
2. effect_list, next_effect_list 초기화
   - 리스트 두 개를 활용한 queue 구현 (단위step 계산을 위함)
3. 한 단위스탭 내에서 토마토가 영향을 줬는 지 확인하는 변수(bool isEffected) 초기화 (단위스탭 동안 effect가 안 일어나면 진행이 끝난 상태라는 뜻)
4. 특정 위치를 입력하면 해당 위치의 상하좌우 토마토에 영향을 주는 effect() 함수 구현
   - 4-1. 해당 위치에서 상하좌우에 안 익은 토마토 (0)이 있는 지 확인
   - 4-2. 있으면 isEffected = True 변경
   - 4-3. 다음 스탭에 사용되는 리스트 (next_effect_list)에 해당 위치 push
5. while True
   - 5-1. effect_list가 비었거나 isEffected = False인 경우 break
   - 5-2. effect_list의 위치에 대해 모두 effect() 호출
   - 5-3. 단위스탭 증가
   - 5-4. effect_list = next_effect_list로 교체
6. field에 안 익은 토마토가 있는 지 검증
7. 결과 출력

## AI 코드 리뷰

### 개선할 점

1. **전역 변수 최소화**: `isEffected`를 전역으로 사용하는 대신, `next_effect_list`가 비었는지로 종료 조건 판단 가능

2. **불필요한 값 변경 제거**: `field[x][y] = -1`은 이미 익은 토마토(1)를 다시 방문하지 않으므로 불필요

3. **변수명 개선**: `effect_list` → `current_queue`, `next_effect_list` → `next_queue`, `isBreaked` → `has_unripe`

4. **deque 사용 권장**: 리스트의 `pop()`은 마지막 원소를 제거하므로 BFS 순서가 보장되지 않음 (이 문제에선 결과에 영향 없지만, 일반적인 BFS에선 `deque`와 `popleft()` 사용이 표준)

5. **크기 변수 중복 계산**: `fieldX`, `fieldY`를 effect() 호출마다 계산하는 대신 전역으로 한 번만 계산

6. **검증 로직 간소화**: 이중 for문 탈출용 플래그 대신 `any()` 사용 가능

## 수정된 코드

```python
"""
7576
토마토
"""
import sys
from collections import deque

def effect(x, y):
    direction = [(1, 0), (-1, 0), (0, 1), (0, -1)]
    
    for dx, dy in direction:
        nx, ny = x + dx, y + dy
        if 0 <= nx < height and 0 <= ny < width:
            if field[nx][ny] == 0:
                field[nx][ny] = 1
                next_queue.append((nx, ny))

input = sys.stdin.readline
width, height = map(int, input().split())

field = []
for _ in range(height):
    row = list(map(int, input().split()))
    field.append(row)

# 초기 익은 토마토 위치 수집
current_queue = deque()
for i in range(height):
    for j in range(width):
        if field[i][j] == 1:
            current_queue.append((i, j))

# BFS 실행
step = 0
while current_queue:
    next_queue = deque()
    
    while current_queue:
        x, y = current_queue.popleft()
        effect(x, y)
    
    if next_queue:
        step += 1
        current_queue = next_queue

# 검증: 안 익은 토마토가 남아있는지 확인
has_unripe = any(0 in row for row in field)

if has_unripe:
    print(-1)
else:
    print(step)
```
