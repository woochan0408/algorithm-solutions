## 흐름

1. N=0 예외 처리 (초기 길이가 이미 0)
2. BFS로 레벨(일수)별 탐색, `popleft()`로 FIFO 보장
3. `visited`를 dict로 관리하여 같은 높이에 더 적은 물로 도달하면 갱신
4. `nh <= N` 조건으로 제곱 연산 폭발 방지
5. N이 visited에 등장하면 해당 레벨에서 최소 물 탐색

## 성공한 코드
```python
N = int(input())
from collections import deque
# 물 양을 저장하자.
dq = deque([(0, 0)])
level = 0
visited = {}
rw = 0
if(N == 0):
    print('0 0')
else:
    while dq:
        level += 1
        for i in range(len(dq)):
            h, w = dq.popleft()
            cand = [(h+1, w+1), (h*3, w+3), (h**2, w+5)]
            for nh, nw in cand:
                if((nh not in visited or (visited[nh] > nw)) and nh <= N):
                    visited[nh] = nw
                    dq.append((nh, nw))
    
        if(N in visited):
            answer = float('inf')
            for cur in dq:
                if(cur[0] == N):
                    answer = min(cur[1], answer)
            print(level,answer)
            break
```

## 질문 & 실수 정리

### 새로 배운 것

#### 상한 조건(`<= N`) 누락 시 제곱 연산 폭발
BFS에서 `nh <= N` 조건을 빠뜨리면 제곱 연산이 연쇄적으로 발생한다. 제곱을 반복하면 `h → h² → h⁴ → h⁸ → h¹⁶` 형태로 지수가 2배씩 늘어나며, 예를 들어 `h=3`이면 `3 → 9 → 81 → 6561 → 43046721`로 폭발한다. 이는 `h^(2^n)` 형태라서 N이 5만 되어도 큐에 천문학적인 수가 쌓여 메모리와 시간 모두 터진다.
- **핵심 원리**: 상태 공간이 무한히 커지는 연산이 있으면 반드시 상한 조건으로 탐색 범위 제한

#### 알고리즘 선택 (BFS vs DP vs 다익스트라 vs 백트래킹)
이 문제는 "최소 일수 우선 → 같은 일수에서 최소 물"이라는 2단계 최적화 문제다. 연산 1회 = 1일이므로 간선 가중치가 모두 1인 그래프와 같다.
- **BFS**: 가중치 1인 최단거리 → BFS가 정석. 레벨별 탐색으로 최소 일수를 자연스럽게 보장
- **DP**: 역방향으로 `dp[i] = (최소 일수, 최소 물)` 정의 가능하지만, 결국 BFS와 로직이 거의 동일
- **다익스트라**: 간선 가중치가 전부 1이므로 오버킬. 우선순위 기준 설정도 까다로움
- **백트래킹**: 탐색 공간이 넓고 가지치기 기준이 불명확하여 비효율적

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`dq.pop()` 사용 (스택 동작)|`dq.popleft()` 사용 (큐 동작)|
|`visited`를 set으로 관리|dict로 관리하여 더 적은 물 경로 갱신|
|`nh <= N` 조건 누락|상한 조건 추가로 제곱 폭발 방지|
|N=0 예외 처리 없음|`if N == 0: print(0, 0)` 추가|

## AI 코드 리뷰

### 개선할 점

1. **미사용 변수 제거**: `rw = 0`이 선언만 되고 사용되지 않음
2. **import 위치**: `from collections import deque`를 파일 상단으로 이동
3. **답 추출 로직 간소화**: 큐를 순회하며 N을 찾는 대신 `visited[N]`을 직접 사용하면 됨. `visited`는 dict로 항상 최소 물을 갱신하므로 `visited[N]`이 곧 정답
4. **출력 형식**: `print('0 0')`은 문자열 출력이므로 `print(0, 0)`으로 통일
5. **변수명 개선**: `dq` → `queue`, `h` → `height`, `w` → `water`, `nh` → `next_h`, `nw` → `next_w`

### DP 풀이 (대안)

0부터 N까지 BFS 대신 순방향 DP로도 풀 수 있다. `dp[i] = (최소 일수, 그때 최소 물)`로 정의하고, 각 높이에서 세 가지 연산의 결과를 갱신한다. 단, 제곱 연산은 `i*i <= N`인 경우만 처리한다.

```python
import sys
from collections import deque
input = sys.stdin.readline

N = int(input())

if N == 0:
    print(0, 0)
else:
    # dp[i] = (최소 일수, 최소 물)
    INF = float('inf')
    dp = [(INF, INF)] * (N + 1)
    dp[0] = (0, 0)
    queue = deque([0])

    while queue:
        cur = queue.popleft()
        day, water = dp[cur]

        for next_h, cost in [(cur + 1, 1), (cur * 3, 3), (cur * cur, 5)]:
            if next_h > N:
                continue
            new_day = day + 1
            new_water = water + cost
            if new_day < dp[next_h][0] or (new_day == dp[next_h][0] and new_water < dp[next_h][1]):
                dp[next_h] = (new_day, new_water)
                queue.append(next_h)

    print(dp[N][0], dp[N][1])
```

## 수정된 코드
```python
import sys
from collections import deque
input = sys.stdin.readline

N = int(input())

if N == 0:
    print(0, 0)
else:
    queue = deque([(0, 0)])
    visited = {}
    day = 0

    while queue:
        day += 1
        for _ in range(len(queue)):
            height, water = queue.popleft()
            for next_h, cost in [(height + 1, 1), (height * 3, 3), (height ** 2, 5)]:
                next_w = water + cost
                if next_h <= N and (next_h not in visited or visited[next_h] > next_w):
                    visited[next_h] = next_w
                    queue.append((next_h, next_w))

        if N in visited:
            print(day, visited[N])
            break
```
