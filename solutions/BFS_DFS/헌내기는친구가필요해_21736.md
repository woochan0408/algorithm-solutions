## 흐름

1. 캠퍼스 정보를 입력받으면서 도연이(I) 시작 위치 저장
2. DFS/BFS로 시작 위치에서 탐색 시작
3. 벽(X)이 아닌 상하좌우로 이동하며 사람(P) 카운트
4. 결과가 0이면 "TT", 아니면 카운트 출력

## 코드

```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)
N, M = map(int, input().split())
grid = []
startX = -1
startY = -1
for i in range(N):
    grid.append([])
    string = input().strip()
    for c in string:
        grid[-1].append(c)
        if(c == 'I'):
            startX = i
            startY = len(grid[i])-1
count = 0
visited = set()
visited.add((startX, startY))
def dfs(x, y):
    global count
    if(grid[x][y] == 'P'):
        count += 1
    for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
        nx = x + dx
        ny = y + dy
        if(0 <= nx < N and 0 <= ny < M):
            if((nx, ny) not in visited and grid[nx][ny] != 'X'):
                visited.add((nx, ny))
                dfs(nx, ny)
dfs(startX, startY)
if(count == 0):
    print("TT")
else:
    print(count)
```

## AI 코드 리뷰

### 개선할 점

1. **grid 입력 간소화**: `list()`로 문자열을 바로 리스트로 변환 가능
2. **시작 위치 탐색**: `enumerate` 활용으로 가독성 향상
3. **global 제거**: 함수 반환값 활용이 더 깔끔
4. **BFS 권장**: 재귀 DFS는 깊이 제한 설정이 필요하고, 최악의 경우 스택 오버플로우 위험. BFS가 더 안전

## 수정된 코드

```python
import sys
from collections import deque
input = sys.stdin.readline

N, M = map(int, input().split())
grid = []
start_row, start_col = 0, 0

for i in range(N):
    row = list(input().strip())
    grid.append(row)
    if 'I' in row:
        start_row, start_col = i, row.index('I')

def bfs(sr, sc):
    count = 0
    visited = [[False] * M for _ in range(N)]
    visited[sr][sc] = True
    queue = deque([(sr, sc)])
    
    while queue:
        x, y = queue.popleft()
        if grid[x][y] == 'P':
            count += 1
        
        for dx, dy in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nx, ny = x + dx, y + dy
            if 0 <= nx < N and 0 <= ny < M and not visited[nx][ny] and grid[nx][ny] != 'X':
                visited[nx][ny] = True
                queue.append((nx, ny))
    
    return count

result = bfs(start_row, start_col)
print("TT" if result == 0 else result)
```
