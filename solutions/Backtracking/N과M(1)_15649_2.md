# 백준 15649 🔢 N과 M (1) 파이썬

## 느낀점
>
- 백트래킹 약점보완하는 날
- 근본풀이로 풀었지만 대안풀이를 AI에게 물어봤다.
- 시간복잡도 측면에서는 내 풀이가 나은 듯 하다.
(떠올릴 수만 있다면..)

## 흐름

1. 1부터 N까지 수 중 M개를 중복 없이 고르는 모든 순열을 구한다.
2. DFS로 하나씩 수를 선택하며 깊이가 M이 되면 출력한다.
3. visited set으로 이미 사용한 수를 관리하여 중복 선택을 방지한다.
4. 재귀 복귀 시 visited에서 제거하여 다른 경로를 탐색한다.

## 코드

```python
"""
4 2
1. 중복없이 4개 중 2개를 고른다.
"""
N, M = map(int, input().split())
visited = set()
def dfs(arr):
    if(len(arr) == M):
        print(' '.join(map(str, arr)))
        return
    for i in range(1, N+1):
        if(i not in visited):
            visited.add(i)
            dfs(arr + [i])
            visited.remove(i)
dfs([])
```

## 질문 & 실수 정리

### 새로 배운 것

#### `join` 문법
리스트의 요소들을 하나의 문자열로 합칠 때 사용한다. `print(*arr)`로도 출력 가능하지만, `join`은 문자열 연결이 필요한 다양한 상황에서 활용된다.
- **핵심 원리**: `'구분자'.join(iterable)` 형태로, iterable의 각 요소 사이에 구분자를 넣어 문자열을 만든다. 요소가 문자열이어야 하므로 `map(str, ...)`과 함께 쓴다.

#### 백트래킹에서 visited 관리
중복 방지를 위해 "이미 선택한 원소"를 추적하는 패턴이다. set을 쓰면 O(1)로 판별 가능하고, 재귀 진입 전 add → 복귀 후 remove로 상태를 원복한다.
- **핵심 원리**: 재귀 호출 전후로 상태를 추가/제거하여 다른 분기에 영향을 주지 않도록 한다.
- **대안**: visited 없이 `if i not in arr`로 체크 가능하지만, 리스트 탐색이라 O(M)이 소요된다.

## AI 코드 리뷰

### 개선할 점

1. **`arr + [i]` 매번 새 리스트 생성**: 호출마다 리스트를 복사하므로 O(M) 비용이 발생한다. `arr.append(i)` / `arr.pop()`으로 in-place 관리하면 메모리와 시간 모두 절약된다.
2. **sys.stdin 사용**: N≤8이라 이 문제에선 불필요하지만, 출력이 많은 백트래킹 문제에서는 `sys.stdout.write`가 `print`보다 빠르다. 습관적으로 적용하면 좋다.

### 대안 풀이 — visited 없이 리스트 체크

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())

def dfs(arr):
    if len(arr) == M:
        print(' '.join(map(str, arr)))
        return
    for i in range(1, N + 1):
        if i not in arr:
            dfs(arr + [i])

dfs([])
```

visited 집합 없이 `in arr`로 중복을 체크한다. N≤8이므로 리스트 탐색 비용이 무시할 수준이라 충분히 통과한다. visited 관리를 떠올리기 어려울 때 먼저 시도할 수 있는 직관적인 방법이다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
visited = set()
arr = []

def dfs():
    if len(arr) == M:
        print(' '.join(map(str, arr)))
        return
    for i in range(1, N + 1):
        if i not in visited:
            visited.add(i)
            arr.append(i)
            dfs()
            arr.pop()
            visited.remove(i)

dfs()
```
