# 백준 15650 🔢 N과 M (2) 파이썬

## 느낀점
>
- 실패해서 로직 참고해서 풀었다.
- 내일 N과 M (3) 풀기

## 흐름

1. 오름차순 수열만 출력해야 하므로, 이전에 선택한 숫자보다 큰 숫자만 탐색
2. `start` 파라미터로 탐색 시작점을 넘겨 오름차순 강제
3. 오름차순 강제 시 중복 선택이 불가능하므로 visited 배열 불필요
4. depth가 M에 도달하면 결과 출력

## 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
result = [0 for i in range (M)]
def back(n, beforeNum):
    if(n == M):
        for i in range(M):
            print(result[i], end = " ")
        print()
        return
    for i in range(beforeNum+1, N+1):
        result[n] = i
        back(n+1, i)
            
back(0, 0)
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| 오름차순은 자동으로 되는 거 아님? | 아니요, `range(1, N+1)` 전체 순회하면 이전 숫자도 다시 나옴 |
| N과 M (1)도 visited 없이 가능? | 불가능. (1)은 전체 순회하면서 중복 체크 필요 |

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `if(visited[i]): return` | `continue`로 건너뛰어야 함 (`return`은 함수 종료) |
| `range(1, K+1)` | `range(1, N+1)` - N이 숫자 범위 |
| `if(i in result): continue` | 오름차순 강제 시 불필요하고, 값 초기화 안 해서 오류 발생 |

## AI 코드 리뷰

### 개선할 점

1. **변수명**: `beforeNum` → `start`가 더 직관적 (시작점 의미)

2. **리스트 초기화 간소화**: `[0 for i in range(M)]` → `[0] * M`

3. **출력 간소화**: for문 대신 `print(*result)` 사용

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
result = [0] * M

def back(depth, start):
    if depth == M:
        print(*result)
        return
    for i in range(start, N + 1):
        result[depth] = i
        back(depth + 1, i + 1)

back(0, 1)
```
