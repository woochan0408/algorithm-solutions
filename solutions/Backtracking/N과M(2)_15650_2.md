# 백준 15650 🔢 N과 M (2) 파이썬

## 느낀점
> 
- 어우 헷갈린다.
- N과M(1) 과 비교해보면 오름차순 하나 바뀌었고 이 조건을 위해 for문이 바뀌었다. (시작지점 추적)
- 지금처럼 복잡하게 계산해도 되지만 start파라미터를 추가하는 것도 방법
(코드리뷰 참고)

## 흐름

1. N과 M을 입력받는다
2. 빈 배열 `arr`을 만들고 DFS 탐색 시작
3. 배열 길이가 M이면 출력하고 return
4. 오름차순 보장을 위해 시작값을 배열의 마지막 값 + 1로 설정 (비어있으면 1)
5. 시작값부터 N까지 순회하며 append → 재귀 → pop (백트래킹)

## 코드

```python
"""
달라진건 오름차순인 것만 인정한다?
"""
N, M = map(int, input().split())
arr = []
def dfs():
    if(len(arr) == M):
        print(" ".join(map(str, arr)))
        return
    startValue = 1 if len(arr) == 0 else arr[-1]+1
    for i in range(startValue, N+1):
        arr.append(i)
        dfs()
        arr.pop()
        
dfs()
```

## 질문 & 실수 정리

### 새로 배운 것

#### 백트래킹에서 오름차순 조합 생성
N과 M (1)에서는 `visited` 배열로 중복을 방지했다면, 오름차순 조건이 추가되면 탐색 시작점을 조절하는 것만으로 충분하다. 마지막으로 선택한 값보다 큰 값만 탐색하면 자연스럽게 오름차순이 보장되고, visited 배열도 필요 없어진다.
- **핵심 원리**: `range(arr[-1]+1, N+1)`로 이전 선택값 이후부터만 탐색
- **시간복잡도**: O(C(N,M)) — 조합의 수만큼만 탐색

#### 백트래킹의 두 가지 구현 방식
백트래킹에서 "원상복구"를 처리하는 방법은 크게 두 가지가 있다.

**방식 1: append/pop** — 배열 크기가 동적으로 변한다. 재귀 후 `pop()`으로 직접 제거해야 원상복구된다.
```python
arr = []
for i in range(start, N + 1):
    arr.append(i)
    dfs(i + 1)
    arr.pop()       # 직접 제거 필수
```

**방식 2: 인덱스 대입** — 고정 크기 배열에 덮어쓰기한다. 다음 반복에서 `result[depth] = 다음값`이 자동으로 이전 값을 덮어쓰므로 별도 제거가 필요 없다.
```python
result = [0] * M
for i in range(start, N + 1):
    result[depth] = i   # 덮어쓰기로 자동 복구
    back(depth + 1, i + 1)
```

두 방식 모두 백트래킹의 "원상복구" 원리는 동일하고, 복구 방법만 다르다.

#### 오름차순 조합에서 visited가 필요 없는 이유
N과 M (1)에서는 `visited` 배열로 중복을 방지했다면, 오름차순 조건이 추가되면 탐색 시작점을 조절하는 것만으로 충분하다. 마지막으로 선택한 값보다 큰 값만 탐색하면 자연스럽게 오름차순이 보장되고, visited 배열도 필요 없어진다.
- **핵심 원리**: `range(start, N+1)`로 이전 선택값 이후부터만 탐색
- **시간복잡도**: O(C(N,M)) — 조합의 수만큼만 탐색



### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `range(..., N)` — N 미포함 | `range(..., N+1)` — N 포함 |
| `range(len(arr)+1, ...)` — 배열 길이 기준 시작 | `range(arr[-1]+1, ...)` — 마지막 값 기준 시작 |
| 종료 조건에서 `return` 누락 | `return` 추가하여 불필요한 재귀 방지 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 snake_case 통일**: `startValue` → `start`로 변경. 파이썬 컨벤션은 snake_case이며, 의미도 충분히 전달된다.
2. **start 파라미터화**: 매번 `arr[-1]+1`을 계산하는 대신, `start`를 함수 인자로 넘기면 배열이 비어있는 경우를 분기할 필요가 없어진다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
arr = []

def dfs(start):
    if len(arr) == M:
        print(" ".join(map(str, arr)))
        return
    for i in range(start, N + 1):
        arr.append(i)
        dfs(i + 1)
        arr.pop()

dfs(1)
```
