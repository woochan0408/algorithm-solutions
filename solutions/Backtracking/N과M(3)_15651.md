# 백준 15651 🔢 N과 M (3) 파이썬

## 느낀점
>
- 이

## 흐름

1. 길이 M짜리 배열 `arr`을 미리 만들어둔다
2. `dfs(depth)`로 재귀하며, 각 깊이에서 1~N까지 모든 수를 `arr[depth]`에 넣는다
3. visited 체크 없이 모든 수를 다시 선택 가능 → 중복 순열
4. `depth == M`이면 현재 배열을 출력하고 return

## 코드

```python
"""
(2)랑 비교해서 뭐가 달라졌을까?
-> 그냥 제한이 사라짐

"""
N, M = map(int, input().split())
arr = [0 for i in range(M)]
def dfs(n):
    if(n == M):
        print(' '.join(map(str, arr)))
        return
        
    for i in range(1, N+1):
        arr[n] = i
        dfs(n+1)
dfs(0)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 백트래킹에서 depth 인자 패턴
`dfs(0)`으로 시작하여 `arr[depth]`에 값을 채워넣는 방식은 백트래킹의 가장 기본적인 패턴이다. 깊이를 인자로 넘기면서 각 위치에 어떤 값을 넣을지 결정하고, 목표 깊이에 도달하면 결과를 처리한다.
- **핵심 원리**: depth가 현재 채울 인덱스 역할을 하므로, 별도의 인덱스 관리 없이 자연스럽게 순서가 보장됨

#### N과 M 시리즈 차이점
N과 M (1)~(4)는 visited 체크 여부와 오름차순 제한 여부의 조합으로 구분된다.
- **(1)**: 순열 — visited O, 순서 제한 X
- **(2)**: 조합 — visited O, 오름차순 O (start 인자)
- **(3)**: 중복순열 — visited X, 순서 제한 X
- **(4)**: 중복조합 — visited X, 오름차순 O (start 인자)

## AI 코드 리뷰

### 개선할 점

1. **매개변수명 `n` → `depth`**: `n`은 보통 전체 크기를 나타내는 변수명으로 쓰이므로, 재귀 깊이를 나타내는 `depth`가 더 명확하다
2. **배열 초기화 간소화**: `[0 for i in range(M)]` → `[0] * M`으로 더 간결하게 작성 가능

## 수정된 코드

```python
N, M = map(int, input().split())
arr = [0] * M

def dfs(depth):
    if depth == M:
        print(' '.join(map(str, arr)))
        return

    for i in range(1, N + 1):
        arr[depth] = i
        dfs(depth + 1)

dfs(0)
```
