# 백준 15652 🔢 N과 M (4) 파이썬

## 느낀점
>
- return 실수하지 않기

## 흐름

1. 1부터 N까지 자연수 중 M개를 고르되, 중복 허용 + 비내림차순 조건
2. 백트래킹으로 현재 수열의 마지막 값 이상부터 탐색 시작
3. 수열 길이가 M이 되면 출력 후 return

## 코드

```python
"""
1. 다른 자릿수에서 중복숫자가 가능함
"""
N, M = map(int, input().split())
def back(cur, n):
    if(n == M):
        for i in cur:
            print(i, end = " ")
        print()
        return
    start = cur[-1] if cur else 1
    for i in range(start, N+1):
        next = list(cur)
        next.append(i)
        back(next, n+1)
back([], 0)
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| (없음) | - |

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `range(start, M+1)` | `range(start, N+1)` — 1~N까지 고르는 것이므로 N+1이 맞음 |

## AI 코드 리뷰

### 개선할 점

1. **`next` 변수명**: 파이썬 내장 함수 `next()`와 이름이 겹침. `nxt`나 다른 이름 권장
2. **리스트 복사 간소화**: `list(cur)` + `append` 대신 `cur + [i]`로 한 줄 처리 가능
3. **출력 간소화**: `' '.join(map(str, cur))`으로 깔끔하게 출력 가능

## 수정된 코드

```python
N, M = map(int, input().split())

def back(cur):
    if len(cur) == M:
        print(' '.join(map(str, cur)))
        return
    
    start = cur[-1] if cur else 1
    for i in range(start, N + 1):
        back(cur + [i])

back([])
```
