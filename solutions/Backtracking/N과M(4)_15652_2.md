# 백준 15652 🔢 N과 M (4) 파이썬

## 느낀점
>
- (1) ~ (4) 까지 연속으로 풀었다.
- (3)부터 감이 잡히는 듯 하다.

## 흐름

1. 길이 M인 수열을 담을 배열 `arr`을 초기화한다.
2. DFS 함수에 현재 깊이(`n`)와 시작 숫자(`start`)를 전달한다.
3. 깊이가 M이 되면 수열을 출력하고 리턴한다.
4. `start`부터 N까지 반복하면서 현재 위치에 숫자를 넣고, 다음 깊이로 재귀 호출한다.
5. 재귀 호출 시 `i`를 그대로 넘겨서 같은 수를 다시 선택할 수 있게 한다 (비내림차순).

## 코드

```python
N, M = map(int, input().split())
arr = [0 for i in range(M)]
def dfs(n, start):
    if(n == M):
        print(' '.join(map(str, arr)))
        return
        
    for i in range(start, N+1):
        arr[n] = i
        dfs(n+1, i)
dfs(0, 1)
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 `n` → `depth`**: 전역 변수 `N`과 소문자 `n`이 혼동될 수 있다. 재귀 깊이를 나타내는 `depth`가 의미가 명확하다.
2. **출력 최적화**: `print()`는 호출마다 flush가 발생할 수 있다. `sys.stdout.write`로 모아서 출력하면 속도가 개선된다.

## 수정된 코드

```python
import sys

input = sys.stdin.readline
write = sys.stdout.write

N, M = map(int, input().split())
arr = [0] * M

def dfs(depth, start):
    if depth == M:
        write(' '.join(map(str, arr)) + '\n')
        return

    for i in range(start, N + 1):
        arr[depth] = i
        dfs(depth + 1, i)

dfs(0, 1)
```
