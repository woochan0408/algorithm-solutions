# 백준 15654 🔢 N과 M (5) 파이썬

## 느낀점
>
- 백트래킹 너무 헷갈린다.. 연습 많이하자.

## 흐름

1. N개의 수를 입력받아 정렬
2. 백트래킹으로 M개를 고르는 모든 순열 생성
3. 현재 수열에 포함되지 않은 수만 선택
4. M개를 모두 고르면 출력

## 코드

```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
arr = list(map(int, input().split()))
arr.sort()
def back(cur):
    if(len(cur) == M):
        print(" ".join(map(str, cur)))
    for i in arr:
        if i not in cur:
            back(cur + [i])
back([])
```

## 질문 & 실수 정리

### 새로 배운 것

#### join 메서드
문자열을 구분자로 연결할 때 사용하는 문자열 메서드. 리스트의 메서드가 아니라 문자열의 메서드라는 점이 핵심이다.
- **핵심 원리**: `"구분자".join(리스트)` 형태로, 구분자가 앞에 옴
- **주의**: 문자열 리스트에만 동작 → 정수는 `map(str, ...)`로 변환 필요

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `cur.join(" ")` | `" ".join(cur)` |

## AI 코드 리뷰

### 개선할 점

1. **return 누락**: 종료 조건 `len(cur) == M` 도달 후 `return`이 없어서 출력 후에도 불필요한 for문이 실행됨

2. **in 연산 비효율**: `i not in cur`는 리스트에서 O(M) 시간 소요 → visited 배열 사용 시 O(1)로 개선 가능

3. **리스트 복사 비효율**: `cur + [i]`는 매번 새 리스트를 생성하여 O(M) 메모리와 시간 소요 → `append/pop` 방식이 더 효율적

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
arr = list(map(int, input().split()))
arr.sort()

visited = [False] * N
cur = []

def back():
    if len(cur) == M:
        print(" ".join(map(str, cur)))
        return
    
    for i in range(N):
        if not visited[i]:
            visited[i] = True
            cur.append(arr[i])
            back()
            cur.pop()
            visited[i] = False

back()
```
