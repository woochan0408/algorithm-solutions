## 흐름

1. N개의 수를 입력받아 오름차순 정렬
2. visited 집합으로 사용 여부를 추적하며 백트래킹
3. 길이 M인 수열이 완성되면 출력
4. 정렬된 배열에서 인덱스 0부터 순회하므로 사전순 보장

## 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
arr = list(map(int, input().split()))
arr.sort()
s = [0] * M
visited = set()
def dfs(n):
    if(n == M):
        for cur in s:
            print(arr[cur], end = " ")
        print()
        return
    for i in range(N):
        if(i not in visited):
            visited.add(i)
            s[n] = i
            dfs(n+1)
            visited.remove(i)
dfs(0)
```

## AI 코드 리뷰

### 개선할 점

1. **출력 방식**: `print(arr[cur], end=" ")`는 마지막 원소 뒤에도 공백이 붙는다. `' '.join()`을 사용하면 깔끔하게 처리된다.

2. **인덱스 대신 값 저장**: `s` 배열에 인덱스를 저장하고 출력 시 `arr[cur]`로 변환하는 대신, 처음부터 값을 저장하면 코드가 직관적이다.

3. **더 간결한 접근**: 이 문제는 N개에서 M개를 뽑는 순열이므로 `itertools.permutations`로 한 줄에 해결 가능하다. 백트래킹 연습이 목적이라면 직접 구현이 좋지만, 실전에서는 라이브러리 활용이 효율적이다.

## 수정된 코드 (백트래킹)
```python
import sys

input = sys.stdin.readline

N, M = map(int, input().split())
arr = sorted(map(int, input().split()))
path = []
visited = [False] * N

def dfs():
    if len(path) == M:
        print(' '.join(map(str, path)))
        return
    for i in range(N):
        if not visited[i]:
            visited[i] = True
            path.append(arr[i])
            dfs()
            path.pop()
            visited[i] = False

dfs()
```

## 수정된 코드 (itertools)
```python
import sys
from itertools import permutations

input = sys.stdin.readline

N, M = map(int, input().split())
arr = sorted(map(int, input().split()))

for perm in permutations(arr, M):
    print(' '.join(map(str, perm)))
```
