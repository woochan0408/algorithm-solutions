## 흐름

1. 각 banned_id 패턴에 매칭 가능한 user_id 후보 리스트 구하기
2. DFS(백트래킹)로 각 banned_id에 user_id를 하나씩 배정
3. 이미 사용된 user_id는 건너뛰기 (visited)
4. 모든 banned_id에 배정 완료 시, 선택된 조합을 set에 저장 (중복 제거)
5. set의 크기 반환

## 코드
```python
from collections import defaultdict

def solution(user_id, banned_id):
    dic = [[] for i in range(len(banned_id))]
    
    def valid(uid, bid):
        if len(uid) != len(bid):
            return False
        for i in range(len(uid)):
            if(uid[i] != bid[i] and bid[i] != '*'):
                return False
        return True
    
    for i in range(len(banned_id)):
        b = banned_id[i]
        for u in user_id:
            if(valid(u, b)):
                dic[i].append(u)
    arr = dic
    N = len(arr)
    visited = set()
    answer = set()
    #dfs n = n번째 할 차례다
    def dfs(n):
        if(n == N):
            a = list(visited)
            a.sort()
            answer.add(tuple(a))
            return
        
        for cur in arr[n]:
            if(cur not in visited):
                visited.add(cur)
                dfs(n+1)
                visited.remove(cur)
    dfs(0)
    return len(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### frozenset vs set 차이
frozenset은 immutable이라 원소 추가/삭제가 불가능하다. 평소에 원소를 넣고 빼야 하는 상황에선 set을 쓰고, frozenset은 더 이상 바뀔 일 없는 집합을 dict 키나 set 원소로 저장해야 할 때 쓴다.
- **핵심 원리**: set은 mutable → 수정 가능, frozenset은 immutable → 수정 불가 대신 해시 가능

```python
# set은 수정 가능
s = {1, 2, 3}
s.add(4)       # OK
s.remove(1)    # OK

# frozenset은 수정 불가
fs = frozenset({1, 2, 3})
fs.add(4)      # AttributeError
fs.remove(1)   # AttributeError

# 차집합, 합집합 등은 둘 다 가능 (frozenset은 새 객체 반환)
a = frozenset({1, 2, 3})
b = frozenset({2, 3, 4})
a | b  # frozenset({1, 2, 3, 4})
a - b  # frozenset({1})
```

#### frozenset을 활용한 조합 중복 제거
백트래킹에서 "순서 무관하게 같은 집합이면 동일"한 경우, sorted tuple 대신 frozenset을 사용하면 정렬 없이 바로 set에 넣어 중복 제거할 수 있다.
- **핵심 원리**: frozenset은 해시 가능한 불변 집합이라 set의 원소로 사용 가능. 원소 순서와 무관하게 동일성 비교됨.

```python
# set은 mutable이라 set의 원소로 사용 불가
s = set()
s.add({1, 2, 3})  # TypeError: unhashable type: 'set'

# frozenset은 immutable이라 set의 원소로 사용 가능
s = set()
s.add(frozenset({1, 2, 3}))  # OK

# 순서가 달라도 같은 원소면 동일하게 취급
frozenset({1, 2, 3}) == frozenset({3, 1, 2})  # True

# sorted tuple 방식과 비교
# tuple 방식: 정렬 필요 O(k log k)
answer.add(tuple(sorted(used)))

# frozenset 방식: 정렬 불필요 O(k)
answer.add(frozenset(used))
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 `dic`**: 실제로 dict가 아닌 리스트이므로 `candidates` 같은 이름이 더 명확
2. **불필요한 재할당 `arr = dic`**: 같은 객체를 가리키는 별칭일 뿐, 하나로 통일
3. **`valid` 함수 간결화**: `zip` + `all` 조합으로 가독성 향상 가능
4. **`frozenset` 활용**: 정렬 후 tuple 변환 대신 frozenset으로 바로 중복 제거 가능

## 수정된 코드
```python
def solution(user_id, banned_id):
    def is_match(uid, bid):
        if len(uid) != len(bid):
            return False
        return all(u == b or b == '*' for u, b in zip(uid, bid))

    # 각 banned_id별 매칭 가능한 user_id 후보
    candidates = []
    for ban in banned_id:
        matched = [user for user in user_id if is_match(user, ban)]
        candidates.append(matched)

    answer = set()
    used = set()

    def dfs(depth):
        if depth == len(candidates):
            answer.add(frozenset(used))
            return

        for user in candidates[depth]:
            if user not in used:
                used.add(user)
                dfs(depth + 1)
                used.remove(user)

    dfs(0)
    return len(answer)
```
