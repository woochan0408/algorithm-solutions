## 실패한 코드 흐름
1. 마지막 열에서 시작하여 역방향(오른쪽→왼쪽)으로 탐색
2. 각 칸에서 아래/직진/위 순으로 한 방향만 선택하고, 막히면 바로 포기
## 실패한 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
grid = []
for _ in range(N):
    grid.append(list(input().strip()))
def update(route):
    global grid
    for i, j in route:
        grid[i][j] = 'X'
def pr():
    for i in range(N):
        print(' '.join(map(str, grid[i])))
    print('-------------------')
def validate(i):
    j = M-2
    route = []
    while True:
        if(j == 0):
            update(route)
            return True
        # 아래부터 검증 -> greedy
        if(i + 1 < N and grid[i+1][j] == '.'):
            i += 1
            route.append((i, j))
            j -= 1
        elif(grid[i][j] == '.'):
            route.append((i, j))
            j -= 1
        elif(i - 1 >= 0 and grid[i-1][j] == '.'):
            i -= 1
            route.append((i, j))
            j -= 1
        else:
            return False
    return False
        
answer = 0
for cur in range(N-1, -1, -1):
    answer += validate(cur)
print(answer)
```

**문제점**: 백트래킹이 없어 한 방향이 막히면 다른 경로를 시도하지 못하고, 검사 대상 셀과 실제 이동 셀이 불일치함

## 성공한 코드 흐름

1. 행 0부터 행 N-1까지 순서대로, 열 0에서 DFS 시작
2. 각 칸에서 오른쪽 위 → 오른쪽 → 오른쪽 아래 순으로 탐색 (위쪽 우선 = 아래 행에게 공간 양보)
3. 마지막 열 도달 시 True 반환, 세 방향 모두 실패 시 False 반환
4. 방문한 칸은 성공/실패 관계없이 표시 유지 (실패한 경로도 다른 행에서 재탐색할 필요 없음)

## 성공한 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
grid = []
for _ in range(N):
    grid.append(list(input().strip()))
def update(route):
    for i, j in route:
        grid[i][j] = 'X'
visited = set()
def dfs(x, y):
    if(y == M-1):
        return True
    ny = y + 1
    if(x - 1 >= 0 and (x-1, ny) not in visited and grid[x-1][ny] == '.'):
        visited.add((x-1, ny))
        route.append((x-1, ny))
        if dfs(x-1, ny):
            return True
    if(grid[x][ny] == '.' and (x, ny) not in visited):
        visited.add((x, ny))
        route.append((x, ny))
        if dfs(x, ny):
            return True
    if(x + 1 < N and (x+1, ny) not in visited and grid[x+1][ny] == '.'):
        visited.add((x+1, ny))
        route.append((x+1, ny))
        if dfs(x+1, ny):
            return True
    return False
    
answer = 0
for i in range(N):
    route = []
    result = dfs(i, 0)
    if(result):
        answer += 1
        update(route)
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 그리디 + DFS 조합 패턴
일반적인 백트래킹은 실패 시 상태를 복구하지만, 이 문제에서는 그리디 전략과 결합하여 실패한 경로의 방문 표시를 유지한다. 행 i에서 위쪽 우선 탐색으로 실패한 칸은, 행 i보다 아래에서 출발하는 파이프가 거쳐도 동일하게 실패하기 때문이다.
- **핵심 원리**: 탐색 순서(위→아래)와 이동 우선순위(위 대각선 우선)가 그리디 조건을 만족시켜, 실패 경로 복구가 불필요해짐
- **시간복잡도**: O(R × C) — 각 칸을 최대 한 번만 방문

#### 백트래킹의 상태 복구 원리
백트래킹에서 방문 표시를 지우는 이유는 "다른 분기에서 그 칸을 사용할 가능성이 있기 때문"이다. N과M 같은 표준 백트래킹 문제에서는 한 분기에서 사용한 원소가 다른 분기에서도 쓰일 수 있으므로 반드시 상태를 복구해야 한다. 반면 이 문제처럼 실패한 경로가 다른 출발점에서도 실패가 보장되면 복구가 불필요하다.
- **핵심 원리**: 상태 복구 여부는 "다른 탐색에서 해당 상태를 활용할 수 있는가"로 판단

### 실수했던 부분

#### DFS 반환값 미사용
재귀 호출 `dfs(x-1, ny)`의 결과를 변수에 받지 않아, 마지막 열에 도달해서 True를 반환해도 중간 호출들이 전부 무시하고 False를 반환했다. `if dfs(...): return True` 패턴으로 성공 시 즉시 전파해야 한다.


#### 검사 대상과 이동 대상 불일치 (실패 코드)
`grid[i+1][j]`를 검사하고 실제로는 `(i+1, j-1)`로 이동하여, 빈 칸 검증이 엉뚱한 셀에 대해 이루어졌다.

## AI 코드 리뷰

### 개선할 점

1. **이중 상태 관리 제거**: `visited` set과 `update(route)`로 grid를 이중 관리하고 있다. grid에 직접 `'X'`를 마킹하면 visited, route, update 함수가 모두 불필요해진다.
2. **방향 배열 활용**: 세 방향을 if 세 개로 나열하는 대신, `dx = [-1, 0, 1]`로 묶어 for 루프 하나로 처리하면 중복이 줄고 가독성이 높아진다.
3. **디버그 함수 제거**: `pr()` 함수는 제출 시 불필요하다.
4. **재귀 깊이 설정**: C가 최대 500이므로 기본값(1000)으로 충분하지만, 안전하게 `sys.setrecursionlimit`을 설정하는 것이 좋다.

## 수정된 코드
```python
import sys
sys.setrecursionlimit(10 ** 6)
input = sys.stdin.readline

R, C = map(int, input().split())
grid = []
for _ in range(R):
    grid.append(list(input().strip()))

dx = [-1, 0, 1]

def dfs(x, y):
    if y == C - 1:
        return True
    for d in dx:
        nx, ny = x + d, y + 1
        if 0 <= nx < R and grid[nx][ny] == '.':
            grid[nx][ny] = 'X'
            if dfs(nx, ny):
                return True
    return False

answer = 0
for i in range(R):
    if dfs(i, 0):
        answer += 1

print(answer)
```
