# 백준 14889 ⚽ 스타트와 링크 파이썬

## 느낀점
>
- 조합을 구현할 땐 start 파라미터를 사용한다

## 흐름

1. N명 중 N/2명을 뽑아 스타트 팀 구성 (나머지는 링크 팀)
2. 백트래킹으로 조합 생성: start 파라미터로 오름차순만 생성
3. 각 팀의 능력치 계산: 팀 내 모든 쌍 (i, j)에 대해 S[i][j] + S[j][i] 합산
4. 두 팀 능력치 차이의 최솟값 갱신

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
grid = []
for _ in range(N):
    grid.append(list(map(int, input().split())))
combs = []
def back(cur, start):
    # 결과 제공
    if(len(cur) == N/2):
        combs.append(set(cur))
        return
    for i in range(start, N):
        back(cur + [i], i+1)
back([], 0)
    
result = float("inf")
for comb in combs:
    # 내가 뽑은건 스타트팀 것이라고 생각하자.
    st = 0
    link = 0
    for i in range(N-1):
        for j in range(i+1, N):
            if(i in comb and j in comb):
                st += grid[i][j]
                st += grid[j][i]
            elif(i not in comb and j not in comb):
                link += grid[i][j]
                link += grid[j][i]
    cur = abs(st - link)
    if(result > cur):
        result = cur
    
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 조합 생성 시 start 파라미터
조합은 순서가 상관없으므로 `[0,1]`과 `[1,0]`은 같은 것으로 취급해야 한다. 백트래킹에서 `start` 파라미터를 사용해 "이전에 선택한 인덱스보다 큰 것만 선택"하도록 제한하면 자연스럽게 오름차순 조합만 생성된다.
- **핵심 원리**: `for i in range(start, N)` + 재귀 시 `i+1` 전달
- **시간복잡도**: O(C(N, N/2)) — N=20일 때 C(20,10) = 184,756

#### set의 in 연산 O(1)
멤버십 검사가 반복문 안에서 여러 번 호출될 때, 자료구조 선택이 성능에 큰 영향을 미친다. tuple/list는 O(N), set은 해시 기반으로 평균 O(1)이다.
- **핵심 원리**: set은 해시 테이블 기반 → 검색/삽입/삭제 평균 O(1)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`for i in range(N)` (순열 생성)|`for i in range(start, N)` (조합 생성)|
|`else`로 링크 팀 계산 (한쪽만 없어도 포함)|`elif i not in comb and j not in comb`|
|tuple에서 `in` 연산 (O(N))|set에서 `in` 연산 (O(1))|
|조건 만족 후 `return` 누락|`return` 추가로 불필요한 재귀 방지|
|`start` 변수명 중복 사용|`st`로 변경하여 충돌 해결|

## AI 코드 리뷰

### 개선할 점

1. **`N/2` → `N//2`**: 정수 나눗셈을 명시적으로 사용하는 것이 안전하다. Python 3에서 `/`는 float를 반환한다.

2. **`itertools.combinations` 활용**: 직접 구현한 백트래킹도 학습에 좋지만, 표준 라이브러리를 쓰면 더 간결하다.

3. **리스트 컴프리헨션으로 입력 간소화**: `grid` 입력 부분을 한 줄로 줄일 수 있다.

4. **링크 팀을 여집합으로 계산**: `comb`의 여집합으로 링크 팀을 미리 구해두면 조건문이 단순해진다.

5. **`min()` 함수 활용**: `if(result > cur)` 대신 `result = min(result, cur)`가 더 직관적이다.

## 수정된 코드

```python
import sys
from itertools import combinations
input = sys.stdin.readline

N = int(input())
grid = [list(map(int, input().split())) for _ in range(N)]

result = float("inf")

for comb in combinations(range(N), N // 2):
    start_team = set(comb)
    link_team = set(range(N)) - start_team
    
    st = 0
    link = 0
    
    for i, j in combinations(start_team, 2):
        st += grid[i][j] + grid[j][i]
    
    for i, j in combinations(link_team, 2):
        link += grid[i][j] + grid[j][i]
    
    result = min(result, abs(st - link))

print(result)
```
