## 흐름

1. 인접 리스트를 `defaultdict(Counter)`로 구성해서 같은 구간 중복 항공권 처리
2. ICN에서 출발하여 DFS + 백트래킹으로 모든 경로 탐색
3. 항공권 사용 시 카운트 감소, 복원 시 증가
4. 모든 유효 경로를 수집한 뒤 `min()`으로 알파벳 순 최소 경로 반환

## 코드

```python
from collections import defaultdict, Counter
def solution(tickets):
    graph = defaultdict(Counter)
    N = len(tickets)+1
    
    for u, v in tickets:
        graph[u][v] += 1
        
    result = ['' for i in range(N)]
    result[0] = 'ICN'
    answer = []
    def dfs(n, cur):
        if(n == N-1):
            counter = graph[cur]
            for key in counter:
                if(counter[key] > 0):
                    result[n] = key
                    answer.append(tuple(result))
            
            
            return
        counter = graph[cur]
        for key in counter:
            if(counter[key] > 0):
                counter[key] -= 1
                result[n] = key
                dfs(n+1, key)
                counter[key] += 1 
    dfs(1, 'ICN')
    return min(answer)
```

## 질문 & 실수 정리

#### 오일러 경로와 항공권 문제의 관계
모든 항공권(간선)을 정확히 한 번씩 사용하는 문제는 오일러 경로(Eulerian Path) 문제와 동일하다. Hierholzer 알고리즘을 사용하면 O(E)에 해결 가능하지만, 이 문제의 제한(공항 10,000개 이하)에서는 백트래킹으로 충분하다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `counter += 1` (Counter 객체에 정수 덧셈) | `counter[key] += 1` (특정 키의 값을 복원) |
| `result` 길이를 항공권 수 `N`으로 설정 | 공항 수는 항공권 수 + 1이므로 `N+1` |
| `n == N-1`에서 별도 종료 분기 작성 | 통일된 종료 조건 `n == N`으로 단순화 가능 |

## AI 코드 리뷰

### 개선할 점

1. **종료 조건 이원화 제거**: `n == N-1`에서 별도로 마지막 항공권을 처리하는 분기가 있어 코드가 불필요하게 복잡하다. `n == N`일 때 `return True` 하나로 통일하면 일반 케이스와 종료 케이스가 같은 구조를 공유한다.

2. **전체 탐색 후 min() → 정렬 + 조기 종료**: 목적지를 `sorted()`로 정렬한 뒤 첫 유효 경로에서 `return True`하면, 모든 경로를 수집할 필요가 없다. 메모리와 시간 모두 절약된다.

3. **고정 배열 → append/pop 패턴**: `result[n] = key` 방식 대신 `route.append(dest)` / `route.pop()` 패턴이 백트래킹의 의도를 더 명확히 드러낸다.

4. **변수명 개선**: `n`, `cur`, `key` 같은 범용적 이름 대신 `dest`(목적지) 등 문맥에 맞는 이름을 사용하면 가독성이 향상된다.

## 수정된 코드

```python
from collections import defaultdict, Counter

def solution(tickets):
    graph = defaultdict(Counter)
    for u, v in tickets:
        graph[u][v] += 1

    total = len(tickets) + 1
    route = ['ICN']

    def dfs():
        if len(route) == total:
            return True
        cur = route[-1]
        for dest in sorted(graph[cur]):
            if graph[cur][dest] > 0:
                graph[cur][dest] -= 1
                route.append(dest)
                if dfs():
                    return True
                route.pop()
                graph[cur][dest] += 1
        return False

    dfs()
    return route
```

## 풀이2: Hierholzer 알고리즘 (오일러 경로)

### 오일러 경로란?
그래프에서 **모든 간선을 정확히 한 번씩** 지나는 경로를 오일러 경로(Eulerian Path)라 한다. 이 문제에서 항공권 = 간선이므로, 모든 항공권을 한 번씩 사용하는 경로를 찾는 것은 곧 오일러 경로를 찾는 것과 같다.

### Hierholzer 알고리즘 동작 원리
1. 현재 노드에서 남은 간선이 있으면 하나를 소모하고 다음 노드로 이동
2. 더 이상 갈 곳이 없으면 현재 노드를 결과 스택에 push
3. 이전 노드로 돌아가서 남은 간선이 있으면 다시 1번 반복
4. 최종 결과를 뒤집으면 오일러 경로 완성

**왜 뒤집는가?** 막다른 곳에 도달한 노드가 경로의 끝부분이기 때문이다. 가장 먼저 막히는 노드가 경로의 마지막이 되고, 거꾸로 쌓아올리면 올바른 순서가 된다.

- **시간복잡도**: O(E log E) — 정렬 포함, 탐색 자체는 O(E)
- **공간복잡도**: O(E)

### 코드

```python
from collections import defaultdict

def solution(tickets):
    graph = defaultdict(list)
    for u, v in tickets:
        graph[u].append(v)

    # 알파벳 역순 정렬 → pop()으로 꺼내면 알파벳순
    for key in graph:
        graph[key].sort(reverse=True)

    stack = ['ICN']
    route = []

    while stack:
        cur = stack[-1]
        if graph[cur]:
            stack.append(graph[cur].pop())
        else:
            route.append(stack.pop())

    return route[::-1]
```

### 풀이1 vs 풀이2 비교

| 항목 | 풀이1 (DFS 백트래킹) | 풀이2 (Hierholzer) |
|---|---|---|
| 시간복잡도 | 최악 O(N!) | O(E log E) |
| 접근 방식 | 모든 경로 탐색 후 최소 선택 / 정렬 후 조기 종료 | 오일러 경로 직접 구성 |
| 중복 항공권 처리 | Counter로 카운트 관리 | 리스트에서 pop |
| 알파벳순 보장 | sorted() 순회 또는 min() | 역순 정렬 후 pop |
| 구현 난이도 | 직관적 | 알고리즘 이해 필요 |
