## 느낀점
>
- 실수가 너무 많았다..

## 흐름
1. 첫 번째 수를 초기값으로 설정하고, 나머지 수열에 대해 DFS 탐색
2. 각 단계에서 남은 연산자(+, -, ×, ÷) 중 사용 가능한 것을 하나씩 선택
3. 연산자를 사용하면 remain 감소, 재귀 복귀 시 복원 (백트래킹)
4. 모든 수를 사용하면 결과를 저장하고, 최종적으로 최댓값/최솟값 출력

## 코드
```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10 ** 6)
def div(a, b):
    if(a*b > 0):
        return a//b
    else:
        return -(-a // b)
        
N = int(input())
arr = list(map(int, input().split()))
start = arr[0]
arr = arr[1:]
visited = set()
result = set()
remain = list(map(int, input().split()))
def dfs(cur, level):
    if(level == len(arr)):
        result.add(cur)
        return
    next = arr[level]
    if(remain[0] > 0):
        remain[0] -= 1
        dfs(cur + next, level+1)
        remain[0] += 1
    if(remain[1] > 0):
        remain[1] -= 1
        dfs(cur - next, level+1)
        remain[1] += 1
    if(remain[2] > 0):
        remain[2] -= 1
        dfs(cur * next, level+1)
        remain[2] += 1
    if(remain[3] > 0):
        remain[3] -= 1
        dfs(div(cur, next), level+1)
        remain[3] += 1
dfs(start, 0)
print(max(result))
print(min(result))
```

## 질문 & 실수 정리

### 새로 배운 것

#### C++14 스타일 정수 나눗셈 (Truncate toward zero)
파이썬의 `//` 연산자는 음수일 때 음의 무한대 방향으로 내림(floor division)하지만, C++14는 0 방향으로 절삭(truncate)한다. 예를 들어 `-7 // 2`는 파이썬에서 `-4`이지만 C++14에서는 `-3`이다. `int(a / b)`를 사용하면 C++14와 동일한 결과를 얻을 수 있다.
- **핵심 원리**: `int()`는 소수점을 버려 0 방향으로 절삭

#### 백트래킹에서 상태 복원
전역 리스트(`remain`)를 직접 수정하며 탐색할 때, 재귀 호출 후 반드시 값을 원래대로 복원해야 한다. 이를 통해 다른 분기에서도 올바른 상태로 탐색할 수 있다.
- **핵심 원리**: 선택 → 재귀 → 복원 패턴

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `next = arr[0]` (항상 첫 번째 원소 참조) | `next = arr[level]` (현재 단계에 맞는 원소 참조) |
| `remain[2] *= 1` (곱셈 연산자 개수 변화 없음) | `remain[2] -= 1` (사용 시 개수 감소) |
| 곱셈에서 `cur + next` (덧셈 연산 수행) | `cur * next` (곱셈 연산 수행) |
| `print(len(visited))` (빈 set의 길이 출력) | `print(max(result))`, `print(min(result))` |

## AI 코드 리뷰

### 개선할 점

1. **미사용 변수 제거**: `visited`가 선언만 되어 있고 사용되지 않으므로 제거한다.
2. **내장 함수명 충돌 회피**: `next`는 파이썬 내장 함수와 이름이 겹기므로 `num` 등으로 변경한다.
3. **결과 저장 방식 개선**: `set` 대신 전역 변수 `max_val`, `min_val`로 관리하면 의도가 명확하고 메모리도 절약된다.
4. **나눗셈 함수 간소화**: `int(a / b)`로 C++14 truncate 동작을 간결하게 구현할 수 있다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

def div(a, b):
    return int(a / b)

N = int(input())
arr = list(map(int, input().split()))
remain = list(map(int, input().split()))

max_val = -1e9
min_val = 1e9

def dfs(cur, level):
    global max_val, min_val
    if level == N - 1:
        max_val = max(max_val, cur)
        min_val = min(min_val, cur)
        return
    num = arr[level + 1]
    if remain[0] > 0:
        remain[0] -= 1
        dfs(cur + num, level + 1)
        remain[0] += 1
    if remain[1] > 0:
        remain[1] -= 1
        dfs(cur - num, level + 1)
        remain[1] += 1
    if remain[2] > 0:
        remain[2] -= 1
        dfs(cur * num, level + 1)
        remain[2] += 1
    if remain[3] > 0:
        remain[3] -= 1
        dfs(div(cur, num), level + 1)
        remain[3] += 1

dfs(arr[0], 0)
print(max_val)
print(min_val)
```
