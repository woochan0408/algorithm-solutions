# 백준 1189 🏠 컴백홈 파이썬

## 느낀점
>
- 백트래킹이 항상 약하다.. 
(백트래킹 문제인데 BFS로 품..)
- 방문을 추적한다 -> 백트래킹 고려해보기.
(방문한 노드를 set로 모두 관리하면 시간초과 가능성이 있다.)
- 시험 전에 오답노트 하고 N과 M 정주행하기

## 흐름
1. BFS로 시작점 `(N-1, 0)`부터 탐색하며, 각 상태에 `(x, y, visited_set)`을 큐에 저장
2. 레벨 단위로 BFS를 진행해 거리 D에 도달하면 도착점 `(0, M-1)` 여부 확인
3. 각 상태마다 `set.copy()`로 visited를 복사해 경로별 독립적인 방문 기록 유지

## 코드
```python
import sys
input = sys.stdin.readline
from collections import deque
grid = []
N, M, D = map(int, input().split())
for i in range(N):
    grid.append([])
    sub = input().strip()
    
    for j in range(M):
        if(sub[j] == '.'):
            grid[i].append(True)
        else:
            grid[i].append(False)
            
dq = deque([(N-1,0, {(N-1, 0)})])
level = 1
while dq and level < D:
    for _ in range(len(dq)):
        x, y, cur = dq.popleft()
        for dx, dy in [[0, 1], [0, -1], [1, 0], [-1, 0]]:
            nx = x + dx
            ny = y + dy
    
            if(0 <= nx < N and 0 <= ny < M and (nx, ny) not in cur and grid[nx][ny]):
                next = cur.copy()
                next.add((nx, ny))
                dq.append((nx, ny, next))
    level += 1
answer = 0
for cur in dq:
    if(cur[0] == 0 and cur[1] == M-1):
        answer += 1
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### BFS vs DFS + 백트래킹 선택 기준
경로 탐색 문제에서 **모든 경로를 열거**해야 할 때, BFS는 각 상태마다 독립적인 방문 기록을 복사해서 들고 다녀야 하므로 메모리와 시간이 폭발한다. 반면 DFS + 백트래킹은 하나의 visited 배열을 공유하면서 "방문 → 재귀 → 해제" 패턴으로 모든 경로를 탐색할 수 있다.
- **핵심 원리**: DFS는 한 경로를 끝까지 탐색한 뒤 되돌아오므로, 돌아올 때 방문 해제하면 다른 경로에서 해당 칸을 다시 사용할 수 있다

#### set 초기화 시 튜플 주의
`set((a, b))`는 튜플을 풀어서 `{a, b}`가 된다. 튜플 하나를 원소로 넣으려면 `{(a, b)}`로 리터럴을 사용해야 한다.
- **핵심 원리**: `set(iterable)`은 이터러블의 각 원소를 집합에 넣는다. 튜플도 이터러블이므로 내부 값이 풀린다

#### 얕은 복사 vs 깊은 복사
set 안에 불변 객체(튜플, 정수 등)만 있으면 `set.copy()`(얕은 복사)로 충분하다. `copy.deepcopy()`는 내부에 가변 객체(리스트 등)가 중첩된 경우에만 필요하다.
- **핵심 원리**: 얕은 복사는 원소의 참조만 복사하지만, 원소가 불변이면 원본과 독립적으로 동작한다

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`set((N-1, 0))` → 정수 2개가 원소로 들어감|`{(N-1, 0)}` → 튜플 1개가 원소로 들어감|
|`copy.deepcopy(cur)` → 불필요하게 무거운 복사|`cur.copy()` → 불변 원소만 있으면 얕은 복사로 충분|

## AI 코드 리뷰

### 개선할 점

1. **grid 구성 간소화**: boolean 리스트로 변환하지 않고 문자열 리스트 그대로 사용하면 코드가 짧아진다. `grid[nx][ny] == '.'`로 비교하면 충분하다.

2. **DFS + 백트래킹으로 전환**: BFS에서 매 상태마다 visited set을 복사하는 대신, DFS 재귀에서 하나의 visited 배열을 "방문 → 탐색 → 해제" 패턴으로 재사용하면 복사 비용이 완전히 제거된다.

3. **방향 리스트 튜플화**: `[[0, 1], ...]`을 튜플로 바꾸면 불변 객체라 약간의 성능 이점이 있다.

4. **global 대신 리스트 활용**: `answer`를 `[0]`으로 만들면 `global` 키워드 없이 클로저로 접근할 수 있다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, M, D = map(int, input().split())
grid = [input().strip() for _ in range(N)]

visited = [[False] * M for _ in range(N)]
visited[N - 1][0] = True
answer = [0]

def dfs(x, y, level):
    if level == D:
        if x == 0 and y == M - 1:
            answer[0] += 1
        return
    for dx, dy in ((-1, 0), (1, 0), (0, -1), (0, 1)):
        nx, ny = x + dx, y + dy
        if 0 <= nx < N and 0 <= ny < M and not visited[nx][ny] and grid[nx][ny] == '.':
            visited[nx][ny] = True
            dfs(nx, ny, level + 1)
            visited[nx][ny] = False

dfs(N - 1, 0, 1)
print(answer[0])
```
