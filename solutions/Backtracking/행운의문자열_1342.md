## 느낀점
>
- 메모이제이션을 안 써서 틀렸다..
- counter를 memo에 저장할 생각하기가 힘들었다..
- 좋은문제. 꼭 다시 풀어보자.

---

## 실패한 코드 흐름
1. Counter로 각 문자의 빈도수를 구한다
2. DFS로 매 단계마다 마지막 문자와 다른 문자를 선택해 문자열을 만든다
3. 길이가 N이 되면 `global answer`를 1 증가시킨다
4. 메모이제이션 없이 모든 경우를 탐색 → **같은 상태를 반복 계산**

## 실패한 코드
```python
from collections import Counter
import sys
input = sys.stdin.readline
string = input().strip()
counter = Counter(string)
N = len(string)
answer = 0
def dfs(n, c):
    global answer
    if(n == N):
        answer += 1
    for key in counter:
        if(counter[key] > 0 and key != c):
            counter[key] -= 1
            dfs(n+1, key)
            counter[key] += 1
dfs(0, '?')
print(answer)
```

**문제점**: 메모이제이션 없이 순수 DFS만 사용해 같은 상태를 반복 계산 → 최악의 경우 O(N!) 시간초과

---

## 성공한 코드 흐름
1. Counter로 각 문자의 빈도수를 구한다
2. DFS에서 현재 상태를 `(남은 문자 개수 튜플, 마지막 문자)`로 정의한다
3. 상태가 memo에 있으면 캐싱된 값을 바로 반환한다
4. 없으면 마지막 문자와 다른 문자를 선택해 재귀 호출, 결과를 합산한다
5. 계산 결과를 memo에 저장 후 반환한다

## 성공한 코드
```python
from collections import Counter
import sys
input = sys.stdin.readline
string = input().strip()
counter = Counter(string)
keys = sorted(counter.keys())
N = len(string)
memo = {}
def to_state(last_char):
    return (tuple(counter[k] for k in keys), last_char)
def dfs(n, last_char):
    if n == N:
        return 1
    state = to_state(last_char)
    if state in memo:
        return memo[state]
    result = 0
    for key in keys:
        if counter[key] > 0 and key != last_char:
            counter[key] -= 1
            result += dfs(n + 1, key)
            counter[key] += 1
    memo[state] = result
    return result
print(dfs(0, '?'))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 딕셔너리 기반 메모이제이션
`lru_cache` 없이도 딕셔너리를 메모 테이블로 활용할 수 있다. 상태를 해시 가능한 키(튜플)로 변환하고, 계산 결과를 값으로 저장한다.
- **핵심 원리**: 함수 진입 시 memo 확인 → 있으면 바로 리턴, 없으면 계산 후 저장
- **주의**: 딕셔너리 키는 해시 가능한 타입(튜플, 문자열 등)이어야 함

#### global 누적 vs return 방식
메모이제이션을 쓰려면 `global answer`로 누적하는 방식이 아닌, 함수가 값을 **return**하는 구조여야 한다. return 값이 있어야 캐싱이 가능하다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 메모이제이션 없이 순수 DFS → TLE | 상태 캐싱으로 중복 계산 제거 |
| `memo` 변수명과 함수명 충돌 | 변수명과 함수명을 다르게 지정 |
| global answer 누적 방식 | return으로 값을 돌려주는 구조 |

## AI 코드 리뷰

### 개선할 점

1. **`n` 파라미터 제거 가능**: `n`은 `N - sum(counter.values())`로 계산 가능하므로 파라미터에서 제거하면 함수 시그니처가 깔끔해진다.

2. **`keys` 정렬 불필요**: 정렬은 상태 튜플의 일관성을 위해 넣었지만, Counter는 삽입 순서를 유지하므로 같은 문자열에선 정렬 없이도 항상 같은 순서가 보장된다. 다만 명시적 정렬이 의도를 더 명확히 드러내므로 유지해도 무방하다.

## 수정된 코드
```python
from collections import Counter
import sys

input = sys.stdin.readline

string = input().strip()
counter = Counter(string)
keys = sorted(counter.keys())
N = len(string)
memo = {}


def to_state(last_char):
    return (tuple(counter[k] for k in keys), last_char)


def dfs(last_char):
    state = to_state(last_char)
    if state in memo:
        return memo[state]

    # 남은 문자가 없으면 행운의 문자열 완성
    if sum(counter[k] for k in keys) == 0:
        return 1

    result = 0
    for key in keys:
        if counter[key] > 0 and key != last_char:
            counter[key] -= 1
            result += dfs(key)
            counter[key] += 1

    memo[state] = result
    return result


print(dfs('?'))
```

## 브루트포스 아이디어

`itertools.permutations`로 모든 순열을 생성한 뒤, `set`으로 중복을 제거하고 인접 문자가 같지 않은 것만 카운트하는 방법. 문자열 길이가 최대 10이라 10! = 3,628,800이지만, 중복 문자가 많으면 set으로 걸러져 줄어든다. 다만 전부 다른 문자일 경우 메모리와 시간이 빡빡하다.

```python
from itertools import permutations

s = input().strip()
count = 0
seen = set()

for p in permutations(s):
    if p in seen:
        continue
    seen.add(p)
    lucky = True
    for i in range(len(p) - 1):
        if p[i] == p[i + 1]:
            lucky = False
            break
    if lucky:
        count += 1

print(count)
```
