# 백준 19637 ⚔️ IF문 좀 대신 써줘 파이썬

## 느낀점
>
- 제발 문제 잘 읽자!!!!!!!!!
- 상한선만 비내림차순이다 -> 입력값에 대해선 이분탐색
- 근데 비내림차순이면 오름차순 아닌가.. 일기예보인줄

## 흐름

1. 칭호와 전투력 상한값을 입력받아 저장
2. 각 캐릭터의 전투력에 대해 이분탐색으로 해당하는 칭호 찾기
3. 전투력 이상인 상한값 중 가장 작은 인덱스의 칭호 출력

## 코드

```python
"""
3 8
WEAK 10000
NORMAL 100000
STRONG 1000000
0
9999
10000
10001
50000
100000
500000
1000000
"""
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
lim = []
# 순서가 있는 칭호
for _ in range(N):
    a, b = input().split()
    lim.append((a, int(b)))
for _ in range(M):
    m = int(input())
    l = 0
    r = len(lim)
    ans = -1
    while l <= r:
        mid = (l+r) // 2
        cur = lim[mid][1]
        if(m <= cur):
            ans = mid
            r = mid - 1
        else:
            l = mid + 1
    print(lim[ans][0])
```

## 질문 & 실수 정리

### 새로 배운 것

#### bisect_left 활용
이분탐색을 직접 구현하지 않고 파이썬 표준 라이브러리 `bisect_left`를 사용하면 코드가 간결해진다. `bisect_left(limits, power)`는 `power` 이상인 첫 위치를 반환하므로, 상한값 리스트에서 조건을 만족하는 최소 인덱스를 바로 찾을 수 있다.
- **핵심 원리**: 정렬된 리스트에서 삽입 위치(왼쪽 기준)를 O(log N)에 반환
- **시간복잡도**: O(log N)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`i`를 전역으로 유지하며 증가만 시킴 (입력이 오름차순이라고 가정)|각 쿼리마다 독립적으로 이분탐색 수행|

## AI 코드 리뷰

### 개선할 점

1. **`r` 초기값**: `r = len(lim)`은 인덱스 범위를 벗어날 수 있다. 문제 조건상 유효한 입력만 들어오므로 통과하지만, `r = len(lim) - 1`이 안전하다.

2. **`bisect` 모듈 활용**: 파이썬 표준 라이브러리 `bisect_left`를 사용하면 직접 이분탐색을 구현할 필요가 없다.

3. **변수명**: `lim`보다 `titles`가 의미를 더 명확히 전달한다.

## 수정된 코드

```python
import sys
from bisect import bisect_left

input = sys.stdin.readline

N, M = map(int, input().split())

titles = []
limits = []
for _ in range(N):
    name, power = input().split()
    titles.append(name)
    limits.append(int(power))

for _ in range(M):
    power = int(input())
    idx = bisect_left(limits, power)
    print(titles[idx])
```
