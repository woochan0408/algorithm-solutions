# 백준 1654 ✂️ 랜선 자르기 파이썬

## 느낀점
>
- 재풀이 성공 (오답노트)

## 흐름

1. K개의 랜선을 잘라서 N개 이상의 동일한 길이 랜선을 만들어야 함
2. 만들 수 있는 랜선의 최대 길이를 구하는 문제
3. 길이를 이분탐색으로 찾음
   - 특정 길이로 잘랐을 때 N개 이상 만들 수 있으면 → 더 긴 길이 시도
   - N개 미만이면 → 더 짧은 길이 시도
4. 탐색 범위: 1 ~ max(arr)

## 코드

```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
arr = []
for _ in range(N):
    arr.append(int(input()))
l = 0
r = max(arr)
ans = -1
while(l <= r):
    mid = (l + r) // 2
    hap = 0
    for pipe in arr:
        hap += pipe//mid
    # 합이 작다
    # 너무 크게 잘랐다.
    # 아래로 가자
    if(hap < M):
        r = mid - 1
    else:
        ans = max(ans, mid)
        l = mid + 1
print(ans)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 이분탐색에서 ans 변수 없이 답 찾기
조건을 만족하는 최댓값을 찾을 때, 별도의 ans 변수 없이 탐색 종료 후 `r` 값이 답이 된다. `count >= N`이면 `l = mid + 1`로 더 큰 값을 탐색하고, 아니면 `r = mid - 1`로 줄인다. 반복 종료 시 `r`이 조건을 만족하는 최대값을 가리킨다.
- **핵심 원리**: upper bound 방식으로 탐색 후 `r` 반환

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `l = 0` (ZeroDivisionError 가능) | `l = 1` (최소 길이는 1cm) |
| 변수명 `N, M` (문제와 불일치) | `K, N` (문제 명세와 일치) |

## AI 코드 리뷰

### 개선할 점

1. **탐색 시작점**: `l = 0`은 `mid = 0`일 때 나눗셈 오류 발생 가능. 랜선 길이는 최소 1cm이므로 `l = 1`로 시작해야 안전함

2. **변수명**: 문제에서 K는 가진 랜선 개수, N은 필요한 랜선 개수인데 코드에서 반대로 사용함. 가독성을 위해 문제와 일치시키는 것이 좋음

3. **ans 변수 불필요**: 이분탐색 종료 후 `r`이 조건을 만족하는 최댓값이므로 별도 변수 없이 `print(r)` 가능

4. **리스트 컴프리헨션**: 입력부와 합계 계산을 한 줄로 간결하게 작성 가능

## 수정된 코드

```python
import sys
input = sys.stdin.readline

K, N = map(int, input().split())
arr = [int(input()) for _ in range(K)]

l = 1
r = max(arr)

while l <= r:
    mid = (l + r) // 2
    count = sum(pipe // mid for pipe in arr)
    
    if count >= N:
        l = mid + 1
    else:
        r = mid - 1

print(r)
```
