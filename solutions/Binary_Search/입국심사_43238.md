## 느낀점

- 이분탐색 -> 답이 숫자로 떨어진다? -> 의심을 해보자.
- 이 문제도 답이 정수로 떨어지고 각각에 대한 연산이 쉽기 떄문에 이분탐색이다.

## 흐름

1. 이분탐색 범위를 `1 ~ n * max(times)`로 설정한다.
2. 중간값 `mid`(시간)를 기준으로, 각 심사관이 처리할 수 있는 사람 수를 합산한다.
   - 심사관 `cur`이 `mid`분 동안 처리 가능한 인원: `mid // cur`
3. 합산 인원이 `n` 이상이면 시간을 줄이고(`r = mid - 1`), 미만이면 늘린다(`l = mid + 1`).
4. 조건을 만족하는 최소 시간을 반환한다.

## 코드
```python
def solution(n, times):
    answer = float('inf')
    l = 1
    r = n*max(times)
    
    while l <= r:
        mid = (l+r)//2
        
        count = 0
        for cur in times:
            count += mid//cur
        
        if(count >= n):
            answer = min(answer, mid)
            r = mid - 1
        else:
            l = mid + 1
    
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### 매개변수 탐색 (Parametric Search)
"최솟값을 구하라"는 문제에서, 답을 직접 구하는 대신 **답을 미리 정해놓고 가능한지 판별**하는 기법이다. 이 문제에서는 "T분이 주어졌을 때 n명을 처리할 수 있는가?"로 질문을 바꾸면, 판별 함수가 `sum(T // t for t in times) >= n`으로 단순해진다. 판별 결과가 단조성(monotonic)을 가지면 이분탐색을 적용할 수 있다.
- **핵심 원리**: 최적화 문제를 결정 문제(Yes/No)로 변환 → 이분탐색으로 경계값 탐색
- **시간복잡도**: O(M × log(N × max(times))), M은 심사관 수

## AI 코드 리뷰

### 개선할 점

1. **`answer` 변수 불필요**: `count >= n`일 때 `r = mid - 1`로 범위를 줄이면, 루프 종료 시 `l`이 곧 조건을 만족하는 최솟값이다. 별도의 `answer` 변수와 `min()` 비교 없이 `return l`로 충분하다.
2. **`sum()` 활용**: `for` 루프 대신 `sum(mid // cur for cur in times)`로 한 줄로 표현하면 더 간결하다.

## 수정된 코드
```python
def solution(n, times):
    l = 1
    r = n * max(times)

    while l <= r:
        mid = (l + r) // 2
        count = sum(mid // cur for cur in times)

        if count >= n:
            r = mid - 1
        else:
            l = mid + 1

    return l
```
