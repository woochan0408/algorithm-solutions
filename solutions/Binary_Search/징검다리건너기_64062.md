# 프로그래머스 64062 🪨 징검다리 건너기 파이썬

## 느낀점
>
- 첫 코드 효율성 테스트에서 실패했다.
- 이분탐색 떠올리지도 못 했다
(항상 못 떠올리는 듯..)
- 문제 풀 때 한번정도는 이분탐색으로 될 지 고민해보자.
- 재밌는 문제다.

## 실패한 코드 흐름
1. 힙에서 가장 작은 값을 꺼내 전체 배열에서 그만큼 빼기
2. 배열을 순회하며 연속 0이 k개 이상이면 해당 값을 반환
3. 힙에서 하나 꺼낼 때마다 전체 배열 O(N) 순회 → 최악 O(N²)으로 시간초과

## 실패한 코드
```python
import heapq
def solution(stones, k):
    heap = list(stones)
    heapq.heapify(heap)
    N = len(stones)
    
    before = 0
    while True:
        cur = heapq.heappop(heap)
        minus = cur - before
        if(minus == 0):
            continue
        for i in range(N):
            stones[i] = 0 if stones[i] - minus <= 0 else stones[i] - minus
        
        i = 0
        zero = 0
        while i < N:
            if(stones[i] == 0):
                zero += 1
            else:
                zero = 0
            if(zero == k):
                return cur
            i += 1
        before = cur
```

**문제점**: 힙에서 값을 꺼낼 때마다 전체 배열을 순회하므로 O(N²)이 되어 N=200,000에서 시간초과 발생

## 성공한 코드 흐름

1. 이분탐색(파라메트릭 서치)으로 접근: "mid명이 건널 수 있는가?"를 판별
2. stones[i] - mid < 0인 돌은 mid번째 사람이 밟을 때 이미 0 → 건너뛸 대상
3. 연속으로 건너뛸 돌이 k개 이상이면 mid명은 불가능 → 범위를 줄임
4. 가능하면 더 많은 인원을 시도 → 범위를 늘림

## 성공한 코드
```python
import heapq
def solution(stones, k):
    l = 0
    r = max(stones)
    N = len(stones)
    answer = 0
    while l <= r:
        mid = (l + r) // 2
        
        zero = 0
        can = True
        for i in range(N):
            if(stones[i] - mid < 0):
                zero += 1
            else:
                zero = 0
            if(zero == k):
                can = False
                break
        if(can):
            answer = max(mid, answer)
            l = mid + 1
        else:
            r = mid - 1
    return answer
```

## AI 코드 리뷰

### 개선할 점

1. **`answer` 변수 제거**: 이분탐색이 끝나면 `r`이 곧 정답이므로 `answer` 변수 없이 `return r`로 간결하게 처리 가능
2. **`import heapq` 제거**: 성공한 코드에서는 힙을 사용하지 않으므로 불필요한 import
3. **변수명 개선**: `zero`보다 `gap` 또는 `consecutive_zero`가 연속된 빈 칸을 세는 의미를 더 명확하게 전달

## 수정된 코드
```python
def solution(stones, k):
    left = 0
    right = max(stones)
    n = len(stones)

    while left <= right:
        mid = (left + right) // 2

        gap = 0
        can_cross = True
        for i in range(n):
            if stones[i] - mid < 0:
                gap += 1
            else:
                gap = 0
            if gap == k:
                can_cross = False
                break

        if can_cross:
            left = mid + 1
        else:
            right = mid - 1

    return right
```
