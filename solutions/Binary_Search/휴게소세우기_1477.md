# 백준 1477 🛣️ 휴게소 세우기 파이썬

## 느낀점
>
- 좋은 문제다
- 처음 그리디로 접근해서 실패
- 문제 변형을 잘 할 줄 알아야 한다
(모든 구간을 X 아래로 만들 수 있냐? -> 이분탐색)

---

## 실패한 코드 흐름
1. 각 구간의 길이를 최대 힙에 넣는다.
2. M번 반복하면서 가장 긴 구간을 꺼내 절반으로 나눠 다시 힙에 넣는다.
3. 마지막에 힙에서 가장 큰 값을 출력한다.

## 실패한 코드
```python
import sys, heapq
input = sys.stdin.readline
N, M, L = map(int, input().split())
arr = list(map(int, input().split()))
arr.append(0)
arr.append(L)
arr.sort()

heap = []
for i in range(len(arr)-1):
    heapq.heappush(heap, -(arr[i+1] - arr[i]))
for i in range(M):
    cur = -heapq.heappop(heap)
    a = cur//2
    b = cur - a
    heapq.heappush(heap, -a)
    heapq.heappush(heap, -b)
print(-heapq.heappop(heap))
```

**문제점**: 그리디로 매번 가장 긴 구간을 반으로 나누면, 원래 하나의 구간을 여러 번 쪼갤 때 최적 분할이 보장되지 않는다. 예를 들어 길이 7인 구간에 휴게소 2개를 세우면 그리디는 7→(3,4)→(3,2,2)로 최댓값 3이지만, 최적 분할은 (2,2,3)이나 (2,3,2) 등으로 동일하게 3이 나오는 경우도 있지만, 다른 구간과의 조합에서 전체 최적이 깨질 수 있다.

---

## 성공한 코드 흐름

1. 0과 L을 포함하여 기존 휴게소 위치를 정렬하고, 인접 구간의 길이 리스트를 만든다.
2. "최댓값을 X 이하로 만들 수 있는가?"를 판별하는 이분탐색(파라메트릭 서치)을 수행한다.
3. 각 구간에 대해 길이를 X 이하로 만들기 위해 필요한 휴게소 수를 계산한다.
   - 구간 길이가 X로 나누어떨어지면: `구간 // X - 1`개 필요
   - 아니면: `구간 // X`개 필요
4. 필요한 총 개수가 M 이하면 가능 → 더 작은 X를 탐색, 초과하면 불가능 → 더 큰 X를 탐색

## 성공한 코드
```python
import sys, math
input = sys.stdin.readline
N, M, L = map(int, input().split())
arr = list(map(int, input().split()))
arr.append(0)
arr.append(L)
arr.sort()
lList = []
for i in range(len(arr) - 1):
    lList.append(arr[i+1] - arr[i])
    
lList.sort()
l = 1
r = max(lList)
answer = float('inf')
while l <= r:
    mid = (l+r) // 2
    req = 0
    for cur in lList:
        plus = 0
        if(cur % mid) == 0:
            plus = cur // mid - 1
        else:
            plus = math.floor(cur / mid)
        req += plus
        if(req > M):
            break
    # 개수 초과함 -> 범위를 키우자
    if(req > M):
        l = mid + 1
    else:
        answer = min(answer, mid)
        r = mid - 1
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 파라메트릭 서치 (Parametric Search)
"최댓값의 최솟값"이나 "최솟값의 최댓값"처럼 최적화 문제를 결정 문제로 바꿔 이분탐색으로 푸는 기법이다. "답이 X일 때 가능한가?"라는 판별 함수를 만들고, X의 범위에서 이분탐색으로 경계를 찾는다.
- **핵심 원리**: 답의 범위가 단조성(monotonic)을 가질 때, 가능/불가능의 경계를 이분탐색으로 탐색
- **시간복잡도**: O(N × log(범위))

#### 구간 분할 시 필요한 개수 계산
길이 `cur`인 구간을 최대 `mid` 이하로 만들려면 필요한 휴게소 수는 `(cur - 1) // mid`로 한 줄로 계산할 수 있다. 나누어떨어지는 경우와 아닌 경우를 분기 없이 처리 가능하다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|그리디(매번 최대 구간을 반분)로 접근|파라메트릭 서치로 답을 이분탐색|
|`range(N - 1)`로 구간 개수 계산|0과 L을 추가했으므로 `range(len(arr) - 1)` 사용|
|`answer = max(answer, mid)` (최댓값 갱신)|`answer = min(answer, mid)` (최솟값 갱신)|

## AI 코드 리뷰

### 개선할 점

1. **`math` 모듈 불필요**: 나누어떨어지는 경우 분기를 `(cur - 1) // mid`로 통합하면 `math.floor` 없이도 동일한 결과를 얻을 수 있다.

2. **변수명 개선**: `lList`는 의미가 모호하므로 `gaps`처럼 구간을 나타내는 이름이 적절하다. `l`, `r`도 `lo`, `hi`로 쓰면 숫자 1과 혼동을 방지할 수 있다.

3. **구간 리스트 생성 간소화**: 리스트 컴프리헨션으로 한 줄로 표현 가능하다.

4. **정렬 불필요**: `lList.sort()`는 이분탐색 로직에 영향을 주지 않으므로 제거해도 된다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, M, L = map(int, input().split())
arr = list(map(int, input().split()))
arr.extend([0, L])
arr.sort()

gaps = [arr[i+1] - arr[i] for i in range(len(arr) - 1)]

lo, hi = 1, max(gaps)
answer = hi

while lo <= hi:
    mid = (lo + hi) // 2
    req = sum((g - 1) // mid for g in gaps)
    
    if req > M:
        lo = mid + 1
    else:
        answer = mid
        hi = mid - 1

print(answer)
```
