# 백준 1052 🧴 물병 파이썬

## 느낀점
>
- 비트 느낌이 났지만 비트마스킹 개념이 부족해서 구현으로 풀었다.
- AI 코드가 내 코드를 반토막 내버렸다.
- 나중에 비트마스킹으로 풀어보자. 
- 불가능하면 `-1` 출력하라고 해서 더 헷갈렸다. 
(해당 경우 없음)

## 흐름

1. 딕셔너리로 `dic[용량] = 개수`를 관리한다
2. `update()`: 같은 용량 물병이 2개 이상이면 합쳐서 2배 용량으로 올린다 (더 이상 합칠 수 없을 때까지 반복)
3. 합친 후 남은 물병 수가 K 이하면 종료
4. K 초과면 가장 작은 용량의 물병을 1개 추가 구매하고 다시 합치기 반복
5. 추가 구매한 총 개수를 출력

## 코드

```python
from collections import defaultdict
# 배열에 저장 arr[i] = 값이 i인 물통 개수
# 물통이 N개 니까 최대 N리터
N, K = map(int, input().split())
dic = defaultdict(int)
dic[1] = N
def update():
    changed = False
    while True:
        # Pass N
        found = False
        keySet = []
        for key in dic:
            keySet.append(key)
        for key in keySet:
            if(dic[key] > 1):
                found = True
                changed = True
                dic[key*2] += dic[key] // 2
                
                if(dic[key]%2 == 0):
                    del dic[key]
                else:
                    dic[key] = 1
        if(not found):
            break
    return changed
def count():
    hap = 0
    for key in dic:
        hap += dic[key]
    return hap
# 모든 작업이 완료되면 이제 나누지 못하는 값만 남아있음
# 여기서 K 아래를 만들자
# 초기 업데이트
answer = 0
while True:
    # 압축하자
    result = update()
    # 만족
    hap = count()
    if(hap <= K):
        break
    #key 중 가장 작은 값 찾자
    minKey = float('inf')
    for key in dic:
        minKey = min(key, minKey)
    answer += minKey
    dic[minKey] += 1
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 딕셔너리 순회 중 키 변경 금지
파이썬에서 `for key in dic:` 루프를 돌면서 `dic`에 키를 추가하거나 삭제하면 `RuntimeError: dictionary changed size during iteration`이 발생한다. 딕셔너리는 내부적으로 해시 테이블 구조이기 때문에, 순회 도중 크기가 바뀌면 이터레이터가 무효화된다.
- **핵심 원리**: 순회 전에 `list(dic.keys())`로 키 목록을 복사해두고, 복사본을 순회하면서 원본을 수정해야 안전하다.

#### 이 문제의 비트마스킹 해석
같은 용량끼리만 합칠 수 있고, 합치면 2배가 되는 구조는 이진수의 올림(캐리)과 동일하다. N개의 1리터 물병을 합치면 결국 N의 이진 표현에서 각 비트가 해당 용량의 물병 존재 여부를 나타낸다. 따라서 **비어있지 않은 물병의 수 = N의 이진수에서 1의 개수(`bin(N).count('1')`)** 가 된다.
- **핵심 원리**: 물병을 추가 구매(N에 더하기)해서 1의 개수를 K 이하로 만드는 최솟값을 구하면 된다. 가장 낮은 비트를 올려서 캐리시키면 1의 개수가 줄어든다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `dic[key*2] + dic[key] // 2` (연산 결과 미저장) | `dic[key*2] += dic[key] // 2` |
| `for key in dic:` 루프 안에서 `del dic[key]` | `list(dic.keys())`로 복사 후 순회 |

## AI 코드 리뷰

### 개선할 점

1. **비트마스킹으로 대폭 간소화 가능**: 딕셔너리로 물병 상태를 관리하는 현재 방식은 문제의 본질(이진수 비트 조작)을 직접 구현한 것이다. `bin(N).count('1')`로 물병 수를 바로 알 수 있고, 가장 낮은 비트만큼 더하면 캐리가 발생해 비트 수가 줄어든다. 전체 코드가 10줄 이내로 줄어든다.

2. **변수명 개선**: `dic` → `bottles`, `hap` → `bottle_count`, `minKey` → `min_volume` 등 의미가 드러나는 이름이 더 좋다.

3. **`count()` 함수 간소화**: `sum(dic.values())`로 한 줄로 대체 가능하다.

## 수정된 코드 (비트마스킹)

```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())

answer = 0
while bin(N).count('1') > K:
    # 가장 낮은 비트(최소 용량 물병)를 올려서 캐리 발생
    lowest_bit = N & -N
    answer += lowest_bit
    N += lowest_bit

print(answer)
```
