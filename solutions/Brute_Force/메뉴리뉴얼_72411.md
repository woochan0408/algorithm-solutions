# 프로그래머스 72411 🍽️ 메뉴 리뉴얼 파이썬

## 느낀점
>
- 실패했다.
- 조합 먼저 만들 생각을 하지 않고 짝을 먼저 찾을 생각했다.
- 방향을 잘못 잡으니 오래 고민해도 풀지 못했다
(투포인터, 문자 전체 순회 ...)
- 조합을 언제 계산할 지 순서만 바뀌어도 로직이 완전 바뀌는구나
(나중에 꼭 다시 풀어보기.)

## 흐름
1. 각 course 길이(n)에 대해 모든 주문에서 n개짜리 조합을 생성
2. 조합을 알파벳 순 정렬 후 문자열로 변환하여 카운팅
3. 각 길이별로 가장 많이 등장한 조합(최소 2회 이상)을 결과에 추가
4. 최종 결과를 사전순 정렬하여 반환

## 코드
```python
from itertools import combinations
from collections import defaultdict
def solution(orders, course):
    N = len(orders)
    arr = [[] for i in range(N)]
    answer = []
    
    def solve(n):
        counter = defaultdict(int)
        for cur in orders:
            for comb in combinations(cur, n):
                comb = list(comb)
                comb.sort()
                s = ''.join(comb)
                counter[s] += 1
        counter = list(counter.items())
        counter.sort(key = lambda x : (-x[1], x[0]))
        if(len(counter) < 1):
            return
        maxCount = counter[0][1]
        
        if(maxCount < 2):
            return
        i = 0
        while i < len(counter) and counter[i][1] == maxCount:
            answer.append(counter[i][0])
            i += 1
    
    for req in course:
        solve(req)
    answer.sort()
    return answer
```

## 실수 정리

|틀린 것|올바른 것|
|---|---|
|조합 결과를 정렬하지 않아 `"XW"`와 `"WX"`가 다르게 카운팅됨|조합을 정렬 후 join하여 동일한 메뉴 조합이 같은 키로 카운팅되도록 처리|
|`counter` 리스트가 비어있을 때 `counter[0][1]` 접근으로 IndexError 발생|빈 리스트 체크(`len(counter) < 1`) 후 early return 처리|

## AI 코드 리뷰

### 개선할 점

1. **미사용 변수 제거**: `N`과 `arr`가 선언만 되고 사용되지 않아 제거 필요
2. **사전 정렬로 조합 정렬 생략**: `orders`의 각 문자열을 미리 정렬해두면 `combinations` 결과가 자동으로 정렬된 순서로 나오므로, 매 조합마다 sort할 필요가 없음
3. **Counter 활용**: `defaultdict(int)` 대신 `Counter`를 사용하면 `most_common()`으로 최대 빈도를 간결하게 추출 가능
4. **max값 추출 간소화**: while 루프 대신 리스트 컴프리헨션으로 최대 빈도 조합을 필터링하면 더 읽기 쉬움

## 수정된 코드
```python
from itertools import combinations
from collections import Counter

def solution(orders, course):
    answer = []
    
    for n in course:
        counter = Counter()
        for cur in orders:
            for comb in combinations(sorted(cur), n):
                counter[''.join(comb)] += 1
        
        if not counter:
            continue
        
        max_count = max(counter.values())
        if max_count < 2:
            continue
        
        answer += [menu for menu, cnt in counter.items() if cnt == max_count]
    
    answer.sort()
    return answer
```
