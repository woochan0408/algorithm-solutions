## 느낀점
>
- 완전탐색 기본문제

## 흐름

1. 수포자 1, 2, 3의 찍기 패턴을 각각 리스트로 정의
2. 정답 배열을 순회하면서 각 수포자의 패턴과 비교 (모듈러 연산으로 순환)
3. 각 수포자의 맞힌 개수를 딕셔너리에 저장
4. 최대 점수를 구한 뒤, 해당 점수를 받은 수포자를 오름차순으로 반환

## 코드
```python
def solution(answers):
    result = {1 : 0, 2: 0, 3: 0}
    
    # 5개
    case_1 = [1, 2, 3, 4, 5]
    
    # 8개
    case_2 = [2, 1, 2, 3, 2, 4, 2, 5]
    
    # 10개
    case_3 = [3, 3, 1, 1, 2, 2, 4, 4, 5, 5]
    
    for i in range(len(answers)):
        cur = answers[i]
        if(case_1[i%5] == cur):
            result[1] += 1
        if(case_2[i%8] == cur):
            result[2] += 1
        if(case_3[i%10] == cur):
            result[3] += 1
    
    results = []
    for key in result:
        results.append((result[key], key))
    
    results.sort(key = lambda x : (-x[0], x[1]))
    maxVal = results[0][0]
        
    answer = []
    for i in range(3):
        if(maxVal == results[i][0]):
            answer.append(results[i][1])
        
    return answer
```

## AI 코드 리뷰

### 개선할 점

1. **`enumerate` 활용**: `for i in range(len(answers))` + `answers[i]` 대신 `enumerate(answers)`를 사용하면 인덱스와 값을 동시에 가져올 수 있어 더 파이썬다운 코드가 된다.

2. **변수명 개선**: `result`(딕셔너리)와 `results`(리스트)가 너무 유사해서 혼동 가능. `scores`처럼 역할이 드러나는 이름이 좋다.

3. **패턴 변수명 개선**: `case_1`, `case_2`, `case_3`보다 `patterns` 리스트로 묶으면 반복문으로 처리할 수 있어 확장성이 좋아진다.

4. **최대값 추출 간소화**: 딕셔너리 → 튜플 리스트 → 정렬 → 필터 과정이 길다. `max()` + 리스트 컴프리헨션으로 간결하게 처리 가능.

## 수정된 코드
```python
def solution(answers):
    patterns = [
        [1, 2, 3, 4, 5],
        [2, 1, 2, 3, 2, 4, 2, 5],
        [3, 3, 1, 1, 2, 2, 4, 4, 5, 5]
    ]
    
    scores = [0, 0, 0]
    
    for i, answer in enumerate(answers):
        for j, pattern in enumerate(patterns):
            if pattern[i % len(pattern)] == answer:
                scores[j] += 1
    
    max_score = max(scores)
    
    return [i + 1 for i in range(3) if scores[i] == max_score]
```
