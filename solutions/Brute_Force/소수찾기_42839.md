## 흐름

1. 에라토스테네스의 체로 10^7 범위의 소수 테이블을 미리 생성
2. numbers의 각 숫자를 1개~N개씩 뽑는 모든 순열(permutations) 생성
3. 각 순열을 정수로 변환 후, 소수 테이블에서 소수인지 O(1)로 판별
4. set으로 중복 제거 후 개수 반환

## 코드

```python
import math
from itertools import permutations

def solution(numbers):
    arr = [True]*(10**7)
    arr[0] = False
    arr[1] = False
    end = int(math.sqrt(10**7))

    for i in range(2, end+1):
        p = i*2
        while p < 10**7:
            arr[p] = False
            p += i
            
            
    numbers = list(numbers)
    result = set()
    
    for i in range(1, len(numbers)+1):
        for cur in permutations(numbers, i):
            s = ""
            for j in cur:
                s += j
                
            if(arr[int(s)] == True):
                result.add(int(s))
    
    answer = len(result)
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### itertools.permutations
순열을 생성해주는 표준 라이브러리 함수. 주어진 iterable에서 r개를 뽑아 순서를 고려한 모든 경우의 수를 튜플로 반환한다. 완전탐색 문제에서 모든 조합을 직접 재귀로 구현할 필요 없이 간결하게 순열을 생성할 수 있다.
- **핵심 원리**: `permutations(iterable, r)` → iterable에서 r개를 뽑는 모든 순열을 튜플의 iterator로 반환
- **시간복잡도**: O(nPr) = O(n! / (n-r)!)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 체에서 `for j in range(i, len(arr))`로 i부터 전부 제거 | `p = i*2`부터 시작해서 i의 **배수만** 제거 |
| `p = i`로 시작 → 소수 자기 자신도 False 처리 | `p = i*2`로 시작해서 자기 자신은 보존 |
| `arr[0]`, `arr[1]`이 True인 채로 방치 | 초기화 시 `arr[0] = False`, `arr[1] = False` 처리 |
| `while p <= 10**7` → 배열 크기 초과 | `while p < 10**7`로 범위 내 접근 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `arr` → `is_prime`으로 변경하면 소수 판별 배열임이 명확해진다.
2. **문자열 합치기**: `for j in cur: s += j` 반복 대신 `''.join(cur)`을 사용하면 한 줄로 간결하게 처리 가능하다.
3. **체 최적화**: 이미 합성수인 수는 배수 제거를 건너뛰도록 `if not is_prime[i]: continue` 조건을 추가하면 불필요한 반복을 줄일 수 있다.
4. **불필요한 변수 제거**: `answer = len(result)` 후 `return answer` 대신 `return len(result)`로 직접 반환하면 된다.

## 수정된 코드

```python
import math
from itertools import permutations

def solution(numbers):
    is_prime = [True] * (10 ** 7)
    is_prime[0] = False
    is_prime[1] = False
    end = int(math.sqrt(10 ** 7))

    for i in range(2, end + 1):
        if not is_prime[i]:
            continue
        p = i * 2
        while p < 10 ** 7:
            is_prime[p] = False
            p += i

    result = set()

    for i in range(1, len(numbers) + 1):
        for cur in permutations(numbers, i):
            num = int(''.join(cur))
            if is_prime[num]:
                result.add(num)

    return len(result)
```
