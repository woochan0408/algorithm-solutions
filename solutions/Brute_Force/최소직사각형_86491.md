# 프로그래머스 86491 📐 최소직사각형 파이썬

## 느낀점
>
- 실수 그만하자..!!

## 흐름

1. 각 명함의 가로, 세로 중 큰 값을 앞으로 정렬 (회전 처리)
2. 정렬된 상태에서 가로 최댓값, 세로 최댓값을 구함
3. 두 값을 곱하면 모든 명함을 수납할 수 있는 최소 지갑 크기

## 코드
```python
def solution(sizes):
    for cur in sizes:
        # 큰게 앞으로 오게
        if(cur[1] > cur[0]):
            cur[0], cur[1] = cur[1], cur[0]
    
    a = max(x[0] for x in sizes)
    b = max(x[1] for x in sizes)
    answer = a*b
    return answer
```

## 질문 & 실수 정리

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `for a, b in sizes`에서 `a, b = b, a` → 지역변수만 스왑됨 | `cur[0], cur[1] = cur[1], cur[0]`로 리스트 요소 직접 수정 |

## AI 코드 리뷰

### 개선할 점

1. **원본 리스트 수정 불필요**: 현재 코드는 `sizes` 리스트를 직접 수정하는데, `max(max(w,h))` / `max(min(w,h))` 패턴을 쓰면 원본을 건드리지 않고 한 줄로 처리 가능

## 수정된 코드
```python
def solution(sizes):
    w = max(max(w, h) for w, h in sizes)
    h = max(min(w, h) for w, h in sizes)
    return w * h
```
