## 흐름

1. 노란색 영역의 약수를 구해서 가능한 (세로, 가로) 조합을 탐색
2. 각 조합에 대해 갈색 격자 수가 `2*(세로 + 가로) + 4`와 일치하는지 검증
3. 조건을 만족하면 `[가로+2, 세로+2]` 반환 (테두리 포함)

## AI 코드 리뷰

### 개선할 점

1. **데드 코드 제거**: 상단의 `h = 0`, `w = 0`과 하단의 `answer = []`은 실제로 사용되지 않으므로 제거
2. **`can` 함수 간소화**: `if-return True-return False` 패턴 대신 `return b == 2*(h+w) + 4`로 한 줄 처리
3. **변수명 개선**: `hCand` → `height_candidates`로 파이썬 snake_case 컨벤션 준수
4. **제곱근 정밀도**: `int(yellow**(1/2))`는 부동소수점 오차 가능성이 있으므로 `math.isqrt()` 사용이 더 안전

## 수정된 코드

```python
from math import isqrt

def solution(brown, yellow):
    def is_valid(h, w, b):
        return b == 2 * (h + w) + 4

    for i in range(1, isqrt(yellow) + 1):
        if yellow % i == 0:
            h, w = i, yellow // i
            if is_valid(h, w, brown):
                return [w + 2, h + 2]
```
