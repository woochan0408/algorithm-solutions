## 흐름

1. 테트로미노 5종류의 회전/대칭을 모두 나열하면 총 19가지
2. 모든 칸 (i, j)에서 19가지 모양을 놓아보며 합의 최댓값 갱신
3. 범위를 벗어나면 해당 모양은 스킵

## 코드

import sys

tet = [

    ((0, 0), (1, 0), (1, 1), (2, 1)),
    ((0, 0), (0, 1), (1, 1), (1, 2)),
    ((0, 1), (0, 2), (1, 0), (1, 1)),
    ((0, 1), (1, 0), (1, 1), (2, 0)),
    
    ((0, 1), (1, 0), (1, 1), (1, 2)),

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `tet` → `TETROMINOES`, `cal` → `max_sum_at`, `cur` → `shape`. 함수와 변수의 역할을 이름만으로 파악할 수 있어야 한다.

2. **함수 내 변수 섀도잉**: `cal` 함수 안에서 `answer`라는 이름을 전역 변수와 동일하게 사용하고 있다. 버그는 아니지만, `best` 등 다른 이름을 쓰면 혼동을 방지할 수 있다.

3. **모양 그룹화 주석 추가**: 19개 모양이 어떤 조각의 회전인지 주석이 없으면 검증이 어렵다. 조각별로 그룹화하고 주석을 달면 유지보수성이 올라간다.

4. **grid 입력 간소화**: `for` 루프 대신 리스트 컴프리헨션으로 한 줄로 작성 가능.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

# 테트로미노 19가지 (회전/대칭 포함)
# (0,0) 기준 상대좌표
TETROMINOES = [
    # I (2가지)
    ((0, 0), (0, 1), (0, 2), (0, 3)),
    ((0, 0), (1, 0), (2, 0), (3, 0)),

    # O (1가지)
    ((0, 0), (0, 1), (1, 0), (1, 1)),

    # L (4가지)
    ((0, 0), (1, 0), (2, 0), (2, 1)),
    ((0, 0), (0, 1), (0, 2), (1, 0)),
    ((0, 0), (0, 1), (1, 1), (2, 1)),
    ((0, 0), (1, 0), (1, 1), (1, 2)),

    # J (4가지)
    ((0, 0), (0, 1), (1, 0), (2, 0)),
    ((0, 0), (0, 1), (0, 2), (1, 2)),
    ((0, 1), (1, 1), (2, 1), (2, 0)),
    ((1, 0), (1, 1), (1, 2), (0, 2)),

    # S (2가지)
    ((0, 0), (0, 1), (1, 1), (1, 2)),
    ((0, 1), (1, 0), (1, 1), (2, 0)),

    # Z (2가지)
    ((0, 1), (0, 2), (1, 0), (1, 1)),
    ((0, 0), (1, 0), (1, 1), (2, 1)),

    # T (4가지)
    ((0, 0), (0, 1), (0, 2), (1, 1)),
    ((0, 1), (1, 0), (1, 1), (2, 1)),
    ((0, 1), (1, 0), (1, 1), (1, 2)),
    ((0, 0), (1, 0), (1, 1), (2, 0)),
]

N, M = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(N)]

def max_sum_at(x, y):
    best = 0
    for shape in TETROMINOES:
        total = 0
        for dx, dy in shape:
            nx, ny = x + dx, y + dy
            if 0 <= nx < N and 0 <= ny < M:
                total += grid[nx][ny]
            else:
                total = -1
                break
        best = max(best, total)
    return best

answer = 0
for i in range(N):
    for j in range(M):
        answer = max(answer, max_sum_at(i, j))
print(answer)
```

## 다른 풀이: DFS 깊이 4 탐색

### 흐름
1. 모든 칸에서 DFS로 4칸까지 탐색 → 대부분의 테트로미노를 자동 커버
2. ㅗ 모양(T자)은 DFS 경로로 만들 수 없으므로 별도 처리
3. T자 처리: 한 칸 기준으로 상하좌우 중 3칸 선택 (가장 작은 값 1개 제외)

### 코드
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(N)]
visited = [[False] * M for _ in range(N)]
answer = 0

dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

# DFS: 4칸 연결된 모든 경로 탐색 (T자 제외한 모든 모양 커버)
def dfs(x, y, depth, total):
    global answer
    if depth == 4:
        answer = max(answer, total)
        return
    for i in range(4):
        nx, ny = x + dx[i], y + dy[i]
        if 0 <= nx < N and 0 <= ny < M and not visited[nx][ny]:
            visited[nx][ny] = True
            dfs(nx, ny, depth + 1, total + grid[nx][ny])
            visited[nx][ny] = False

# T자 별도 처리: 한 칸 기준 상하좌우 4칸 중 3칸 선택
def check_t_shape(x, y):
    global answer
    neighbors = []
    for i in range(4):
        nx, ny = x + dx[i], y + dy[i]
        if 0 <= nx < N and 0 <= ny < M:
            neighbors.append(grid[nx][ny])
    if len(neighbors) >= 3:
        answer = max(answer, grid[x][y] + sum(neighbors) - min(neighbors))

for i in range(N):
    for j in range(M):
        visited[i][j] = True
        dfs(i, j, 1, grid[i][j])
        visited[i][j] = False
        check_t_shape(i, j)

print(answer)
```
