## 흐름

1. 길이 N인 2진 수열을 `1` 타일과 `00` 타일로 채우는 경우의 수를 구하는 문제
2. 마지막 자리를 기준으로 점화식 도출
   - 마지막에 `1`을 놓으면 → 나머지 N-1자리를 채우는 경우의 수 = dp[N-1]
   - 마지막에 `00`을 놓으면 → 나머지 N-2자리를 채우는 경우의 수 = dp[N-2]
   - dp[N] = dp[N-1] + dp[N-2] (피보나치 수열)
3. dp[1] = 1, dp[2] = 2를 기저 조건으로 설정
4. N이 최대 1,000,000이므로 배열 대신 변수 두 개로 공간 O(1) 최적화
5. 매 단계 15746으로 나눈 나머지를 저장

## 코드

```python
"""
4
5
0000
0011
1001
1100
1111
dp[1] = 1
dp[2] = 2
dp[3] = dp[1] + dp[2] = 3
"""
N = int(input())
prev_1 = 2
prev_2 = 1
if(N == 1):
    print(1)
elif(N == 2):
    print(2)
else:
    for _ in range(N-2):
        prev_1, prev_2 = (prev_1 + prev_2)%15746, prev_1%15746
    print(prev_1)
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `prev_1`, `prev_2`는 어느 쪽이 더 최근 값인지 직관적이지 않다. `cur`, `prev`로 바꾸면 역할이 명확해진다.
2. **불필요한 모듈러 연산 제거**: `prev_2`에 `%15746`을 적용하고 있지만, `prev_1`이 이미 모듈러가 적용된 값이므로 대입만 하면 된다.
3. **매직넘버 상수화**: `15746`을 `MOD` 상수로 분리하면 가독성이 올라간다.
4. **기저 조건 통합**: `N == 1`일 때 1, `N == 2`일 때 2를 출력하는데, `N <= 2`이면 `N`을 출력하는 것으로 통합할 수 있다.

## 수정된 코드

```python
N = int(input())
MOD = 15746

if (N <= 2):
    print(N)
else:
    cur, prev = 2, 1
    for _ in range(N - 2):
        cur, prev = (cur + prev) % MOD, cur
    print(cur)
```
