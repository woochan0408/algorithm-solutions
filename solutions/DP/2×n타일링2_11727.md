# 백준 11727 🧩 2×n 타일링 2 파이썬

## 느낀점
>
- 잘 풀었다.
- 중복 케이스 (세로 두 개)를 안 빼줘서 삽질 한 번 했다.

## 흐름
1. `N == 1`, `N == 2`는 바로 답을 출력한다.
2. 길이가 `n`일 때의 경우의 수를 `dp[n]`이라 두고, 점화식으로 해결한다.
3. 이전 두 값만 있으면 다음 값을 만들 수 있으므로 배열 대신 변수 두 개로 관리한다.
4. 매 단계마다 `10007`로 나눈 나머지를 저장해 범위를 관리한다.

## 코드
```python
'''
8 -> 171
'''

N = int(input())
if(N == 1):
    print(1)
elif(N == 2):
    print(3)
else:
    prev_1 = 3
    prev_2 = 1
    for i in range(N-2):
        temp = prev_1
        prev_1 = (prev_1 + prev_2*2)%10007
        prev_2 = temp
    print(prev_1)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 중복 계산
점화식을 세울 때는 단순히 "마지막에 붙일 수 있는 모양이 몇 개냐"만 보면 중복 계산이 생길 수 있다. 이 문제에서는 `2칸을 채우는 방법`이 여러 개 보이더라도, 이미 이전 상태에서 세어진 경우와 새로 추가되는 경우를 겹치지 않게 나눠야 올바른 점화식이 만들어진다.
- **핵심 원리**: 경우의 수를 나눌 때는 마지막 상태를 기준으로 서로 겹치지 않게 분리해야 한다.
- **시간복잡도**: O(N)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`dp[n] = dp[n-1] + 3 * dp[n-2]`처럼 세기|`dp[n] = dp[n-1] + 2 * dp[n-2]`로 중복 없이 세기|

## AI 코드 리뷰

### 개선할 점

1. **변수명**: `prev_1`, `prev_2`도 동작은 하지만, `dp_n_1`, `dp_n_2`처럼 의미가 드러나는 이름이 점화식을 읽을 때 더 직관적이다.
2. **반복 범위 표현**: `range(N - 2)`보다 `3`부터 `N`까지 진행하는 형태가 현재 몇 번째 값을 구하는지 바로 보여준다.
3. **가독성**: 현재 로직은 이미 공간복잡도까지 잘 챙긴 풀이이므로, 알고리즘 자체보다 변수 의미와 반복문의 의도를 드러내는 쪽으로만 다듬으면 된다.

## 수정된 코드
```python
n = int(input())
MOD = 10007

if n == 1:
    print(1)
elif n == 2:
    print(3)
else:
    dp_n_2 = 1  # dp[1]
    dp_n_1 = 3  # dp[2]

    for _ in range(3, n + 1):
        next_value = (dp_n_1 + 2 * dp_n_2) % MOD
        dp_n_2 = dp_n_1
        dp_n_1 = next_value

    print(dp_n_1)
```
