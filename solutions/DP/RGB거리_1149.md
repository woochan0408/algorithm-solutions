# 백준 1149 🎨 RGB거리 파이썬

## 느낀점
>
- 내려가기(2096) 하위호환 문제
- 어렵지 않았다.

## 흐름

1. `dp[i][색상]` = i번째 집을 해당 색상으로 칠할 때의 최소 누적 비용
2. 이전 집과 다른 색상 중 최소 비용을 선택하여 현재 색상 비용을 더함
3. 마지막 집에서 세 가지 색상 중 최소값 출력

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
arr = []
for i in range(N):
    arr.append(list(map(int, input().split())))
dp =[[0]*3 for i in range(N)]
dp[0] = arr[0]
for i in range(1,N):
    dp[i][0] = min(dp[i-1][1] + arr[i][0], dp[i-1][2] + arr[i][0])
    dp[i][1] = min(dp[i-1][0] + arr[i][1], dp[i-1][2] + arr[i][1])
    dp[i][2] = min(dp[i-1][0] + arr[i][2], dp[i-1][1] + arr[i][2])
print(min(dp[i]))
```

## AI 코드 리뷰

### 개선할 점

1. **입력 간소화**: `arr` 리스트 컴프리헨션으로 한 줄 처리 가능
2. **마지막 인덱스 명시**: `min(dp[i])` → `min(dp[-1])` - 루프 변수 의존보다 명시적 인덱스가 가독성에 좋음
3. **공백 일관성**: `dp =[[0]*3` → `dp = [[0]*3`

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = [list(map(int, input().split())) for _ in range(N)]

dp = [[0] * 3 for _ in range(N)]
dp[0] = arr[0]

for i in range(1, N):
    dp[i][0] = min(dp[i-1][1], dp[i-1][2]) + arr[i][0]
    dp[i][1] = min(dp[i-1][0], dp[i-1][2]) + arr[i][1]
    dp[i][2] = min(dp[i-1][0], dp[i-1][1]) + arr[i][2]

print(min(dp[-1]))
```
