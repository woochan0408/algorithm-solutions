## 느낀점
>
- 잘 풀었다.
- 슬라이딩 윈도우 습관화 하자.

## 흐름

1. `dp[0]`은 첫 번째 창고만 선택하는 경우 → `arr[0]`
2. `dp[1]`은 첫 번째와 두 번째 중 큰 값 → `max(arr[0], arr[1])`
3. `i >= 2`부터 점화식 적용:
   - `i`번째를 **털면**: `dp[i-2] + arr[i]` (인접 불가이므로 i-2까지의 최적 + 현재)
   - `i`번째를 **안 털면**: `dp[i-1]` (이전까지의 최적 유지)
   - 둘 중 큰 값을 `dp[i]`에 저장
4. `dp[N-1]` 출력

## 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
dp = [0]*N
dp[0] = arr[0]
dp[1] = max(arr[0], arr[1])
for i in range(2, N):
    dp[i] = max(dp[i-2] + arr[i], dp[i-1])
print(dp[N-1])
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `arr`는 범용적인 이름이라 `foods` 또는 `storages`처럼 문맥에 맞는 이름이 좋다.
2. **공간 최적화**: `dp` 배열 전체를 유지하고 있지만, 실제로 참조하는 값은 `dp[i-1]`과 `dp[i-2]` 두 개뿐이다. 변수 두 개로 O(1) 공간에 풀 수 있다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
foods = list(map(int, input().split()))

prev2 = foods[0]            # dp[i-2]
prev1 = max(foods[0], foods[1])  # dp[i-1]

for i in range(2, N):
    current = max(prev2 + foods[i], prev1)
    prev2 = prev1
    prev1 = current

print(prev1)
```
