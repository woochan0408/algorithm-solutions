## 실패한 코드 흐름
1. "가장 긴 공통 부분 문자열" → 모든 시작점 (i, j) 조합에서 일치하는 문자 수를 세는 브루트포스 접근
2. `cal(i, j)` 함수로 s1[i:]와 s2[j:]의 공통 접두사 길이를 계산
3. 이중 for문으로 모든 (i, j) 조합에 대해 `cal` 호출 → 최댓값 갱신

## 실패한 코드
```python
import sys
input = sys.stdin.readline
s1 = input().strip()
s2 = input().strip()
N = len(s1)
M = len(s2)
def cal(i, j):
    count = 0
    while(i < N and j < M):
        if(s1[i] != s2[j]):
            break
        else:
            count += 1
            i += 1
            j += 1
    return count
answer = 0
for i in range(N):
    for j in range(M):
        answer = max(cal(i, j), answer)
print(answer)
```

**문제점**: O(N × M × min(N,M))으로 N=M=4000일 때 최악 640억 연산 → 시간초과

## 성공한 코드 흐름

1. DP 테이블 정의: `dp[i][j]` = s1[i]와 s2[j]로 **끝나는** 공통 부분 문자열의 최대 길이
2. 점화식: `s1[i] == s2[j]`이면 `dp[i][j] = dp[i-1][j-1] + 1`, 아니면 `0`
3. 메모리 최적화: 2D 배열 대신 `prev`, `curr` 두 개의 1D 배열로 롤링
4. j=0일 때는 이전 문자가 없으므로 일치하면 무조건 1
5. 매 행마다 `answer`를 갱신하여 전체 최댓값 추적

## 성공한 코드
```python
import sys
input = sys.stdin.readline
s1 = input().strip()
s2 = input().strip()
N = len(s1)
M = len(s2)
# dp[i][j] = i, j idx 문자열 포함하는 문자열 최대 길이
prev_1 = [0]*M
curr = [0]*M
for i in range(M):
    if(s1[0] == s2[i]):
        curr[i] = 1
    else:
        curr[i] = 0
answer = max(prev_1)
for i in range(1, N):
    prev_1 = curr
    curr = [0]*M
    if(s1[i] == s2[0]):
        curr[0] = 1
    else:
        curr[0] = 0
    for j in range(1, M):
        if(s1[i] == s2[j]):
            curr[j] = prev_1[j-1] + 1
        else:
            curr[j] = 0
    answer = max(max(curr), answer)
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 공통 부분 문자열 DP (Longest Common Substring)
두 문자열의 공통 **연속** 부분 문자열을 찾는 문제에서, `dp[i][j]`를 "s1[i]와 s2[j]로 끝나는 공통 부분 문자열의 길이"로 정의하면 O(N×M)에 풀 수 있다. 부분 수열(subsequence)이 아닌 부분 문자열(substring)이므로 문자가 불일치하면 바로 0으로 초기화하는 것이 핵심이다.
- **핵심 원리**: `s1[i] == s2[j]`이면 `dp[i][j] = dp[i-1][j-1] + 1`, 아니면 `0`
- **시간복잡도**: O(N × M)

#### 롤링 배열 (메모리 최적화)
DP에서 현재 행이 바로 이전 행만 참조할 때, 전체 2D 배열 대신 `prev`와 `curr` 두 개의 1D 배열만으로 공간을 O(N×M) → O(M)으로 줄일 수 있다. Python에서는 리스트 하나가 차지하는 메모리가 크기 때문에 4000×4000 같은 크기에서 메모리 초과가 발생할 수 있어 실전에서 자주 필요하다.
- **핵심 원리**: 이전 행 → `prev`, 현재 행 → `curr`, 행 계산 완료 후 `prev = curr`, `curr = [0]*M`으로 교체

### 실수했던 부분

#### 시간복잡도 과소평가 (브루트포스)
N=4000일 때 O(N²)까지는 괜찮지만, `cal` 함수가 최대 O(N)을 추가해 O(N³)이 된다는 것을 간과했다. 이중 루프 안에서 호출하는 함수의 시간복잡도도 반드시 곱해서 계산해야 한다.

#### 계산 결과 대입 누락
`dp[i-1][j-1] + 1`이라고만 쓰고 `dp[i][j] = `를 빠뜨렸다. 계산식만 쓰면 Python에서는 값을 평가만 하고 버린다. 항상 결과를 변수에 저장해야 한다.

#### 1D 배열 하나로 이전 행 값 보존 불가
배열 하나로 in-place 갱신하면 `prev[j-1]`이 이미 현재 행 값으로 덮어써진 상태가 된다. `dp[i][j]`가 `dp[i-1][j-1]`을 참조하므로, 왼쪽에서 오른쪽으로 갱신하면 이전 행 값이 사라진다. 두 배열을 분리해야 한다.

#### ⭐얕은 복사 문제 (prev = curr)
`prev = curr`은 같은 리스트 객체를 가리키게 만든다. 이후 `curr`을 수정하면 `prev`도 함께 바뀐다. `prev = curr` 후 `curr = [0]*M`으로 새 리스트를 할당해야 한다.


#### j=0 처리 누락
내부 루프를 `range(1, M)`으로 시작했지만, `s1[i] == s2[0]`인 경우에 대한 처리가 없었다. `curr[0]`이 항상 0으로 남아 첫 번째 열에서 시작하는 공통 부분 문자열을 놓친다.

#### prev[-1] 음수 인덱스 참조
j=0일 때 `prev[j-1]` = `prev[-1]`은 리스트의 마지막 원소를 참조한다. Python은 음수 인덱스에서 에러를 내지 않으므로 잘못된 값을 조용히 사용하게 된다. j=0은 반드시 별도 분기로 처리해야 한다.

#### j=0일 때 값 계산 오류
j=0에서 일치하면 `prev[0] + 1`로 계산했는데, j=0은 s2의 첫 문자이므로 이전에 이어지는 문자가 없다. 일치하면 무조건 1이다.

#### ⭐전체 최댓값 갱신 누락
마지막에 `max(prev, curr)`만 비교하면 이전 행들의 최댓값을 놓친다. 매 행마다 `answer = max(answer, max(curr))`로 갱신해야 한다.

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `prev_1`보다 `prev`가 더 직관적이다. `_1`이 의미하는 바가 불명확하다.

2. **초기화와 경계 처리 간소화**: 현재 i=0 행 초기화와 j=0 처리를 별도로 하고 있지만, DP 테이블 크기를 (N+1)×(M+1)로 잡고 0행/0열을 패딩으로 두면 모든 경계 처리가 사라진다. 이 문제에서 발생한 실수 대부분(j=0 누락, prev[-1] 참조, j=0 값 계산 오류)이 이 방식으로 원천 차단된다.

3. **answer 초기화 위치**: `answer = max(prev_1)`로 시작하는데, 이 시점에서 prev_1은 전부 0이므로 항상 0이다. `answer = max(curr)`로 첫 행의 값을 반영해야 정확하다. (현재 코드에서는 이후 루프에서 갱신되므로 결과에는 영향 없지만 의도가 불명확하다.)

## 수정된 코드
```python
import sys
input = sys.stdin.readline

s1 = input().strip()
s2 = input().strip()
N = len(s1)
M = len(s2)

# dp[i][j] = s1[i-1], s2[j-1]로 끝나는 공통 부분 문자열의 최대 길이
# 0행/0열은 패딩 (경계 처리 불필요)
prev = [0] * (M + 1)
curr = [0] * (M + 1)
answer = 0

for i in range(1, N + 1):
    curr = [0] * (M + 1)
    for j in range(1, M + 1):
        if s1[i - 1] == s2[j - 1]:
            curr[j] = prev[j - 1] + 1
            if curr[j] > answer:
                answer = curr[j]
        else:
            curr[j] = 0
    prev = curr

print(answer)
```
