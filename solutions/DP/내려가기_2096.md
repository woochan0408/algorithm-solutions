# 백준 2096 ⬇️ 내려가기 파이썬

## 느낀점
>
- 단순 DP로 갔다가 메모리 초과 발생
- 테이블 없이 푸는 방식으로 해결
- 골드는 난이도 기복이 심한 것 같다.

## 흐름

1. 메모리 제한 4MB → 2차원 배열 불가, 슬라이딩 윈도우 필요
2. 각 위치에서 이동 가능한 곳:
   - 왼쪽(0): 아래 왼쪽(0), 아래 중앙(1)
   - 중앙(1): 아래 왼쪽(0), 아래 중앙(1), 아래 오른쪽(2)
   - 오른쪽(2): 아래 중앙(1), 아래 오른쪽(2)
3. 이전 행의 max/min 값만 유지하며 갱신
4. 최종적으로 max 배열의 최대값, min 배열의 최소값 출력

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
arr = []
arr = list(map(int, input().split()))
beforeMax = arr
beforeMin = arr
for i in range(1, N):
    arr = list(map(int, input().split()))
    a = max(beforeMax[0] + arr[0], beforeMax[1] + arr[0])
    b = max(beforeMax[0] + arr[1], beforeMax[1] + arr[1], beforeMax[2] + arr[1])
    c = max(beforeMax[1] + arr[2], beforeMax[2] + arr[2])
    beforeMax = [a, b, c]
    
    a = min(beforeMin[0] + arr[0], beforeMin[1] + arr[0])
    b = min(beforeMin[0] + arr[1], beforeMin[1] + arr[1], beforeMin[2] + arr[1])
    c = min(beforeMin[1] + arr[2], beforeMin[2] + arr[2])
    beforeMin = [a, b, c]
print("%d %d" % (max(beforeMax), min(beforeMin)))
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 `a, b, c`**: 의미가 불명확함 → `left, mid, right` 또는 리스트로 직접 구성하면 가독성 향상

2. **중복 계산 패턴**: max/min 로직이 거의 동일한 구조로 반복됨 → 리스트 컴프리헨션으로 정리 가능

3. **주석 부재**: DP 점화식의 의미를 주석으로 남기면 복기할 때 유용

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
row = list(map(int, input().split()))
prev_max = row[:]
prev_min = row[:]

for _ in range(1, N):
    row = list(map(int, input().split()))
    
    # 최대값 DP 갱신
    curr_max = [
        max(prev_max[0], prev_max[1]) + row[0],
        max(prev_max[0], prev_max[1], prev_max[2]) + row[1],
        max(prev_max[1], prev_max[2]) + row[2]
    ]
    
    # 최소값 DP 갱신
    curr_min = [
        min(prev_min[0], prev_min[1]) + row[0],
        min(prev_min[0], prev_min[1], prev_min[2]) + row[1],
        min(prev_min[1], prev_min[2]) + row[2]
    ]
    
    prev_max, prev_min = curr_max, curr_min

print(max(prev_max), min(prev_min))
```
