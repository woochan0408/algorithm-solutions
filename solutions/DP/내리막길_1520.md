## 느낀점
>
- 항상 DP와 백트래킹을 헷갈려했는데 결국 해당 문제에서 야단이 나버렸다.
- `그리디 < DP < 백트래킹` 순으로 떠올리고 문제를 푸는 것이 중요하다
   - **시간복잡도** - `그리디 < DP < 백트래킹`
   - **범용성** -  `백트래킹 > DP > 그리디`
   - 즉, 백트래킹은 대부분 문제를 해결 가능하지만 시간복잡도가 커진다.
   - 최적화를 위해서 `그리디 > DP > 백트래킹` 순으로 풀이를 떠올리자.
- 해당 문제는 DP 풀이가 가능하지만 백트래킹으로 풀어서 시간초과가 났다.
- 탑다운 바텀업은 골딱이 문제에서는 취향껏 풀자.
(나는 골딱이므로 혼용해서 사용한다)

---

## 실패한 코드 흐름
1. (0,0)에서 (N-1,M-1)까지 DFS + 백트래킹으로 모든 경로를 직접 탐색
2. 도착할 때마다 `answer += 1`로 경로 수를 누적
3. 경로 수가 많아지면 모든 경로를 하나씩 탐색하므로 시간초과 발생

## 실패한 코드
```python
import sys
sys.setrecursionlimit(10**6)

N, M = map(int, input().split())
grid = []
for i in range(N):
    grid.append(list(map(int, input().split())))

visited = [[False] * M for i in range(N)]
visited[0][0] = True
move = [[-1, 0], [1, 0], [0, -1], [0, 1]]
answer = 0

def dfs(x, y):
    if x == N - 1 and y == M - 1:
        global answer
        answer += 1
    for dx, dy in move:
        nx = x + dx
        ny = y + dy
        if not (0 <= nx < N and 0 <= ny < M and grid[nx][ny] < grid[x][y] and not visited[nx][ny]):
            continue
        visited[nx][ny] = True
        dfs(nx, ny)
        visited[nx][ny] = False

dfs(0, 0)
print(answer)
```

**문제점**: 백트래킹으로 모든 경로를 직접 탐색하여 경로 수가 많은 경우 시간초과

## 성공한 코드 흐름 (풀이1 - 탑다운 DP)
1. 도착점 (N-1, M-1)에서 시작하여 출발점 (0, 0)으로 역방향 탐색
2. `memo[(0, 0)] = 1`을 기저 사례로 설정
3. 각 칸에서 높이가 더 높은 이웃으로 재귀 호출하여 경로 수를 합산
4. 한 번 계산한 칸은 `memo`에 저장하여 재계산 방지

## 성공한 코드 (풀이1 - 탑다운 DP)
```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

N, M = map(int, input().split())
grid = []
for i in range(N):
    grid.append(list(map(int, input().split())))

memo = {(0, 0) : 1}
move = [[-1, 0], [1, 0], [0, -1], [0, 1]]

# x, y에서도 모든 경로
def dfs(x, y):
    cur = grid[x][y]
    if (x, y) in memo:
        return memo[(x, y)]
    cand = []
    for dx, dy in move:
        nx = x + dx
        ny = y + dy
        if 0 <= nx < N and 0 <= ny < M and grid[nx][ny] > cur:
            cand.append(dfs(nx, ny))
    memo[(x, y)] = sum(cand)
    return memo[(x, y)]

print(dfs(N - 1, M - 1))
```

## 풀이2 흐름 (바텀업 DP)
1. 모든 칸을 높이 기준 오름차순으로 정렬
2. `dp[N-1][M-1] = 1` (도착점)을 기저 사례로 설정
3. 낮은 칸부터 순서대로 처리 → 이웃 중 자신보다 낮은 칸은 이미 계산 완료
4. 각 칸의 dp값 = 이웃 중 높이가 더 낮은 칸들의 dp값 합

## 풀이2 코드 (바텀업 DP)
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
grid = []
for i in range(N):
    grid.append(list(map(int, input().split())))

# 모든 칸을 (높이, x, y)로 저장 후 오름차순 정렬
cells = []
for i in range(N):
    for j in range(M):
        cells.append((grid[i][j], i, j))
cells.sort()

dp = [[0] * M for _ in range(N)]
dp[N - 1][M - 1] = 1

move = [(-1, 0), (1, 0), (0, -1), (0, 1)]

for h, x, y in cells:
    if x == N - 1 and y == M - 1:
        continue
    for dx, dy in move:
        nx, ny = x + dx, y + dy
        if 0 <= nx < N and 0 <= ny < M and grid[nx][ny] < h:
            dp[x][y] += dp[nx][ny]

print(dp[0][0])
```

## 질문 & 실수 정리

### 새로 배운 것

#### DP vs 백트래킹 — 경로 개수 문제의 판단 기준

경로 관련 문제에서 어떤 기법을 쓸지는 **"무엇을 구하는가"**와 **"사이클이 있는가"**로 결정된다.

| 구하는 것 | 사이클 없음 (DAG) | 사이클 있음 |
|---|---|---|
| **경로 개수** | DP (메모이제이션) | 백트래킹 (visited 필수) |
| **경로 자체 출력** | 백트래킹 / DFS | 백트래킹 (visited 필수) |
| **최단 경로** | BFS / 다익스트라 | BFS / 다익스트라 |
| **최단 경로 개수** | BFS/다익스트라 + DP | BFS/다익스트라 + DP |

- **핵심 원리**: "높은 곳 → 낮은 곳"처럼 한 방향으로만 이동하면 사이클이 생기지 않는다 (DAG). DAG에서는 `dfs(x, y)`의 결과가 "어떤 경로로 (x, y)에 도착했는지"와 무관하게 항상 동일하므로 메모이제이션이 가능하다.
- **판단 흐름**: ① 사이클이 없는가? → ② 경로 개수만 구하면 되는가? → 둘 다 Yes면 DP

#### 탑다운 vs 바텀업 DP

같은 문제를 두 가지 방식으로 풀 수 있다.
- **탑다운**: 재귀 + 메모이제이션. 필요한 칸만 계산하므로 직관적이지만 재귀 깊이 제한에 주의
- **바텀업**: 반복문 + 정렬. 모든 칸을 높이순으로 정렬하여 의존성 순서대로 처리. 재귀 오버헤드 없음
- **시간복잡도**: 둘 다 O(N × M) (바텀업은 정렬 때문에 O(NM log NM))

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 백트래킹으로 모든 경로 직접 탐색 (시간초과) | 사이클 없는 구조 → 메모이제이션으로 중복 계산 제거 |
| 경로 개수 문제를 항상 백트래킹으로 접근 | DAG에서 경로 개수 = DP 문제 |

## AI 코드 리뷰

### 개선할 점

1. **`cand` 리스트 제거**: 리스트에 모았다가 `sum()` 하는 대신 변수에 바로 누적하면 불필요한 리스트 생성을 줄일 수 있다
2. **`memo`를 2차원 리스트로 변경**: 딕셔너리는 해시 연산 오버헤드가 있으므로, `-1`로 초기화한 2차원 리스트를 사용하면 "미방문"과 "경로 0개"를 구분하면서 더 빠르게 동작한다
3. **`cur` 변수 제거**: `grid[x][y]`를 직접 비교해도 가독성에 큰 차이가 없다

## 수정된 코드
```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

N, M = map(int, input().split())
grid = []
for i in range(N):
    grid.append(list(map(int, input().split())))

memo = [[-1] * M for _ in range(N)]
memo[0][0] = 1
move = [(-1, 0), (1, 0), (0, -1), (0, 1)]

def dfs(x, y):
    if memo[x][y] != -1:
        return memo[x][y]
    result = 0
    for dx, dy in move:
        nx = x + dx
        ny = y + dy
        if 0 <= nx < N and 0 <= ny < M and grid[nx][ny] > grid[x][y]:
            result += dfs(nx, ny)
    memo[x][y] = result
    return result

print(dfs(N - 1, M - 1))
```
