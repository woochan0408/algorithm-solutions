# 백준 1309 🦁 동물원 파이썬

## 느낀점
>
- 실수 줄이자.

## 흐름

1. 2×N 우리에서 각 행의 상태를 3가지로 분류: 아무것도 안 놓음(0), 왼쪽만(1), 오른쪽만(2)
2. `dp[i][상태]` = i번째 행까지 고려했을 때, i번째 행이 해당 상태인 경우의 수
3. 초기값: `dp[1][0] = dp[1][1] = dp[1][2] = 1`
4. 점화식:
   - `dp[i][0]` = 이전 행이 어떤 상태든 가능 → `dp[i-1][0] + dp[i-1][1] + dp[i-1][2]`
   - `dp[i][1]` = 이전 행에 왼쪽 사자 없어야 함 → `dp[i-1][0] + dp[i-1][2]`
   - `dp[i][2]` = 이전 행에 오른쪽 사자 없어야 함 → `dp[i-1][0] + dp[i-1][1]`
5. 결과: `sum(dp[N]) % 9901`

## 코드

```python
"""
dp? + 2차원?
dp[N][M]
N = N번쨰 줄까지 있을때
M
0 : 아무것도 배치안함
1 : 왼쪽만 배치
2 : 오른쪽만 배치
"""
N = int(input())
dp = [[0, 0, 0] for _ in range(N+1)]
dp[1][0] = 1
dp[1][1] = 1
dp[1][2] = 1
for i in range(2, N+1):
    dp[i][0] = (dp[i-1][0] + dp[i-1][1] + dp[i-1][2])%9901
    dp[i][1] = (dp[i-1][0] + dp[i-1][2])%9901
    dp[i][2] = (dp[i-1][0] + dp[i-1][1])%9901
print(sum(dp[N])%9901)
```

## 질문 & 실수 정리

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `dp[1][0]` 초기값 누락 (아무것도 안 놓는 경우 미고려) | `dp[1][0] = 1`로 초기화 |
| `dp[i][1]`, `dp[i][2]`에 `+ 1` 추가 | 이전 행 상태의 합만으로 결정 (+ 1 불필요) |
| `sum(dp[N])`에 모듈러 연산 누락 | `sum(dp[N]) % 9901` |

## AI 코드 리뷰

### 개선할 점
1. **변수명 개선**: 상태를 나타내는 인덱스 0, 1, 2에 대한 주석이 있지만, 상수로 분리하면 가독성이 더 좋아짐 (예: `EMPTY, LEFT, RIGHT = 0, 1, 2`)
2. **공간 최적화 가능**: 점화식에서 `dp[i]`는 `dp[i-1]`만 참조하므로, 2×3 배열로 공간을 O(1)로 줄일 수 있음

## 수정된 코드

```python
# dp[i][상태]: i번째 행이 해당 상태일 때 경우의 수
# 상태: 0=빈칸, 1=왼쪽 배치, 2=오른쪽 배치
EMPTY, LEFT, RIGHT = 0, 1, 2
MOD = 9901

N = int(input())
prev = [1, 1, 1]  # dp[1] 초기값

for _ in range(2, N + 1):
    curr = [0, 0, 0]
    curr[EMPTY] = (prev[EMPTY] + prev[LEFT] + prev[RIGHT]) % MOD
    curr[LEFT] = (prev[EMPTY] + prev[RIGHT]) % MOD
    curr[RIGHT] = (prev[EMPTY] + prev[LEFT]) % MOD
    prev = curr

print(sum(prev) % MOD)
```
