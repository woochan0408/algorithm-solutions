>
- 어려웠는데 재밌는 문제이다
- dp를 못 떠올렸다.
- 항상 풀 때 아는 알고리즘 한 번 스캔하고 시작하자.
(많지도 않잖아..)

## 흐름

1. `dp[0] = 1` 기저값 설정 (아무 동전도 안 쓰는 경우 1가지)
2. 동전을 하나씩 순회하면서, 해당 동전을 사용해 만들 수 있는 금액을 갱신
3. 바깥 루프: 동전 종류 / 안쪽 루프: 금액
4. `dp[i] += dp[i - cur]`로 이전 금액의 경우의 수를 누적
5. 동전 순서를 강제하여 순서 중복을 방지

## 코드

```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
dp = [0] * (M+1)
arr = []
for i in range(N):
    arr.append(int(input()))
dp[0] = 1
for cur in arr:
    for i in range(cur, M+1):
        cand = 0
        if(i-cur >= 0):
            cand += dp[i-cur]
        dp[i] += cand
print(dp[M])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 루프 순서로 순열/조합 제어하기
DP에서 바깥 루프와 안쪽 루프의 순서를 바꾸는 것만으로 **순열(순서 있음)**과 **조합(순서 없음)**을 구분할 수 있다.
- **금액 → 동전** 순서: 같은 금액을 서로 다른 순서로 만드는 경우를 모두 세어 **순열**이 된다
- **동전 → 금액** 순서: 동전을 하나씩 허용하며 갱신하므로, 이미 허용된 동전들로만 조합이 만들어져 **순서 중복이 제거**된다

#### dp[0] = 1 기저값의 의미
`dp[0] = 1`은 "금액 0을 만드는 방법은 1가지(아무것도 안 쓰기)"라는 의미이다. 점화식 `dp[cur] += dp[0]`에서 "동전 하나로 정확히 그 금액을 만드는 경우"가 올바르게 세어지기 위한 기저값이다.

#### 2차원 DP의 1차원 최적화
원래 `dp[i][j]` = 동전 1~i번째까지 사용해서 금액 j를 만드는 경우의 수로 2차원 DP가 정석이지만, 이전 행(`dp[i-1]`)만 참조하므로 1차원 배열로 공간 최적화가 가능하다. 이 문제는 메모리 제한이 4MB로 1차원이 사실상 필수이다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 금액 기준 바깥 루프 → 순서 중복 발생 | 동전 기준 바깥 루프로 변경하여 조합만 카운트 |
| `dp[cur] += 1`로 초기화 → 동전 가치 > M일 때 인덱스 에러 | `dp[0] = 1` 기저값으로 자동 처리 |
| `dp[0] = len(arr)` 설정 | `dp[0] = 1` (동전 종류 수와 무관) |
| `range(cur+1, M+1)` → `dp[cur]` 미갱신 | `range(cur, M+1)`로 변경 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `arr` → `coins`, `M` → `K`(목표 금액), `cur` → `coin`으로 의미 명확화
2. **불필요한 조건 제거**: `range(cur, M+1)`에서 시작하므로 `if(i-cur >= 0)`은 항상 참 — 제거 가능
3. **불필요한 임시 변수 제거**: `cand` 변수 없이 `dp[i] += dp[i - coin]`으로 직접 갱신
4. **입력 간소화**: 리스트 컴프리헨션으로 동전 입력 처리

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
coins = [int(input()) for _ in range(N)]

dp = [0] * (K + 1)
dp[0] = 1

for coin in coins:
    for i in range(coin, K + 1):
        dp[i] += dp[i - coin]

print(dp[K])
```
