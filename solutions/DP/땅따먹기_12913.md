# 프로그래머스 12913 🏡 땅따먹기 파이썬

## 느낀점
>
- 항상 dp문제가 양쪽 방향으로만 이동할 수 있어서 고정관념으로 인해 삽질했다.
(1열에서 4열로 점프도 가능)
- 수정 후 별 문제 없이 잘 돌아갔다.

## 흐름

1. N행 4열 격자에서 한 행씩 내려오며 한 칸씩 선택, 같은 열 연속 불가
2. `dp[i][j]` = i행 j열을 밟았을 때의 최대 점수
3. 이전 행에서 j가 아닌 열들의 dp 최댓값 + 현재 칸 점수로 점화식 구성
4. 마지막 행의 최댓값 반환

## 코드

```python
"""
점수의 최댓값.
"""
def solution(land):
    N = len(land)
    M = len(land[0])
    dp = [[0]*M for i in range(N)]
    answer = 0
    for i in range(M):
        dp[0][i] = land[0][i]
    
    for i in range(1, N):
        for j in range(M):
            cand = []
            for k in range(M):
                if(j != k):
                    cand.append(dp[i-1][k])
            dp[i][j] = max(cand) + land[i][j]            
            
    return max(dp[N-1])
```

## AI 코드 리뷰

### 개선할 점

1. **불필요한 리스트 생성 제거**: 매 반복마다 `cand` 리스트를 생성하고 `append`하는 대신, 제너레이터 표현식 `max(... for k in range(M) if k != j)`로 한 줄에 처리하면 불필요한 메모리 할당을 줄일 수 있다.

2. **별도 dp 배열 제거**: `land` 배열 자체를 누적하면 별도의 2차원 배열 생성 없이 O(1) 추가 메모리로 해결 가능하다. 첫 행 초기화와 dp 배열 선언이 모두 필요 없어진다.

3. **미사용 변수 제거**: `answer = 0`은 선언만 되고 사용되지 않았다.

## 수정된 코드

```python
def solution(land):
    N = len(land)
    M = len(land[0])

    for i in range(1, N):
        for j in range(M):
            land[i][j] += max(land[i-1][k] for k in range(M) if k != j)

    return max(land[N-1])
```
