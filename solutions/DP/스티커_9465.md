## 느낀점

## 흐름

1. 2×n 스티커 배열에서 변을 공유하지 않게 선택하여 점수 최대화
2. DP 정의: `dp[i][j]` = j번째 열까지 있을 때 i행 j열을 반드시 선택한 경우의 최댓값
3. 점화식 도출:
   - i열의 0행을 선택하면 → i-1열의 0행 선택 불가, i열의 1행 선택 불가
   - 가능한 이전 상태: `dp[0][i-2]`, `dp[1][i-2]`, `dp[1][i-1]`
4. `dp[0][i] = max(dp[0][i-2], dp[1][i-2], dp[1][i-1]) + grid[0][i]`
5. `dp[1][i] = max(dp[0][i-2], dp[1][i-2], dp[0][i-1]) + grid[1][i]`
6. N==1인 경우 예외처리 (i-2 인덱스 접근 불가)

## 코드

```python
import sys
input = sys.stdin.readline
testCount = int(input())
for _ in range(testCount):
    N = int(input())
    grid = []
    grid.append(list(map(int, input().split())))
    grid.append(list(map(int, input().split())))
    
    # 스티커가 두개
    if(N == 1):
        print(max(grid[0][0], grid[1][0]))
        continue
    dp = [[0]*N for _ in range(2)]
    dp[0][0] = grid[0][0]
    dp[1][0] = grid[1][0]
    dp[0][1] = grid[1][0] + grid[0][1]
    dp[1][1] = grid[0][0] + grid[1][1]
    for i in range(2, N):
        dp[0][i] = max(dp[0][i-2] + grid[0][i], dp[1][i-2] + grid[0][i], dp[1][i-1] + grid[0][i])
        dp[1][i] = max(dp[0][i-2] + grid[1][i], dp[1][i-2] + grid[1][i], dp[0][i-1] + grid[1][i])
    print(max(dp[0][N-1], dp[1][N-1]))
```

## AI 코드 리뷰

### 개선할 점

1. **max() 중복 계산 정리**: `dp[0][i-2]`와 `dp[1][i-2]`가 양쪽 점화식에서 동일하게 사용되므로 한 번만 계산 가능

2. **대안 로직 - 3가지 상태 DP**: 현재 점화식은 i-2까지 참조해야 하지만, "선택 안 함" 상태를 추가하면 i-1만 보면 됨. N==1 예외처리도 불필요해지고 점화식이 더 직관적

## 수정된 코드

```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    N = int(input())
    grid = [list(map(int, input().split())) for _ in range(2)]
    
    # dp[0]: 0행 선택, dp[1]: 1행 선택, dp[2]: 선택 안 함
    dp = [[0] * N for _ in range(3)]
    dp[0][0] = grid[0][0]
    dp[1][0] = grid[1][0]
    dp[2][0] = 0
    
    for i in range(1, N):
        dp[0][i] = max(dp[1][i-1], dp[2][i-1]) + grid[0][i]
        dp[1][i] = max(dp[0][i-1], dp[2][i-1]) + grid[1][i]
        dp[2][i] = max(dp[0][i-1], dp[1][i-1])
    
    print(max(dp[0][N-1], dp[1][N-1], dp[2][N-1]))
```
