# 백준 1912 📊 연속합 파이썬

## 느낀점
>
- 투포인트와 DP 헷갈려서 실패.
- 구분 잘 하자.

## 흐름

1. DP 배열 초기화: `dp[0] = arr[0]` (첫 번째 원소는 자기 자신)
2. 각 위치 i에서 선택:
   - 이전 합에 현재 값 추가: `dp[i-1] + arr[i]`
   - 현재 값부터 새로 시작: `arr[i]`
   - 둘 중 큰 값을 `dp[i]`에 저장
3. dp 배열 중 최댓값 출력

## 코드

```python
"""
배열 중 연속합의 최대 구하기
10
10 -4 3 1 5 6 -35 12 21 -1
"""
import sys
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
dp = [0 for i in range(N)]
dp[0] = arr[0]
for i in range(1, N):
    dp[i] = max(dp[i-1] + arr[i], arr[i])
print(max(dp))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 연속 부분 수열 최대 합 (Kadane's Algorithm)

연속된 부분 수열의 합 중 최댓값을 구하는 대표적인 DP 문제입니다. 핵심은 **각 위치에서 "여기까지 포함하는 연속 합"의 최댓값**을 저장하는 것입니다.

- **DP 정의**: `dp[i]` = i번째 원소를 반드시 포함하고 i번째에서 끝나는 연속 부분 수열의 최대 합
- **점화식**: `dp[i] = max(dp[i-1] + arr[i], arr[i])`
  - `dp[i-1] + arr[i]`: 이전까지의 합에 현재 값 추가
  - `arr[i]`: 현재 값부터 새로 시작
- **시간복잡도**: O(N)

#### DP vs 투포인터 비교

이 문제를 투포인터로 접근하면 실패합니다. 왜 그럴까요?

**투포인터가 실패하는 이유:**
- 투포인터는 **정렬된 배열** 또는 **구간을 확장/축소하며 조건을 만족하는 경우**에 유효합니다
- 이 문제는 음수와 양수가 섞여 있어서, 단순히 구간을 늘리거나 줄이는 것만으로는 최적해를 찾을 수 없습니다
- 예: `[10, -4, 3, 1]`에서 -4를 포함할지 말지는 **뒤의 값들을 봐야** 결정됩니다

**DP가 적합한 이유:**
- **각 위치마다 독립적으로 결정**을 내릴 수 있습니다
- "이전 합에 더하기" vs "새로 시작하기" 두 선택지만 비교하면 됩니다
- 모든 끝 위치에 대한 최댓값을 저장하므로, 전체 최댓값을 놓치지 않습니다

**구분 기준:**
- 연속 구간의 합/곱 문제 + 음수 포함 → **DP**
- 정렬된 배열에서 두 원소 찾기 → **투포인터**
- 구간 내 조건 만족하는 경우의 수 → **슬라이딩 윈도우 or 투포인터**

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`sys.stdin.readline` 사용|입력이 적어서 `input()` 충분|
|`[0 for i in range(N)]`|`[0] * N`이 더 간결|

## AI 코드 리뷰

### 개선할 점

1. **입출력**: `sys.stdin.readline`은 이 문제에서 불필요합니다. 입력이 적어서 `input()`으로 충분합니다.

2. **리스트 생성**: `[0 for i in range(N)]`보다 `[0] * N`이 더 간결합니다.

3. **주석**: 예시 입력은 테스트용이므로 제출 시 제거하는 것이 좋습니다.

## 수정된 코드

```python
n = int(input())
arr = list(map(int, input().split()))

dp = [0] * n
dp[0] = arr[0]

for i in range(1, n):
    dp[i] = max(dp[i-1] + arr[i], arr[i])

print(max(dp))
```
