# 백준 11051 🔢 이항 계수 2 파이썬

## 느낀점
>
- 잘 풀었다.
- 슬라이딩 윈도우 습관화하자.

## 흐름

1. 파스칼 삼각형의 성질 `C(n, k) = C(n-1, k-1) + C(n-1, k)`를 이용한 DP 테이블 구성
2. `dp[i][j]`는 `C(i, j)`를 의미하며, 기저 조건은 `dp[i][0] = 1`, `dp[i][i] = 1`
3. 이중 반복문으로 테이블을 채우면서 매번 `% 10007` 적용
4. `dp[N][K]` 출력

## 코드

```python
N, K = map(int, input().split())
dp = [[1]*(N+1) for i in range(N+1)]
for i in range(1, N+1):
    for j in range(1, i):
        dp[i][j] = (dp[i-1][j-1] + dp[i-1][j])%10007
print(dp[N][K])
```

## AI 코드 리뷰

### 개선할 점

1. **매직 넘버 상수화**: `10007`이 코드 중간에 직접 사용되어 있어 의미 파악이 어려울 수 있다. `MOD = 10007`로 상수 선언하면 가독성이 올라간다.

2. **초기화 의도 명확화**: `[[1]*(N+1)]`로 전체를 1로 초기화하는 방식은 동작하지만, `dp[i][0] = 1`, `dp[i][i] = 1`만 1인 것이 파스칼 삼각형의 본래 의미이다. 기저 조건을 명시적으로 설정하면 코드의 의도가 더 명확해진다.

3. **입력 최적화**: `sys.stdin.readline` 사용으로 입력 속도를 개선할 수 있다. 이 문제에서는 입력이 한 줄이라 큰 차이는 없지만, 습관적으로 적용하면 좋다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
MOD = 10007

dp = [[0] * (N + 1) for _ in range(N + 1)]
for i in range(N + 1):
    dp[i][0] = 1
    dp[i][i] = 1

for i in range(2, N + 1):
    for j in range(1, i):
        dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j]) % MOD

print(dp[N][K])
```
