# 프로그래머스 43105 📐 정수 삼각형 파이썬

## 느낀점
>
- 시간이 너무 오래걸렸다..
- 문제를 풀다가 내가 지금 하는 풀이가 DP인지 메모이제이션인지 헷갈렸다.
(물론 두 풀이 모두 가능하지만, 내가 뭘하고 있는지 갑자기 헷갈렸다.)
- 결국 삼각형 예시를 들어 규칙성을 찾고 DP로 구현했다.
- 실전에선 이러지 말자
(둘 차이 정리해두자)

## 흐름
1. 삼각형의 꼭대기부터 아래로 내려가면서 각 위치까지의 최대 합을 DP 테이블에 저장
2. 양쪽 끝(j==0, j==i)은 부모가 하나뿐이므로 그대로 더함
3. 중간 위치는 왼쪽 위(`dp[i-1][j-1]`)와 바로 위(`dp[i-1][j]`) 중 큰 값을 선택
4. 마지막 행에서 최댓값을 반환

## 코드
```python
"""
dp로 풀자
[2]에 대해서 [0], [2]는 길이 한개다.
그 중간에 대해서는 길이 2개.
"""
def solution(triangle):
    N = len(triangle)
    dp = [[0]*N for _ in range(N)]
    dp[0][0] = triangle[0][0]
    
    for i in range(1, N):
        for j in range(i+1):
            if(j == 0):
                dp[i][j] = dp[i-1][j] + triangle[i][j]
            if(j == i):
                dp[i][j] = dp[i-1][j-1] + triangle[i][j]
            else:
                dp[i][j] = max(dp[i-1][j-1], dp[i-1][j]) + triangle[i][j]
    return max(dp[N-1])
```

## 질문 & 실수 정리

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`if(j==0)` → `if(j==i)` → `else` 구조|`if` → `elif` → `else`로 변경해야 함. 두 번째 `if`가 False일 때 `else`가 첫 번째 `if`의 결과를 덮어씀|
|j==0일 때 `dp[i-1][j-1]` = `dp[i-1][-1]` 참조|양수 값이라 우연히 통과했지만, 음수가 포함되면 오답 발생|

## AI 코드 리뷰

### 개선할 점

1. **if/elif/else 분기 오류**: `if` → `if` → `else`는 독립된 두 조건문이다. `j == 0`에서 값을 세팅해도 `j == i`가 False이면 `else`에서 덮어쓴다. 반드시 `elif` 체인으로 수정해야 한다.

2. **변수명 개선**: `N`은 관례상 상수에 사용하지만, `n` 또는 `height`가 더 명확하다.

3. **불필요한 2차원 배열**: N×N 배열을 만들지만 실제로는 삼각형 모양만 사용한다. `triangle` 자체를 DP 테이블로 재활용하거나, 이전 행만 유지하면 공간을 절약할 수 있다.

## 수정된 코드

### 풀이 1: 바텀업 DP (원본 코드 정제)
```python
def solution(triangle):
    n = len(triangle)
    dp = [[0] * n for _ in range(n)]
    dp[0][0] = triangle[0][0]

    for i in range(1, n):
        for j in range(i + 1):
            if j == 0:
                dp[i][j] = dp[i - 1][j] + triangle[i][j]
            elif j == i:
                dp[i][j] = dp[i - 1][j - 1] + triangle[i][j]
            else:
                dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + triangle[i][j]

    return max(dp[n - 1])
```

### 풀이 2: functools.lru_cache 메모이제이션
```python
from functools import lru_cache

def solution(triangle):
    n = len(triangle)

    @lru_cache(maxsize=None)
    def dfs(i, j):
        if i == n - 1:
            return triangle[i][j]
        return triangle[i][j] + max(dfs(i + 1, j), dfs(i + 1, j + 1))

    return dfs(0, 0)
```

### 풀이 3: 딕셔너리 직접 메모이제이션
```python
def solution(triangle):
    n = len(triangle)
    memo = {}

    def dfs(i, j):
        if (i, j) in memo:
            return memo[(i, j)]
        if i == n - 1:
            memo[(i, j)] = triangle[i][j]
            return memo[(i, j)]
        result = triangle[i][j] + max(dfs(i + 1, j), dfs(i + 1, j + 1))
        memo[(i, j)] = result
        return result

    return dfs(0, 0)
```

### 세 풀이 비교

| 구분 | 바텀업 DP | lru_cache | 딕셔너리 메모 |
|------|-----------|-----------|---------------|
| 방향 | 아래→위 (테이블 채우기) | 위→아래 (재귀) | 위→아래 (재귀) |
| 시간복잡도 | O(N²) | O(N²) | O(N²) |
| 공간복잡도 | O(N²) | O(N²) + 재귀 스택 | O(N²) + 재귀 스택 |
| 실행 속도 | 가장 빠름 (반복문) | 데코레이터 오버헤드 있음 | 딕셔너리 조회 오버헤드 |
| 재귀 제한 | 없음 | `sys.setrecursionlimit` 필요할 수 있음 | 동일 |
| 코드 간결성 | 보통 | 가장 간결 | 가장 길지만 제어 자유로움 |
| 추천 상황 | 코딩테스트 실전 | 빠른 구현, 작은 입력 | 캐시 세밀 제어 필요 시 |
