## 흐름

1. 지름길 정보를 도착 위치 기준으로 딕셔너리에 저장 (역방향 참조)
2. dp[i] = 위치 0에서 i까지의 최단거리
3. 각 위치 i에서 두 가지 선택지 비교:
   - 일반 도로: dp[i-1] + 1
   - 지름길: dp[시작위치] + 지름길 길이
4. 둘 중 최솟값을 dp[i]에 저장
5. dp[D] 출력

## 코드

```python
from collections import deque, defaultdict
import sys
input = sys.stdin.readline
dic = defaultdict(list)
M, N = map(int, input().split())
for _ in range(M):
    u, v, d = map(int, input().split())
    dic[v].append((u, d))
dp = [0]*(N+1)
for i in range(1, N+1):
    # N까지의 최단거리?
    cand = [dp[i-1]+1]
    for u, d in dic[i]:
        cand.append(dp[u]+d)
    dp[i] = min(cand)
print(dp[N])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 최단경로 문제에서 알고리즘 선택 기준
이 문제처럼 "가중치가 있는 그래프에서 최단거리"를 구할 때, 어떤 알고리즘을 쓸 수 있는지 판단하는 기준이 중요하다.

- **DP**: 이동 방향이 한쪽(왼→오른쪽)으로 고정되어 사이클이 없으면, 위치 순서대로 테이블을 채울 수 있어서 DP가 가능하다. 이 문제는 고속도로가 일방통행이라 DP가 가장 자연스럽다.
- **다익스트라**: 각 위치를 노드, 일반 이동과 지름길을 간선으로 모델링하면 가중 그래프 최단경로 문제가 되므로 다익스트라도 가능하다. 다만 이 문제에서는 오버킬.
- **BFS**: 모든 간선의 가중치가 동일해야 최단경로를 보장한다. 이 문제는 일반 도로(가중치 1)와 지름길(가중치 제각각)이 섞여 있어서 BFS로는 최단거리를 보장할 수 없다.

| 알고리즘 | 적용 가능 | 조건 |
|---|---|---|
| DP | ✅ | 방향이 한쪽이라 순서대로 탐색 가능 |
| 다익스트라 | ✅ | 가중 그래프 최단경로로 모델링 가능 |
| BFS | ❌ | 간선 가중치가 균일하지 않음 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 혼동**: 문제 원문에서 N=지름길 개수, D=고속도로 길이인데, `M, N`으로 뒤바꿔 받아서 혼란 유발. 원문과 일치시키는 것이 좋다.
2. **불필요한 import 제거**: `deque`를 import했지만 사용하지 않으므로 제거.
3. **cand 리스트 대신 변수 비교**: 매번 리스트를 생성하는 대신 변수 하나로 최솟값을 갱신하면 더 간결하다.

## 수정된 코드

### 풀이 1: DP

```python
from collections import defaultdict
import sys
input = sys.stdin.readline

N, D = map(int, input().split())
shortcuts = defaultdict(list)
for _ in range(N):
    s, e, d = map(int, input().split())
    shortcuts[e].append((s, d))

dp = [0] * (D + 1)
for i in range(1, D + 1):
    dp[i] = dp[i - 1] + 1
    for s, d in shortcuts[i]:
        dp[i] = min(dp[i], dp[s] + d)

print(dp[D])
```

### 풀이 2: 다익스트라

```python
import heapq
from collections import defaultdict
import sys
input = sys.stdin.readline

N, D = map(int, input().split())
graph = defaultdict(list)
for _ in range(N):
    s, e, d = map(int, input().split())
    graph[s].append((e, d))

# 일반 도로 간선: 각 위치 i → i+1 (가중치 1)
dist = [float('inf')] * (D + 1)
dist[0] = 0
pq = [(0, 0)]  # (거리, 위치)

while pq:
    cost, cur = heapq.heappop(pq)
    if cost > dist[cur]:
        continue
    # 일반 도로 이동
    if cur + 1 <= D and cost + 1 < dist[cur + 1]:
        dist[cur + 1] = cost + 1
        heapq.heappush(pq, (cost + 1, cur + 1))
    # 지름길 이동
    for nxt, d in graph[cur]:
        if nxt <= D and cost + d < dist[nxt]:
            dist[nxt] = cost + d
            heapq.heappush(pq, (cost + d, nxt))

print(dist[D])
```
