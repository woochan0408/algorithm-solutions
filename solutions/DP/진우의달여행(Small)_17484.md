# 백준 17484 🚀 진우의 달 여행 (Small) 파이썬

## 느낀점
>
- 패딩 배운 후 첫 직접 구현
- 시간단축만 하자.
- 문제 잘 읽고 (같은 방향 또 안된다.)

## 흐름

1. N×M 행렬에서 첫 행(지구)부터 마지막 행(달)까지 이동
2. 이동 방향: ↙(왼쪽 아래), ↓(아래), ↘(오른쪽 아래) 세 가지
3. **제약 조건**: 같은 방향으로 연속 이동 불가
4. 3차원 DP 사용: `dp[i][j][d]` = i행 j열에 방향 d로 도착했을 때 최소 연료
5. 패딩으로 경계 처리 간소화 (열 양쪽에 INF 추가)
6. 점화식: 현재 방향이 d면, 이전 행에서 d가 아닌 방향들 중 최소값 + 현재 비용

## 코드

```python
import sys
input = sys.stdin.readline
R, C = map(int, input().split())
grid = []
for i in range(R):
    arr = list(map(int, input().split()))
    grid.append(arr)
# dp 처음 초기화
dp = [[[float("inf"), float("inf"), float("inf")] for i in range(C+2)] for i in range(R)]
# 초기화하자.. 패딩해서 좀 계산 편리하게 하자.
for i in range(C):
    dp[0][i+1][0] = grid[0][i]
    dp[0][i+1][1] = grid[0][i]
    dp[0][i+1][2] = grid[0][i]
# 계산하자..
for i in range(1, R):
    for j in range(C):
        # 패딩 생각해서 + 1
        # 왼쪽에서 왔을 때 최소는?
        dp[i][j+1][0] = min(dp[i-1][j][1], dp[i-1][j][2]) + grid[i][j]
        # 오른쪽에서 왔을 때 최소는?
        dp[i][j+1][2] = min(dp[i-1][j+2][0], dp[i-1][j+2][1]) + grid[i][j]
        # 중앙에서 왔을 때 최소는?
        dp[i][j+1][1] = min(dp[i-1][j+1][0], dp[i-1][j+1][2]) + grid[i][j]
        
print(min(min(dp[R-1][i+1]) for i in range(C)))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 3차원 DP로 상태 확장하기
단순히 위치(i, j)만으로는 "이전 방향" 정보를 알 수 없을 때, DP 차원을 추가해서 상태를 확장하는 기법이다. `dp[i][j][d]`처럼 "어떤 방향으로 여기 왔는지"를 함께 저장하면, 연속 이동 제한 같은 조건을 처리할 수 있다.
- **핵심 원리**: 상태 정의에 필요한 모든 정보를 DP 차원에 포함
- **시간복잡도**: O(R × C × 방향 수)

#### 패딩을 활용한 경계 처리
배열 양쪽에 `inf` 값으로 패딩을 추가하면 경계 체크 없이 동일한 점화식을 적용할 수 있다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 2차원 DP로 방향 조건 무시 | 3차원 DP로 이전 방향 상태 추가 |
| `dp[R-1][i-1]` (잘못된 인덱스) | `dp[R-1][i+1]` (패딩 고려) |

## AI 코드 리뷰

### 개선할 점

1. **주석 오타**: "최대는?" → "최소는?" (최소 연료를 구하는 문제)

2. **초기화 간소화**: 같은 값 반복 시 곱셈 연산 활용 가능

3. **최종 출력 간소화**: 중첩 min 대신 제너레이터 활용으로 가독성 향상

## 수정된 코드

```python
import sys
input = sys.stdin.readline

R, C = map(int, input().split())
grid = [list(map(int, input().split())) for _ in range(R)]

# dp[행][열][방향]: 패딩 포함 (열 양쪽에 +1씩)
# 방향: 0=왼쪽위에서, 1=바로위에서, 2=오른쪽위에서
INF = float("inf")
dp = [[[INF] * 3 for _ in range(C + 2)] for _ in range(R)]

# 첫 행 초기화 (어느 방향으로든 시작 가능)
for j in range(C):
    dp[0][j + 1] = [grid[0][j]] * 3

# DP 계산
for i in range(1, R):
    for j in range(C):
        col = j + 1  # 패딩 고려한 실제 인덱스
        cost = grid[i][j]
        # 왼쪽 위에서 온 경우 (이전에 왼쪽으로 오지 않았어야 함)
        dp[i][col][0] = min(dp[i - 1][col - 1][1], dp[i - 1][col - 1][2]) + cost
        # 바로 위에서 온 경우 (이전에 아래로 오지 않았어야 함)
        dp[i][col][1] = min(dp[i - 1][col][0], dp[i - 1][col][2]) + cost
        # 오른쪽 위에서 온 경우 (이전에 오른쪽으로 오지 않았어야 함)
        dp[i][col][2] = min(dp[i - 1][col + 1][0], dp[i - 1][col + 1][1]) + cost

# 마지막 행에서 최소값
print(min(dp[R - 1][j][d] for j in range(1, C + 1) for d in range(3)))
```
