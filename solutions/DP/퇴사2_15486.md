## 실패한 코드 흐름

1. 문제를 그래프로 모델링: 각 날짜를 노드로, 상담 선택/미선택을 간선으로 표현
2. **간선 추가 아이디어**: 상담 선택 시 `u → u+t` (가중치: 수익), 상담 미선택 시 `u → u+1` (가중치: 0)으로 N+1번 노드까지 도달
3. 다익스트라로 최소 비용 경로를 구하려 했으나, 이 문제는 **최대 수익**을 구해야 함
4. 다익스트라는 최솟값을 찾는 알고리즘이므로, 양수 가중치 간선 중 0-가중치 경로가 최소로 잡혀 항상 0이 출력됨

## 실패한 코드

```python
import heapq, sys
input = sys.stdin.readline
N = int(input())
graph = [[] for _ in range(N+2)]
for u in range(1, (N+1)):
    t, d = map(int, input().split())
    v = min(N+1, u + t)
    graph[u].append((d, v))
for i in range(1, N+1):
    graph[i].append((0, i+1))
heap = []
heap.append((0, 1))
dist = [float('inf')]*(N+2)
dist[1] = 0
while heap:
    d, cur = heapq.heappop(heap)
    if(dist[cur] < d):
        continue
    for weight, next_node in graph[cur]:
        cost = d + weight
        if(dist[next_node] >= cost):
            dist[next_node] = cost
            heapq.heappush(heap, (cost, next_node))
print(dist[N+1])
```

**문제점**: 다익스트라는 최솟값을 구하는 알고리즘이라 최대 수익 문제에 직접 적용할 수 없고, 음수 변환 시에도 음수 가중치를 처리하지 못한다.

## 성공한 코드 흐름

1. 수익에 `-`를 붙여 최대화 문제를 최소화 문제로 변환
2. 이 그래프는 날짜가 항상 증가하는 **DAG(방향 비순환 그래프)**이므로, 힙 없이 1번부터 순서대로 relaxation
3. `u + t > N+1`이면 퇴사일을 넘기므로 상담 간선을 추가하지 않음
4. 최종 `dist[N+1]`에 `-1`을 곱해 최대 수익 복원

## 성공한 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
graph = [[] for _ in range(N+2)]
for u in range(1, N+1):
    t, d = map(int, input().split())
    if u + t <= N + 1:             # 퇴사일 안 넘길 때만
        graph[u].append((-d, u + t))
    graph[u].append((0, u + 1))   # 상담 안 함

dist = [float('inf')] * (N+2)
dist[1] = 0
for u in range(1, N+2):           # DAG 순서대로 relaxation
    for weight, v in graph[u]:
        if dist[v] > dist[u] + weight:
            dist[v] = dist[u] + weight

print(-dist[N+1])                  # 다시 양수로 복원
```

## 질문 & 실수 정리

### 새로 배운 것

#### 다익스트라 `continue` 조건에서 등호를 빼야 하는 이유
힙에서 `(d, cur)`를 꺼냈을 때 `dist[cur] == d`인 경우는 **아직 인접 노드로 relaxation을 한 번도 안 한 최적 경로**다. 등호를 넣으면(`dist[cur] <= d`) 이 첫 번째 처리까지 skip되어 노드가 아예 처리되지 않는다. 같은 값으로 두 번째 꺼내는 경우는 중복이라 skip해도 되지만, `dist` 비교만으로는 첫 번째인지 두 번째인지 구분할 수 없으므로 등호를 빼야 한다.
- **핵심 원리**: `if dist[cur] < d: continue` — 엄격한 부등호 사용

#### 힙에서 꺼낸 `d`의 의미
`d`는 해당 노드를 **힙에 넣는 시점**에서의 시작점 → cur까지의 최단 거리 추정값이다. 특정 경로 하나의 거리가 아니라, 그 시점까지 갱신된 `dist[cur]` 값을 그대로 복사한 것이다. 힙에 넣은 이후 다른 경로를 통해 더 짧은 거리가 발견되면 `dist[cur]`가 갱신되어 `d > dist[cur]`가 되고, 이때 outdated로 판단하여 skip한다.

#### 이 문제에서 다익스트라가 안 되는 이유
이 문제는 **최대** 수익을 구해야 하는데, 다익스트라는 **최소** 비용을 구하는 알고리즘이다. 수익에 `-`를 붙여 최소화 문제로 변환할 수 있지만, 그러면 가중치가 음수가 된다. 다익스트라는 "힙에서 꺼낸 노드는 이미 최적"이라는 전제로 동작하는데, 음수 가중치가 있으면 나중에 더 작은 값이 발견될 수 있어 이 전제가 깨진다.

#### DAG(Directed Acyclic Graph)와 위상정렬
DAG는 **방향이 있고 순환이 없는 그래프**다. 이 문제에서 간선이 항상 과거→미래로만 향하므로 DAG이다. DAG에서는 **위상정렬 순서**(여기서는 1, 2, ..., N+1)로 relaxation하면 각 노드를 처리할 때 그 노드에 영향을 주는 모든 노드가 이미 처리된 상태이므로, **음수 가중치가 있어도 정확한 답**을 보장한다. 힙이 필요 없고 단순 for문으로 처리 가능하다.
- **위상정렬의 목적**: 순환 없는 그래프에서 의존 관계 순서대로 처리하기 위함

#### DAG relaxation ≈ DP
DAG에서 순서대로 relaxation하는 것은 결국 **DP와 완전히 같은 구조**다. `dist[i]`가 곧 `dp[i]`이고, 간선을 통한 갱신이 곧 점화식이다. 그래프로 모델링하여 DAG relaxation을 하느니, 처음부터 DP로 푸는 것이 자연스럽고 간결하다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`v = min(N+1, u + t)` — 퇴사일 넘기는 상담도 간선 추가|`if u + t <= N + 1`일 때만 간선 추가|
|`dist[1] = 0` 초기화 누락|시작 노드 dist 초기화 필수|
|`range(v, min(v, N+2))` — 항상 빈 범위|루프 없이 간선을 직접 추가|

## AI 코드 리뷰

### 개선할 점

1. **DP로 전환**: 이 문제는 DAG 구조를 이용한 그래프 풀이보다 DP가 훨씬 자연스럽다. 그래프 생성, 음수 변환, 복원 과정이 모두 생략되어 코드가 간결해진다.
2. **역방향 DP 활용**: `dp[i] = i일부터 마지막 날까지 최대 수익`으로 정의하면, 뒤에서부터 순회하며 상담 선택/미선택만 비교하면 된다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
T = [0] * (N + 1)
P = [0] * (N + 1)
for i in range(1, N + 1):
    T[i], P[i] = map(int, input().split())

# dp[i]: i일부터 마지막 날까지 얻을 수 있는 최대 수익
dp = [0] * (N + 2)
for i in range(N, 0, -1):
    if i + T[i] <= N + 1:
        dp[i] = max(dp[i + 1], P[i] + dp[i + T[i]])  # 상담 선택 vs 미선택
    else:
        dp[i] = dp[i + 1]  # 상담 불가 → 다음 날로

print(dp[1])
```
