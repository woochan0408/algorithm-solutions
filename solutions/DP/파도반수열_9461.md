## 흐름
1. 여러 테스트 케이스가 존재하므로 입력을 모두 저장
2. 가장 큰 N 값을 구해 그 범위까지만 DP 테이블 생성
3. 점화식 `dp[n] = dp[n-2] + dp[n-3]` 적용
4. 요청된 값만 출력

## 코드
```python
"""
1, 1, 1, 2, 2, 3, 4, 5, 7, 9
n-2 n-3 더한거구나

"""
import sys
input = sys.stdin.readline

T = int(input())
req = []

for _ in range(T):
    req.append(int(input()))
m = max(req)

dp = [0] * (m+1)
dp[1] = 1
dp[2] = 1
dp[3] = 1

for i in range(4, m+1):
    dp[i] = dp[i-2] + dp[i-3]
for cur in req:
    print(dp[cur])
```

---
## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**
   - `req` → `queries`
   - `m` → `max_n`
   의미가 더 명확해짐.

2. **초기값 안전 처리**
   현재는 `m >= 3`이 보장되지만, 일반화하면 조건 분기 처리하는 습관이 좋다.

3. **가독성 개선**
   입력과 출력 부분을 논리적으로 구분하면 더 읽기 쉬움.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

T = int(input())
queries = [int(input()) for _ in range(T)]

max_n = max(queries)

dp = [0] * (max_n + 1)

if max_n >= 1:
    dp[1] = 1
if max_n >= 2:
    dp[2] = 1
if max_n >= 3:
    dp[3] = 1

for i in range(4, max_n + 1):
    dp[i] = dp[i - 2] + dp[i - 3]

for n in queries:
    print(dp[n])
```
