## 흐름
1. 여러 테스트 케이스가 존재하므로 입력을 모두 저장
2. 가장 큰 N 값을 구해 그 범위까지만 DP 테이블 생성
3. 점화식 `dp[n] = dp[n-2] + dp[n-3]` 적용
4. 요청된 값만 출력

## 코드
```python
"""
1, 1, 1, 2, 2, 3, 4, 5, 7, 9
n-2 n-3 더한거구나

"""
import sys
input = sys.stdin.readline

T = int(input())
req = []

for _ in range(T):
    req.append(int(input()))
m = max(req)

dp = [0] * (m+1)
dp[1] = 1
dp[2] = 1
dp[3] = 1

for i in range(4, m+1):
    dp[i] = dp[i-2] + dp[i-3]
for cur in req:
    print(dp[cur])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 점화식 관찰을 통한 DP 설계
수열의 앞부분을 직접 써보면서 규칙을 찾는 방식은 DP 문제에서 매우 중요하다.

- **핵심 원리**: 작은 값에서 규칙을 찾고 일반화한다.
- **시간복잡도**: O(N)

#### 여러 테스트 케이스 최적화 처리
매번 DP를 계산하지 않고, 최대값까지만 한 번 계산 후 재사용하는 방식은 효율적인 처리 방법이다.

- **핵심 원리**: 중복 계산 제거
- **시간복잡도**: O(maxN)

---

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|매 테스트마다 DP 생성 가능성|최대값 기준 한 번만 생성|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**
   - `req` → `queries`
   - `m` → `max_n`
   의미가 더 명확해짐.

2. **초기값 안전 처리**
   현재는 `m >= 3`이 보장되지만, 일반화하면 조건 분기 처리하는 습관이 좋다.

3. **가독성 개선**
   입력과 출력 부분을 논리적으로 구분하면 더 읽기 쉬움.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

T = int(input())
queries = [int(input()) for _ in range(T)]

max_n = max(queries)

dp = [0] * (max_n + 1)

if max_n >= 1:
    dp[1] = 1
if max_n >= 2:
    dp[2] = 1
if max_n >= 3:
    dp[3] = 1

for i in range(4, max_n + 1):
    dp[i] = dp[i - 2] + dp[i - 3]

for n in queries:
    print(dp[n])
```
