## 실패한 코드 흐름

1. BFS로 모든 경로를 완전탐색하는 방식
2. 현재 상태(방향)에서 이동 가능한 다음 상태들을 검증 후 큐에 추가
3. (N-1, N-1) 도달 시 결과 카운트 증가

## 실패한 코드

```python
import sys
from collections import deque
input = sys.stdin.readline
N = int(input())
grid = []
# 0 : 가로상태, 1 : 대각상태, 2: 세로상태
validateMove = {0: [(0, 1)], 1 : ((1, 1), (1, 0), (0, 1)), 2 : [(1, 0)]}
for i in range(N):
    grid.append(list(map(int, input().split())))
dq = deque([(0, 0, 1)])
result = 0
while dq:
    cur = dq.popleft()
    curState = cur[0]
    x = cur[1]
    y = cur[2]
    #도착했다면 결과 추가
    if(x == N-1 and y == N-1):
        result += 1
        continue
    # visited는 있을 필요가 없다 (모든 경우의 수 구하는거니까)
    nextState = set()
    nextState.add(max(0, curState-1))
    nextState.add(min(2, curState+1))
    nextState.add(curState)
    # 모든 nextState에 대해서 검증할 것임
    for nextS in nextState:
        
        # 이걸 다 검증해야 이동 가능
        vaildateCoor = validateMove[nextS]
        canMove = True
        for dx, dy in vaildateCoor:
            nx = x + dx
            ny = y + dy
            if(0 <= nx < N and 0 <= ny < N and grid[nx][ny] != 1):
                continue
            canMove = False
        if(canMove):
            mx = x + validateMove[nextS][0][0]
            my = y + validateMove[nextS][0][1]
            dq.append((nextS, mx, my))
print(result)
```

**문제점**: 같은 (위치, 방향) 상태에 여러 경로로 도달할 때마다 중복 탐색하여 시간초과 발생

## 성공한 코드 흐름

1. `dp[x][y][방향]` = (x, y)에 해당 방향으로 도달하는 경우의 수 정의
2. 방향별로 이전 상태에서 전이 가능한 경우의 수를 합산
   - 가로(0): 왼쪽에서 가로 또는 대각선으로 온 경우
   - 세로(2): 위에서 세로 또는 대각선으로 온 경우
   - 대각선(1): 왼쪽 위에서 모든 방향으로 온 경우 (3칸 빈 칸 검증 필요)
3. 최종 답: `dp[N-1][N-1][0] + dp[N-1][N-1][1] + dp[N-1][N-1][2]`

## 성공한 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
grid = [list(map(int, input().split())) for _ in range(N)]

# dp[x][y][상태] = 해당 위치에 해당 상태로 도달하는 경우의 수
# 상태: 0=가로, 1=대각선, 2=세로
dp = [[[0] * 3 for _ in range(N)] for _ in range(N)]
dp[0][1][0] = 1  # 초기 상태: (0,1)에 가로로 놓임

for x in range(N):
    for y in range(2, N):
        if grid[x][y] == 1:
            continue
        
        # 가로로 도달: 왼쪽에서 가로 또는 대각선
        dp[x][y][0] = dp[x][y-1][0] + dp[x][y-1][1]
        
        # 세로로 도달: 위에서 세로 또는 대각선
        if x > 0:
            dp[x][y][2] = dp[x-1][y][2] + dp[x-1][y][1]
        
        # 대각선으로 도달: 왼쪽 위에서 모든 방향
        # 단, 위(x-1,y)와 왼쪽(x,y-1)도 빈 칸이어야 함
        if x > 0 and grid[x-1][y] == 0 and grid[x][y-1] == 0:
            dp[x][y][1] = dp[x-1][y-1][0] + dp[x-1][y-1][1] + dp[x-1][y-1][2]

print(sum(dp[N-1][N-1]))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 3차원 DP를 이용한 상태 전이
경로의 개수를 구할 때, 단순 BFS는 같은 상태에 여러 경로로 도달하면 중복 탐색이 발생한다. DP를 사용하면 각 상태에 도달하는 경우의 수를 저장하여 중복 계산을 방지할 수 있다.
- **핵심 원리**: `dp[위치][방향]` = 해당 상태로 도달하는 모든 경우의 수를 누적
- **시간복잡도**: O(N²) - 각 칸을 한 번씩만 방문

#### BFS vs DP 선택 기준
모든 경로를 탐색해야 하지만 "경로의 개수"만 필요한 경우, BFS보다 DP가 효율적이다. BFS는 실제 경로 추적이 필요할 때 적합하다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `dq.append((nextS, nx, ny))` | `dq.append((nextS, mx, my))` |
| BFS로 모든 경로 탐색 (시간초과) | DP로 경우의 수 누적 (O(N²)) |
