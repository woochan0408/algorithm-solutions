## 흐름
1. `dp[길이] = (최소 일수, 최소 물)`로 상태 정의
2. 목표 길이 N에서 역방향으로 탐색 (top-down 재귀)
3. 각 길이에서 3가지 역연산 시도: `-1`, `//3` (3으로 나누어떨어질 때), `sqrt` (완전제곱수일 때)
4. 후보 중 `(일수, 물)` 기준 최솟값을 메모이제이션

## 코드
```python
memo = {0 : (0, 0), 1 : (1, 1)}
import sys, math
sys.setrecursionlimit(10**6)
def dfs(n):
    if(n in memo):
        return memo[n]
    cand = []
    nn = math.isqrt(n)
    if nn*nn == n:
        nn = int(nn)
        d = dfs(nn)
        a, b = d[0]+1, d[1]+5
        cand.append((a, b))
    if n%3 == 0:
        nn = n//3
        d = dfs(nn)
        a, b = d[0]+1, d[1]+3
        cand.append((a, b))
    d = dfs(n-1)
    a, b = d[0]+1, d[1]+1
    cand.append((a, b))
    cand.sort()
    memo[n] = cand[0]
    return memo[n]
N = int(input())
print(' '.join(map(str, dfs(N))))
```

## 질문 & 실수 정리

### 새로 배운 것

#### float 타입과 정수 판별
파이썬에서 `/` 나눗셈과 `**` 거듭제곱은 항상 `float`를 반환한다. 따라서 `isinstance(n / 3, int)`는 항상 `False`이고, `n ** (1/2)`도 마찬가지다. 정수 나누어떨어짐은 `n % 3 == 0`으로, 정수 제곱근은 `math.isqrt()`로 판별해야 한다.
- **핵심 원리**: `math.isqrt(n)`은 n 이하의 최대 정수 제곱근을 반환하며, `sq * sq == n`으로 완전제곱수 여부를 정확하게 확인할 수 있다.

#### Bottom-up DP 전환
top-down 재귀 DP는 `n-1` 체인이 깊어지면 파이썬 재귀 한계(실제 OS 스택 크기)에 걸린다. `setrecursionlimit`을 올려도 해결되지 않는 경우가 있다. 이럴 때는 `for i in range(...)` 반복문으로 bottom-up 전환하면 동일한 로직을 재귀 없이 처리할 수 있다.
- **핵심 원리**: 모든 상태 전이가 작은 인덱스 → 큰 인덱스 방향이면, 순방향 반복문으로 안전하게 전환 가능하다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `isinstance(n/3, int)`으로 정수 판별 | `n % 3 == 0`으로 나누어떨어짐 확인 |
| `n**(1/2)`로 제곱근 구하기 (float 오차) | `math.isqrt(n)`으로 정수 제곱근 구하기 |
| `import sys` 없이 `sys.setrecursionlimit` 사용 | `import sys` 추가 |

## AI 코드 리뷰

### 개선할 점

1. **bottom-up 순방향 DP로 전환**: `n-1` 재귀 체인으로 N=1,000,000에서 스택 오버플로 위험이 있다. 길이 0에서 출발하여 `+1`, `*3`, `제곱` 연산으로 N까지 도달하는 bottom-up 방식이 안전하다.
2. **변수명 개선**: `d`, `a`, `b`, `nn` 등을 `days`, `water` 등 의미가 드러나는 이름으로 변경.
3. **cand 리스트 + sort 대신 직접 비교**: 후보를 리스트에 모아 정렬하는 대신, 각 연산마다 현재 최솟값과 비교하여 갱신하면 더 간결하다.

## 수정된 코드
```python
import sys
import math

input = sys.stdin.readline

N = int(input())

if N == 0:
    print(0, 0)
else:
    INF = (float('inf'), float('inf'))
    dp = [INF] * (N + 1)
    dp[0] = (0, 0)

    for i in range(N + 1):
        if dp[i] == INF:
            continue
        days, water = dp[i]

        # 물 1: 길이 +1
        if i + 1 <= N:
            new = (days + 1, water + 1)
            if new < dp[i + 1]:
                dp[i + 1] = new

        # 물 3: 길이 *3
        if i * 3 <= N:
            new = (days + 1, water + 3)
            if new < dp[i * 3]:
                dp[i * 3] = new

        # 물 5: 길이 제곱
        if i >= 2 and i * i <= N:
            new = (days + 1, water + 5)
            if new < dp[i * i]:
                dp[i * i] = new

    print(dp[N][0], dp[N][1])
```
