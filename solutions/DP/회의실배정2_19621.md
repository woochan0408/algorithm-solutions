# 백준 19621 🏢 회의실 배정 2 파이썬

## 느낀점
>
- 제한 조건 안 읽어서 못 풀음.. 문제 꼼꼼히 읽자.

## 흐름

1. 핵심 제한 조건 파악: "회의 K는 K-1, K+1과만 겹친다" → 연속 선택 불가
2. House Robber DP 패턴 적용
3. 점화식: `dp[i] = max(dp[i-2] + meetings[i], dp[i-1])`
4. i번째 회의를 선택하면 i-1은 못 쓰고 i-2까지의 최대값에 더함
5. 선택 안 하면 i-1까지의 최대값 유지

## 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
meetings = []
for _ in range(N):
    meetings.append(tuple(map(int, input().split())))
if(N == 1):
    print(meetings[0][2])
elif(N == 2):
    print(max(meetings[0][2], meetings[1][2]))
else:
    dp = [0]*N
    dp[0] = meetings[0][2]
    dp[1] = max(meetings[0][2], meetings[1][2])
    for i in range(2, N):
        dp[i] = max(dp[i-2] + meetings[i][2], dp[i-1])
    print(dp[N-1])
```

## AI 코드 리뷰

### 개선할 점

1. **예외 처리 통합**: N == 1, N == 2 케이스를 따로 처리하지 않아도 됨. 초기화 방식으로 모든 케이스 커버 가능

2. **공간 최적화**: dp 배열 대신 변수 2개만 사용하면 O(1) 공간으로 개선

3. **리스트 컴프리헨션**: for 루프 대신 한 줄로 입력 처리 가능

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
meetings = [tuple(map(int, input().split())) for _ in range(N)]

prev2 = 0
prev1 = 0

for i in range(N):
    people = meetings[i][2]
    curr = max(prev2 + people, prev1)
    prev2 = prev1
    prev1 = curr

print(prev1)
```
