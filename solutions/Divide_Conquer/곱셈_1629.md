## 흐름

1. B를 이진수로 변환 (LSB부터 저장)
2. 이진수의 각 자리는 2^0, 2^1, 2^2... 를 의미
3. cur을 A^1 → A^2 → A^4 → A^8... 로 제곱하며 갱신
4. 해당 비트가 1이면 result에 cur을 곱함
5. 모든 연산에서 C로 나눈 나머지 유지

## 코드

```python
from collections import deque
A, B, C = map(int, input().split())

# 이진수 변환 (Reverse 그대로 사용)
def to2Reverse(n):
    dq = deque()
    while (n > 0):
        dq.append(n%2)
        n = n//2
    result = ""
    for i in range(len(dq)):
        result += str(dq[i])
        
    return result

cur = A
result = 1
BString = to2Reverse(B)
for c in BString:
    if(c == '1'):
        result = (cur*result)%C
    cur = (cur*cur)%C
print(result)
```

## AI 코드 리뷰

### 개선할 점

1. **불필요한 deque 사용**: 단방향 append만 하므로 일반 리스트로 충분함

2. **문자열 변환 불필요**: 비트를 문자열로 바꿨다가 다시 비교할 필요 없이, 정수 리스트로 직접 처리 가능

3. **문자열 연결 비효율**: `result += str(dq[i])`는 매번 새 문자열을 생성하므로 O(n²). 리스트에 모아서 `join` 하거나 정수 리스트 사용 권장

4. **더 간단한 방법**: 파이썬 내장 `pow(A, B, C)`는 동일한 알고리즘을 C로 최적화하여 구현되어 있음

## 수정된 코드

```python
import sys
input = sys.stdin.readline

A, B, C = map(int, input().split())

def get_bits(n):
    """n을 이진수로 변환하여 LSB부터 비트 리스트로 반환"""
    bits = []
    while n > 0:
        bits.append(n % 2)
        n //= 2
    return bits

bits = get_bits(B)
cur = A
result = 1

for bit in bits:
    if bit == 1:
        result = (cur * result) % C
    cur = (cur * cur) % C

print(result)
```
