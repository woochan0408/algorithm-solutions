## 흐름

1. 힙에 튜플 `(절댓값, 원래값)` 형태로 저장
2. heapq는 첫 번째 요소 기준 정렬 → 절댓값이 같으면 두 번째 요소(원래값)로 비교
3. 0 입력 시 힙에서 pop하여 원래값 출력

## 코드
```python
import sys, heapq
input = sys.stdin.readline
N = int(input())
heap = []
for _ in range(N):
    n = int(input())
    if(n != 0):
        heapq.heappush(heap, (abs(n), n))
    if(n == 0):
        if(heap):
            print(heapq.heappop(heap)[1])
        else:
            print(0)
```

## AI 코드 리뷰

### 개선할 점

1. **조건문 구조**: `if(n != 0)` 다음에 `if(n == 0)`은 `else`로 바꾸는 게 더 명확함

2. **변수명**: `n` → `x`가 문제 설명과 일치

import heapq

input = sys.stdin.readline
