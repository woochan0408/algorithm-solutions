# 백준 11279 🔝 최대 힙 파이썬

## 느낀점
>
- heapq 기본문법 복습

## 흐름

1. 파이썬 `heapq`는 최소 힙만 지원하므로, 음수 변환으로 최대 힙 구현
2. 값을 넣을 때 `-q`로 넣고, 뺄 때 `abs()`로 원래 값 복원
3. 힙이 비어있을 때 0 출력 처리

## 코드
```python
import heapq
import sys
input = sys.stdin.readline
N = int(input())
heap = []
for _ in range(N):
    q = int(input())
    
    if(q != 0):
        heapq.heappush(heap, -q)
    else:
        if(heap):
            print(abs(heapq.heappop(heap)))
        else:
            print(0)
```

### 개선할 점

1. **변수명 개선**: `q`보다는 `x` 또는 `num`이 문제 설명과 일치하여 더 직관적

## 수정된 코드
```python
import heapq
import sys

input = sys.stdin.readline

N = int(input())
heap = []

for _ in range(N):
    x = int(input())
    
    if x != 0:
        heapq.heappush(heap, -x)
    else:
        if heap:
            print(-heapq.heappop(heap))
        else:
            print(0)
```
