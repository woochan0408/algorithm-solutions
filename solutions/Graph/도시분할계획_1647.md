- 개념서 보고 풀었으므로 꼭 다시 풀어보자.

## 흐름

1. 간선 리스트를 가중치 기준 오름차순 정렬
2. Union-Find로 사이클을 피하면서 간선을 하나씩 선택 (크루스칼)
3. N-1개가 아닌 **N-2개**만 선택하면 자연스럽게 두 마을로 분리됨
4. 선택된 간선의 가중치 합 = 답

## 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
edges = []
for _ in range(M):
    u, v, w = map(int, input().split())
    edges.append((u, v, w))
edges.sort(key = lambda x : x[2])
parent = [i for i in range(N+1)]
def find(n):
    if(parent[n] != n):
        parent[n] = find(parent[n])
    return parent[n]
def union(a, b):
    a = find(a)
    b = find(b)
    if(a == b):
        return False
    parent[b] = a
    return True
total = 0
count = 0
s = 0
for a, b, cost in edges:
    if(union(a, b)):
        count += 1
        total += cost
    if(count == N-2):
        s = cost
        break
hap = sum(edges[i][2] for i in range(len(edges)))
print(total)
```

## 질문 & 실수 정리

### 새로 배운 것

#### MST (최소 신장 트리)
모든 정점을 사이클 없이 최소 비용으로 연결하는 트리. 정점 N개를 연결하려면 간선이 정확히 N-1개 필요하고, N-2개만 선택하면 그래프가 2개의 컴포넌트로 분리된다. 이 성질을 이용하면 "두 그룹으로 나누면서 비용 최소화" 문제를 풀 수 있다.
- **핵심 원리**: 가장 싼 간선부터 선택하되 사이클이 생기면 스킵 (크루스칼)
- **시간복잡도**: O(E log E)

#### Union-Find (서로소 집합)
크루스칼에서 사이클 판별에 사용하는 자료구조. 두 노드의 루트가 같으면 이미 연결된 상태이므로 그 간선을 추가하면 사이클이 된다. 경로 압축을 적용하면 find 연산이 거의 O(1)에 수행된다.
- **핵심 원리**: find로 루트 탐색 + union으로 집합 합치기
- **시간복잡도**: O(α(N)) ≈ O(1) (경로 압축 시)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 인접 리스트로 그래프를 그림 | 크루스칼은 간선 리스트만 필요 |
| `hap - total`로 출력 (전체 간선 합 - MST 일부) | `total` 자체가 답 (N-2개 간선의 비용 합) |
| total이 한 마을의 가중치 합이라고 생각 | N-2개 선택 시 total은 두 마을의 비용 합 전체 |

## AI 코드 리뷰

### 개선할 점

1. **사용하지 않는 변수 제거**: `s`와 `hap`은 계산만 하고 사용하지 않는 dead code이다. 코드 가독성을 위해 제거해야 한다.

2. **break 조건을 union 내부로 이동**: `if(count == N-2)` 체크가 union 성공 여부와 무관하게 매 반복 실행된다. 현재 코드에서는 결과적으로 동작하지만, union 성공 블록 안에 넣는 것이 논리적으로 명확하다.

3. **parent 초기화 간소화**: `[i for i in range(N+1)]`은 `list(range(N+1))`로 동일하게 작성할 수 있다.

4. **union에 rank 최적화 추가**: 현재 항상 `parent[b] = a`로 합치는데, rank(또는 size) 기반으로 합치면 트리 깊이를 줄여 최악의 경우 성능이 개선된다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())
edges = []
for _ in range(M):
    u, v, w = map(int, input().split())
    edges.append((u, v, w))

edges.sort(key=lambda x: x[2])

parent = list(range(N + 1))
rank = [0] * (N + 1)

def find(x):
    if parent[x] != x:
        parent[x] = find(parent[x])
    return parent[x]

def union(a, b):
    a, b = find(a), find(b)
    if a == b:
        return False
    if rank[a] < rank[b]:
        a, b = b, a
    parent[b] = a
    if rank[a] == rank[b]:
        rank[a] += 1
    return True

total = 0
count = 0

for a, b, cost in edges:
    if union(a, b):
        total += cost
        count += 1
        if count == N - 2:
            break

print(total)
```
