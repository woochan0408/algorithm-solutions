## 흐름

1. 간선 리스트를 가중치 기준으로 오름차순 정렬 (Kruskal)
2. Union-Find 자료구조 초기화 (경로 압축 + rank 기반 합치기)
3. 가중치가 작은 간선부터 순회하며, 두 정점이 다른 집합이면 union하고 가중치 누적
4. N-1개의 간선을 선택하면 종료
5. 누적 가중치 출력

## 코드
```python
import sys
input = sys.stdin.readline
N,M = map(int, input().split())
rank = [1]*(N+1)
parent = list(range(N+1))
edges = []
def find(n):
    if(n != parent[n]):
        parent[n] = find(parent[n])
    return parent[n]
def union(a, b):
    a = find(a)
    b = find(b)
    if(a == b):
        return False
    if(rank[a] < rank[b]):
        a, b = b, a
    parent[b] = a
    if(rank[a] == rank[b]):
        rank[a] += 1
    return True
for i in range(M):
    u, v, w = map(int, input().split())
    edges.append((w, u, v))
edges.sort()
cost = 0
count = 0
for cur in edges:
    w, u, v = cur
    if(union(u, v)):
        cost += w
        count += 1
    if(count == N-1):
        break
print(cost)
```

## 질문 & 실수 정리

### 새로 배운 것

#### Kruskal 알고리즘
그래프의 최소 스패닝 트리(MST)를 구하는 대표적인 그리디 알고리즘. 간선을 가중치 기준으로 정렬한 뒤, 사이클을 만들지 않는 간선만 선택해 나가는 방식이다. 사이클 판별에 Union-Find를 사용하면 효율적으로 동작한다.
- **핵심 원리**: 가중치가 작은 간선부터 탐욕적으로 선택하되, 같은 집합에 속한 정점 간의 간선은 스킵 (사이클 방지)
- **시간복잡도**: O(E log E) — 간선 정렬이 지배적

#### Union-Find (경로 압축 + rank 기반 합치기)
서로소 집합을 효율적으로 관리하는 자료구조. find 시 경로 압축으로 트리를 평탄화하고, union 시 rank가 낮은 트리를 높은 트리 아래에 붙여 트리 높이를 최소화한다.
- **핵심 원리**: 경로 압축(path compression) + union by rank로 거의 O(α(N)) ≈ O(1)에 동작
- **시간복잡도**: 연산 당 O(α(N)) — α는 아커만 역함수, 사실상 상수

## AI 코드 리뷰

### 개선할 점

1. **`rank` 초기값**: `[1]*(N+1)`로 초기화했는데, 관례적으로 rank는 0에서 시작함. 동작에는 문제없지만 통상적인 컨벤션에 맞추면 `[0]*(N+1)`.
2. **반복문 언패킹 간소화**: `for cur in edges:` 후 `w, u, v = cur` 대신 `for w, u, v in edges:`로 바로 언패킹하면 더 깔끔함.
3. **변수명 문제 매칭**: 문제에서 정점 수를 V, 간선 수를 E로 정의하는데, N/M으로 받으면 문제와의 대응이 떨어짐. `V, E`로 받으면 가독성 향상.
