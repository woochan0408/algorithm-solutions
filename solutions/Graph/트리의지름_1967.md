# 백준 1967 🌳 트리의 지름 파이썬

## 느낀점
>
- 새로운 트리의 특징을 배웠다.
- 다시 풀 필요는 없고 정리한 것 한번 더 읽어보자

---

## 실패한 코드 흐름
1. 자식이 2개 이상인 노드만 후보(`cand`)로 선정하고, 해당 노드에서 아래로 BFS를 돌려 가장 긴 두 경로의 합을 지름으로 계산
2. 자식이 2개 이상인 노드가 없으면(일직선 트리) 루트에서 총 거리를 계산
3. **문제점**:
   - 단방향 그래프만 구성해서 부모 방향 경로를 고려하지 못함
   - 자식 수 기반 후보 선정이 불완전함 (예: `1→2→3→4`에서 노드 2만 자식 2개인데, 실제 지름은 부모 경유 경로)
   - 일직선 보정 로직을 추가해도 근본적으로 "위로 올라가는 경로"를 놓침

## 실패한 코드
```python
from collections import deque, Counter
import sys
input = sys.stdin.readline
N = int(input())
parent = [-1]*(N+1)
counter = Counter()
graph = [[] for _ in range(N+1)]
for i in range(N-1):
    u, v, w = map(int, input().split())
    counter.update([u])
    graph[u].append((v, w))
cand = set()
for k in counter:
    if(counter[k] >= 2):
        cand.add(k)
def maxL(n):
    dq = deque()
    dq.append((n, 0))
    ans = []
    while dq:
        node, value = dq.popleft()
        for v, w in graph[node]:
            cost = value + w
            if(not graph[v]):
                ans.append(cost)
                continue
            dq.append((v, cost))
    ans.sort()
    return ans[-1] + ans[-2]
def straight():
    dq = deque()
    dq.append((1, 0))
    total = 0
    while dq:
        node, value = dq.popleft()
        for v, w in graph[node]:
            cost = value + w
            total = max(total, cost)
            dq.append((v, cost))
    return total
answer = 0
if(len(cand) >= 1):
    for cur in cand:
        answer = max(answer, maxL(cur))
else:
    answer = straight()
print(answer)
```

**문제점**: 단방향 그래프 + 자식 수 기반 후보 선정으로, 부모를 경유하는 지름 경로를 탐색할 수 없음

## 성공한 코드 흐름

1. 양방향 그래프를 구성
2. 임의의 노드(1번)에서 BFS → 가장 먼 노드 A를 찾음 (지름의 한쪽 끝점)
3. 노드 A에서 다시 BFS → 가장 먼 거리가 트리의 지름
4. **원리**: 임의의 노드에서 가장 먼 노드는 반드시 지름의 끝점이다. 만약 끝점이 아니라면 더 먼 노드가 존재하게 되어 "가장 멀다"는 가정에 모순

## 성공한 코드
```python
from collections import deque
import sys
input = sys.stdin.readline
N = int(input())
parent = [-1]*(N+1)
graph = [[] for _ in range(N+1)]
for i in range(N-1):
    u, v, w = map(int, input().split())
    graph[u].append((v, w))
    graph[v].append((u, w))
def maxL(n):
    dq = deque()
    dq.append((n, 0))
    visited = [False]*(N+1)
    visited[n] = True
    ansV = 0
    ansN = 0
    while dq:
        node, value = dq.popleft()
        for v, w in graph[node]:
            if(visited[v]):
                continue
            visited[v] = True
            cost = value + w
            if(ansV < cost):
                ansV = cost
                ansN = v
            dq.append((v, cost))
    return (ansN, ansV)
re = maxL(1)
sult = maxL(re[0])
print(sult[1])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 트리의 지름 (BFS 2번)
트리에서 가장 긴 경로(지름)를 구하는 표준 알고리즘. 임의의 노드에서 BFS를 돌려 가장 먼 노드를 찾으면, 그 노드는 반드시 지름의 한쪽 끝점이다. 해당 끝점에서 다시 BFS를 돌리면 최대 거리가 지름이 된다.
- **핵심 원리**: 임의의 노드에서 가장 먼 노드가 지름의 끝점이 아니라고 가정하면 모순 (더 먼 노드가 존재해야 하므로)
- **시간복잡도**: O(N) — BFS 2번

#### 양방향 그래프에서 visited 처리
양방향 그래프로 BFS를 돌릴 때, 시작 노드를 반드시 방문 처리해야 한다. 그렇지 않으면 인접 노드에서 시작 노드로 다시 돌아오는 순환이 발생한다.
- **핵심 원리**: `visited[start] = True`를 BFS 시작 전에 설정

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|단방향 그래프만 구성|양방향 그래프 구성 필요 (부모 경유 경로 탐색)|
|자식 수 기반으로 후보 노드 선정|BFS 2번으로 지름의 끝점을 직접 탐색|
|시작 노드 visited 처리 누락|`visited[n] = True` 시작 전 설정|
|`if(not graph[v])`로 리프 판별|양방향 그래프에서는 모든 노드가 간선을 가지므로 불가|
|갱신 시 `continue`로 큐 삽입 차단|갱신 여부와 관계없이 항상 `dq.append` 실행|

## AI 코드 리뷰

### 개선할 점

1. **사용하지 않는 변수 제거**: `parent` 배열이 선언만 되고 사용되지 않음
2. **변수명 개선**: `ansV`, `ansN`, `re`, `sult` 등 의미가 불분명한 이름 → 의도가 드러나는 이름으로 변경
3. **함수 반환 구조 명확화**: 튜플 반환 시 인덱스 접근(`re[0]`, `sult[1]`)보다 의미 있는 변수에 언패킹

## 수정된 코드
```python
from collections import deque
import sys
input = sys.stdin.readline

N = int(input())
graph = [[] for _ in range(N + 1)]
for _ in range(N - 1):
    parent, child, weight = map(int, input().split())
    graph[parent].append((child, weight))
    graph[child].append((parent, weight))

def bfs_farthest(start):
    dq = deque()
    dq.append((start, 0))
    visited = [False] * (N + 1)
    visited[start] = True
    max_distance = 0
    farthest_node = start
    while dq:
        node, distance = dq.popleft()
        for neighbor, weight in graph[node]:
            if visited[neighbor]:
                continue
            visited[neighbor] = True
            new_distance = distance + weight
            if new_distance > max_distance:
                max_distance = new_distance
                farthest_node = neighbor
            dq.append((neighbor, new_distance))
    return farthest_node, max_distance

endpoint, _ = bfs_farthest(1)
_, diameter = bfs_farthest(endpoint)
print(diameter)
```
