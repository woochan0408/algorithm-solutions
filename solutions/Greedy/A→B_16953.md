# 백준 16953 🔄 A → B 파이썬

## 느낀점
>
- 그리디가 먼저 떠올랐지만 반례가 있을 것 같아 시도를 못했다.
- 생각해보니 끝자리에 1을 더한다는게 포인트이다. (2도 아니고 1)
- 결국 경로는 1개로 정해지고 이 떄문에 그리디가 가능해진다.

## 흐름
- 단순 BFS 로직

## 코드
```python
from collections import deque
N, M = map(int, input().split())
dq = deque([N])
found = False
level = 1
while dq:
    level += 1
    for i in range(len(dq)):
        cur = dq.popleft()
        next = [cur*10 + 1, cur*2]
    
        for n in next:
            if(n == M):
                found = True
                break
            if(n <= M):
                dq.append(n)
    if(found):
        print(level)
        break
if(not found):
    print(-1)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 역방향 탐색으로 그리디 전환
A→B 방향에서는 매 단계 2가지 선택지(×2, 끝에 1 추가)가 있어서 어떤 걸 먼저 해야 할지 판단이 어렵다. 하지만 B→A 방향으로 뒤집으면 선택지가 유일해진다. B가 짝수면 2로 나누는 수밖에 없고, 홀수이면서 끝자리가 1이면 그 1을 제거(//10)하는 수밖에 없고, 둘 다 아니면 불가능. 이렇게 역방향에서 선택지가 하나뿐인 구조는 그리디가 성립하는 전형적인 패턴이다.
- **핵심 원리**: 정방향에서 그리디가 안 되면 역방향을 고려해본다
- **시간복잡도**: O(log B) — BFS의 최악 케이스보다 훨씬 효율적

#### 역방향 그리디가 성립하지 않는 조건
역방향 그리디의 핵심은 "역연산이 유일하게 결정되는가"이다. 이 문제에서 ×2의 역연산은 "짝수일 때 //2", 끝에 1 추가의 역연산은 "끝자리가 1일 때 //10"으로 서로 겹치지 않아 선택지가 항상 하나뿐이다. 만약 연산이 "×2, +2"였다면 역연산이 "//2, -2"가 되는데, 짝수일 때 //2로 온 건지 -2로 온 건지 구분이 안 되어 선택지가 2개가 된다. 예를 들어 A=5, B=12일 때 정답은 5→10(×2)→12(+2)인데, 역방향 그리디로 12가 짝수니까 //2를 선택하면 6→...→실패. 실제로는 12→10(-2)→5(//2)로 가야 한다. 역연산의 조건이 겹치면 그리디가 아니라 BFS/DFS 탐색이 필요하다.
- **핵심 원리**: 역연산들의 적용 조건이 서로 배타적이어야 그리디 성립

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|그리디에 반례가 있을 거라 판단하고 포기|역방향에서 보면 선택지가 유일하므로 그리디 가능|

## AI 코드 리뷰

### 개선할 점

1. **`next` 변수명 충돌**: `next`는 파이썬 내장 함수명이므로 `candidates` 등으로 변경
2. **반복 변수 `n` 모호**: `nxt`처럼 의미를 살린 이름 사용
3. **found 플래그 + 이중 break**: 함수로 감싸서 `return`하면 플래그 없이 깔끔하게 처리 가능
4. **더 나은 로직 — 역방향 그리디**: B에서 A로 역추적하면 O(log B)로 해결 가능. 짝수면 //2, 끝자리 1이면 //10, 둘 다 아니면 -1 출력

## 수정된 코드
```python
import sys
input = sys.stdin.readline

def solve():
    A, B = map(int, input().split())
    count = 1

    while B > A:
        if B % 2 == 0:
            B //= 2
        elif B % 10 == 1:
            B //= 10
        else:
            print(-1)
            return
        count += 1

    if B == A:
        print(count)
    else:
        print(-1)

solve()
```
