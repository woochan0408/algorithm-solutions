# 프로그래머스 138476 🍊 귤 고르기 파이썬

## 느낀점
>
- 잘 풀었다.
- 귤이 영어로 tangerine이구나

## 흐름

1. Counter로 각 크기별 귤 개수를 센다
2. (개수, 크기) 튜플 리스트를 만들어 오름차순 정렬한다
3. 뒤에서부터 pop하며 가장 많은 크기부터 k에서 빼나간다
4. pop할 때마다 종류 수(answer)를 1 증가시킨다
5. k가 0 이하가 되면 answer를 반환한다

## 코드

```python
"""
k개 골라서 팔거임
"""
from collections import Counter
def solution(k, tangerine):
    counter = Counter(tangerine)
    arr = []
    
    for key in counter:
        arr.append((counter[key], key))
    arr.sort()
    
    answer = 0
    while k > 0:
        k -= arr.pop()[0]
        answer += 1
        
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### Counter.most_common()
`Counter` 객체의 `most_common()` 메서드는 빈도수 기준 내림차순으로 정렬된 리스트를 반환한다. 직접 튜플 리스트를 만들고 정렬하는 과정을 한 줄로 대체할 수 있다.
- **핵심 원리**: `Counter.most_common()` → `[(요소, 빈도), ...]` 내림차순 반환
- **시간복잡도**: O(N log N) — 내부적으로 정렬 수행

## AI 코드 리뷰

### 개선할 점

1. **`most_common()` 활용**: Counter에서 직접 튜플 리스트를 만들고 정렬하는 대신, `most_common()`을 쓰면 이미 빈도 내림차순으로 정렬된 결과를 얻을 수 있어 코드가 간결해진다.
2. **변수명 개선**: `arr`보다 `counts`처럼 내용을 설명하는 이름이 가독성에 좋다.
3. **불필요한 key 저장 제거**: 종류 수만 필요하므로 key 값은 저장할 필요 없이 개수(values)만 사용하면 된다.

## 수정된 코드

```python
from collections import Counter

def solution(k, tangerine):
    counts = sorted(Counter(tangerine).values(), reverse=True)
    
    answer = 0
    for count in counts:
        k -= count
        answer += 1
        if k <= 0:
            break
    
    return answer
```
