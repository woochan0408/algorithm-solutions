# 프로그래머스 42884 📷 단속카메라 파이썬

## 느낀점
>
- 풀면서 그리디(정석풀이)보다 스택이 먼저 떠올랐다.
- 아래 문제가 영향을 준 것 같다.
(https://www.acmicpc.net/problem/10799)
- 풀면서도 좀 복잡하지 않나 생각이 들었다.
- 아무튼 풀었으면 오케이
- 그리디 풀이로 나중에 한번 더 풀어보자.

## 흐름

1. 각 차량의 진입/진출을 이벤트로 분리 (진입: 음수 인덱스, 진출: 양수 인덱스)
2. 이벤트를 좌표 기준 내림차순 정렬 후 `pop()`으로 작은 값부터 처리
3. 진입 이벤트 → 스택에 추가
4. 진출 이벤트 → 스택에 쌓인 차량 모두 단속 처리 (카메라 1대 설치), `fin` set에 기록
5. 이미 단속된 차량(`fin`)은 스킵

## 코드
```python
"""
모든 차량에 대해서 단속 한번은 해야함
stack?
"""
def solution(routes):
    answer = 0
    
    arr = []
    for i in range(len(routes)):
        cur = routes[i]
        arr.append((cur[0], -(i+1)))
        arr.append((cur[1], i+1))
        
    # 무조건 번호에 음수 들어간게 시작 -> 양수로 끝남
    arr.sort(reverse = True)
    
    stack = []
    fin = set()
    while arr:
        d, idx = arr.pop()
        if(abs(idx) in fin):
            continue
        elif(idx > 0):
            while stack:
                fin.add(-stack.pop())
            answer += 1
        elif(idx < 0):
            stack.append(idx)
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### 활동 선택(Activity Selection) 그리디 패턴
구간(interval) 문제에서 "최소 개수로 모든 구간 커버"하는 전형적인 그리디 패턴이다. 핵심은 **끝점 기준 정렬** 후, 현재 카메라(또는 선택 지점)가 다음 구간의 시작점을 커버하지 못하면 새로운 지점을 추가하는 방식이다.
- **핵심 원리**: 끝점이 빠른 구간부터 처리하면, 하나의 선택으로 최대한 많은 겹치는 구간을 커버할 수 있다
- **시간복잡도**: O(N log N) 정렬 + O(N) 순회

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 이벤트 기반 스위핑 + 스택 + set으로 복잡하게 구현 | 끝점 정렬 후 카메라 위치 갱신으로 간결하게 해결 가능 |

## AI 코드 리뷰

### 개선할 점

1. **과도한 자료구조 사용**: 스택, set, 이벤트 분리 등 이 문제에 불필요한 복잡도를 추가했다. 끝점 정렬 그리디로 변수 2개(`camera`, `answer`)만으로 해결 가능하다.

2. **`for i in range(len(routes))` → `enumerate` 활용**: 인덱스와 값을 동시에 순회할 때는 `enumerate`가 파이썬다운 표현이다.

3. **변수명 개선**: `arr` → `events`, `d` → `pos`, `fin` → `finished` 등 의미가 드러나는 이름이 가독성을 높인다.

4. **더 나은 로직 — 끝점 정렬 그리디**: 끝점 기준 오름차순 정렬 후, 각 차량의 시작점이 현재 카메라 위치보다 뒤에 있으면 새 카메라를 해당 차량의 끝점에 설치한다. 이벤트 분리·스택·set이 모두 필요 없어지며, 코드가 절반 이하로 줄어든다.

## 수정된 코드
```python
def solution(routes):
    routes.sort(key=lambda x: x[1])  # 끝점 기준 오름차순 정렬
    camera = -30001
    answer = 0

    for start, end in routes:
        if start > camera:  # 현재 카메라가 이 차량을 커버 못 함
            camera = end    # 끝점에 새 카메라 설치
            answer += 1

    return answer
```
