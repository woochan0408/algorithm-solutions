## 느낀점
>
- 아이디어를 못 떠올렸다.. 그리디 + 힌트를 받아 풀었다.
- 그리디는 문제를 볼 떄마다 참신하고 시야를 넓혀주는 느낌이다.
- 좋은 문제다.

## 흐름

1. 책 위치를 정렬하고 deque에 넣는다
2. 음수(왼쪽)와 양수(오른쪽) 각각 **가장 먼 책부터 M권씩 묶어서** 처리한다
3. 한 묶음당 비용은 가장 먼 책의 절댓값 × 2 (왕복)
4. 양쪽 모두 편도로 계산한 뒤, **짧은 쪽 거리를 다시 더해서** 마지막 편도를 한 번만 적용
5. 음수 쪽은 deque 왼쪽에서, 양수 쪽은 deque 오른쪽에서 pop하며 처리

## 코드
```python
import sys
from collections import deque
input = sys.stdin.readline
N, M = map(int, input().split())
arr = list(map(int, input().split()))
arr.sort()
dq = deque(arr)
# 음수부터 작업
# M개만큼 먼저 빼자 (끝나면 0으로 돌아갈 필요 없음)
answer = 0
# 양쪽에 값이 있을 경우 작은 값은 왕복해야 함
if(dq and dq[-1]*dq[0] < 0):
    answer += min(abs(dq[-1]), abs(dq[0]))
isFirst = True
while dq and dq[0] < 0:
    # 첫 pop (즉, 최장거리에 대해선 편도)
    if(isFirst):
        answer -= dq.popleft()
        isFirst = False
    else:
        answer -= dq.popleft()*2
        
    for _ in range(M-1):
        if(dq and dq[0] < 0):
            dq.popleft()
# 양수 작업 -> 같은방식
isFirst = True
while dq and dq[-1] > 0:
    if(isFirst):
        answer += dq.pop()
        isFirst = False
    else:
        answer += dq.pop()*2
        
    for _ in range(M-1):
        if(dq and dq[-1] > 0):
            dq.pop()
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 그리디에서 "마지막 행동 최적화" 패턴
왕복해야 하는 작업을 반복할 때, 마지막 한 번은 돌아오지 않아도 되는 문제 유형이 있다. 이때 핵심은 **가장 비용이 큰 작업을 마지막으로 남기는 것**이다. 이 문제에서는 양쪽 모두 편도로 계산한 뒤 짧은 쪽을 왕복으로 보정하는 방식으로 구현했다.
- **핵심 원리**: 전체 비용 = Σ(각 묶음 최대 거리 × 2) - 가장 먼 묶음 거리
- **시간복잡도**: O(N log N) (정렬 지배)

#### 음수/양수 분리 처리
좌표에서 양쪽 방향으로 이동해야 하는 문제는 **음수와 양수를 독립적으로 처리**하면 단순해진다. 반대 방향 책을 한 번에 가져가는 것은 비효율적이므로, 방향별로 묶는 것이 최적이다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|양수 내부 루프 조건 `dq[-1] < 0`|`dq[-1] > 0`으로 양수 체크|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `dq` → `books`, `isFirst` → `is_first` (PEP8 snake_case 준수)
2. **편도 보정 로직이 한쪽에만 책이 있는 경우를 놓침**: 모든 책이 음수 또는 양수에만 있으면 `dq[-1]*dq[0] < 0` 조건이 False라서 `min()` 보정이 안 되는데, 이 경우 편도가 한 번만 적용되므로 결과적으로 맞다. 하지만 의도가 드러나지 않아 가독성이 떨어진다.
3. **더 명확한 접근**: 음수/양수를 리스트로 분리하고 각각 M개씩 묶어 왕복 비용 합산 후, 전체 최대 거리를 한 번 빼는 방식이 로직이 더 직관적이다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

n, m = map(int, input().split())
arr = list(map(int, input().split()))

# 음수/양수 분리 후 절댓값 기준 내림차순 정렬
neg = sorted([-x for x in arr if x < 0], reverse=True)
pos = sorted([x for x in arr if x > 0], reverse=True)

total = 0

# 각 방향에서 M개씩 묶어 왕복 비용 계산
for i in range(0, len(neg), m):
    total += neg[i] * 2

for i in range(0, len(pos), m):
    total += pos[i] * 2

# 가장 먼 거리는 편도 (왕복 비용에서 한 번 빼기)
farthest = 0
if neg:
    farthest = max(farthest, neg[0])
if pos:
    farthest = max(farthest, pos[0])
total -= farthest

print(total)
```
