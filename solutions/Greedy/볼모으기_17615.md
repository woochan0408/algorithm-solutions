# 백준 17615 🔴 볼 모으기 파이썬

## 느낀점
>
- 좌우 계산까지 생각해야된다.

## 흐름

1. R, B 각각에 대해 왼쪽/오른쪽으로 모으는 4가지 경우 계산
2. **오른쪽으로 모으기**: 오른쪽 끝에 연속된 target 색상 제거 → 남은 것 중 target 색상 개수
3. **왼쪽으로 모으기**: 왼쪽 끝에 연속된 target 색상 제거 → 남은 것 중 target 색상 개수
4. 4가지 경우 중 최솟값 출력

## 코드

```python
"""
1. 앞에 타겟과 같은 색상 있으면 빼고 시작
뒤에서 부터 pop
red 나오면 
"""
import heapq, sys
from collections import deque
input = sys.stdin.readline
targetColor = ['R', 'B']
N = int(input())
arr = list(input().strip())
results = []
for color in targetColor:
    result = 0
    stack = arr.copy()
    
    # 앞에 target인 경우는 모두 제거
    while stack:
        if(stack[-1] != color):
            break
        stack.pop()
            
    while stack:
        cur = stack.pop()
        if(cur == color):
            result += 1
    results.append(result)
    result = 0
    dq = deque(arr.copy())
    while dq:
        if(dq[0] != color):
            break
        dq.popleft()
            
    while dq:
        cur = dq.popleft()
        if(cur == color):
            result += 1
    results.append(result)
print(min(results))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 그리디 문제의 경우의 수 탐색
한쪽 방향만 생각하기 쉬운 문제에서 **모든 가능한 경우**(왼쪽/오른쪽, R/B)를 체크해야 최솟값을 찾을 수 있다.
- **핵심 원리**: 같은 색을 한쪽으로 모을 때 왼쪽/오른쪽 두 방향 모두 고려
- **시간복잡도**: O(N) × 4가지 경우 = O(N)

#### input() 개행문자 처리
`input()`은 개행문자(`\n`)를 포함하므로 문자열 파싱 시 `.strip()` 또는 `.rstrip()` 필요
- **핵심 원리**: `list(input())`은 `\n`도 리스트 요소로 포함

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|오른쪽으로 모으는 경우만 고려|왼쪽/오른쪽 모두 고려 (4가지 경우)|
|`arr = list(input())`|`arr = list(input().strip())`|

## AI 코드 리뷰

### 개선할 점

1. **불필요한 import 제거**: `heapq`는 사용하지 않음
2. **변수명 개선**: `stack`, `dq` → 통일된 이름으로 개선
3. **코드 중복 제거**: 왼쪽/오른쪽 모으기 로직을 함수로 분리
4. **주석 정리**: 상단 주석 제거 및 명확한 주석 추가

## 수정된 코드

```python
import sys
from collections import deque
input = sys.stdin.readline

N = int(input())
arr = list(input().strip())

results = []

for color in ['R', 'B']:
    # 오른쪽으로 모으기
    temp = arr.copy()
    while temp and temp[-1] == color:
        temp.pop()
    
    count = sum(1 for ball in temp if ball == color)
    results.append(count)
    
    # 왼쪽으로 모으기
    temp = deque(arr)
    while temp and temp[0] == color:
        temp.popleft()
    
    count = sum(1 for ball in temp if ball == color)
    results.append(count)

print(min(results))
```
