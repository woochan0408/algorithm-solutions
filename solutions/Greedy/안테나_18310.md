## 실패한 코드 흐름
1. 정렬 후 모든 위치에 대해 완전탐색
2. 각 위치에서 모든 집까지의 거리 합 계산
3. 최소값을 갖는 위치 선택

## 실패한 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
arr.sort()
minHap = float("inf")
result = -1
for cur in arr:
    curHap = 0
    for target in arr:
        curHap += abs(target - cur)
    if(curHap < minHap):
        result = cur
        minHap = curHap
print(result)
```

**문제점**: O(N²) 시간복잡도로 N=200,000일 때 시간초과 발생

## 성공한 코드 흐름

1. 집의 위치를 정렬
2. 중앙값 위치를 출력 (N이 짝수면 중앙 2개 중 작은 값)

## 성공한 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
arr.sort()
print(arr[(N-1)//2])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 중앙값(Median)을 이용한 거리 합 최소화
일직선 상에서 모든 점까지의 거리 합을 최소화하는 위치는 중앙값이다. 이는 수학적으로 증명 가능하다.

어떤 위치 x에서 왼쪽으로 1칸 이동할 때:
- 왼쪽 점들(개수 L): 각각 거리 +1 증가
- 오른쪽 점들(개수 R): 각각 거리 -1 감소
- 총 변화량: +L - R

따라서:
- L < R이면 왼쪽 이동 시 거리 합이 감소 (개선)
- L > R이면 왼쪽 이동 시 거리 합이 증가 (악화)
- L = R이면 왼쪽 이동 시 거리 합 동일 (최적)

결론: L = R인 위치, 즉 중앙값이 최적 위치다.

- **핵심 원리**: 정렬 후 `arr[(N-1)//2]` 선택 (N이 짝수면 중앙 2개 중 작은 값)
- **시간복잡도**: O(NlogN) (정렬)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|O(N²) 완전탐색으로 모든 위치 확인|중앙값 이용해 O(NlogN)으로 해결|
|그리디로 해결 불가능하다고 판단|수학적 증명을 통해 중앙값이 항상 최적임을 확인|
