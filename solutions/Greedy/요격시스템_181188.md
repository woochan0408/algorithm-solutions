- 이전에는 그리디 대신 스택으로 어렵게 구현했는데 이번엔 잘 풀었다.

## 흐름

1. 각 폭격 미사일의 개구간 `(s, e)`를 `*2` 변환으로 정수 폐구간 `(s*2+1, e*2-1)`로 변환
2. 끝점 기준 오름차순 정렬
3. 그리디로 순회하며, 현재 구간의 시작점이 마지막 요격 위치보다 크면 새로운 요격 미사일 발사
4. 새 미사일의 요격 위치는 현재 구간의 끝점으로 설정

## 코드
```python
def solution(targets):
    arr = []
    for cur in targets:
        arr.append((cur[0]*2+1, cur[1]*2-1))
    
    arr.sort(key = lambda x : (x[1]))
    answer = 0
    
    last = 0
    for cur in arr:
        if(cur[0] > last):
            last = cur[1]
            answer += 1
    
    
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### 활동 선택 문제 (Activity Selection Problem)
겹치는 구간들 중 최소 개수의 점으로 모든 구간을 커버하는 문제는 **끝점 기준 오름차순 정렬** 후 그리디로 해결할 수 있다. 끝점이 가장 빠른 구간부터 처리하면, 하나의 요격으로 최대한 많은 구간을 커버할 수 있다.
- **핵심 원리**: 끝점 기준 정렬 → 현재 구간이 이전 요격에 포함되지 않으면 새 요격 발사
- **시간복잡도**: O(N log N) (정렬)

#### 개구간 처리
개구간 `(s, e)`에서 경계값 `s`, `e`로는 요격할 수 없다. `*2` 변환으로 정수 폐구간으로 바꾸는 방법도 있지만, 정수 범위에서는 `s >= last_end` 비교만으로 충분히 처리 가능하다.
- **핵심 원리**: 요격을 `e - ε`에 쏜다고 가정하면, 다음 구간의 시작 `s >= e`일 때만 새 미사일 필요

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 끝점 기준 내림차순 정렬 `(-x[1])` | 끝점 기준 **오름차순** 정렬 `(x[1])` |

## AI 코드 리뷰

### 개선할 점

1. **불필요한 `*2` 변환 제거**: 개구간을 정수 폐구간으로 변환하지 않아도, `s >= last_end` 비교로 개구간 처리가 가능하다. 변환 로직을 없애면 코드가 훨씬 간결해진다.

2. **변수명 개선**: `arr` → `intervals`, `cur` → `s, e` 튜플 언패킹으로 의미를 명확하게 전달.

3. **리스트 컴프리헨션 활용**: `for` 루프로 리스트를 만드는 대신 한 줄로 변환 가능.

## 수정된 코드
```python
def solution(targets):
    targets.sort(key=lambda x: x[1])
    answer = 0
    last_end = -1

    for s, e in targets:
        if s >= last_end:
            last_end = e
            answer += 1

    return answer
```
