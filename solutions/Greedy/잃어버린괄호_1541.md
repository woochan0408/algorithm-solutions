## 오늘 푼 코드 흐름

1. 식을 앞에서부터 순회하며 숫자를 이어붙여 파싱한다
2. `-`를 한 번이라도 만나면 `op = False`로 전환하고, 이후 모든 숫자는 빼기 처리한다
3. `-` 뒤에 오는 `+` 연산도 괄호로 묶어 빼기로 만들 수 있으므로, 한 번 `False`가 되면 다시 `True`로 돌아가지 않는다

## 오늘 푼 코드
```python
import sys
input = sys.stdin.readline
arr = input().strip()
i = 0
hap = 0
op = True
if(not arr[0].isdigit()):
    op = False
    i += 1
while True:
    # 숫자 이어붙이기
    num = ''
    while True:
        num += arr[i]
        i += 1
        # 배열의 끝이거나 op를 만났다.
        if(i >= len(arr) or not arr[i].isdigit()):
            break
    num = int(num)
    if(op == True):
        hap += num
    else:
        hap -= num
    if(i >= len(arr)):
        break
    if(arr[i] == '-'):
        op = False
    i += 1
print(hap)
```

## 1년 전 코드 흐름

1. `minusing` 플래그로 음수 구간 진입 여부를 관리한다
2. `makeNum()` 함수를 별도로 만들어, 현재 인덱스부터 연산자가 나올 때까지 숫자를 이어붙여 반환한다
3. 메인 루프에서 연산자 종류에 따라 분기 처리하며, `-`를 만나면 `minusing = True`로 전환 후 이후 모든 숫자를 뺀다

## 1년 전 코드
```python
import sys
input = sys.stdin.readline
q = input()
result = 0
minusing = False
i = 0
operates = ['+', '-']

def makeNum():
    global i
    global q
    global char
    num = ""
    while i < len(q) and (not q[i] in operates):
        num += q[i]
        i += 1
    return int(num)

while i < len(q):
    char = q[i]
    if(minusing):
        i += 1
        result -= makeNum()
    else:
        if(char == "+"):
            i += 1
            result += makeNum()
        elif(char == "-"):
            i += 1
            minusing = True
            result -= makeNum()
        else:
            result += makeNum()
print(result)
```

## 비교

| 항목 | 오늘 코드 | 1년 전 코드 |
|------|-----------|-------------|
| 숫자 파싱 | while 루프 내에서 직접 처리 | `makeNum()` 함수로 분리 |
| 상태 변수 | `op` (bool) | `minusing` (bool) |
| 전역 변수 | 없음 | `global i, q, char` 사용 |
| 연산자 분기 | `-`만 체크, `+`는 무시 | `+`, `-` 모두 명시적 분기 |
| 코드 구조 | 단일 루프, 평탄한 흐름 | 함수 분리 + 메인 루프 분기 |
| 가독성 | 간결하지만 흐름 파악에 집중 필요 | 함수명으로 의도가 명확 |

핵심 로직은 동일하다. 1년 전 코드는 `makeNum()` 함수 분리로 역할이 명확하지만 `global` 변수 남용이 아쉽고, 오늘 코드는 함수 없이 간결하게 처리했지만 연산자 분기가 암묵적이다.

## AI 코드 리뷰

### 개선할 점

1. **`split` 활용으로 파싱 간소화**: 인덱스를 직접 관리하며 한 글자씩 파싱하는 방식 대신, `-`로 먼저 split하고 각 그룹을 `+`로 split하면 코드가 훨씬 간결해진다.

2. **`op == True` 비교 제거**: `if op:`만으로 충분하며, 불리언 값을 `True`와 직접 비교하는 것은 불필요하다.

3. **첫 글자 음수 체크 불필요**: 문제 조건에서 "가장 처음 문자는 숫자"라고 명시되어 있으므로 `if(not arr[0].isdigit())` 분기는 없어도 된다.

4. **변수명 개선**: `hap` → `result`, `op` → `is_positive` 등 의미가 드러나는 이름이 좋다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

expression = input().strip()

# '-'로 먼저 분리 → 각 그룹을 '+'로 분리하여 합산
groups = expression.split('-')

# 첫 그룹은 무조건 더하기
result = sum(map(int, groups[0].split('+')))

# 나머지 그룹은 모두 빼기
for group in groups[1:]:
    result -= sum(map(int, group.split('+')))

print(result)
```
