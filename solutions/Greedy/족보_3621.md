## 흐름
1. 각 부모 노드별 자식 수를 센다
2. 자식 수가 d를 초과하는 노드에 대해, d진 트리를 만들기 위한 최소 내부 노드 수를 계산한다
3. 기존 노드(루트) 1개는 이미 존재하므로 내부 노드 수에서 1을 빼면 추가해야 할 노드 수가 된다
4. 공식: `ceil((c-1) / (d-1)) - 1` (c: 자식 수, d: 최대 부모 수)

## 코드
```python
from collections import Counter
import math
n, d = map(int, input().split())
arr = list(map(int, input().split()))
counter = Counter(arr)
result = 0
for key in counter:
    cur = counter[key]
    if(cur > d):
        result += math.ceil((cur-1) / (d-1)) - 1
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### d진 트리 내부 노드 수 공식
c개의 잎을 d진 트리로 묶을 때 필요한 최소 내부 노드 수는 `ceil((c-1) / (d-1))`이다. 각 내부 노드가 최대 d개의 자식을 가질 수 있으므로, 전체 자식 슬롯 `k*d`에서 내부 노드끼리 차지하는 슬롯 `k-1`을 빼면 잎 수용량이 `k(d-1)+1`이 되고, 이를 역산하면 공식이 도출된다.
- **핵심 원리**: 기존 노드가 이미 존재하면 `-1`을 해서 추가해야 할 노드만 계산

#### B-트리와의 연결
이 공식은 데이터베이스의 B-트리 인덱스 설계에서도 동일하게 쓰인다. B-트리에서 "각 노드가 최대 m개의 자식을 가질 수 있을 때, n개의 잎 노드를 수용하려면 내부 노드가 몇 개 필요한가"라는 질문이 이 문제와 본질적으로 같다. 분지 계수(branching factor)로 트리의 최소 구조를 결정하는 근본 원리가 동일하기 때문이다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `c // d`로 단순 나눗셈 | `ceil((c-1) / (d-1)) - 1` 공식 적용 |
| 내부 노드 총 개수를 바로 답으로 출력 | 기존 노드 1개를 빼서 추가 노드 수만 계산 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `key`, `cur`는 의미가 불명확하다. `node`, `count` 등으로 바꾸면 가독성이 올라간다.
2. **정수 올림 나눗셈**: `math.ceil`은 부동소수점을 거치므로 큰 수에서 오차 가능성이 있다. `(a + b - 1) // b` 패턴이 더 안전하다.
3. **counter.items() 활용**: `counter[key]`로 다시 접근하는 대신 `items()`로 키-값을 동시에 순회하면 더 깔끔하다.

## 수정된 코드
```python
import sys
from collections import Counter

input = sys.stdin.readline

n, d = map(int, input().split())
parents = list(map(int, input().split()))

child_count = Counter(parents)
result = 0

for node, count in child_count.items():
    if count > d:
        result += (count - 1 + d - 2) // (d - 1) - 1

print(result)
```
