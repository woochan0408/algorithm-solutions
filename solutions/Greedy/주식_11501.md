# 백준 11501 📈 주식 파이썬

## 느낀점
>
- 잘 풀었다.
- 먼가 소마가 좋아할 것 같은 유형이다.
(설명 간결한 구현 문제)

## 흐름

1. 뒤에서부터 순회하면서 현재까지의 최대 주가를 추적한다.
2. 현재 가격이 최대 주가보다 작으면 차이만큼 이익에 더한다 (그날 사서 최대가에 파는 것).
3. 현재 가격이 최대 주가 이상이면 최대 주가를 갱신한다.

## 코드
```python
from collections import Counter
import sys
input = sys.stdin.readline
def solve(arr):
    curMax = arr.pop()
    answer = 0
    while arr:
        cur = arr.pop()
        diff = curMax - cur
        if(diff <= 0):
            curMax = cur
        else:
            answer += diff
    return answer
T = int(input())
for _ in range(T):
    N = int(input())
    arr = list(map(int, input().split()))
    print(solve(arr))
```

## AI 코드 리뷰

### 개선할 점

1. **불필요한 import 제거**: `from collections import Counter`는 사용하지 않으므로 삭제
2. **`arr.pop()` 대신 `reversed()` 사용**: `pop()`은 원본 배열을 파괴하므로, `reversed()`로 순회하면 의도가 명확하고 안전함
3. **변수명 스네이크 케이스 적용**: `curMax` → `max_price`, `cur` → `price`로 변경하여 파이썬 컨벤션 준수 및 의미 명확화

## 수정된 코드
```python
import sys
input = sys.stdin.readline

def solve(arr):
    max_price = arr[-1]
    answer = 0
    for price in reversed(arr):
        if price >= max_price:
            max_price = price
        else:
            answer += max_price - price
    return answer

T = int(input())
for _ in range(T):
    N = int(input())
    arr = list(map(int, input().split()))
    print(solve(arr))
```
