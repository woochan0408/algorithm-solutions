# 백준 13305 ⛽ 주유소 파이썬

## 느낀점
>
- 잘 풀었다.

## 흐름

1. 첫 번째 도시의 기름 가격을 현재 최소 가격으로 설정
2. 왼쪽에서 오른쪽으로 이동하며, 각 구간마다 현재 최소 가격 × 거리를 비용에 누적
3. 다음 도시의 가격이 더 싸면 최소 가격을 갱신
4. 핵심: 더 싼 주유소를 만나기 전까지는 현재 최소 가격으로 계속 주유하는 것이 최적

## 코드

```python
"""
지금보다 작은 값 나오면 무조건 주유소 변경 -> 그리디
"""
import sys
input = sys.stdin.readline
N = int(input())
edges  = list(map(int, input().split()))
nodes = list(map(int, input().split()))
price = nodes.pop(0)
answer = 0
for i in range(N-1):
    answer += edges[i]*price
    if(nodes[i] < price):
        price = nodes[i]
print(answer)
```

## AI 코드 리뷰

### 개선할 점

1. **`pop(0)` → 인덱스 접근**: `list.pop(0)`은 O(N) 연산이다. 리스트 맨 앞 원소를 제거하면 나머지 원소가 모두 한 칸씩 앞으로 이동하기 때문. 이 문제에서는 N이 최대 100,000이라 큰 차이는 없지만, 인덱스를 조정하면 O(1)로 처리할 수 있다.

2. **변수명 개선**: `edges` → `distances`, `nodes` → `prices`로 변경하면 문제 맥락에 더 맞는 이름이 된다. 그래프 용어(edge, node)보다 선형 경로에 맞는 이름이 가독성에 좋다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
distances = list(map(int, input().split()))
prices = list(map(int, input().split()))

min_price = prices[0]
answer = 0

for i in range(N - 1):
    answer += distances[i] * min_price
    if prices[i + 1] < min_price:
        min_price = prices[i + 1]

print(answer)
```
