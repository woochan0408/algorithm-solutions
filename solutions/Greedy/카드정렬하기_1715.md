# 백준 1715 🃏 카드 정렬하기 파이썬

## 느낀점
>
- 잘 풀었다.
- 엣지케이스 조심하자 항상..!
(더한 값이 기존 값보다 커질 수 있다.)

## 흐름

1. N개의 카드 묶음 크기를 입력받아 최소 힙에 넣는다
2. 힙에서 가장 작은 두 묶음을 꺼내 합친다
3. 합친 값을 정답에 누적하고, 다시 힙에 넣는다
4. 힙에 1개만 남을 때까지 반복한다

## 코드

```python
"""
3
10
20
40
더한 것이 최소
"""
import sys, heapq
input = sys.stdin.readline
N = int(input())
arr = []
for _ in range(N):
    arr.append(int(input()))
heapq.heapify(arr)
ans = 0
while len(arr) != 1:
    a = heapq.heappop(arr)
    b = heapq.heappop(arr)
    heapq.heappush(arr, a+b)
    ans += a+b
print(ans)
```
## AI 코드 리뷰

### 개선할 점

1. **변수명 `arr` → `heap`**: 힙으로 사용하는 리스트이므로 이름을 `heap`으로 바꾸면 역할이 명확해진다

## 수정된 코드

```python
import sys
import heapq

input = sys.stdin.readline

N = int(input())
heap = []
for _ in range(N):
    heap.append(int(input()))

heapq.heapify(heap)

ans = 0
while len(heap) > 1:
    a = heapq.heappop(heap)
    b = heapq.heappop(heap)
    merged = a + b
    heapq.heappush(heap, merged)
    ans += merged

print(ans)
```
