# 백준 15903 🃏 카드 합체 놀이 파이썬

## 느낀점
>
- 잘 풀었다.

## 흐름

1. 카드 합체 시 전체 합을 최소화하려면, 매번 가장 작은 두 수를 골라 합쳐야 한다
2. 가장 작은 두 수를 빠르게 꺼내기 위해 최소 힙(heapq) 사용
3. m번 반복하며 최솟값 2개를 pop → 합산값을 2번 push
4. 최종적으로 힙에 남은 모든 수의 합이 정답

## 코드
```python
"""
3 1
3 2 6
계속 작은 놈 두개 고르자
"""
import heapq, sys
input = sys.stdin.readline
N, M = map(int, input().split())
arr = list(map(int, input().split()))
heapq.heapify(arr)
for i in range(M):
    a = heapq.heappop(arr)
    b = heapq.heappop(arr)
    heapq.heappush(arr, a+b)
    heapq.heappush(arr, a+b)
print(sum(arr))
```

### 개선할 점

1. **미사용 루프 변수**: `for i in range(M)`에서 `i`를 사용하지 않으므로 `for _ in range(M)`으로 바꾸면 "이 변수는 안 쓴다"는 의도가 명확해진다.
2. **변수명 명확화**: `a`, `b` 대신 `min1`, `min2`로 쓰면 "가장 작은 두 수를 꺼낸다"는 로직이 변수명만으로 드러난다.
3. **합산값 중복 계산 방지**: `a+b`를 두 번 계산하지 않도록 변수에 저장하면 가독성과 의도가 더 분명해진다.

## 수정된 코드
```python
import heapq
import sys

input = sys.stdin.readline

N, M = map(int, input().split())
cards = list(map(int, input().split()))

heapq.heapify(cards)

for _ in range(M):
    min1 = heapq.heappop(cards)
    min2 = heapq.heappop(cards)
    merged = min1 + min2
    heapq.heappush(cards, merged)
    heapq.heappush(cards, merged)

print(sum(cards))
```
