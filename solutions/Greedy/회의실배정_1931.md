# 백준 1931 📅 회의실 배정 파이썬

## 느낀점
>
- 항상 헷갈리는 유형이다.. 복습하자.
- 최적해 보장이 왜 되는 지 잘 고민해보기.

## 흐름

1. 회의 정보를 (시작시간, 종료시간) 튜플로 저장
2. 시작시간 기준 오름차순 정렬
3. 뒤에서부터 pop하며 회의 선택
4. 현재 회의의 종료시간이 마지막 선택한 회의의 시작시간 이하면 선택
5. 선택 시 lastStart를 현재 회의의 시작시간으로 갱신

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
meetings = []
for _ in range(N):
    meetings.append(tuple(map(int, input().split())))
meetings.sort(key = lambda x : (x[0], x[1]))
lastStart = float("inf")
count = 0
while meetings:
    cur = meetings.pop()
    curStart = cur[0]
    curEnd = cur[1]
    if(curEnd <= lastStart):
        count += 1
        lastStart = curStart
print(count)
```

## 질문 & 실수 정리

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| `lastStart = meetings[-1][0]` (첫 회의 선택 불가) | `lastStart = float("inf")` |

## AI 코드 리뷰

### 개선할 점

1. **입력 처리 간소화**: 리스트 컴프리헨션으로 한 줄 처리 가능
2. **역순 순회 방식 변경**: `while + pop` 대신 `reversed()` 사용하면 원본 리스트 보존 및 가독성 향상
3. **일반적인 풀이**: 종료시간 기준 정렬 후 앞에서 선택하는 방식이 더 직관적이고 널리 사용됨

## 수정된 코드

```python
import sys
input = sys.stdin.readline

n = int(input())
meetings = [tuple(map(int, input().split())) for _ in range(n)]
meetings.sort(key=lambda x: (x[1], x[0]))  # 종료시간 기준 정렬

count = 0
last_end = 0

for start, end in meetings:
    if start >= last_end:
        count += 1
        last_end = end

print(count)
```
