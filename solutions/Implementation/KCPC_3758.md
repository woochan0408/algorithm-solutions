## 느낀점
>
- 오타 조심 (,과 .)
- 시간단축 하자.

## 흐름

1. 테스트케이스 T번 반복
2. 각 팀별 딕셔너리로 문제별 최고 점수 관리
3. 각 팀의 총점, 제출 횟수, 마지막 제출 시간 기록
4. 정렬 기준: 총점 내림차순 → 제출 횟수 오름차순 → 마지막 제출 시간 오름차순
5. 더미(index 0)를 항상 1등으로 고정하여, `index(target)`이 곧 순위가 되도록 처리

## 코드
```python
import sys
input = sys.stdin.readline
T = int(input())
for _ in range(T):
    N, k, t, m = map(int, input().split())
    # 총점수, 제출횟수, last
    result = [[0, 0, 0] for i in range(N+1)]
    result[0] = [float("inf"), -1, -1]
    dic = [{} for i in range(N+1)]
    for i in range(m):
        # 팀id, 문제번호, score
        cur = list(map(int, input().split()))
        teamId = cur[0]
        pId = cur[1]
        score = cur[2]
        dic[teamId][pId] = max(dic[teamId].get(pId, 0), score)
        result[teamId][1] += 1
        result[teamId][2] = i
    for i in range(1, N+1):
        hap = 0
        for key in dic[i]:
            hap += dic[i][key]
        result[i][0] = hap
    target = result[t]
    result.sort(key = lambda x : (-x[0], x[1], x[2]))
    print(result.index(target))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 더미 원소를 활용한 순위 계산
리스트의 0번 인덱스에 항상 1등이 되는 더미값을 넣으면, 정렬 후 `list.index(target)`의 반환값이 곧 1-based 순위가 된다. 0번이 항상 맨 앞에 위치하므로 실제 팀들은 인덱스 1부터 시작하게 되어 별도의 +1 없이 순위를 구할 수 있다.
- **핵심 원리**: 더미가 정렬 후에도 항상 0번 위치를 차지하도록 극단값 설정

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `result[0] = [float("inf"), -1. -1]` (점으로 작성) | `result[0] = [float("inf"), -1, -1]` (쉼표로 구분) |

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `dic`, `hap`, `cur` 등이 의미가 불명확함. `scores`, `total`, 등으로 변경하면 가독성 향상
2. **불필요한 리스트 변환 제거**: `cur = list(map(...))` 후 인덱스 접근 대신 바로 언패킹 가능
3. **합산 간소화**: `for key in dic[i]` 루프 대신 `sum(dic[i].values())` 사용 가능

## 수정된 코드
```python
import sys
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    N, k, t, m = map(int, input().split())
    # [총점수, 제출횟수, 마지막 제출 시간]
    result = [[0, 0, 0] for _ in range(N + 1)]
    result[0] = [float("inf"), -1, -1]
    scores = [{} for _ in range(N + 1)]

    for i in range(m):
        team_id, prob_id, score = map(int, input().split())
        scores[team_id][prob_id] = max(scores[team_id].get(prob_id, 0), score)
        result[team_id][1] += 1
        result[team_id][2] = i

    for i in range(1, N + 1):
        result[i][0] = sum(scores[i].values())

    target = result[t]
    result.sort(key=lambda x: (-x[0], x[1], x[2]))
    print(result.index(target))
```
