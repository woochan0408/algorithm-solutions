## 흐름
1. 메모장에 있는 키워드 N개를 set에 저장
2. 각 글마다:
   - 콤마로 구분된 키워드들을 분리
   - 각 키워드가 메모장(set)에 있으면 삭제
   - 남은 키워드 개수 출력

## 코드
```python
"""
키워드 N개
하나의 글당 키워드 1개
"""
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
memo = set()
for _ in range(N):
    memo.add(input().strip())
for _ in range(M):
    arr = list(input().strip().split(','))
    for cur in arr:
        if(cur in memo):
            memo.remove(cur)
    print(len(memo))
```

## 질문 & 실수 정리

### 새로 배운 것

#### set의 discard() 메서드
set에서 요소를 삭제할 때 `remove()`와 `discard()` 두 가지 방법이 있습니다. 존재하지 않는 요소를 삭제할 가능성이 있다면 `discard()`가 더 안전합니다.
- **핵심 원리**: `remove()`는 없는 요소 삭제 시 KeyError 발생, `discard()`는 에러 없이 무시
- **시간복잡도**: 둘 다 O(1)

## AI 코드 리뷰

### 개선할 점

1. **변수명 명확성**: `memo` → `keywords`, `arr` → `blog_keywords`, `cur` → `keyword`로 변경하면 의도가 더 명확합니다.

2. **discard() 활용**: `if (cur in memo)` 체크 후 `remove()` 대신, `discard()`를 사용하면 존재 여부 체크 없이 안전하게 삭제 가능합니다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())

keywords = set()
for _ in range(N):
    keywords.add(input().strip())

for _ in range(M):
    blog_keywords = input().strip().split(',')
    for keyword in blog_keywords:
        keywords.discard(keyword)  # 존재하지 않아도 에러 없음
    print(len(keywords))
```
