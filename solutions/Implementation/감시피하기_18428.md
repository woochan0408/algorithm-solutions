## 느낀점
>
- 빡구현 문제
- 실수가 조금 많았다..
- 실수를 줄이기 위해선? 그냥 많이 풀어보는 방법밖에 없어보인다.
- AI 리뷰처럼 간결하게 쓰는 것도 익혀두자.

## 흐름

1. N×N 복도에서 빈 칸(`X`), 선생님(`T`), 장애물(`O`) 위치를 파싱
2. 빈 칸 중 3개를 고르는 모든 조합을 생성 (`combinations`)
3. 각 조합에 대해 기존 장애물 + 새 장애물 3개를 합친 벽 리스트 생성
4. 모든 선생님에 대해 상하좌우 4방향으로 감시 시뮬레이션
5. 벽을 만나면 해당 방향 탐색 중단, 학생을 만나면 해당 조합 실패
6. 모든 선생님이 학생을 발견하지 못하면 `YES` 출력 후 종료
7. 모든 조합에서 실패하면 `NO` 출력

## 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
grid = []
from collections import deque
from itertools import combinations
canMake = []
teacher = []
wall = []
for i in range(N):
    grid.append(list(input().strip().split()))
    for j in range(N):
        if(grid[i][j] == 'X'):
            canMake.append((i, j))
        elif(grid[i][j] == 'T'):
            teacher.append((i, j))
        elif(grid[i][j] == 'O'):
            wall.append((i, j))
result = 'NO'
for cur_wall in combinations(canMake, 3):
    cur_wall = wall + list(cur_wall)
    valid = True
    for tx, ty in teacher:
        # 위쪽 검증
        i = tx-1
        while valid and i >= 0:
            if((i, ty) in cur_wall):
                break
            if(grid[i][ty] == 'S'):
                valid = False
                break
            i -= 1
        # 아래쪽 검증
        i = tx+1
        while valid and i < N:
            if((i, ty) in cur_wall):
                break
            if(grid[i][ty] == 'S'):
                valid = False
                break
            i += 1
        # 왼쪽 검증
        i = ty-1
        while valid and i >= 0:
            if((tx, i) in cur_wall):
                break
            if(grid[tx][i] == 'S'):
                valid = False
                break
            i -= 1
                
        # 오른쪽 검증
        i = ty+1
        while valid and i < N:
            if((tx, i) in cur_wall):
                break 
            if(grid[tx][i] == 'S'):
                valid = False
                break
            i += 1
        if(not valid):
            break
    if(valid):
        result = 'YES'
        break
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### set vs list의 `in` 연산 시간복잡도
리스트에서 `in` 연산은 원소를 처음부터 끝까지 순회하므로 O(n)이 걸리지만, set은 해시 테이블 기반이라 O(1)에 탐색할 수 있다. 반복적으로 `in` 체크를 해야 하는 경우, 리스트를 set으로 한 번 변환(O(n))해두면 이후 모든 탐색이 O(1)이 되어 총 연산량이 줄어든다.
- **핵심 원리**: 해시 테이블 기반 자료구조는 평균 O(1) 탐색 제공
- **시간복잡도**: set 변환 O(n), 이후 탐색 O(1) vs 리스트 탐색 매번 O(n)

#### 조합(Combinations) 개수 계산
nCr = n! / (r! × (n-r)!)로 계산한다. 브루트포스 풀이의 시간복잡도를 판단하려면 조합 수를 직접 계산해서 전체 연산량을 추정해야 한다. 이 문제에서 최악의 경우 빈 칸 36개 중 3개를 고르면 36C3 = 7,140이고, 각 조합마다 선생님 5명 × 4방향 × 6칸 = 약 856,800 연산으로 충분히 통과 가능하다.
- **핵심 원리**: 브루트포스 전에 조합 수 계산으로 시간복잡도 사전 검증

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`valid`를 for문 밖에서 한 번만 초기화|각 조합(`cur_wall`)마다 `valid = True`로 초기화|
|기존 장애물(`'O'`)을 벽 체크에 포함하지 않음|기존 장애물도 벽 리스트에 포함하거나 grid에서 `'O'` 체크|
|디버깅용 `print(cur_wall)` 남겨둠|제출 전 디버깅 출력 제거|

## AI 코드 리뷰

### 개선할 점

1. **불필요한 import 제거**: `deque`를 사용하지 않으므로 `from collections import deque` 제거
2. **벽 체크를 set으로 변환**: `cur_wall`이 리스트라서 `in` 연산이 O(n). set으로 변환하면 O(1)
3. **변수명 충돌 해소**: `combinations`에서 받은 `cur_wall`을 바로 덮어쓰고 있어 가독성이 떨어짐. 조합 변수와 전체 벽 변수를 분리
4. **별도 wall 리스트 불필요**: grid에서 `'O'`를 직접 체크하면 별도 리스트 관리 없이도 기존 장애물 처리 가능
5. **감시 로직 함수 분리**: 4방향 감시 로직이 반복되므로 함수로 추출하면 가독성 향상

## 수정된 코드
```python
import sys
from itertools import combinations

input = sys.stdin.readline
N = int(input())
grid = []
empty = []
teachers = []

for i in range(N):
    row = input().strip().split()
    grid.append(row)
    for j in range(N):
        if row[j] == 'X':
            empty.append((i, j))
        elif row[j] == 'T':
            teachers.append((i, j))

dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]


def is_safe(walls):
    for tx, ty in teachers:
        for d in range(4):
            nx, ny = tx + dx[d], ty + dy[d]
            while 0 <= nx < N and 0 <= ny < N:
                if (nx, ny) in walls or grid[nx][ny] == 'O':
                    break
                if grid[nx][ny] == 'S':
                    return False
                nx += dx[d]
                ny += dy[d]
    return True


for chosen in combinations(empty, 3):
    if is_safe(set(chosen)):
        print("YES")
        break
else:
    print("NO")
```
