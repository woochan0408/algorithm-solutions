>
- 요즘 개발도 AI를 많이 사용하고 머리쓰는 일을 안 하는 것 같아서 1일 1코테를 다시 시작했다.
- 수학 구현으로 풀 수 있을 것 같았지만 오랜만에 푸는 문제라 머리가 안 돌아갔다.
- 가볍게 원형큐로 풀었다.
(시간제한도 넉넉)
- 나중에 한번 정도는 다시 풀어봐도 좋을 것 같다.

## 흐름

1. 각 신호등의 초록불, 노란불, 빨간불 상태를 지속 시간만큼 `deque`에 저장한다.
2. 모든 신호등의 주기를 곱한 값을 전체 탐색 범위로 설정한다.
3. 1초부터 시작해 각 신호등의 현재 상태를 확인한 뒤 `rotate(-1)`로 다음 상태로 이동한다.
4. 모든 신호등의 현재 상태가 노란불이면 현재 시각을 반환한다.
5. 전체 탐색 범위 안에서 조건을 만족하지 못하면 `-1`을 반환한다.

## 코드

```python
'''
초 -> 노 -> 빨

모든 신호등 노란불이 되면 정전

수학문제
시작 = 초록길이
주기 = 빨 + 파
최소공배수로 풀 수 있을 것 같은데 머리가 아프므로 그냥 풀자.
(조건 안 까다로움)

최소공배수의 상한선 = 모든 주기의 곱
'''
from collections import deque

def solution(signals):
    dequeSignals = []
    minLoop = 1


    for signal in signals:
        minLoop *= sum(signal)

        sub = deque([])
        for i in range(3):
            for j in range(signal[i]):
                sub.append(i)

        dequeSignals.append(deque(sub))

    answer = 0
    turn = 1
    for i in range(minLoop):
        result = []
        for signal in dequeSignals:
            result.append(signal[0])
            signal.rotate(-1)

        # 노란불이 아님
        if(result[0] != 1):
            turn += 1
            continue

        re = True
        for i in range(len(result)):
            if(result[i] != 1):
                re = False
        if(re):
            return turn
        turn += 1
    return -1
```

## 질문 & 실수 정리

### 새로 배운 것

#### 전체 상태의 반복 주기

각 신호등의 전체 주기는 `초록불 + 노란불 + 빨간불`이다. 여러 신호등의 상태가 처음과 완전히 같아지는 시점은 각 주기의 **최소공배수**이다.

각 주기의 곱도 모든 주기로 나누어떨어지므로 탐색 상한으로 사용할 수 있지만, 최소공배수보다 크거나 같기 때문에 불필요한 반복이 생길 수 있다.

- **핵심 원리**: 최소공배수만큼 시간이 지나면 모든 신호등이 처음 상태로 돌아온다.
- **시간복잡도**: 최소공배수를 `L`, 신호등 개수를 `N`이라 하면 `O(L × N)`

#### 나머지 연산으로 현재 신호 구하기

시간이 1초부터 시작하므로 현재 주기 안에서의 위치는 다음과 같이 계산할 수 있다.

```python
offset = (time - 1) % period
```

초록불의 지속 시간이 `G`, 노란불의 지속 시간이 `Y`라면 아래 범위에서 노란불이다.

```python
G <= offset < G + Y
```

`deque`에 각 초의 상태를 저장하고 회전하지 않아도 현재 신호를 바로 계산할 수 있다.

- **핵심 원리**: 반복되는 상태는 현재 시간을 주기로 나눈 나머지로 찾을 수 있다.
- **공간복잡도**: 각 초의 상태를 저장하지 않으므로 `O(N)`

#### `all()`을 이용한 전체 조건 확인

리스트의 모든 원소가 조건을 만족하는지 확인할 때 별도의 불리언 변수와 반복문 대신 `all()`을 사용할 수 있다.

```python
all(value == 1 for value in result)
```

조건을 만족하지 않는 원소를 발견하면 즉시 검사를 중단하므로 의도가 명확하고 불필요한 반복도 줄일 수 있다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 첫 번째 코드에서 일부 분기에만 `turn`을 증가시킴 | 한 번의 상태 확인이 끝날 때마다 시간을 1초 증가시켜야 함 |

## AI 코드 리뷰

### 잘한 점

1. **유효한 탐색 상한 설정**: 각 주기의 곱이 전체 상태가 반복되는 시점의 배수라는 점을 이용해 무한 반복을 방지했다.
2. **시간의 시작점 처리**: `turn = 1`로 두어 문제에서 시간이 1초부터 시작한다는 조건을 반영했다.
3. **상태를 직관적으로 표현**: 초록불, 노란불, 빨간불을 각각 `0`, `1`, `2`로 저장해 현재 상태를 쉽게 비교했다.
4. **제한사항 안에서 충분히 통과 가능한 구현**: 신호등은 최대 5개이고 각 주기는 최대 20이므로 주기의 곱을 사용해도 최대 약 320만 초만 확인한다.

### 개선할 점

1. **변수명 개선**
   - `dequeSignals` → `signal_queues`
   - `minLoop` → `search_limit`
   - `sub` → `states`
   - `re` → `all_yellow`
   - `turn` → `time`

   `minLoop`는 실제로 최솟값이 아니고, `re`는 의미를 파악하기 어렵다. 변수명만으로 역할을 알 수 있게 작성하는 편이 좋다.

2. **불필요한 자료구조 제거**

   각 신호등의 상태를 지속 시간만큼 `deque`에 저장할 필요는 없다. 현재 시간을 전체 주기로 나눈 나머지만 알면 현재 신호를 계산할 수 있다.

3. **탐색 범위 축소**

   각 주기의 곱까지 탐색하는 것은 정답이지만, 모든 신호등의 전체 상태는 주기의 최소공배수마다 반복된다. 따라서 최소공배수까지만 확인하면 충분하다.

4. **조건 검사 단순화**

   첫 번째 신호등을 따로 검사한 뒤 다시 모든 신호등을 검사하는 구조보다 `all()`로 전체 조건을 한 번에 표현하는 편이 읽기 쉽다.

5. **중복된 `deque` 생성 제거**

   ```python
   sub = deque([])
   dequeSignals.append(deque(sub))
   ```

   이미 `sub`가 `deque`이므로 다시 `deque(sub)`로 감쌀 필요가 없다.

6. **반복 변수 중복 사용 제거**

   바깥 시간 반복문과 결과 확인 반복문에서 모두 `i`를 사용하고 있다. 실행 오류가 발생하지는 않지만 코드의 흐름을 읽기 어려워진다.

### 기존 접근을 유지한 개선 코드

```python
from collections import deque
from math import lcm


def solution(signals):
    signal_queues = []
    periods = []

    for green, yellow, red in signals:
        states = deque(
            [0] * green
            + [1] * yellow
            + [2] * red
        )
        signal_queues.append(states)
        periods.append(green + yellow + red)

    search_limit = lcm(*periods)

    for time in range(1, search_limit + 1):
        current_states = []

        for signal_queue in signal_queues:
            current_states.append(signal_queue[0])
            signal_queue.rotate(-1)

        if all(state == 1 for state in current_states):
            return time

    return -1
```

기존의 `deque` 시뮬레이션 흐름을 유지하면서 변수명, 반복 범위, 조건 검사를 개선한 코드다.

## 더 나은 로직

각 신호등의 상태를 직접 회전시키지 않고 현재 시각이 해당 신호등 주기의 어느 위치인지 계산한다.

1. 각 신호등의 전체 주기 `G + Y + R`을 구한다.
2. 모든 주기의 최소공배수를 구한다.
3. `1초`부터 최소공배수까지 확인한다.
4. 현재 주기 안에서의 위치를 `(time - 1) % period`로 계산한다.
5. 위치가 `G 이상 G + Y 미만`이면 현재 노란불이다.
6. 모든 신호등이 노란불이면 현재 시각을 반환한다.
7. 최소공배수까지 찾지 못하면 이후에도 같은 상태가 반복되므로 `-1`을 반환한다.

- **시간복잡도**: `O(L × N)`
- **공간복잡도**: `O(N)`
- `L`: 모든 신호등 주기의 최소공배수
- `N`: 신호등의 개수

## 수정된 코드

```python
from math import lcm


def solution(signals):
    periods = [sum(signal) for signal in signals]
    full_cycle = lcm(*periods)

    for time in range(1, full_cycle + 1):
        all_yellow = all(
            green <= (time - 1) % period < green + yellow
            for (green, yellow, red), period in zip(signals, periods)
        )

        if all_yellow:
            return time

    return -1
```
