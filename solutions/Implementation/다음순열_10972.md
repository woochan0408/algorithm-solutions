# 백준 10972 🔢 다음 순열 파이썬

## 느낀점
>
- 백트래킹으로 풀었다가 메모리초과..
- 구현이 생각보다 빡셌다.

---

## 실패한 코드 흐름

1. 백트래킹으로 1부터 N까지의 모든 순열을 생성
2. 생성된 순열 리스트에서 현재 순열과 일치하는 것을 찾음
3. 그 다음 인덱스의 순열을 출력

**문제점**: N이 최대 10,000이므로 N!개의 순열을 생성하면 시간/메모리 초과

## 실패한 코드

```python
import sys
input = sys.stdin.readline
sys.setrecursionlimit(10**6)

N = int(input())
arr = list(map(int, input().split()))
result = []

def back(cur):
    if len(cur) == N:
        result.append(cur)
    for i in range(1, N+1):
        if i not in cur:
            back(cur + [i])

back([])

re = []
for i in range(len(result)-1):
    if re:
        break
    cur = result[i]
    isSame = True
    for j in range(N):
        if cur[j] != arr[j]:
            isSame = False
            break
    if isSame:
        re = result[i+1]

if re:
    for c in range(N):
        print(re[c], end=" ")
else:
    print(-1)
```

**문제점**: 모든 순열 생성 O(N!) → N=10,000일 때 불가능

---

## 성공한 코드 흐름

1. 뒤에서부터 탐색하여 **꺾이는 지점**(arr[i-1] < arr[i])을 찾음
2. 꺾이는 지점이 없으면 마지막 순열이므로 -1 출력
3. 꺾이는 지점(target) 뒤에서 target보다 큰 값을 찾아 교환
4. target 뒤의 부분을 오름차순으로 정렬 (뒤집기)

## 성공한 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))

# 꺽이는 지점 찾기
target = -1
for i in range(N - 1, 0, -1):
    if (arr[i-1] < arr[i]):
        target = i - 1
        break

re = []
# 다음 순열이 있는 경우
if (target != -1):
    # target보다 큰 값 찾기
    for i in range(N - 1, target, -1):
        if (arr[target] < arr[i]):
            # 두 값 교환
            arr[target], arr[i] = arr[i], arr[target]
            break
            
    # 뒷부분 오름차순 정렬
    re = arr[:target + 1] + sorted(arr[target + 1:])

# 결과 출력
if (re):
    for c in range(N):
        print(re[c], end = " ")
else:
    # 다음 순열이 없음
    print(-1)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 다음 순열 알고리즘 (Next Permutation)
현재 순열에서 사전순으로 바로 다음에 오는 순열을 O(N)에 구하는 알고리즘. 모든 순열을 생성하지 않고 직접 계산할 수 있다.
- **핵심 원리**: 뒤에서부터 내림차순이 깨지는 지점을 찾고, 그 지점과 뒤쪽에서 교환할 대상을 찾아 교환 후 뒷부분을 뒤집음
- **시간복잡도**: O(N)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `sys.setrecursion` | `sys.setrecursionlimit` |
| 모든 순열 생성 (N! 개) | 현재 순열에서 직접 다음 순열 계산 O(N) |

## AI 코드 리뷰

### 개선할 점

1. **변수명**: `re`는 정규표현식 모듈명과 겹치고 의미가 불명확함. `result`가 더 명확함
2. **출력 방식**: `print(*리스트)`를 사용하면 반복문 없이 공백 구분 출력 가능
3. **뒷부분 정렬 최적화**: 교환 후 뒷부분은 이미 내림차순이 보장되므로 `sorted()` O(n log n) 대신 `[::-1]`로 O(n)에 처리 가능
4. **불필요한 리스트 생성**: 새 리스트를 만들지 않고 in-place로 처리하면 메모리 효율적

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))

# 꺾이는 지점 찾기
target = -1
for i in range(N - 1, 0, -1):
    if arr[i - 1] < arr[i]:
        target = i - 1
        break

# 다음 순열이 없는 경우
if target == -1:
    print(-1)
else:
    # target보다 큰 값 찾아서 교환
    for i in range(N - 1, target, -1):
        if arr[target] < arr[i]:
            arr[target], arr[i] = arr[i], arr[target]
            break
    
    # 뒷부분 뒤집기 (이미 내림차순이므로)
    arr[target + 1:] = arr[target + 1:][::-1]
    
    print(*arr)
```
