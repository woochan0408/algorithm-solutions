## 느낀점
>
- 좋은 문제다.
- SQL 날짜 겹침 조건에서 아이디어를 얻었다.
(구간 끼리의 겹침 판단)
- 오랜만에 코테 풀었더니 잔실수가 많았다.

---

## 실패한 코드 흐름
1. 입력을 받을 때마다 기존 구간 배열 `arr` 안에서 겹치는 구간을 바로 찾아 합치려고 했다.
2. 하지만 새로 들어온 구간이 기존 여러 구간을 연쇄적으로 이어 붙이는 경우, 처음 만난 한 구간만 갱신하고 종료해서 전체 병합이 되지 않았다.
3. 즉, **입력 시점 병합**으로 처리하다 보니 `기존 구간 + 새 입력 + 또 다른 기존 구간` 형태의 연결을 놓친 접근이었다.

## 실패한 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())
arr = []
for _ in range(M):
    start, end = map(int, input().split())
    for j in range(len(arr)):
        cur = arr[j]
        # 구간이 겹친다.
        if(cur[1] >= start and cur[0] <= end):
            if(cur[0] > start):
                arr[j][0] = start
            if(cur[1] < end):
                arr[j][1] = end
            break
    # 겹치는 구간 없었음
    else:
        arr.append([start, end])

# 1, 2, 3, 4 가 1이 되어어. 즉 4 - 1만큼 사라짐
minus = 0
for cur in arr:
    minus += cur[1] - cur[0]
print(N - minus)
```

**문제점**: 새 구간이 여러 기존 구간을 한 번에 이어 붙이는 경우를 처리하지 못했다.

---

## 성공한 코드 흐름
1. 모든 입력 구간을 먼저 배열에 저장한다.
2. 시작점 기준으로 정렬해서 왼쪽부터 순서대로 본다.
3. 현재 병합 중인 구간 `working`을 유지하면서,
   - 겹치면 끝점을 늘리고
   - 겹치지 않으면 이전 구간 길이를 누적한 뒤 새 구간으로 교체한다.
4. 반복이 끝난 뒤 마지막으로 남아 있는 `working` 구간도 길이를 반영한다.
5. 합쳐진 구간들의 총 길이만큼 벽이 사라진 것이므로 `N - minus`를 출력한다.

## 성공한 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())
arr = []
for _ in range(M):
    start, end = map(int, input().split())
    arr.append([start, end])

i = 0
arr.sort()
working = []
minus = 0
while i < M:
    #작업 중인 것이 있음
    if(working):
        s1, e1 = working
        s2, e2 = arr[i][0], arr[i][1]

        # 겹침
        if(e1 >= s2):
            if(e2 > e1):
                working[1] = e2
        # 안 겹침
        else:
            minus += working[1] - working[0]
            working = [s2, e2]
    else:
        working = arr[i]
    i += 1
if(working):
    minus += working[1] - working[0]
print(N - minus)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 닫힌 구간 겹침 판단
두 닫힌 구간 `[a, b]`, `[c, d]`가 겹치는지는 **안 겹치는 경우를 먼저 생각한 뒤 뒤집는 방식**이 가장 직관적이다. 안 겹치는 경우는 `b < c` 또는 `d < a` 두 가지뿐이므로, 겹치는 조건은 `NOT (b < c OR d < a)`가 된다. 이를 정리하면 `b >= c AND d >= a`이다. 이 문제처럼 구간 병합을 구현할 때 조건을 안정적으로 세우는 데 도움이 된다.
- **핵심 원리**: 여집합으로 보면 겹침 조건을 빠뜨리지 않고 정리할 수 있다.
- **시간복잡도**: `O(1)`

#### 정렬 후 구간 병합
입력을 받을 때마다 바로 합치려고 하면, 새 구간이 기존 여러 구간을 연쇄적으로 이어 붙이는 상황을 놓치기 쉽다. 그래서 모든 구간을 먼저 저장한 뒤 정렬하고, 현재 병합 중인 구간 하나만 유지하며 왼쪽부터 한 번 훑는 방식이 훨씬 안전하다. 겹치면 끝점을 확장하고, 안 겹치면 이전 구간을 확정하는 방식으로 처리하면 된다.
- **핵심 원리**: 시작점 기준 정렬 후 한 번 스캔하며 병합한다.
- **시간복잡도**: 정렬 `O(M log M)`, 스캔 `O(M)`

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|새 입력을 기존 구간 하나와만 합치고 바로 종료함|정렬 후 한 번 스캔하면서 연쇄적으로 병합해야 함|
|반복 도중에만 길이를 누적해 마지막 구간이 빠질 수 있었음|반복 종료 후 남아 있는 구간도 마지막으로 반영해야 함|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `arr`, `working`, `minus`는 의미가 조금 압축되어 있다. `intervals`, `current_start`, `current_end`, `removed_walls`처럼 역할이 드러나는 이름이면 읽기가 더 편하다.
2. **반복문 구조 단순화**: 인덱스를 직접 관리하는 `while`보다 정렬된 구간을 순회하는 `for`가 흐름을 더 자연스럽게 보여준다.
3. **상태 표현 명확화**: `working`을 빈 리스트와 비교하기보다, 현재 병합 중인 시작점과 끝점을 별도 변수로 들고 가면 조건 분기가 단순해진다.
4. **예외 케이스 분리**: `M == 0`인 경우를 초반에 바로 처리하면 본문 로직이 더 깔끔해진다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())
intervals = [tuple(map(int, input().split())) for _ in range(M)]

if M == 0:
    print(N)
else:
    intervals.sort()
    current_start, current_end = intervals[0]
    removed_walls = 0

    for start, end in intervals[1:]:
        if start <= current_end:
            current_end = max(current_end, end)
        else:
            removed_walls += current_end - current_start
            current_start, current_end = start, end

    removed_walls += current_end - current_start
    print(N - removed_walls)
```
