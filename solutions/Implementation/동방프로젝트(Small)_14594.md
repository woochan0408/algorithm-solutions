# 백준 14594 🚪 동방 프로젝트 (Small) 파이썬
## 느낀점
>
- union?, 딕셔너리? 여러 생각이 나는 좋은 문제다.
- 일단 Small 문제는 브루트포스로 풀고 Large는 저녁에 풀어보려 한다.

## 흐름
처음에 방의 개수를 `N`개로 두고, 각 방이 **새로운 동방의 시작점인지**를 불리언 배열로 관리했다.

- 처음에는 모든 방이 독립적이므로 전부 `True`로 둔다.
- `a b`가 들어오면 `a`번 방부터 `b`번 방 사이의 벽이 무너지므로, `a+1`번 방부터 `b`번 방까지는 더 이상 새로운 동방의 시작점이 아니게 된다.
- 그래서 배열에서 `a`부터 `b-1` 구간을 `False`로 바꾼다.
- 마지막에 `True`의 개수를 세면 남아 있는 동방 수가 된다.

## 코드
```python
'''
5
2
1 2
2 4

재밌는 문제다
'''
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())
wall = [True]*(N)

for _ in range(M):
    a, b = map(int, input().split())
    for i in range(a, b):
        wall[i] = False
print(sum(wall))
```

## 질문 & 실수 정리

### 새로 배운 것
이번 풀이에서는 별도로 새로 정리할 개념은 없었다.

### 실수했던 부분
이번 풀이에서는 특별한 실수 없이 바로 해결했다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())

# True면 해당 방이 하나의 동방 시작점이라는 뜻
room_start = [True] * N

for _ in range(M):
    left, right = map(int, input().split())

    for room in range(left, right):
        room_start[room] = False

print(sum(room_start))
```
