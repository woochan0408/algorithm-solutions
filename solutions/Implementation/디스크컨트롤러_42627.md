## 느낀점
>
- 아 거의 다 풀었는데 마지막 실수로 못 풀었다...
- 실수 뼈에 새겨두자.

## 흐름

1. 작업 목록을 (요청시각, 소요시간, 번호) 형태로 변환 후 역순 정렬 → `pop()`으로 가장 빠른 요청부터 꺼냄
2. 매 ms마다 루프를 돌며 시뮬레이션
   - 현재 작업이 완료되었으면 반환 시간 기록 후 `cur` 비움
   - 현재 시각에 도착한 작업들을 힙에 삽입 (소요시간, 요청시각, 번호 순 우선순위)
   - 작업이 없고 힙이 비어있지 않으면 우선순위가 가장 높은 작업 꺼내서 실행
3. 모든 작업 완료 후 반환 시간 합계를 작업 수로 나눈 정수부분 반환

## 코드
```python
"""
대기 큐 - 작업번호, 요청시각, 소요시간
우선순위대로 써내 씀
소요시간 짧은 것, 요청시간 빠른 것 번호 작은 것
"""
import heapq
def solution(jobs):
    
    # arr: 요청시각, 종료시간, 번호
    arr = []
    for i in range(len(jobs)):
        arr.append((jobs[i][0], jobs[i][1], i))
        
    arr.sort(reverse = True)
    
    t = 0
    
    result = []
    
    # cur은 지금 진행중인 프로세스
    cur = []
    
    # 대기중인 프로세스
    heap = []
    while True:
        if(not cur and not heap and not arr):
            break
            
        if(cur and (t - cur[3]) == cur[0]):
            result.append(t - cur[1])
            cur = []
        while(arr and arr[-1][0] == t):
            a = arr.pop()
            heapq.heappush(heap, (a[1], a[0], a[2]))
        
        if(not cur and heap):
            n = heapq.heappop(heap)
            cur = [n[0], n[1], n[2], t]
        
        t += 1
    answer = sum(result) // len(result)
    return answer
```

## 질문 & 실수 정리

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`cur = []` 한 뒤에 `cur[1]` 접근 → IndexError|반환 시간 먼저 기록한 후 `cur = []`로 비워야 함|
|`round()`로 평균 계산|문제 요구사항은 "정수부분" → `//` 사용|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `arr`은 역할이 모호하므로 `tasks` 같은 이름이 의미를 더 잘 전달한다. `cur`의 인덱스 접근(`cur[0]`, `cur[3]`)도 가독성이 떨어진다.

2. **매 ms 시뮬레이션 → 이벤트 기반 점프**: 현재 `t += 1`로 매 ms 루프를 도는 방식은 최악의 경우 약 50만 회 반복한다. 작업 완료 시점으로 바로 점프하면 루프 횟수가 작업 수(n)로 줄어들어 O(n log n)으로 개선된다.

3. **enumerate 활용**: `for i in range(len(jobs))` 대신 `enumerate`를 쓰면 더 파이썬답다.

## 수정된 코드
```python
import heapq

def solution(jobs):
    # (요청시각, 소요시간, 번호) 정렬
    tasks = sorted((s, l, i) for i, (s, l) in enumerate(jobs))

    t = 0
    idx = 0
    heap = []
    total = 0
    done = 0

    while done < len(jobs):
        # 현재 시각까지 도착한 작업 모두 힙에 삽입
        while idx < len(tasks) and tasks[idx][0] <= t:
            s, l, i = tasks[idx]
            heapq.heappush(heap, (l, s, i))
            idx += 1

        if heap:
            l, s, i = heapq.heappop(heap)
            t += l
            total += t - s
            done += 1
        else:
            # 대기 중인 작업 없으면 다음 작업 도착 시각으로 점프
            t = tasks[idx][0]

    return total // len(jobs)
```
