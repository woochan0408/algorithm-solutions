## 느낀점
>
- 실수가 많았다.
- 두 번째 풀이로 처음 풀 떄보다 훨씬 잘 풀었다.

## 흐름

1. 작업을 (번호, 요청시각, 소요시간) 튜플로 변환 후 요청시각 기준 정렬
2. 현재 시각 `t` 이하인 작업들을 힙(우선순위 큐)에 삽입 — (소요시간, 요청시각, 번호) 순으로 정렬
3. 힙에서 가장 우선순위 높은 작업을 꺼내 처리, `t += 소요시간`
4. 각 작업 완료 시 `반환시간 = 완료시각 - 요청시각` 누적
5. 힙이 비어있고 아직 요청 안 된 작업이 있으면 다음 작업 요청시각으로 점프
6. 모든 작업 완료 후 반환시간 평균의 정수부분 리턴

## 코드
```python
import heapq
def solution(jobs):
    result = []
    # 작업번호, 시작시간, 소요시간
    arr = []
    heap = []
    for i in range(len(jobs)):
        s, l = jobs[i]
        arr.append((i, s, l))
    arr.sort(key = lambda x : x[1])
    N = len(arr)
    
    t = 0
    i = 0
    while True:
        # 대기큐 작업 i작업 할 차례
        while True:
            if(i < N and arr[i][1] <= t):
                heapq.heappush(heap, (arr[i][2], arr[i][1], arr[i][0]))
                i += 1
            else:
                break
        
        # 연산작업
        if(heap):
            l, s, j = heapq.heappop(heap)
            t += l
            result.append(t - s)
        
        # 검증
        # 모든 작업 완료
        if(not heap and i == N):
            break
        # 다음 작업이 없는데 할 작업은 있음
        if(not heap and i < N and arr[i][1] > t):
            # 시작 시간으로 점프
            t = arr[i][1]
    
    return sum(result) // N
```

## 질문 & 실수 정리

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`l, s, i = heapq.heappop(heap)` — 인덱스 `i`를 작업번호로 덮어씀|`l, s, j = heapq.heappop(heap)` — 별도 변수 사용|
|`return t` — 마지막 완료 시각만 반환|`return sum(result) // N` — 반환시간 평균 계산|
|`arr[i][0] > t` — 작업번호와 시각 비교|`arr[i][1] > t` — 요청시각과 현재시각 비교|

## AI 코드 리뷰

### 개선할 점

1. **디버그 출력 제거**: `print(i)`가 남아있으면 제출 시 불필요한 출력이 발생한다.

2. **변수명 명확화**: `arr`, `l`, `s`, `j` 등 약어가 많아 가독성이 떨어진다. 역할이 드러나는 이름을 사용하면 실수도 줄어든다.

3. **enumerate 활용**: `for i in range(len(jobs))` + 인덱싱 대신 `enumerate`를 쓰면 더 간결하다.

4. **반환시간 누적 방식**: `result` 리스트에 append 후 마지막에 sum하는 대신, 정수 변수 하나로 누적하면 메모리를 절약할 수 있다.

## 수정된 코드
```python
import heapq

def solution(jobs):
    # (작업번호, 요청시각, 소요시간) 튜플로 변환 후 요청시각 기준 정렬
    tasks = [(idx, start, duration) for idx, (start, duration) in enumerate(jobs)]
    tasks.sort(key=lambda x: x[1])
    
    n = len(tasks)
    heap = []
    total_turnaround = 0
    time = 0
    i = 0
    
    while True:
        # 현재 시각까지 요청된 작업을 대기큐에 삽입
        while i < n and tasks[i][1] <= time:
            _, start, duration = tasks[i]
            heapq.heappush(heap, (duration, start, i))
            i += 1
        
        # 우선순위가 가장 높은 작업 처리
        if heap:
            duration, start, _ = heapq.heappop(heap)
            time += duration
            total_turnaround += time - start
        
        # 모든 작업 완료
        if not heap and i == n:
            break
        
        # 대기큐가 비었지만 아직 요청 안 된 작업이 있으면 점프
        if not heap and i < n and tasks[i][1] > time:
            time = tasks[i][1]
    
    return total_turnaround // n
```
