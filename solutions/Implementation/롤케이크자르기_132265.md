## 느낀점
>
- 같은방향 투포인터인가?? 라는 생각을 한번 했다.
- 바로 접고 O(N)으로 풀었다.

## 흐름

1. 전체 토핑의 개수를 Counter로 세어 오른쪽(right) 카운터에 저장
2. 왼쪽(left) 카운터는 빈 상태로 시작
3. 앞에서부터 하나씩 오른쪽에서 빼고 왼쪽에 추가
4. 오른쪽 카운터에서 개수가 0이 되면 해당 키 삭제
5. 양쪽 카운터의 키 개수(= 토핑 종류 수)가 같으면 정답 증가

## 코드
```python
from collections import Counter, defaultdict
def solution(topping):
    N = len(topping)
    c1 = Counter(topping)
    c2 = Counter()
    answer= 0
    for i in range(N):
        cur = topping[i]
        
        c1[cur] -= 1
        c2[cur] += 1
        
        if(c1[cur] == 0):
            del c1[cur]
        if(len(c1) == len(c2)):
            answer += 1
    return answer
```

## AI 코드 리뷰

### 개선할 점

1. **미사용 import 제거**: `defaultdict`를 import했지만 사용하지 않음
2. **변수명 개선**: `c1`, `c2`는 의미가 불명확 → `right_count`, `left_count`로 변경
3. **불필요한 변수 제거**: `cur = topping[i]`와 인덱스 순회 대신 직접 순회 가능하지만, Counter에서 0인 키 삭제가 필요하므로 `enumerate` 없이 직접 순회가 더 깔끔
4. **`answer=` 공백 누락**: `answer= 0` → `answer = 0`

## 수정된 코드
```python
from collections import Counter

def solution(topping):
    right_count = Counter(topping)
    left_count = Counter()
    answer = 0

    for t in topping:
        right_count[t] -= 1
        left_count[t] += 1

        if right_count[t] == 0:
            del right_count[t]

        if len(right_count) == len(left_count):
            answer += 1

    return answer
```
