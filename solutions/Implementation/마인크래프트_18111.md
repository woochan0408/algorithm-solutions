                inv += cur - h
                time += (cur - h)*2
            else:
                req = h - cur
                if(inv - req >= 0):
                    inv -= req
                    time += req
                else:

    return time

## 성공한 코드 흐름

1. 높이 0~256을 모두 시도하는 브루트포스
2. 매 높이마다 N×M 칸을 순회하면 시간초과 → Counter로 빈도 압축
3. Counter의 키(높이별 개수)만 순회하며 파는 시간(×2) + 쌓는 시간(×1) 계산
4. 인벤토리가 부족하면 불가능(-1), 가능하면 (시간, -높이) 저장
5. 결과를 정렬하여 최소 시간 & 최대 높이 출력

## 성공한 코드

```python
"""
최적 시간이 아니라 최대 높이로 만드는 것..


"""
import sys
from collections import Counter
input = sys.stdin.readline
N, M, B = map(int, input().split())
# h로 땅 만드는데 걸리는 시간 반환 함수
# 못 만들면 -1 반환
def build(h):
    inv = B
    time = 0
    keySet = list(counter.keys())
    # 내림차순으로 하면 인벤 최대한 채우므로 부족하면 바로 return 가능
    keySet.sort(reverse = True)
    
    for cur in keySet:
        curH = cur
        curCount = counter[cur]
        if(curH > h):
            time += (curH - h)*curCount*2
            inv += (curH - h)*curCount
        elif(curH < h):
            req = (h - curH)*curCount
            if(inv - req >= 0):
                inv -= req
                time += req
            else:
                return -1
    return time
    
counter = Counter()
for i in range(N):
    counter.update(list(map(int, input().split())))
results = []
for h in range(256, -1, -1):
    result = build(h)
    if(result == -1):
        continue
    else:
        results.append((result, -h))
results.sort()
print(results[0][0], -results[0][1])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 빈도 압축을 통한 2D 배열 최적화 (Counter)
N×M 크기의 2D 배열에서 각 셀의 좌표가 아니라 **값의 분포**만 중요한 경우, Counter로 빈도를 압축하면 내부 루프를 N×M에서 고유 값의 개수(최대 257)로 줄일 수 있다. 이 문제에서는 500×500=250,000칸을 매번 순회하는 대신, 최대 257개의 높이별 빈도만 순회하여 시간복잡도를 대폭 줄였다.
- **핵심 원리**: 개별 위치가 아닌 값의 빈도(개수)만으로 전체 계산이 가능할 때, Counter로 차원을 압축
- **시간복잡도**: O(N×M) → O(고유값 수) (내부 루프 기준)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `max(maxVal, arr)` — int와 list 비교 | `max(maxVal, max(arr))` — list 내 최댓값을 먼저 추출 |
| 매 높이마다 N×M 칸 전체 순회 (시간초과) | Counter로 빈도 압축 후 고유 높이만 순회 |

## AI 코드 리뷰

### 개선할 점

1. **`keySet.sort()` 반복 호출**: `build()` 함수가 호출될 때마다 `keySet`을 새로 만들고 정렬하고 있다. Counter의 키는 변하지 않으므로 한 번만 정렬해두면 된다.

2. **results 리스트 + sort 불필요**: 모든 결과를 리스트에 모아서 정렬하는 대신, 순회하면서 최소 시간과 최대 높이만 추적하면 메모리와 시간 모두 절약된다.

3. **불필요한 변수 할당**: `curH = cur`는 `cur`을 그대로 써도 된다. 변수명 자체를 의미 있게 하면 중간 할당이 불필요하다.

4. **`list()` 불필요**: `counter.update(list(map(...)))` → `counter.update(map(...))`으로 충분하다.

## 수정된 코드

```python
import sys
from collections import Counter

input = sys.stdin.readline
N, M, B = map(int, input().split())

counter = Counter()
for _ in range(N):
    counter.update(map(int, input().split()))

# 키를 한 번만 내림차순 정렬 (높은 높이부터 처리하여 인벤토리 조기 확보)
sorted_keys = sorted(counter.keys(), reverse=True)

min_time = float('inf')
best_h = 0

for h in range(257):
    inv = B
    time = 0
    possible = True

    for k in sorted_keys:
        cnt = counter[k]
        if k > h:
            diff = (k - h) * cnt
            time += diff * 2
            inv += diff
        elif k < h:
            diff = (h - k) * cnt
            inv -= diff
            time += diff
            if inv < 0:
                possible = False
                break

    if possible and time <= min_time:
        min_time = time
        best_h = h

print(min_time, best_h)
```
