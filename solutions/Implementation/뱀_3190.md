# 백준 3190 🐍 뱀 파이썬

## 느낀점
>
- 이런 문제 반복문 순서가 항상 헷갈린다..
- 연습 많이하자.

## 흐름

1. 뱀의 몸을 deque로 관리 (앞: 꼬리, 뒤: 머리)
2. 매 초마다 머리를 다음 칸으로 이동
3. 벽이나 자기 몸에 부딪히면 게임 종료
4. 사과가 있으면 꼬리 유지, 없으면 꼬리 제거
5. 이동 완료 후 방향 변경 명령이 있으면 처리

## 코드

```python
import sys
from collections import deque
input = sys.stdin.readline
N = int(input())
appleCount = int(input())
moveSign = deque()
move = deque([(0, 1), (1, 0), (0, -1), (-1, 0)])
grid = [[0]*N for i in range(N)]
for _ in range(appleCount):
    r, c = map(int, input().split())
    grid[r-1][c-1] = 2
moveCount = int(input())
for _ in range(moveCount):
    t, sign = input().split()
    moveSign.append((int(t), sign))
time = 0
x = 0
y = 0
cur = deque([(0, 0)])
while True:
    time += 1
    # 이동
    nx, ny = x + move[0][0], y + move[0][1]
    
    # 벽부터 확인
    if(nx < 0 or nx >= N or ny < 0 or ny >= N):
        break
    
    # 꼬리 닿았니?
    if((nx, ny) in cur):
        break
    
    # 사과 계산
    if(grid[nx][ny] == 2):
        grid[nx][ny] = 0
    else:
        # 길이를 줄여야 해
        cur.popleft()
    
    cur.append((nx, ny))
    x = nx
    y = ny
    
    # 이동 완료 후 방향 변경
    if(moveSign and moveSign[0][0] == time):
        t, s = moveSign.popleft()
        if(s == 'L'):
            move.rotate(1)
        else:
            move.rotate(-1)
print(time)
```

## 질문 & 실수 정리

### 새로 배운 것

#### deque.rotate()를 활용한 방향 회전
deque의 rotate 메서드를 사용하면 순환 배열처럼 방향을 관리할 수 있다. 오른쪽(시계방향) 회전은 `rotate(-1)`, 왼쪽(반시계방향) 회전은 `rotate(1)`로 구현한다.
- **핵심 원리**: 우/하/좌/상 순서로 배열하면 rotate(-1)이 시계방향 90도 회전

#### 시뮬레이션에서 "X초 후" 타이밍 해석
"X초가 끝난 뒤" = X초 동작 완료 후 = 이동 먼저, 방향 변경은 나중. 문제의 시간 표현을 정확히 해석하는 것이 중요하다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 방향 변경을 이동 전에 처리 | 방향 변경은 이동 완료 후 처리 |
| time = 1로 시작 | time = 0으로 시작 후 루프에서 증가 |
| 사과 위치 그대로 사용 | 1-indexed → 0-indexed 변환 필요 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `moveSign`, `cur`, `move` 등이 의미가 불명확합니다. `turns`, `snake`, `directions` 등이 더 직관적입니다.

2. **꼬리 충돌 체크 최적화**: `(nx, ny) in cur`는 deque에서 O(n) 시간이 걸립니다. set을 병행 사용하면 O(1)로 개선됩니다.

3. **방향 관리 방식**: deque.rotate()도 좋지만, 인덱스 기반 방향 관리가 더 직관적일 수 있습니다.

## 수정된 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

N = int(input())
apple_count = int(input())

# 방향: 우, 하, 좌, 상 (시계방향 순서)
directions = [(0, 1), (1, 0), (0, -1), (-1, 0)]
direction_idx = 0

grid = [[0] * N for _ in range(N)]
for _ in range(apple_count):
    r, c = map(int, input().split())
    grid[r - 1][c - 1] = 1

turn_count = int(input())
turns = deque()
for _ in range(turn_count):
    t, sign = input().split()
    turns.append((int(t), sign))

time = 0
x, y = 0, 0
snake = deque([(0, 0)])
snake_set = {(0, 0)}

while True:
    time += 1
    
    # 이동
    dx, dy = directions[direction_idx]
    nx, ny = x + dx, y + dy
    
    # 벽 충돌 확인
    if nx < 0 or nx >= N or ny < 0 or ny >= N:
        break
    
    # 자기 몸 충돌 확인
    if (nx, ny) in snake_set:
        break
    
    # 사과 처리
    if grid[nx][ny] == 1:
        grid[nx][ny] = 0
    else:
        tail = snake.popleft()
        snake_set.remove(tail)
    
    snake.append((nx, ny))
    snake_set.add((nx, ny))
    x, y = nx, ny
    
    # 이동 완료 후 방향 변경
    if turns and turns[0][0] == time:
        _, sign = turns.popleft()
        if sign == 'L':
            direction_idx = (direction_idx - 1) % 4
        else:
            direction_idx = (direction_idx + 1) % 4

print(time)
```
