# 백준 34936 🔗 블록 생성 파이썬

## 느낀점
>
- 항상 최소 범위가 정해져 있다 -> pop하는 순간 필요 없는 값
- heap 비어있는 지 확인 필요

## 흐름

1. 트랜잭션 풀을 최대 힙으로 관리 (수수료 기준 내림차순, 같으면 생성시간 오름차순)
2. 트랜잭션 생성(1) 시 힙에 (-수수료, 생성시간) 형태로 push
3. 블록 생성(2) 시 힙에서 K개를 꺼내되, 유효 범위(현재시간 - T 이하) 내의 트랜잭션만 선택
4. 유효 범위 밖 트랜잭션은 시간이 단조 증가하므로 다시 넣지 않고 버림
5. 선택된 트랜잭션의 수수료 합을 누적

## 코드

```python
"""
7 3 2
1 1 5
1 2 10
2 3
1 5 7
1 6 9
2 7
2 10
"""
import sys, heapq
input = sys.stdin.readline
N, T, K = map(int, input().split())
heap = []
result = 0
for _ in range(N):
    req = list(map(int, input().split()))
    # pull에 넣는 작업
    if(req[0] == 1):
        heapq.heappush(heap, (-req[2], req[1]))
    else:
        stack = []
        while heap and len(stack) < K:   
            cur = heapq.heappop(heap)
            if(req[1] - T <= cur[1]):
                stack.append(-cur[0])
        # 계산
        result += sum(stack)
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 힙에서 조건부 추출 패턴
우선순위 큐에서 조건을 만족하는 원소만 K개 추출할 때, 조건을 만족하지 않는 원소는 버릴지 다시 넣을지 판단해야 한다. 이 문제에서는 시간이 단조 증가하므로 한 번 유효 범위를 벗어난 트랜잭션은 영원히 유효하지 않아 버려도 된다.
- **핵심 원리**: 단조성을 활용한 lazy deletion

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| heap이 비어있을 때 pop 시도 | `while heap and ...` 조건 추가 |
| 유효 범위 밖 트랜잭션을 다시 heap에 넣음 | 시간 단조 증가이므로 버려도 됨 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 명확화**: `req` → `event`, `cur` → `tx`, `stack` → `selected` (스택처럼 동작하지 않으므로)
2. **주석 오타**: `pull` → `pool`
3. **불필요한 리스트 변환**: `list(map(...))` 대신 직접 언패킹 가능
4. **sum 대신 즉시 누적**: 리스트에 모았다가 sum하는 대신 바로 더하면 메모리 절약

## 수정된 코드

```python
import sys
import heapq

input = sys.stdin.readline

N, T, K = map(int, input().split())
pool = []  # (-수수료, 생성시간)
result = 0

for _ in range(N):
    event = list(map(int, input().split()))
    
    if event[0] == 1:
        # 트랜잭션 생성
        heapq.heappush(pool, (-event[2], event[1]))
    else:
        # 블록 생성
        current_time = event[1]
        count = 0
        
        while pool and count < K:
            fee, created_time = heapq.heappop(pool)
            if current_time - T <= created_time:
                result += -fee
                count += 1
            # 유효 범위 밖이면 버림 (시간 단조 증가이므로 재사용 불가)

print(result)
```
