# 백준 2607 🔤 비슷한 단어 파이썬

## 느낀점
>
- 구현이 비효율적인 것 같다.
- set문법 배워두자.

## 흐름

1. 첫 번째 단어를 Counter로 저장하여 각 문자별 개수 파악
2. 나머지 단어들과 비교: base - compare로 차이 계산
3. 차이값을 양수(base가 더 많음)와 음수(compare가 더 많음)로 분류
4. 비슷한 단어 조건 검증:
   - 같은 구성: 차이 없음
   - 한 문자 추가/삭제: 한쪽만 1개 차이
   - 한 문자 교체: 양쪽 각각 1개씩 차이
5. 조건 만족 시 카운트 증가

## 코드

```python
"""
4
DOG
GOD
GOOD
DOLL
"""
import sys
from collections import Counter, defaultdict
input = sys.stdin.readline
N = int(input())
string = Counter(input().strip())
target = defaultdict(int)
for key in string:
    target[key] += string[key]
result = 0
for _ in range(N-1):
    cur = Counter(input().strip())
    t = target.copy()
    for key in cur:
        t[key] -= cur[key]
    # 검증시간
    life = 0
    can = True
    
    for key in t:
        cur = t[key]
        if(cur == 0):
            continue
        elif(cur >= 2 or cur <= -2):
            can = False
            break
        elif(cur == 1 or cur == -1):
            if(life == 0):
                life = cur
            else:
                if(life + cur) == 0:
                    life = -3
                else:
                    can = False
                    break
    if(can):
        result += 1
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### Counter의 기본값 동작
Counter는 존재하지 않는 키에 접근해도 0을 반환하므로 defaultdict(int)처럼 사용 가능하다. 별도로 defaultdict로 변환할 필요 없이 Counter를 직접 활용하면 코드가 간결해진다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `target[key] += 1` (개수 무시) | `target[key] += string[key]` (실제 개수 추가) |

## AI 코드 리뷰

### 개선할 점

1. **불필요한 중복 제거**: `string`이 이미 Counter인데 `target`으로 다시 복사하는 과정이 불필요. Counter를 직접 사용 가능.

2. **변수명 중복**: `cur`가 루프 안에서 Counter로도, `t[key]` 값으로도 사용되어 혼란 유발.

3. **변수명 개선**: `string`, `t`, `life`, `can` → `base`, `diff`, `plus_diff/minus_diff` 등 의미가 명확한 이름으로 변경.

4. **간결한 로직**: 양수/음수 차이를 분리해서 세면 조건 검사가 직관적. `plus_diff <= 1 and minus_diff <= 1` 한 줄로 모든 케이스 커버.

## 수정된 코드

```python
import sys
from collections import Counter
input = sys.stdin.readline

N = int(input())
base = Counter(input().strip())
result = 0

for _ in range(N - 1):
    compare = Counter(input().strip())
    
    plus_diff = 0   # base가 더 많은 문자 개수
    minus_diff = 0  # compare가 더 많은 문자 개수
    
    all_keys = set(base.keys()) | set(compare.keys())
    for key in all_keys:
        diff = base.get(key, 0) - compare.get(key, 0)
        if diff > 0:
            plus_diff += diff
        elif diff < 0:
            minus_diff += -diff
    
    if plus_diff <= 1 and minus_diff <= 1:
        result += 1

print(result)
```
