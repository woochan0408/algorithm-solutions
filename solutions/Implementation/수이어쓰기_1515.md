# 백준 1515 ✍️ 수 이어 쓰기 파이썬

## 느낀점
>
- i, j 혼동해서 삽질함.
- 처음 아이디어 떠올리기 시간 많이 걸림.

## 흐름
1. 1부터 N까지 숫자를 하나씩 증가시키며 탐색
2. 현재 숫자의 각 자릿수를 순회하면서 입력 문자열과 매칭 시도
3. 매칭되면 입력 문자열의 포인터를 전진
4. 입력 문자열을 모두 소진하면 현재 N이 답

## 코드
```python
inputString = input()
cur = ""
curNum = 1
i = 0
while i < len(inputString):
    c = inputString[i]
    found = False
    
    for j in range(len(cur)):
        # 찾았네?
        if(cur[j] == c):
            if(len(cur) == 1):
                cur = ""
            else:
                cur = cur[j+1:]
            found = True
            break
    # 찾았으면 다음 글자
    if(found):
        i += 1
    #못찾았으면 다음 숫자 넣고 반복
    else:
        cur = str(curNum)
        curNum += 1
print(curNum-1)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 순차 매칭 패턴
1부터 N까지 이어 쓴 문자열에서 부분 수열을 찾는 문제는, 각 숫자를 순회하며 자릿수별로 매칭하는 그리디 접근으로 해결할 수 있다. 핵심은 "찾는 순간 이전 것들은 고민거리가 될 수 없다"는 통찰이다.
- **핵심 원리**: 작은 숫자부터 순서대로 매칭을 시도하면 자연스럽게 최솟값 N을 찾게 됨
- **시간복잡도**: O(N × log N) — N까지 순회하며 각 숫자의 자릿수만큼 비교

## AI 코드 리뷰

### 개선할 점

1. **불필요한 상태 관리**: `cur` 문자열을 유지하며 슬라이싱하는 방식이 복잡합니다. 각 숫자를 순회하며 바로 매칭하는 방식이 더 직관적입니다.

2. **변수명**: `inputString` → `s`, `curNum` → `n`으로 간결하게

3. **found 플래그 제거**: 현재 구조는 while 안에서 i가 안 움직이면 다시 반복하는 방식인데, 이를 명시적인 이중 루프로 바꾸면 의도가 더 명확해집니다.

## 수정된 코드
```python
s = input()
n = 0
idx = 0

while idx < len(s):
    n += 1
    for c in str(n):
        if idx < len(s) and s[idx] == c:
            idx += 1

print(n)
```
