# 백준 1244 🔘 스위치 켜고 끄기 파이썬

## 느낀점
>
- 인덱스 시작값 조심

## 흐름

1. 스위치 배열을 1-indexed로 만들기 위해 앞에 더미값 삽입
2. 남학생: 받은 수의 배수 번호 스위치를 모두 토글
3. 여학생: 받은 수 중심으로 좌우 대칭 구간을 찾아 해당 구간 모두 토글
4. 20개씩 줄바꿈하여 출력

## 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
arr.insert(0, -1)
def s(i):
    if(arr[i] == 0):
        arr[i] = 1
    else:
        arr[i] = 0
M = int(input())
for _ in range(M):
    g, n = map(int, input().split())
    # 남자 계산
    if(g == 1):
        i = n
        while i < N:
            s(i)
            i += n
    # 여자 계산
    else:
        i = n
        s(i)
        l = n
        r = n
        while True:
            l -= 1
            r += 1
            if(0 <= l < N and 0 <= r < N and arr[l] == arr[r]):
                s(l)
                s(r)
            else:
                break
i = 1
while i < len(arr):
    print(arr[i], end = " ")
    if(i != 0 and i%20 == 0):
        print()
    i += 1
```

## 질문 & 실수 정리

### 새로 배운 것

#### 1-indexed 배열 처리
배열 앞에 더미값을 삽입하면 문제의 1-indexed 번호를 그대로 사용할 수 있다. 단, 이 경우 반복문의 경계값도 함께 수정해야 한다.
- **핵심 원리**: `arr.insert(0, -1)` 후 배열 길이가 N+1이 되므로, 유효 인덱스는 1~N

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`while i < N` (남학생)|`while i <= N` (1-indexed이므로 N번까지 포함)|
|`0 <= l < N and 0 <= r < N`|`l >= 1 and r <= N` (1-indexed 범위)|

## AI 코드 리뷰

### 개선할 점

1. **함수명 개선**: `s`보다 `toggle`이 의미 전달에 명확함
2. **토글 로직 간소화**: if-else 대신 XOR 연산(`^= 1`) 사용 가능
3. **경계값 수정**: 1-indexed 전환 후 범위 조건 누락

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))
arr.insert(0, -1)

def toggle(i):
    arr[i] ^= 1

M = int(input())
for _ in range(M):
    g, n = map(int, input().split())
    
    if g == 1:
        # 남학생: 배수 번호 토글
        i = n
        while i <= N:
            toggle(i)
            i += n
    else:
        # 여학생: 중심 기준 대칭 구간 토글
        toggle(n)
        l, r = n - 1, n + 1
        while l >= 1 and r <= N and arr[l] == arr[r]:
            toggle(l)
            toggle(r)
            l -= 1
            r += 1

# 20개씩 출력
for i in range(1, N + 1):
    print(arr[i], end=" ")
    if i % 20 == 0:
        print()
```
