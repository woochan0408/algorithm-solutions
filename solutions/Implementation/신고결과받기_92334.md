# 프로그래머스 92334 📩 신고 결과 받기 파이썬

## 느낀점
>
- 설명이 길어서 그렇지 어렵진 않았다.
- 뭔가 카카오 주니어 개발자가 된 느낌을 주는 문제다.

## 흐름

1. `id_dic`으로 유저 이름 → 인덱스 매핑
2. `report_dic`에 신고받은 사람을 key로, 신고한 사람들을 set으로 저장 (중복 자동 제거)
3. `report_count`로 각 유저가 신고당한 횟수 계산
4. k번 이상 신고된 유저를 찾고, 해당 유저를 신고한 사람들의 메일 수를 +1

## 코드

```python
from collections import defaultdict
def solution(id_list, report, k):
    N = len(id_list)
    report_dic = defaultdict(set)
    id_dic = {}
    report_count = [0]*N
    answer = [0]*N
    
    # id_dic 생성
    for i in range(len(id_list)):
        id_dic[id_list[i]] = i
    
    # report_set 생성
    for cur in report:
        a, b = cur.split()
        
        # b를 신고한 세트에 a이름 추가 (중복 방지)
        report_dic[b].add(a)
    
    # report_count 계산
    for key in report_dic:
        report_count[id_dic[key]] = len(report_dic[key])
    
    # answer 만들기
    for i in range(N):
        if(report_count[i] >= k):
            for cur in report_dic[id_list[i]]:
                answer[id_dic[cur]] += 1
    return answer
```

## AI 코드 리뷰

### 개선할 점

1. **`report_count` 배열 제거**: `report_count`는 `len(report_dic[key])`로 바로 비교할 수 있어서 별도 배열이 불필요하다. 배열을 만들고 → 다시 순회하는 이중 작업을 줄일 수 있다.

2. **`enumerate` 활용**: `id_dic` 생성 시 `for i in range(len(id_list))` 대신 `enumerate`를 쓰면 더 파이썬다운 코드가 된다.

3. **변수명 명확화**: `cur`가 report 순회와 신고자 순회에서 각각 다른 의미로 사용된다. `record`(신고 기록)와 `reporter`(신고자)로 구분하면 가독성이 올라간다.

## 수정된 코드

```python
from collections import defaultdict

def solution(id_list, report, k):
    reported_by = defaultdict(set)  # 신고받은 사람 → 신고한 사람들
    id_to_idx = {name: idx for idx, name in enumerate(id_list)}
    answer = [0] * len(id_list)

    # 신고 기록 정리 (set으로 중복 자동 제거)
    for record in report:
        reporter, target = record.split()
        reported_by[target].add(reporter)

    # k번 이상 신고된 유저 → 신고한 사람들에게 메일 +1
    for target, reporters in reported_by.items():
        if len(reporters) >= k:
            for reporter in reporters:
                answer[id_to_idx[reporter]] += 1

    return answer
```
