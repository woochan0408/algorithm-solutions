## 흐름
1. 격자판에서 `*`인 좌표를 모두 `target` 집합에 저장
2. 모든 칸을 순회하며, 각 칸에서 가능한 **최대 크기 십자가**를 탐색
3. 십자가가 성립하면 `result`에 추가하고, 해당 좌표들을 `visited` 집합에 추가
4. 최종적으로 `visited == target`이면 결과 출력, 아니면 `-1` 출력

## 질문 & 실수 정리

### 새로 배운 것

#### set의 재할당과 global
`set`은 mutable 객체라서 `.add()`, `.remove()` 같은 메서드로 내용을 변경할 때는 `global` 없이 가능하다. 하지만 `visited = visited | curVisited`처럼 `=` 연산자로 **재할당**하면 파이썬이 로컬 변수로 인식하기 때문에 반드시 `global` 선언이 필요하다.
- **핵심 원리**: `=`은 새 객체를 바인딩하는 것이므로 `global` 필요. 메서드 호출은 기존 객체를 수정하는 것이므로 불필요.

#### set 연산 정리
- **합집합**: `a | b` 또는 `a.union(b)` — 재할당 없이 하려면 `a.update(b)` (= `a |= b`)
- **교집합**: `a & b` 또는 `a.intersection(b)` — `a.intersection_update(b)` (= `a &= b`)
- **차집합**: `a - b` 또는 `a.difference(b)` — `a.difference_update(b)` (= `a -= b`)
- **대칭차집합**: `a ^ b` 또는 `a.symmetric_difference(b)` — `a.symmetric_difference_update(b)` (= `a ^= b`)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`makeCross`에서 파라미터 `n` 대신 전역변수 `N`(격자 행 수) 사용|`range(1, n+1)`로 전달받은 크기 파라미터 사용|
|`makeCross`가 절대 좌표를 반환하는데 `valid`에서 `dx, dy`로 받아 `x+dx, y+dy`로 이중 적용|반환값을 `nx, ny`로 받아 바로 사용|

## AI 코드 리뷰

### 개선할 점

1. **`visited.update()` 사용으로 `global` 제거**: `visited = visited | curVisited` 대신 `visited.update(curVisited)`를 쓰면 기존 set을 직접 수정하므로 `global` 선언이 불필요해진다.

2. **`all()` 활용으로 플래그 변수 제거**: `canIn` 플래그와 `for-else` 패턴 대신 `all()`을 사용하면 더 간결하고 파이썬다운 코드가 된다.

3. **변수명 개선**: `makeCross` → `get_cross_cells`, `canIn` → 제거, `curCase` → `cross_cells`, `curVisited` → 제거(바로 update), `maxLen` → `max_size`

4. **불필요한 범위 체크 제거**: `maxLen = min(N-1-x, x, M-1-y, y)`로 이미 범위를 보장하므로 내부의 `0 <= nx < N and 0 <= ny < M` 체크는 불필요하다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline


def get_cross_cells(x, y, size):
    cells = [(x, y)]
    for i in range(1, size + 1):
        cells.append((x + i, y))
        cells.append((x - i, y))
        cells.append((x, y + i))
        cells.append((x, y - i))
    return cells


def find_cross(x, y):
    max_size = min(N - 1 - x, x, M - 1 - y, y)
    for size in range(max_size, 0, -1):
        cross_cells = get_cross_cells(x, y, size)
        if all(grid[cx][cy] == '*' for cx, cy in cross_cells):
            result.append((x + 1, y + 1, size))
            visited.update(cross_cells)
            return


N, M = map(int, input().split())
grid = []
result = []
visited = set()
target = set()

for i in range(N):
    grid.append(list(input().strip()))
    for j in range(M):
        if grid[i][j] == '*':
            target.add((i, j))

for i in range(N):
    for j in range(M):
        find_cross(i, j)

if visited != target:
    print(-1)
else:
    print(len(result))
    for x, y, size in result:
        print(x, y, size)
```
