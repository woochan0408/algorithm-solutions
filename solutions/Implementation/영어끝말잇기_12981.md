# 프로그래머스 12981 🔤 영어 끝말잇기 파이썬

## 느낀점
>
- 잘 풀었다.

## 흐름

1. set으로 이미 등장한 단어를 관리
2. `before`를 첫 단어의 첫 글자로 초기화해서 첫 번째 단어도 루프 안에서 자연스럽게 처리
3. 각 단어마다 중복 여부(`cur in s`)와 끝말잇기 규칙(`before[-1] != cur[0]`) 검사
4. 탈락 조건 발견 시 `i % n + 1`(번호), `i // n + 1`(차례) 계산 후 즉시 반환
5. 끝까지 탈락자가 없으면 `[0, 0]` 반환

## 코드
```python
def solution(n, words):
    answer = []
    
    s = set()
    before = words[0][0]
    
    for i in range(len(words)):
        cur = words[i]
        
        if(cur in s or before[-1] != cur[0]):
            return [(i%n) + 1, (i//n) + 1]
        s.add(cur)
        before = cur
    return [0, 0]
```

### 개선할 점

1. **미사용 변수 제거**: `answer = []`를 선언했지만 한 번도 사용하지 않았다. 불필요한 코드는 제거하는 것이 좋다.

2. **변수명 개선**: `before`보다 `prev`가 "이전 단어"라는 의미를 더 직관적으로 전달한다. `s`도 `seen`으로 바꾸면 역할이 명확해진다.

3. **enumerate 활용**: `for i in range(len(words))`보다 `for i, cur in enumerate(words)`가 더 파이썬다운 순회 방식이다. 별도의 `cur = words[i]` 라인도 제거된다.

## 수정된 코드
```python
def solution(n, words):
    seen = set()
    prev = words[0][0]
    
    for i, cur in enumerate(words):
        if cur in seen or prev[-1] != cur[0]:
            return [i % n + 1, i // n + 1]
        seen.add(cur)
        prev = cur
    
    return [0, 0]
```
