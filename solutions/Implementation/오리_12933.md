## 흐름

1. 각 문자를 순회하며 오리의 울음 상태를 추적
2. `left`: 현재 쉬고 있는 (quack 완성한) 오리 수
3. `count[0~3]`: q, u, a, c까지 진행 중인 오리 수
4. `q`를 만나면: 쉬는 오리가 있으면 재활용, 없으면 새 오리 추가
5. `u, a, c, k`를 만나면: 이전 단계 오리가 있어야 함 (없으면 -1)
6. `k`를 만나면: 오리 한 사이클 완성 → left에 복귀
7. 순회 종료 후 진행 중인 오리가 남아있으면 -1

## 코드
```python
from collections import deque, defaultdict
import sys
input = sys.stdin.readline
string = input().strip()
dic = {'q':0, 'u':1, 'a':2, 'c':3, 'k':4}
# left는 놀고먹는 오리 수
left = 0
# 각각 q, u, a, c로 끝난 오리 수
# k로 끝난 경우는 의미 없음 (이미 오리 완성)
count = [0, 0, 0, 0]
answer = 0
for c in string:
    cur = dic[c]
    if(cur == 0):
        # 놀고먹는 오리 부족하면 한 마리 추가
        if(left == 0):
            answer += 1
            left += 1
            
        count[cur] += 1
        left -= 1
        
        
    # 이전 울음소리를 가지고 있는 경우
    elif(count[cur-1] > 0):
        #k로 끝나서 한 오리가 완성된 경우
        if(cur == 4):
            # 놀고먹는 오리 추가
            left += 1
            count[cur-1] -= 1
        else:
            count[cur] += 1
            count[cur-1] -= 1
    # 해당 안하는 경우
    else:
        answer = -1
        break
for c in count:
    if(c != 0):
        answer = -1
        break
print(answer)
```

## AI 코드 리뷰

### 개선할 점

1. **불필요한 import 제거**: `deque`, `defaultdict`를 import했지만 실제로 사용하지 않음. 불필요한 import는 코드 가독성을 떨어뜨림
2. **변수명 개선**: `left`보다 `idle`이 "쉬고 있는 오리"라는 의미를 더 명확히 전달. `dic`보다 `QUACK_IDX`가 역할을 드러냄. `count`보다 `progress`가 "진행 중인 상태"를 나타냄
3. **매직 넘버 제거**: `cur == 0`, `cur == 4` 같은 숫자 대신 의미 있는 비교 사용
4. **count 초기화 간소화**: `[0, 0, 0, 0]` → `[0] * 4`
5. **검증 로직 간소화**: `for + break` 대신 `any()` 활용

## 수정된 코드
```python
import sys
input = sys.stdin.readline

string = input().strip()
QUACK = "quack"
QUACK_IDX = {c: i for i, c in enumerate(QUACK)}

idle = 0          # 쉬고 있는 오리 수
progress = [0] * 4  # q, u, a, c 단계별 진행 중인 오리 수
answer = 0

for c in string:
    cur = QUACK_IDX[c]

    if cur == 0:
        if idle == 0:
            answer += 1
            idle += 1
        progress[0] += 1
        idle -= 1

    elif progress[cur - 1] > 0:
        progress[cur - 1] -= 1
        if cur == 4:
            idle += 1
        else:
            progress[cur] += 1
    else:
        answer = -1
        break

if any(progress):
    answer = -1

print(answer)
```
