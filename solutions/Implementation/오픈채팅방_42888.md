# 프로그래머스 42888 💬 오픈채팅방 파이썬

## 느낀점
>
- 잘 풀었다.
- 어렵지 않은 문제

## 흐름

1. 딕셔너리(`dic`)에 유저 ID → 닉네임 매핑을 관리
2. record를 순회하며 Enter/Change 시 닉네임을 갱신하고, Enter/Leave 시 `(행동, uid)` 튜플을 result에 저장
3. 모든 record 처리 후, result를 순회하며 최종 닉네임으로 메시지를 생성

## 코드
```python
def solution(record):
    dic = {}
    result = []
    answer = []
    for cur in record:
        req = list(cur.split())
        if(req[0] == 'Enter'):
            dic[req[1]] = req[2]
            result.append((req[0], req[1]))
        
        elif req[0] == 'Leave':
            result.append((req[0], req[1]))
        else:
            dic[req[1]] = req[2]
            
    for req in result:
        if(req[0] == 'Enter'):
            answer.append(dic[req[1]] + '님이 들어왔습니다.')
        else:
            answer.append(dic[req[1]] + '님이 나갔습니다.')
    
    return answer
```

## AI 코드 리뷰

### 개선할 점

1. **`list()` 제거**: `str.split()`은 이미 리스트를 반환하므로 `list()`로 감싸는 것은 불필요한 연산이다.

2. **변수명 개선**: `dic`, `req`, `result` 등의 변수명이 역할을 명확히 드러내지 않는다. `nicknames`, `parts`, `logs` 등으로 변경하면 코드만 보고도 의미를 파악할 수 있다.

3. **f-string 활용**: 문자열 연결(`+`)보다 f-string을 사용하면 가독성이 향상된다.

4. **메시지 매핑 딕셔너리**: Enter/Leave에 따른 메시지를 딕셔너리로 관리하면 if-else 분기를 줄일 수 있다.

## 수정된 코드
```python
def solution(record):
    nicknames = {}
    logs = []
    messages = {"Enter": "님이 들어왔습니다.", "Leave": "님이 나갔습니다."}

    for line in record:
        parts = line.split()
        action, uid = parts[0], parts[1]

        if action in ("Enter", "Change"):
            nicknames[uid] = parts[2]

        if action != "Change":
            logs.append((action, uid))

    return [f"{nicknames[uid]}{messages[action]}" for action, uid in logs]
```
