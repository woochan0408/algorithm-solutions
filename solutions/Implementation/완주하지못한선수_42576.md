## 흐름

1. 완주자 명단을 딕셔너리로 카운팅
2. 참가자를 순회하면서 완주자에 있으면 카운트 감소
3. 카운트가 0이거나 없으면 해당 참가자가 완주 못한 사람

## 코드
```python
from collections import defaultdict
def solution(participant, completion):
    answer = ""
    wan = defaultdict(int) 
    for m in completion:
        wan[m] += 1
    print(wan)
    
    for m in participant:
        print("m",m)
        if(m in wan and wan[m] > 0):
            wan[m] -= 1
        else:
            answer = m
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### Counter 뺄셈 연산
`Counter` 객체끼리 빼기 연산이 가능하다. 같은 키의 값을 빼고, 결과가 0 이하인 항목은 자동으로 제거된다.
- **핵심 원리**: `Counter(A) - Counter(B)`는 A에만 있거나 A가 더 많은 항목만 남김
- **시간복잡도**: O(n)

## AI 코드 리뷰

### 개선할 점

1. **디버깅 코드 제거**: print문은 제출 전 삭제
2. **불필요한 조건 제거**: defaultdict(int)는 없는 키에 0 반환하므로 `in` 체크 불필요
3. **변수명 개선**: `wan` → `count` 또는 `completion_count`로 의도 명확히

## 수정된 코드
```python
from collections import Counter

def solution(participant, completion):
    return list(Counter(participant) - Counter(completion))[0]
```
