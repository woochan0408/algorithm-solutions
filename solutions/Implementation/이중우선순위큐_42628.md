## 느낀점
>
- 잘 풀어놓고 딕셔너리 key순 정렬을 안 해서 틀렸다.
- 다음부터 이런 실수 하지 말자
(딕셔너리 key 순서는 삽입순서)

## 흐름

1. 최대힙(`maxh`)과 최소힙(`minh`) 두 개를 동시에 운영
2. `Counter`로 각 값의 유효 개수를 관리 (lazy deletion)
3. `I` 명령: 양쪽 힙에 모두 push + Counter 증가
4. `D 1` (최댓값 삭제): maxh에서 pop하면서 Counter에 없는 값은 건너뜀
5. `D -1` (최솟값 삭제): minh에서 pop하면서 Counter에 없는 값은 건너뜀
6. 모든 연산 후 Counter에 남은 키들을 정렬해서 최댓값/최솟값 반환

## 코드

```python
from collections import defaultdict, Counter
import heapq
def solution(operations):
    maxh = []
    minh = []
    counter = Counter()
    
    for req in operations:
        r, n = req.split()
        n = int(n)
        if(r == 'I'):
            heapq.heappush(maxh, -n)
            heapq.heappush(minh, n)
            counter.update([n])
        elif(r == 'D' and n == -1):
            while minh:
                cur = heapq.heappop(minh)
                if(cur in counter):
                    counter[cur] -= 1
                    if(counter[cur] == 0):
                        del counter[cur]
                    break
                        
        elif(r == 'D' and n == 1):
            while maxh:
                cur = -heapq.heappop(maxh)
                if(cur in counter):
                    counter[cur] -= 1
                    if(counter[cur] == 0):
                        del counter[cur]
                    break
    
    lst = list(counter.keys())
    lst.sort()
    if(lst):
        answer = [lst[-1], lst[0]]
    else:
        answer = [0, 0]
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### Lazy Deletion (지연 삭제)
두 개의 힙을 동시에 사용할 때, 한쪽 힙에서 삭제한 원소를 다른 쪽 힙에서 즉시 제거하기 어렵다. 이때 실제로 삭제하지 않고 "유효한지" 여부만 별도로 관리하다가, 나중에 해당 원소를 만났을 때 건너뛰는 방식이 lazy deletion이다. Counter나 딕셔너리로 유효 카운트를 관리하면 O(1)에 유효성을 판단할 수 있다.
- **핵심 원리**: 삭제 표시만 해두고, 실제 pop 시점에 유효하지 않은 원소를 스킵
- **시간복잡도**: 각 원소는 최대 한 번씩만 실제로 pop되므로 전체 O(N log N)

#### dict.keys()는 삽입 순서
Python 3.7+에서 `dict.keys()`는 삽입 순서를 유지하지, 정렬된 순서가 아니다. Counter도 dict 기반이므로 동일하다. 최댓값/최솟값을 구하려면 반드시 `sort()`, `max()`, `min()` 등을 사용해야 한다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`counter.keys()`가 정렬되어 있다고 가정|`list(counter.keys())`를 `sort()` 후 사용|

## AI 코드 리뷰

### 개선할 점

1. **`counter.update([n])` → `counter[n] += 1`**: `update`는 iterable을 받아 처리하므로, 단일 값 증가에는 `+= 1`이 의도가 더 명확하다.

2. **`defaultdict` 미사용 import 제거**: `defaultdict`를 import하지만 사용하지 않는다.

3. **최종 결과에서 정렬 대신 `max()`/`min()` 사용**: 리스트 전체를 정렬(O(K log K))하는 대신 `max(counter)`와 `min(counter)`로 O(K)에 구할 수 있다.

## 수정된 코드

```python
from collections import Counter
import heapq

def solution(operations):
    maxh = []
    minh = []
    counter = Counter()
    
    for req in operations:
        r, n = req.split()
        n = int(n)
        
        if r == 'I':
            heapq.heappush(maxh, -n)
            heapq.heappush(minh, n)
            counter[n] += 1
        elif r == 'D' and n == -1:
            while minh:
                cur = heapq.heappop(minh)
                if cur in counter:
                    counter[cur] -= 1
                    if counter[cur] == 0:
                        del counter[cur]
                    break
        elif r == 'D' and n == 1:
            while maxh:
                cur = -heapq.heappop(maxh)
                if cur in counter:
                    counter[cur] -= 1
                    if counter[cur] == 0:
                        del counter[cur]
                    break
    
    if counter:
        return [max(counter), min(counter)]
    return [0, 0]
```
