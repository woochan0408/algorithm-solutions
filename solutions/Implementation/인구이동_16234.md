# 백준 16234 🌍 인구 이동 파이썬

## 느낀점
>
- 잘 풀었다.
- 파이썬 변수 스코프가 갑자기 헷갈려서 한번 정리했다.

## 흐름

1. N×N 격자에서 인접한 나라 간 인구 차이가 L 이상 R 이하이면 국경선을 열어 연합을 형성한다.
2. BFS로 연합을 탐색하고, 연합 내 인구를 평균으로 갱신한다.
3. 모든 칸에 대해 BFS를 수행한 뒤, 연합이 하나도 형성되지 않았으면(모든 칸이 독립) 종료한다.
4. 인구 이동이 발생한 횟수(일 수)를 출력한다.

## 코드
```python
import sys
input = sys.stdin.readline
from collections import deque
N, L, R = map(int, input().split())
move = [[-1, 0], [1, 0], [0, -1], [0, 1]]
arr = []
for i in range(N):
    arr.append(list(map(int, input().split())))
level = 0
while True:
    area = 0
    visited = [[False]*N for i in range(N)]
    def bfs(i, j):
        dq = deque([(i, j)])
        visited[i][j] = True
        updated = [(i, j)]
        hap = arr[i][j]
        while dq:
            x, y = dq.popleft()
            for dx, dy in move:
                nx = x + dx
                ny = y + dy
                if not (0 <= nx < N and 0 <= ny < N):
                    continue
                if(visited[nx][ny]):
                    continue
                if not (L <= abs(arr[x][y] - arr[nx][ny]) <= R):
                    continue
                dq.append((nx, ny))
                visited[nx][ny] = True
                updated.append((nx, ny))
                hap += arr[nx][ny]
        hap = hap // len(updated)
        for x, y in updated:
            arr[x][y] = hap
            
    
    for i in range(N):
        for j in range(N):
            if(not visited[i][j]):
                area += 1
                bfs(i, j)
    if(area == N**2):
        break
    level += 1
print(level)
```

## 질문 & 실수 정리

### 새로 배운 것

#### Python 변수 스코프 (LEGB)
함수에서 변수를 찾을 때 **호출 위치가 아니라 정의 위치** 기준으로 Local → Enclosing → Global → Built-in 순서로 탐색한다. A가 B를 호출해도 B는 A의 지역 변수를 볼 수 없고, B가 A **안에 정의**되어 있어야만 Enclosing 스코프로 접근 가능하다.
- **핵심 원리**: mutable(list, dict)은 내부 수정(인덱싱, 메서드)이 `global` 없이 가능하지만, immutable(int, str)은 재대입이므로 `global`/`nonlocal` 선언 필수

## AI 코드 리뷰

### 개선할 점

1. **`bfs` 함수 위치**: `while` 루프 내부에서 매 반복마다 함수를 재정의하고 있다. 함수를 바깥으로 빼고 `arr`, `visited`, `N`, `L`, `R`을 인자로 전달하면 불필요한 재정의를 방지할 수 있다.

2. **변수명 개선**: `area`는 연합 개수를 세는 변수인데 면적으로 오해할 수 있다. `union_count`가 더 명확하다. `hap` → `pop_sum`, `updated` → `union_cells`로 변경하면 가독성이 좋아진다.

3. **방향 상수 네이밍**: `move`는 상수이므로 `DIRECTIONS`로 대문자 네이밍하고, 내부 요소도 튜플로 바꾸면 의도가 명확해진다.

4. **종료 조건 개선**: `area == N**2` 대신 `moved` 플래그로 "연합이 생겼는지"를 직접 추적하면 의미가 더 직관적이다.

5. **입력 처리 간소화**: `for` + `append` 대신 리스트 컴프리헨션으로 `arr`를 한 줄로 초기화할 수 있다.

## 수정된 코드
```python
import sys
from collections import deque

input = sys.stdin.readline

DIRECTIONS = ((-1, 0), (1, 0), (0, -1), (0, 1))

def bfs(arr, visited, si, sj, N, L, R):
    dq = deque([(si, sj)])
    visited[si][sj] = True
    union_cells = [(si, sj)]
    pop_sum = arr[si][sj]

    while dq:
        x, y = dq.popleft()
        for dx, dy in DIRECTIONS:
            nx, ny = x + dx, y + dy
            if not (0 <= nx < N and 0 <= ny < N):
                continue
            if visited[nx][ny]:
                continue
            if not (L <= abs(arr[x][y] - arr[nx][ny]) <= R):
                continue
            dq.append((nx, ny))
            visited[nx][ny] = True
            union_cells.append((nx, ny))
            pop_sum += arr[nx][ny]

    avg = pop_sum // len(union_cells)
    for x, y in union_cells:
        arr[x][y] = avg

    return len(union_cells) > 1


N, L, R = map(int, input().split())
arr = [list(map(int, input().split())) for _ in range(N)]

days = 0
while True:
    visited = [[False] * N for _ in range(N)]
    moved = False

    for i in range(N):
        for j in range(N):
            if not visited[i][j]:
                if bfs(arr, visited, i, j, N, L, R):
                    moved = True

    if not moved:
        break
    days += 1

print(days)
```
