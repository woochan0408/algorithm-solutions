## 흐름

1. 딕셔너리와 힙큐를 사용하여 고릴라별 정보 관리
2. 쿼리 1: 고릴라가 정보를 얻으면 최대 힙에 저장 (음수로 저장)
3. 쿼리 2: 고릴라에게서 가장 비싼 정보부터 구매
4. 정보를 구매하면 힙에서 제거

## 코드

```python
"""
7
1 Cpp 5 10 4 2 8 4
1 Java 2 8 2
2 Cpp 2
1 Cpp 2 10 3
2 Cpp 3
2 Java 1
2 Python 10
dic + heapq
정보 쓰면 제거
"""
import heapq, sys
from collections import defaultdict
input = sys.stdin.readline
N = int(input())
dic = defaultdict(list)
result = 0
for _ in range(N):
    cur = list(input().strip().split())
    q = int(cur[0])
    key = cur[1]
    if(q == 1):
        arr = list(map(int, cur[3:]))
        for c in arr:
            heapq.heappush(dic[key], -c)
    elif(q == 2):
        i = 0
        while dic[key] and i < int(cur[2]):
            result -= heapq.heappop(dic[key])
            i += 1
print(result)
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 명확화**: `dic`, `q`, `key`, `c` 등이 너무 축약되어 가독성이 떨어짐

2. **반복되는 접근 최적화**: `int(cur[2])`를 while 조건에서 매번 계산하므로 변수로 분리

3. **반복문 간결화**: while문 대신 for문으로 더 명확하게 표현 가능

4. **조건문 개선**: 쿼리는 1 또는 2만 오므로 `elif` 대신 `else` 사용 가능

## 수정된 코드

```python
import heapq
import sys
from collections import defaultdict

input = sys.stdin.readline

Q = int(input())
gorilla_info = defaultdict(list)  # 고릴라별 정보 저장 (최대 힙)
total_value = 0

for _ in range(Q):
    query = input().strip().split()
    query_type = int(query[0])
    name = query[1]
    
    if query_type == 1:
        # 고릴라가 정보 획득
        values = list(map(int, query[3:]))
        for value in values:
            heapq.heappush(gorilla_info[name], -value)  # 최대 힙 구현
    else:
        # 호석이가 정보 구매
        buy_count = int(query[2])
        for _ in range(min(buy_count, len(gorilla_info[name]))):
            total_value -= heapq.heappop(gorilla_info[name])

print(total_value)
```
