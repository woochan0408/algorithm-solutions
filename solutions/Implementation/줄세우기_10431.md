# 백준 10431 🧍 줄세우기 파이썬

## 느낀점
>
- 슬라이싱 범위 (-1)  조심하기
- insert 구문 이해하고 활용하기

## 흐름

1. 학생들이 순서대로 줄 맨 뒤에 선다
2. 자기보다 키가 큰 학생 중 가장 앞에 있는 학생을 찾는다
3. 그 학생 앞에 끼어들고, 뒤의 학생들이 한 발씩 물러선다
4. 총 물러선 횟수를 누적하여 출력

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
for _ in range(N):
    arr = list(map(int, input().split()))
    caseNum = arr[0]
    arr = arr[1:]
    i = 0
    result = 0
    while i < 20:
        sub = arr[0:i]
        for j in range(len(sub)):
            if(sub[j] > arr[i]):
                arr = arr[0:j] + [arr[i]] + arr[j:i] + arr[i+1:]
                result += i - j
                break
        i += 1
    print(caseNum, result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### list.insert(i, x)
리스트의 특정 위치에 값을 삽입하는 메서드. 인덱스 i 위치에 x를 넣고, 기존 i번 이후의 요소들은 자동으로 한 칸씩 뒤로 밀린다.
- **핵심 원리**: `arr.insert(j, val)` → j번 위치에 val 삽입, j~끝 요소들이 뒤로 이동
- **시간복잡도**: O(n)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `break`가 `if`문 밖에 위치 | `if`문 안에 들여쓰기 |
| `arr[0:i-1]` (i번째 앞 학생 누락) | `arr[0:i]` |
| `range(1, len(sub))` (0번 인덱스 건너뜀) | `range(len(sub))` |
| `arr[0:j-1]` (j=0일 때 `arr[0:-1]`) | `arr[0:j]` |
| `arr[j:i-1]` (i-1번 학생 누락) | `arr[j:i]` |

## AI 코드 리뷰

### 개선할 점

1. **변수명**: `sub`보다 `line`이나 `queue`가 의미를 더 잘 전달합니다.

2. **불필요한 변수**: `sub = arr[0:i]`를 만들지 않고 `arr`를 직접 순회해도 됩니다.

3. **while → for**: 인덱스를 수동으로 증가시키는 대신 `for i in range(20)`이 더 깔끔합니다.

4. **insert() 활용**: 슬라이싱으로 배열을 재구성하는 대신 `insert()`와 `pop()`을 사용하면 더 직관적입니다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

n = int(input())
for _ in range(n):
    data = list(map(int, input().split()))
    case_num = data[0]
    heights = data[1:]
    
    line = []
    result = 0
    
    for height in heights:
        inserted = False
        for j in range(len(line)):
            if line[j] > height:
                line.insert(j, height)
                result += len(line) - 1 - j
                inserted = True
                break
        
        if not inserted:
            line.append(height)
    
    print(case_num, result)
```
