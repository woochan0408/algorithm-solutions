# 백준 2304 🏭 창고 다각형 파이썬

## 느낀점
>
- 제한시간 보고 어렵게 풀 필요 없으면 복잡하게 풀지 말자.
- 이 문제도 굳이 최적화 없이 각 칸마다 계산하면 됐는데 더 어렵게 풀었다.

## 흐름

1. 기둥들을 위치 기준으로 정렬
2. 가장 높은 기둥의 높이와 해당 기둥들의 좌우 경계 인덱스 찾기
3. 왼쪽 끝에서 최대 높이 구간까지: 높이가 증가할 때마다 직전 높이로 면적 누적
4. 오른쪽 끝에서 최대 높이 구간까지: 동일하게 처리
5. 최대 높이 구간의 면적을 더해서 출력

## 코드

```python
import sys
input = sys.stdin.readline
arr = []
N = int(input())
for _ in range(N):
    L, H = map(int, input().split())
    arr.append((L, H))
arr.sort()
# 1. 최고 높이(maxH)와 그 높이가 나타나는 첫 위치(maxIdx), 마지막 위치(maxIdxR) 찾기
maxH = -1
for i in range(N):
    if arr[i][1] > maxH:
        maxH = arr[i][1]
# 가장 왼쪽의 maxH 인덱스
maxIdx = -1
for i in range(N):
    if arr[i][1] == maxH:
        maxIdx = i
        break
maxL = arr[maxIdx][0]
# maxR을 찾자. (가장 오른쪽의 maxH를 찾아야 함)
maxIdxR = -1
for i in range(N-1, -1, -1):
    if arr[i][1] == maxH:
        maxIdxR = i
        break
maxR = arr[maxIdxR][0] + 1
result = 0
# 왼쪽에서부터 maxIdx까지 (기존 로직 유지)
l = arr[0][0]
h = arr[0][1]
for i in range(1, maxIdx + 1): # maxIdx까지 검사
    curL = arr[i][0]
    curH = arr[i][1]
    if(curH > h):
        result += h * (curL - l)
        l = curL
        h = curH
# 오른쪽에서부터 maxIdxR까지 (기존 로직 유지)
r = arr[-1][0] + 1
h = arr[-1][1]
for i in range(N-2, maxIdxR - 1, -1): # maxIdxR까지 거꾸로 검사
    curR = arr[i][0] + 1
    curH = arr[i][1]
    if(curH > h):
        result += h * (r - curR)
        r = curR
        h = curH
# 마지막으로 가장 높은 구간(maxL ~ maxR) 더해주기
print(result + (maxR - maxL) * maxH)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 양방향 스위핑
한 방향으로만 처리하기 어려운 문제에서 왼쪽→오른쪽, 오른쪽→왼쪽 두 번 순회하여 각각의 결과를 합치는 기법이다. 이 문제에서는 가장 높은 기둥을 기준으로 좌우를 분리하여, 각 방향에서 "현재까지의 최대 높이"를 유지하며 면적을 계산했다.
- **핵심 원리**: 기준점(최대 높이 구간)을 중심으로 좌우 독립적으로 처리
- **시간복잡도**: O(N)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `while True`로 maxR 탐색 → 인덱스 초과 가능 | `while i < N` 조건 추가 |
| maxH 도달 시 별도 계산 후 break | 루프 범위를 `maxIdx`, `maxIdxR`까지로 제한하여 일반 로직으로 통일 |

## AI 코드 리뷰

### 개선할 점

1. **maxH 탐색 루프 통합**: maxH를 찾고, maxIdx를 찾고, maxIdxR을 찾는 루프가 3개로 분리되어 있다. 한 번의 순회 또는 `max()`, `next()` 활용으로 간결하게 작성 가능하다.

2. **변수명 명확화**: `l`, `h`, `r`은 짧지만 의미 파악이 어렵다. `left`, `height`, `right` 정도로 써도 충분히 간결하다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
pillars = []
for _ in range(N):
    L, H = map(int, input().split())
    pillars.append((L, H))
pillars.sort()

# 최대 높이와 해당 구간 찾기
max_height = max(p[1] for p in pillars)
max_left_idx = next(i for i in range(N) if pillars[i][1] == max_height)
max_right_idx = next(i for i in range(N - 1, -1, -1) if pillars[i][1] == max_height)

max_left = pillars[max_left_idx][0]
max_right = pillars[max_right_idx][0] + 1

result = 0

# 왼쪽에서 최대 높이 구간까지
left = pillars[0][0]
height = pillars[0][1]
for i in range(1, max_left_idx + 1):
    cur_left, cur_height = pillars[i]
    if cur_height > height:
        result += height * (cur_left - left)
        left = cur_left
        height = cur_height

# 오른쪽에서 최대 높이 구간까지
right = pillars[-1][0] + 1
height = pillars[-1][1]
for i in range(N - 2, max_right_idx - 1, -1):
    cur_right = pillars[i][0] + 1
    cur_height = pillars[i][1]
    if cur_height > height:
        result += height * (right - cur_right)
        right = cur_right
        height = cur_height

# 최대 높이 구간 더하기
result += (max_right - max_left) * max_height
print(result)
```
