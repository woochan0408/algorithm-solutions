## 느낀점
>
- Combination 새 개념 배웠다.
- 브루트포스로 풀었지만 더 좋은 방법이 있다
(AI 코드리뷰 참고)


## 흐름

1. 입력받으면서 집 좌표와 치킨집 좌표를 각각 리스트에 저장
2. 치킨집 중 M개를 선택하는 모든 조합을 생성 (combinations)
3. 각 조합에 대해:
   - 모든 집을 순회하며, 선택된 치킨집 중 가장 가까운 거리(치킨 거리) 계산
   - 모든 집의 치킨 거리를 합산 (도시의 치킨 거리)
4. 모든 조합 중 도시의 치킨 거리가 최소인 값 출력

## 코드

```python
import sys
from itertools import combinations
input = sys.stdin.readline
N, M = map(int, input().split())
grid = []
house = []
chick = []
for i in range(N):
    arr = list(map(int, input().split()))
    grid.append(arr)
    
    for j in range(N):
        if(grid[i][j] == 1):
            house.append((i, j))
        elif(grid[i][j] == 2):
            chick.append((i, j))
def chickLen(cx, cy, hx, hy):
    return abs(cx - hx) + abs(cy - hy)
# 각 컴비네이션별 도시 치킨거리
result = []
for comb in combinations(chick, M):
    # 각 집별 치킨거리
    dosiChick = []
    for hx, hy in house:
        # 모든 치킨집과의 거리
        houseChick = []
        for cx, cy in comb:
            houseChick.append(chickLen(cx, cy, hx, hy))
        dosiChick.append(min(houseChick))
    result.append(sum(dosiChick))
# 그중 최소 result
print(min(result))
```

## 질문 & 실수 정리

### 새로 배운 것

#### itertools.combinations
n개 중 r개를 순서 없이 선택하는 모든 경우를 생성해주는 함수. 브루트포스에서 "선택" 문제를 풀 때 비트마스킹 대신 간편하게 사용할 수 있다.
- **핵심 원리**: `combinations(iterable, r)` → r개짜리 튜플들을 순회
- **시간복잡도**: O(nCr)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 치킨집 기준으로 순회하며 거리 계산 | 집 기준으로 순회하며 가장 가까운 치킨집 거리 계산 |
| "도시의 치킨 거리"를 최솟값으로 이해 | 모든 집의 치킨 거리 **합** |

## AI 코드 리뷰

### 개선할 점

1. **불필요한 변수 `grid`**: 집과 치킨집 좌표만 필요한데, `grid` 전체를 저장하고 있다. 입력받으면서 바로 좌표만 추출하면 된다.

2. **변수명 개선**: `dosiChick`, `houseChick`, `chickLen` 등이 의미를 명확히 전달하지 못한다. 영어로 통일하거나 더 명확한 이름이 좋다.

3. **메모리 최적화**: `result` 리스트에 모든 값을 저장 후 `min()`을 찾는 대신, 변수 하나로 최솟값을 갱신하면 메모리를 절약할 수 있다.

4. **거리 계산 간소화**: 별도 함수 대신 인라인으로 계산해도 충분히 가독성이 좋다.

## 수정된 코드

```python
import sys
from itertools import combinations
input = sys.stdin.readline

N, M = map(int, input().split())
houses = []
chickens = []

for i in range(N):
    row = list(map(int, input().split()))
    for j in range(N):
        if row[j] == 1:
            houses.append((i, j))
        elif row[j] == 2:
            chickens.append((i, j))

min_city_dist = float('inf')

for selected in combinations(chickens, M):
    city_dist = 0
    for hx, hy in houses:
        chicken_dist = min(abs(hx - cx) + abs(hy - cy) for cx, cy in selected)
        city_dist += chicken_dist
    min_city_dist = min(min_city_dist, city_dist)

print(min_city_dist)
```
