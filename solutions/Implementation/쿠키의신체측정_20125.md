# 백준 20125 🍪 쿠키의 신체 측정 파이썬

## 느낀점
>
- 구현이 내 약점
- 이중for문 break조심
- 문제 꼼꼼히 읽자

## 흐름

1. 격자를 위에서부터 탐색하여 첫 번째 `*`(머리) 찾기
2. 머리 바로 아래가 심장 (문제에서 머리는 1칸이라고 명시)
3. 심장 기준 왼쪽/오른쪽으로 팔 길이 계산
4. 심장 아래로 허리 길이 계산하며 허리 끝 위치 저장
5. 허리 끝 기준 왼쪽 아래/오른쪽 아래로 다리 길이 계산

## 코드
```python
import sys
input = sys.stdin.readline
N = int(input())
grid = []
for _ in range(N):
    string = input().strip()
    grid.append([])
    for i in range(N):
        if string[i] == '*':
            grid[-1].append(1)
        else:
            grid[-1].append(0)

# 머리찾기
headX = -1
headY = -1
breaked = False
for i in range(N):
    for j in range(N):
        if grid[i][j] == 1:
            headX = i
            headY = j
            breaked = True
            break
    if breaked:
        break

# 머리는 1칸이므로 심장은 바로 아래
heartX = headX + 1
heartY = headY

# 왼쪽 팔
larmLen = 0
y = heartY - 1
while y >= 0 and grid[heartX][y] == 1:
    larmLen += 1
    y -= 1

# 오른쪽 팔
rarmLen = 0
y = heartY + 1
while y < N and grid[heartX][y] == 1:
    rarmLen += 1
    y += 1

# 허리 길이 및 낭심 찾기
waistLen = 0
x = heartX + 1
while x < N and grid[x][heartY] == 1:
    waistLen += 1
    x += 1
nangX = x - 1
nangY = heartY

# 왼다리
llegLen = 0
x = nangX + 1
y = nangY - 1
while x < N and grid[x][y] == 1:
    llegLen += 1
    x += 1

# 오른다리
rlegLen = 0
x = nangX + 1
y = nangY + 1
while x < N and grid[x][y] == 1:
    rlegLen += 1
    x += 1

print(heartX + 1, heartY + 1)
print(larmLen, rarmLen, waistLen, llegLen, rlegLen)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 중첩 반복문 탈출
파이썬에서 `break`는 가장 안쪽 반복문만 탈출한다. 바깥 반복문까지 탈출하려면 플래그 변수를 사용하거나, 함수로 분리해서 `return`하는 방법이 있다.
- **핵심 원리**: `break`의 스코프는 직접 감싸는 반복문 하나뿐
- **대안**: 플래그 변수, 함수 분리 후 return, 예외 처리

#### 변수 스코프 주의
여러 while 루프를 연속으로 사용할 때, 이전 루프에서 설정된 `nx`, `ny` 같은 변수가 다음 루프에서 의도치 않게 사용될 수 있다. 각 루프에서 어떤 변수를 기준으로 탐색하는지 명확히 해야 한다.
- **핵심 원리**: 파이썬은 블록 스코프가 없어 루프 변수가 루프 종료 후에도 유지됨

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `break` 하나로 이중 for문 탈출 시도 | 플래그 변수로 바깥 루프도 탈출 |
| `neartY = ny` (오타) | `heartY = ny` |
| 팔 탐색에서 `grid[nx][ny]` 사용 | `grid[heartX][ny]` (심장 행 기준) |
| 낭심 탐색에서 `ny` 사용 | `y` 사용 (현재 루프 변수) |
| 범위 체크 `0 <= nx+1 < N` | `0 <= nx < N` (실제 접근하는 인덱스) |
| 머리 길이 계산 로직 작성 | 문제에서 머리는 1칸이라고 명시됨 |

## AI 코드 리뷰

### 개선할 점

1. **grid 변환 불필요**: 문자열을 0/1 리스트로 변환하지 않고 `'*'`와 직접 비교해도 된다. 메모리와 코드 양이 줄어든다.

2. **breaked 플래그 제거**: 함수로 분리하면 `return`으로 깔끔하게 탈출할 수 있다.

3. **변수명 명확화**: `larmLen` → `left_arm` 처럼 축약을 줄이면 가독성이 좋아진다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

def find_head(grid, n):
    for i in range(n):
        for j in range(n):
            if grid[i][j] == '*':
                return i, j
    return -1, -1

n = int(input())
grid = [input().strip() for _ in range(n)]

head_x, head_y = find_head(grid, n)

heart_x = head_x + 1
heart_y = head_y

# 왼쪽 팔
left_arm = 0
y = heart_y - 1
while y >= 0 and grid[heart_x][y] == '*':
    left_arm += 1
    y -= 1

# 오른쪽 팔
right_arm = 0
y = heart_y + 1
while y < n and grid[heart_x][y] == '*':
    right_arm += 1
    y += 1

# 허리
waist = 0
x = heart_x + 1
while x < n and grid[x][heart_y] == '*':
    waist += 1
    x += 1
waist_end_x = x - 1

# 왼쪽 다리
left_leg = 0
x = waist_end_x + 1
y = heart_y - 1
while x < n and grid[x][y] == '*':
    left_leg += 1
    x += 1

# 오른쪽 다리
right_leg = 0
x = waist_end_x + 1
y = heart_y + 1
while x < n and grid[x][y] == '*':
    right_leg += 1
    x += 1

print(heart_x + 1, heart_y + 1)
print(left_arm, right_arm, waist, left_leg, right_leg)
```
