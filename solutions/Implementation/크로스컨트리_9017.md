## 흐름
- 팀별 참가 인원을 먼저 세서(6명인지) **점수 계산 대상 팀만 필터링**
- 완주 순서대로 점수를 매기되, **점수 계산 대상 팀 선수에게만** 1점부터 부여
- 팀별로 부여된 점수 리스트에서
  - 상위 4명 점수 합이 가장 작은 팀이 우승
  - 동점이면 5번째 선수 점수가 더 작은 팀이 우승

## 코드
```python
import sys
from collections import defaultdict, Counter

input = sys.stdin.readline

T = int(input())

for _ in range(T):
    N = int(input())
    dic = defaultdict(list)
    mems = list(map(int, input().split()))
    counter = Counter(mems)
    i = 1
    for mem in mems:
        if(counter[mem] >= 6):
            dic[mem].append(i)
            i += 1

    hap = []
    for key in dic:
        hap.append((key, sum(dic[key][0:4]), dic[key][4]))
    hap.sort(key = lambda x : (x[1], x[2], x[0]))
    print(hap[0][0])
```

## 질문 & 실수 정리

### 새로 배운 것

#### Counter (collections.Counter)
리스트(또는 iterable)에서 각 값의 **등장 횟수**를 빠르게 셀 때 사용.
이번 문제에서는 “팀별 참가 인원이 6명인지”를 판별하기 위해 `Counter`로 팀 번호의 개수를 집계했다.

- **핵심 원리**: `Counter(arr)[x]` 형태로 값 `x`의 빈도를 빠르게 조회 가능(해시 기반).
- **시간복잡도**: 전체 카운팅 O(N)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|파이썬 슬라이싱에서 마지막 인덱스가 포함된다고 착각|슬라이싱은 `start` 포함, `end` **미포함** (예: `a[0:4]`는 0~3까지)|

## AI 코드 리뷰

### 개선할 점
1. **변수명 명확화**: `dic`, `hap`, `i`는 의미가 모호해서 읽는 사람이 한 번 더 해석해야 함. (예: `score_by_team`, `candidates`, `score` 등)
2. **로직 흐름 분리**: “필터링 → 점수 부여 → 팀 점수 계산/비교” 단계가 보이게 나누면 가독성이 좋아짐.
3. **정렬 대신 최솟값 갱신 방식도 가능**: 후보 팀이 많지 않아 정렬해도 충분하지만, 최솟값만 갱신하면 의도가 더 직접적으로 드러남.

## 수정된 코드
```python
import sys
from collections import Counter, defaultdict

input = sys.stdin.readline

T = int(input())

for _ in range(T):
    N = int(input())
    teams = list(map(int, input().split()))

    team_cnt = Counter(teams)
    qualified = {team for team, cnt in team_cnt.items() if cnt == 6}

    score_by_team = defaultdict(list)
    score = 1

    # 완주 순서대로 점수 부여(자격 팀 선수만 점수 받음)
    for team in teams:
        if team in qualified:
            score_by_team[team].append(score)
            score += 1

    # 팀 점수(상위 4명 합) + 타이브레이커(5번째 점수)로 우승팀 결정
    best_team = None
    best_sum4 = None
    best_5th = None

    for team, scores in score_by_team.items():
        sum4 = sum(scores[:4])
        fifth = scores[4]

        if (best_team is None) or (sum4 < best_sum4) or (sum4 == best_sum4 and fifth < best_5th):
            best_team = team
            best_sum4 = sum4
            best_5th = fifth

    print(best_team)
```
