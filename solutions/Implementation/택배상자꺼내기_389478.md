# 프로그래머스 389478 📦 택배 상자 꺼내기 파이썬

## 느낀점
>
- 내가 못하는 유형이다. (규칙 + 수학)
- 틀렸다. 시간을 갈면 풀 것 같았는데 머리가 잘 안 돌아갔다.
- 다시한번 꼭 풀어보자.

## 흐름

1. 상자의 층을 0층부터 계산한다.
   - `target_row = (num - 1) // w`
   - `top_row = (n - 1) // w`
2. `num`이 해당 층에서 몇 번째로 놓였는지 구한 뒤, 층의 진행 방향을 반영해 실제 열 좌표로 변환한다.
   - 짝수 층: 왼쪽 → 오른쪽
   - 홀수 층: 오른쪽 → 왼쪽
3. 목표 층부터 최고 층까지는 같은 열의 상자를 꺼낼 후보 층이다.
4. 최고 층이 상자로 가득 차지 않았다면, 목표 열에 상자가 실제로 놓여 있는지 확인한다.
5. 최고 층의 해당 열이 비어 있다면 후보 개수에서 1을 뺀다.

- 시간복잡도: `O(1)`
- 공간복잡도: `O(1)`

## 코드

```python
def solution(n, w, num):
    target_floor = (num-1)//w
    max_floor = (n-1)//w

    if(max_floor%2 == 0):
        offset = -1 if num + (max_floor - target_floor)*w < n else 0
    else:
        offset = -1 if num + (max_floor - target_floor)*w > n else 0
    print(target_floor, max_floor, offset, (max_floor - target_floor-1)*w + num)

    return max_floor - target_floor + offset + 1
```

## 질문 & 실수 정리

### 새로 배운 것

#### 지그재그 배치의 실제 열 좌표 구하기

각 층에서 상자가 놓인 순서와 창고에서의 실제 열 위치는 다를 수 있다.  
짝수 층은 왼쪽에서 오른쪽으로 놓이므로 층 내부 인덱스를 그대로 사용하지만, 홀수 층은 오른쪽에서 왼쪽으로 놓이므로 열 좌표를 뒤집어야 한다.

- **핵심 원리**:
  - 짝수 층: `column = index`
  - 홀수 층: `column = w - 1 - index`
- **시간복잡도**: `O(1)`

#### 마지막 부분 층의 채워진 범위 판단

마지막 층에 놓인 상자 수는 `n - top_row * w`이다.  
마지막 층의 방향에 따라 실제로 채워진 열의 범위가 달라진다.

- 짝수 층: 왼쪽 열부터 채워진다.
- 홀수 층: 오른쪽 열부터 채워진다.
- **핵심 원리**: 번호의 크기를 비교하지 않고, 목표 열이 채워진 범위 안에 있는지를 비교한다.
- **시간복잡도**: `O(1)`

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|같은 열의 위쪽 상자 번호가 항상 `num + 층 차이 × w`라고 판단|층마다 방향이 바뀌므로 먼저 `num`의 실제 열 좌표를 구한다.|
|최고 층의 짝·홀수만 보고 `offset`을 결정|목표 층의 방향으로 목표 열을 구하고, 최고 층의 방향으로 채워진 범위를 구한다.|
|상자 번호와 `n`의 대소 관계로 마지막 상자의 존재 여부를 판단|목표 열이 마지막 층의 채워진 열 범위에 포함되는지 판단한다.|
|일부 입력에서 `offset = -1`이 되어 결과가 0이 될 수 있음|우선 목표 층부터 최고 층까지의 개수를 구하고, 최고 층의 목표 열이 비었을 때만 1을 뺀다.|

## AI 코드 리뷰

### 개선할 점

1. **층이 아닌 실제 열 좌표가 필요함**: `target_floor`와 `max_floor` 계산은 정확하지만, 같은 세로줄인지 판단하려면 목표 상자의 실제 열 위치가 필요하다.
2. **번호 증가량으로 열을 추적하면 안 됨**: 지그재그 배치에서는 같은 열의 상자 번호 차이가 항상 `w`가 아니다.
3. **조건문의 의미를 변수명으로 표현**: `offset`보다 `top_has_target_col`처럼 조건의 의미가 드러나는 이름을 사용하면 로직을 검증하기 쉽다.
4. **디버깅 출력 제거**: 제출 코드에서는 `print`를 제거해 불필요한 출력을 없앤다.
5. **층과 행 용어 통일**: `floor`도 이해 가능하지만, 배열 좌표처럼 다룰 때는 `row`, `col`을 함께 사용하면 관계가 더 명확하다.

## 수정된 코드

```python
def solution(n, w, num):
    target_row = (num - 1) // w
    target_index = (num - 1) % w

    if target_row % 2 == 0:
        target_col = target_index
    else:
        target_col = w - 1 - target_index

    top_row = (n - 1) // w
    answer = top_row - target_row + 1

    top_box_count = n - top_row * w

    if top_row % 2 == 0:
        top_has_target_col = target_col < top_box_count
    else:
        top_has_target_col = target_col >= w - top_box_count

    if not top_has_target_col:
        answer -= 1

    return answer
```
