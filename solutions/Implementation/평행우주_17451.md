## 흐름

1. 행성을 역순으로 순회하면서 필요한 속도를 누적한다
2. 현재 누적 속도가 이번 구간 속도 이하이면 이번 구간 속도로 갱신한다
3. 현재 누적 속도가 이번 구간 속도보다 크면, 구간 속도의 배수 중 누적 속도 이상인 최솟값으로 갱신한다
4. 최종 누적 속도가 지구에서 올려야 할 최소 속도이다

## 코드

```python
import sys, math
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
arr = arr[::-1]
answer = 0
for cur in arr:
    if(answer <= cur):
        answer = cur
    else:
        answer = cur * math.ceil(answer/cur)
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 정수 올림 나눗셈
파이썬에서 `math.ceil(a/b)`는 부동소수점 나눗셈을 거치기 때문에 큰 수에서 정밀도 오차가 발생할 수 있다. 정수 연산만으로 올림 나눗셈을 수행하면 이 문제를 피할 수 있다.
- **핵심 원리**: `-(-a // b)` 또는 `(a + b - 1) // b`로 정수만 사용해 올림 나눗셈 가능

## AI 코드 리뷰

### 개선할 점

1. **부동소수점 올림 나눗셈**: `math.ceil(answer/cur)`는 큰 수(10^18 등)에서 float 변환 시 정밀도 오차가 생길 수 있다. 정수 올림 나눗셈 `-(-answer // cur)`로 대체하면 안전하다.

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))
arr = arr[::-1]

answer = 0
for cur in arr:
    if answer <= cur:
        answer = cur
    else:
        answer = cur * -(-answer // cur)

print(answer)
```
