## 실패한 로직 1 흐름
1. 먼저 `N` 이하의 제곱수들을 모두 구해 리스트에 저장했다.
2. 큰 제곱수부터 하나씩 빼면서 남은 값을 재귀적으로 해결하려고 했다.
3. `n == 0`이 되면 지금까지 사용한 제곱수 개수를 반환하도록 구성했다.
4. 이미 계산한 값은 `memo`에 저장해 다시 계산하지 않으려 했다.

## 실패한 코드 1
```python
N = int(input())

squares = []
i = 1
while i * i <= N:
    squares.append(i * i)
    i += 1

memo = {}

def dfs(n, cnt):
    if n == 0:
        return cnt

    for idx in range(len(squares) - 1, -1, -1):
        square = squares[idx]
        next_n = n - square

        if next_n < 0:
            continue

        if next_n in memo:
            return memo[next_n]

        memo[next_n] = dfs(next_n, cnt + 1)
        return memo[next_n]

print(dfs(N, 0))
```

**문제점**: 가능한 모든 제곱수 선택을 비교해야 하는데, 큰 제곱수부터 한 경로만 따라가며 바로 반환해서 최솟값을 보장하지 못했다.

## 실패한 로직 2 흐름
1. `dfs(n)`을 `n을 만드는 최소 제곱수 개수`로 정의했다.
2. 가능한 모든 제곱수를 하나씩 빼 보면서 `dfs(n - square) + 1`의 최솟값을 구하도록 바꿨다.
3. 이미 계산한 값은 `memo`에 저장해 중복 계산을 줄이려 했다.
4. 점화식 자체는 맞았지만, 재귀 호출과 딕셔너리 기반 메모이제이션으로 구현했다.

## 실패한 코드 2
```python
import sys
sys.setrecursionlimit(10 ** 6)

N = int(input())

squares = []
i = 1
while i * i <= N:
    squares.append(i * i)
    i += 1

memo = {}

def dfs(n):
    if n == 0:
        return 0

    if n in memo:
        return memo[n]

    result = float('inf')
    for idx in range(len(squares) - 1, -1, -1):
        square = squares[idx]
        next_n = n - square

        if next_n < 0:
            continue

        result = min(result, dfs(next_n) + 1)

    memo[n] = result
    return memo[n]

print(dfs(N))
```

**문제점**: 점화식은 맞았지만, 시간초과 발생

## 성공한 코드 흐름 & AI 코드 리뷰
1. 먼저 입력값이 완전제곱수인지 확인한다. 완전제곱수라면 답은 `1`이다.
2. `N`에서 `4`를 최대한 나누어 형태를 단순화한다.
3. 단순화한 값이 `8k + 7` 꼴이면 답은 반드시 `4`개다.
4. 그다음 `a^2 + b^2 = N` 형태가 가능한지 확인한다. 가능하면 답은 `2`개다.
5. 위 세 경우에 걸리지 않으면 답은 `3`개다.
6. 라그랑주의 네 제곱수 정리와 르장드르의 세 제곱수 정리를 이용하면, 모든 수는 `1~4`개 제곱수 합으로 표현되며 `4`가 필요한 경우를 빠르게 판별할 수 있다.
7. 최종적으로는 `1개 / 4개 / 2개 / 3개` 순서로 판정하면 `O(√N)` 안에 답을 구할 수 있다.

## 성공한 코드
```python
import math

n = int(input())

def is_square(x):
    root = int(math.isqrt(x))
    return root * root == x

if is_square(n):
    print(1)
else:
    temp = n
    while temp % 4 == 0:
        temp //= 4

    if temp % 8 == 7:
        print(4)
    else:
        answer = 3
        for i in range(1, int(math.isqrt(n)) + 1):
            if is_square(n - i * i):
                answer = 2
                break
        print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### DP 상태는 “지금까지 사용한 개수”보다 “앞으로 필요한 최소 개수”로 잡는 것이 깔끔할 수 있다
처음에는 `dfs(n, k)`처럼 현재까지 몇 개를 썼는지를 함께 넘기려 했지만, 이렇게 하면 메모이제이션 상태가 불안정해진다. 이 문제에서는 `dfs(n)`처럼 `n을 만드는 최소 개수`만 상태로 두는 쪽이 더 자연스럽다.
- **핵심 원리**: 메모이제이션의 상태는 같은 입력이면 항상 같은 의미를 가져야 한다.
- **시간복잡도**: 상태 수를 `N`, 제곱수 개수를 `√N`이라 보면 DP는 보통 `O(N√N)`

#### `4^a(8b+7)` 꼴이면 세 제곱수로 표현할 수 없다는 성질을 활용했다
이 문제에서는 모든 수가 최대 4개의 제곱수 합으로 표현된다는 점을 이용하고, 그중에서도 어떤 수가 정확히 4개가 필요한지 빠르게 판별하는 것이 중요했다. `N`에서 `4`를 최대한 나눈 뒤 남은 값이 `8b + 7` 꼴이면 세 제곱수로 만들 수 없으므로 답이 `4`가 된다.
- **핵심 원리**: 르장드르의 세 제곱수 정리를 이용하면 `4`가 필요한 경우를 빠르게 걸러낼 수 있다.
- **시간복잡도**: 형태 판별은 `O(log N)` 수준이고, 전체 풀이는 두 제곱수 확인까지 포함해 `O(√N)`

#### 두 제곱수 합 판별은 하나를 고정하고 나머지가 완전제곱수인지 확인하면 된다
답이 `1`도 아니고 `4`도 아니면, 다음으로 `2`개로 가능한지 확인하면 된다. `a^2`를 하나씩 시도하면서 `N - a^2`가 완전제곱수인지 검사하면 `a^2 + b^2 = N` 형태를 판별할 수 있다.
- **핵심 원리**: `a`를 순회하면서 남은 값이 완전제곱수인지 확인하면 두 제곱수 합 여부를 판별할 수 있다.
- **시간복잡도**: `a`를 `1`부터 `√N`까지 확인하므로 `O(√N)`

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 큰 제곱수부터 한 경로만 따라가면 최소 개수가 나올 것이라 생각함 | 가능한 모든 제곱수 선택을 비교한 뒤 최솟값을 판단해야 함 |
| `dfs(n, k)`처럼 누적 개수를 상태에 포함해 메모를 단순화하려고 함 | `dfs(n)`처럼 현재 수만 상태로 두고 반환값 자체를 최소 개수로 두는 편이 안정적임 |
| 점화식이 맞으면 재귀 메모이제이션도 충분하다고 생각함 | 이 문제는 시간 제한이 짧아서 정수론 성질을 이용한 풀이가 더 안전함 |
