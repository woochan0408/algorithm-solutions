## 실패한 코드 흐름

1. 각 행에 대해 1D 누적합 배열을 미리 계산
2. 쿼리마다 해당 행 범위를 순회하며 각 행의 구간 합을 더함
3. 시간복잡도: O(M × N) = 100,000 × 1,024 ≈ 1억 → 시간초과

## 실패한 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
nuArr = [[] for i in range(N)]
# 각 열 누적합 구하기
for i in range(N):
    subList = list(map(int, input().split()))
    hap = 0
    for cur in subList:
        hap += cur
        nuArr[i].append(hap)
# 목표 파싱
for _ in range(M):
    sr, sc, er, ec = map(int, input().split())
    result = 0
    for i in range(sr-1, er-1+1):
        a = nuArr[i][ec-1]
        b = nuArr[i][sc-2] if sc - 2 >= 0 else 0
        result += a - b
    print(result)
```

**문제점**: 쿼리당 O(N)으로 M개 쿼리 처리 시 O(M×N) 시간초과

## 성공한 코드 흐름

1. 2D 누적합 사용: `prefix[i][j]` = (0,0)부터 (i,j)까지 왼쪽 위 전체 영역의 합
2. 누적합 배열 채우기: `prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + arr[i][j]`
3. 구간 합 계산: 포함-배제 원리로 O(1)에 계산
4. 시간복잡도: O(N²) 전처리 + O(M) 쿼리 = O(N² + M)

## 성공한 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
arr = []
nuArr = [[0]*N for i in range(N)]
# 초기화
for i in range(N):
    subList = list(map(int, input().split()))
    arr.append(subList)
nuArr[0] = arr[0]
hapRow = 0
hapCol = 0
for i in range(N):
    hapRow += arr[i][0]
    nuArr[i][0] = hapRow
    hapCol += arr[0][i]
    nuArr[0][i] = hapCol
for i in range(1, N):
    for j in range(1, N):
        nuArr[i][j] = nuArr[i-1][j] + nuArr[i][j-1] - nuArr[i-1][j-1] + arr[i][j]
        
# 목표 파싱
for _ in range(M):
    sr, sc, er, ec = map(int, input().split())
    sr -= 1
    sc -= 1
    er -= 1
    ec -= 1
    
    a1 = nuArr[er][ec]
    a2 = nuArr[er][sc-1] if sc-1 >= 0 else 0
    a3 = nuArr[sr-1][ec] if sr-1 >= 0 else 0
    a4 = nuArr[sr-1][sc-1] if sr-1 >= 0 and sc-1 >= 0 else 0
    result = a1 - a2 - a3 + a4
    print(result)
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| 2D 누적합 개념이 뭔가요? | `prefix[i][j]` = (1,1)부터 (i,j)까지 왼쪽 위 전체 영역의 합으로 정의. 임의 구간 합을 포함-배제 원리로 O(1)에 계산 가능 |
| 누적합 배열은 어떻게 채우나요? | `prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + arr[i][j]` (포함-배제 원리) |

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|-----------|
| 각 행별 1D 누적합 → O(M×N) 시간초과 | 2D 누적합으로 쿼리당 O(1) 달성 |
| `nuArr[i][j] = nuArr[i-1][j] + nuArr[i][j-1] - nuArr[i-1][j-1]` | `+ arr[i][j]` 현재 칸 값 추가 필요 |
| 첫 행/열에 원본 값 그대로 저장 | 첫 행/열도 누적합으로 저장해야 함 (예: `[1,2,3,4]` → `[1,3,6,10]`) |

## AI 코드 리뷰

### 개선할 점

1. **패딩 기법으로 경계 조건 제거**: (N+1)×(N+1) 크기 배열에 0번 인덱스를 패딩으로 사용하면 경계 체크 불필요
2. **초기화 로직 통합**: 첫 행/열 별도 처리 없이 하나의 이중 루프로 통합 가능
3. **변수명 개선**: `nuArr` → `prefix`, `hapRow/hapCol` → 불필요하게 됨

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, M = map(int, input().split())

# 패딩을 위해 (N+1) x (N+1) 크기로 생성
arr = [[0] * (N + 1) for _ in range(N + 1)]
prefix = [[0] * (N + 1) for _ in range(N + 1)]

for i in range(1, N + 1):
    row = list(map(int, input().split()))
    for j in range(1, N + 1):
        arr[i][j] = row[j - 1]

# 누적합 계산 (경계 조건 없이 깔끔하게)
for i in range(1, N + 1):
    for j in range(1, N + 1):
        prefix[i][j] = prefix[i-1][j] + prefix[i][j-1] - prefix[i-1][j-1] + arr[i][j]

# 쿼리 처리
for _ in range(M):
    x1, y1, x2, y2 = map(int, input().split())
    result = prefix[x2][y2] - prefix[x1-1][y2] - prefix[x2][y1-1] + prefix[x1-1][y1-1]
    print(result)
```
