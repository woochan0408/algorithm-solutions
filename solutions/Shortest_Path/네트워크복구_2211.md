## 느낀점
>
- MST와 최단경로 트리를 헷갈렸다.
- 개념 깔끔하게 정리했으니 자주 보면서 복습하자
- 문제도 좋으니 꼭 오답노트하자

## 흐름
1. 1번(슈퍼컴퓨터)에서 모든 노드까지 다익스트라로 최단 거리를 구한다
2. 최단 거리 갱신 시 parent를 기록하여 최단 경로 트리를 만든다
3. 2~N번 노드의 (노드, parent) 쌍을 출력하면 N-1개 간선이 된다

## 코드
```python
"""
"""
import sys, heapq
input = sys.stdin.readline
INF = float('inf')
N, M = map(int, input().split())
heap = [(0, 1)]
dist = [INF]*(N+1)
dist[1] = 0
graph = [[] for i in range(N+1)]
parent = [i for i in range(N+1)]
for _ in range(M):
    u, v, w = map(int, input().split())
    graph[v].append((w, u))
    graph[u].append((w, v))
while heap:
    d, now = heapq.heappop(heap)
    if(d > dist[now]):
        continue
    for weight, nxt in graph[now]:
        cost = d + weight
        if(cost < dist[nxt]):
            dist[nxt] = cost
            parent[nxt] = now
            heapq.heappush(heap, (cost, nxt))
print(N-1)
for i in range(2, N+1):
    print(i, parent[i])
```

## 질문 & 실수 정리

### 새로 배운 것

#### 스패닝 트리 / MST / 최단 경로 트리 비교
그래프에서 트리를 뽑는 방법은 목적에 따라 다르다. 세 가지 트리는 모두 N개 노드, N-1개 간선인 스패닝 트리지만 최적화 기준이 다르다.

| 구분 | 스패닝 트리 | MST (최소 스패닝 트리) | 최단 경로 트리 |
|------|------------|----------------------|--------------|
| **목적** | 모든 노드 연결 | 간선 가중치 **총합 최소** | 시작점에서 각 노드까지 **최단 거리 보존** |
| **알고리즘** | DFS/BFS | 크루스칼, 프림 | 다익스트라 |
| **기준** | 없음 (아무거나) | 전체 비용 최소화 | 특정 노드 기준 거리 최소화 |
| **포함 관계** | MST ⊂ 스패닝 트리, 최단경로트리 ⊂ 스패닝 트리 | 최단 경로 트리와 별개 | MST와 별개 |

- **핵심 원리**: MST와 최단 경로 트리는 서로 포함 관계가 아니다. 같은 그래프에서 완전히 다른 트리가 나올 수 있다.

#### 다익스트라에서 parent 기록으로 최단 경로 트리 구하기
다익스트라의 relaxation 과정에서 `dist[nxt]`가 갱신될 때 `parent[nxt] = now`를 기록하면, 각 노드가 어떤 간선을 통해 최단 거리로 도달했는지 추적할 수 있다. 이렇게 기록된 parent 관계가 곧 최단 경로 트리의 간선이 된다.
- **핵심 원리**: 다익스트라에서 각 노드는 최단 거리가 확정될 때 parent가 딱 하나로 정해지므로, 사이클 없이 자연스럽게 트리 구조가 만들어진다.
- **시간복잡도**: 다익스트라 자체와 동일 O((V+E)logV) — parent 기록은 추가 비용 없음

#### parent 배열로 트리 간선 출력하기
트리에서 루트(1번)를 제외한 모든 노드는 부모가 정확히 하나다. 따라서 2~N번 노드에 대해 `(i, parent[i])`를 출력하면 총 N-1개, 이것이 트리의 모든 간선이 된다. 여러 노드가 같은 parent를 가질 수 있는데, 이는 한 노드가 자식을 여럿 가지는 것이므로 정상이다.
- **핵심 원리**: 트리의 노드 수 N → 간선 수 N-1, 루트 제외 각 노드마다 parent 간선 하나

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`dist[1]` 초기화 없이 INF로 시작|`dist[1] = 0`으로 시작 노드 초기화 필수|
|`graph`에 `(w, u)` 저장 후 `for nxt, weight`로 언패킹|저장 순서와 언패킹 순서를 일치시켜야 함 (`(w, u)` → `for weight, nxt`)|

## AI 코드 리뷰

### 개선할 점

1. **parent 초기화 방식**: `parent = [i for i in range(N+1)]` 대신 `parent = [0]*(N+1)`이면 충분하다. 자기 자신으로 초기화할 필요 없이, 다익스트라에서 갱신되지 않는 노드는 어차피 출력하지 않는다.
2. **출력 최적화**: `print()`를 반복 호출하면 I/O 오버헤드가 생긴다. `sys.stdout.write`나 리스트에 모아서 `'\n'.join()`으로 한 번에 출력하는 것이 더 빠르다.

## 수정된 코드
```python
import sys, heapq
input = sys.stdin.readline
INF = float('inf')
N, M = map(int, input().split())
heap = [(0, 1)]
dist = [INF] * (N + 1)
dist[1] = 0
graph = [[] for _ in range(N + 1)]
parent = [0] * (N + 1)
for _ in range(M):
    u, v, w = map(int, input().split())
    graph[u].append((w, v))
    graph[v].append((w, u))
while heap:
    d, now = heapq.heappop(heap)
    if d > dist[now]:
        continue
    for weight, nxt in graph[now]:
        cost = d + weight
        if cost < dist[nxt]:
            dist[nxt] = cost
            parent[nxt] = now
            heapq.heappush(heap, (cost, nxt))
result = [str(N - 1)]
for i in range(2, N + 1):
    result.append(f"{i} {parent[i]}")
print('\n'.join(result))
```
