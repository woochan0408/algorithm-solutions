## 흐름

1. N개의 도시와 M개의 단방향 통로가 주어진다
2. 도시 C에서 출발하여 모든 도시에 메시지를 동시에 전파한다
3. C에서 다익스트라를 돌려 각 도시까지의 최단 거리를 구한다
4. 도달 가능한 도시의 수 = 메시지를 받는 도시 수
5. 모든 도시가 메시지를 받는 데 걸리는 시간 = 도달 가능한 도시 중 최단 거리의 최댓값 (동시 전파이므로)

## 코드

```python
from collections import deque
import heapq
N, M, C = map(int, input().split())
graph = [[] for i in range(N+1)]
INF = float('inf')
for _ in range(M):
    u, v, w = map(int, input().split())
    graph[u].append((v, w))
    
def dij(n):
    dist = [INF]*(N+1)
    heap = []
    heapq.heappush(heap, (0, n))
    dist[n] = 0
    while heap:
        w, cur = heapq.heappop(heap)
        if(dist[cur] < w):
            continue
        for nxt, nw in graph[cur]:
            cost = w + nw
            if(dist[nxt] > cost):
                dist[nxt] = cost
                heapq.heappush(heap, (cost, nxt))
    return dist
# 방문 먼저 가능한지 판단.
result = dij(C)
count = 0
wei = 0
for i in range(1, N+1):
    if(result[i] == INF or i == C):
        continue
    count += 1
    wei = max(wei, result[i])
print(count, wei)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 동시 전파에서의 총 소요 시간
메시지가 하나의 출발점에서 여러 도시로 동시에 퍼져나갈 때, 모든 도시가 메시지를 수신하는 데 걸리는 총 시간은 각 도시까지의 최단 거리의 **합**이 아니라 **최댓값**이다. 각 경로가 병렬로 진행되므로, 가장 늦게 도착하는 도시가 전체 소요 시간을 결정한다.
- **핵심 원리**: 병렬 전파 → 총 시간 = max(각 도시까지의 최단 거리)

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 역방향 다익스트라로 양방향 도달 가능 여부 확인 | C에서 단방향 전송만 확인하면 됨 (문제 조건: C→다른 도시) |
| 총 시간을 각 도시까지 거리의 합으로 계산 | 동시 전파이므로 최댓값(max)으로 계산 |

## AI 코드 리뷰

### 개선할 점

1. **미사용 import 제거**: `from collections import deque`는 사용하지 않으므로 제거해야 한다.
2. **변수명 개선**: `wei`는 의미가 불분명하다. 최대 소요 시간을 나타내는 `max_time`이 더 직관적이다. `dij` → `dijkstra`, `nw` → `next_weight`로 변경하면 가독성이 높아진다.
3. **입력 최적화**: N ≤ 30,000, M ≤ 200,000이므로 `sys.stdin.readline`을 사용하면 입력 속도가 크게 개선된다.

## 수정된 코드

```python
import sys
import heapq

input = sys.stdin.readline

node_count, edge_count, start = map(int, input().split())
graph = [[] for _ in range(node_count + 1)]
INF = float('inf')

for _ in range(edge_count):
    from_node, to_node, weight = map(int, input().split())
    graph[from_node].append((to_node, weight))

def dijkstra(start_node):
    dist = [INF] * (node_count + 1)
    heap = []
    heapq.heappush(heap, (0, start_node))
    dist[start_node] = 0

    while heap:
        current_dist, current_node = heapq.heappop(heap)
        if dist[current_node] < current_dist:
            continue
        for next_node, next_weight in graph[current_node]:
            new_dist = current_dist + next_weight
            if dist[next_node] > new_dist:
                dist[next_node] = new_dist
                heapq.heappush(heap, (new_dist, next_node))
    return dist

result = dijkstra(start)
reachable_count = 0
max_time = 0

for i in range(1, node_count + 1):
    if result[i] == INF or i == start:
        continue
    reachable_count += 1
    max_time = max(max_time, result[i])

print(reachable_count, max_time)
```
