# 백준 1753 🛤️ 최단경로 파이썬

## 느낀점
>
- Heap에 노드 넣을 때 순서 주의하기
- 다익스트라 익숙해질 때까지 연습하기

## 흐름

1. 방향 그래프를 인접 리스트로 구성
2. 시작점에서 모든 정점까지의 거리를 INF로 초기화, 시작점은 0
3. 최소힙에 (거리, 노드) 형태로 시작점 push
4. 힙에서 꺼낸 노드의 인접 노드들에 대해 거리 갱신 가능하면 갱신 후 힙에 push
5. 이미 처리된 노드(현재 거리 > 저장된 거리)는 스킵
6. 모든 정점에 대해 최단 거리 출력, 도달 불가면 INF

## 코드

```python
import sys, heapq
input = sys.stdin.readline

N, V = map(int, input().split())
graph = {}
startNode = int(input())

for i in range(1,N+1):
    graph[i] = []

for i in range(V):
    u, v, w = map(int, input().split())
    graph[u].append((w, v))

dist = [float("inf") for i in range(N+1)]
dist[startNode] = 0
heap = [(0, startNode)]

while heap:
    d, now = heapq.heappop(heap)
    if d > dist[now]:
        continue

    for nextWeight, nextNode in graph[now]:
        cost = nextWeight + d
        if(cost < dist[nextNode]):
            dist[nextNode] = cost
            heapq.heappush(heap, (cost, nextNode))
for i in range(1, len(dist)):
    if(dist[i] == float("inf")):
        print("INF")
    else:
        print(dist[i])
```

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `heap = [(startNode, 0)]` 순서로 push | 최소힙이 거리 기준 정렬되려면 `(거리, 노드)` 순서 |
| `heappush(heap, (nextWeight, nextNode))` | 간선 가중치가 아닌 **누적 거리** `cost`를 push해야 함 |

## AI 코드 리뷰

### 개선할 점

1. **변수명 혼동**: 문제에서 V는 정점, E는 간선인데, 코드에서 `N`이 정점, `V`가 간선으로 되어 있어 혼동 가능

2. **그래프 초기화 간소화**: `defaultdict(list)` 사용하면 초기화 루프 제거 가능

3. **리스트 컴프리헨션 간소화**: `[float("inf") for i in range(N+1)]` → `[float("inf")] * (N+1)`

## 수정된 코드

```python
import sys
import heapq
from collections import defaultdict

input = sys.stdin.readline

V, E = map(int, input().split())
start = int(input())

graph = defaultdict(list)
for _ in range(E):
    u, v, w = map(int, input().split())
    graph[u].append((w, v))

dist = [float("inf")] * (V + 1)
dist[start] = 0
heap = [(0, start)]

while heap:
    current_dist, now = heapq.heappop(heap)
    if current_dist > dist[now]:
        continue

    for weight, next_node in graph[now]:
        cost = current_dist + weight
        if cost < dist[next_node]:
            dist[next_node] = cost
            heapq.heappush(heap, (cost, next_node))

for i in range(1, V + 1):
    print(dist[i] if dist[i] != float("inf") else "INF")
```
