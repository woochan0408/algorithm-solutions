# 백준 1916 💸 최소비용 구하기 파이썬

## 느낀점
>
- 다익스트라 기본문제
- 양방향인지 확인 잘 하자..

## 흐름

1. N개의 도시, M개의 버스 (단방향 간선)
2. 출발점에서 도착점까지 최소 비용 → 다익스트라 알고리즘
3. 인접 리스트로 그래프 구성 (가중치, 도착노드) 형태
4. 우선순위 큐(힙)로 최소 비용 노드부터 탐색
5. 이미 처리된 노드는 스킵 (dist[cur] < w)
6. 더 짧은 경로 발견 시 갱신 후 힙에 추가

## 코드

```python
from collections import defaultdict
import heapq
import sys
input = sys.stdin.readline 
N = int(input())
M = int(input())
graph = defaultdict(list)
for _ in range(M):
    u, v, w = map(int, input().split())
    graph[u].append((w, v))
startNode, endNode = map(int, input().split())
heap = [(0, startNode)]
dist = [float("inf")]*(N+1)
while heap:
    w, cur = heapq.heappop(heap)
    if(dist[cur] < w):
        continue
    for cost, nextNode in graph[cur]:
        if(dist[nextNode] > w + cost):
            dist[nextNode] = w + cost
            heapq.heappush(heap, (w+cost, nextNode))
print(dist[endNode])
```

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| `dist = [float("inf")*(N+1)]` - 길이 1짜리 리스트 | `dist = [float("inf")]*(N+1)` - 괄호 위치 |
| `graph[v].append((w, u))` - 양방향 그래프 | 버스는 단방향이므로 제거 |

## AI 코드 리뷰

### 개선할 점

1. **시작 노드 거리 명시적 초기화**: `dist[startNode] = 0`을 추가하면 의도가 명확해집니다. 현재 코드도 동작하지만, `startNode == endNode`인 경우 `inf`를 출력하는 버그가 있습니다.

2. **변수명 중복**: `w`가 "heap에서 꺼낸 현재까지의 거리"와 "간선 가중치" 두 의미로 사용됩니다. `current_dist` 등으로 구분하면 가독성이 향상됩니다.

## 수정된 코드

```python
from collections import defaultdict
import heapq
import sys
input = sys.stdin.readline

N = int(input())
M = int(input())

graph = defaultdict(list)
for _ in range(M):
    u, v, w = map(int, input().split())
    graph[u].append((w, v))

start, end = map(int, input().split())

dist = [float("inf")] * (N + 1)
dist[start] = 0
heap = [(0, start)]

while heap:
    current_dist, current_node = heapq.heappop(heap)
    
    if dist[current_node] < current_dist:
        continue
    
    for weight, next_node in graph[current_node]:
        new_dist = current_dist + weight
        if dist[next_node] > new_dist:
            dist[next_node] = new_dist
            heapq.heappush(heap, (new_dist, next_node))

print(dist[end])
```
