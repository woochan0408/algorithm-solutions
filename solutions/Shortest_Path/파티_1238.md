## 느낀점
>
- 다익스트라 처음 사용해봄
- 생각보다 코드 상으로는 복잡하지 않았다.
- 시간초과 안났지만 이런 유형 역방향 그래프 탐색으로 풀기
(AI 리뷰 참고)

## 흐름

1. N명의 학생이 각자 마을에서 X번 마을로 갔다가 돌아옴
2. 왕복 시간 = (i → X 최단거리) + (X → i 최단거리)
3. 다익스트라로 최단거리 계산
4. 모든 학생 중 왕복 시간 최댓값 출력

## 코드

```python
import heapq
def dij(start):
    INF = float('inf')
    dist = [INF] * (N + 1)
    dist[start] = 0
    pq = [(0, start)]
    
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
            
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    
    return dist
N, M, X = map(int, input().split())
graph = [[] for _ in range(N + 1)]
for _ in range(M):
    a, b, t = map(int, input().split())
    graph[a].append((b, t))
back = dij(X)
go = [0]
for i in range(1, N+1):
    dist = dij(i)
    go.append(dist[X])
result = []
for i in range(1, N+1):
    result.append(go[i] + back[i])
print(max(result))
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| 다익스트라 알고리즘이란? | 가중치가 양수인 그래프에서 한 정점 → 모든 정점 최단거리를 구하는 알고리즘. 우선순위 큐(힙) 사용 |

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|----------|
| X → 각 마을 (편도)만 계산 | 각 마을 → X (가는 길) + X → 각 마을 (오는 길) 왕복 계산 필요 |

## AI 코드 리뷰

### 개선할 점

1. **시간복잡도 개선**: 현재 다익스트라를 N+1번 호출 → **역방향 그래프** 활용하면 2번만 호출. 역방향 그래프에서 X 출발 다익스트라 = 정방향에서 각 정점 → X 최단거리

2. **함수명**: `dij` → `dijkstra`가 더 명확

3. **불필요한 리스트 생성**: `result` 리스트 없이 바로 `max()` 계산 가능

4. **전역 변수 의존**: 함수가 `N`, `graph`를 전역에서 참조 → 파라미터로 전달하면 재사용성 향상

## 수정된 코드

```python
import heapq
import sys
input = sys.stdin.readline

def dijkstra(start, n, graph):
    INF = float('inf')
    dist = [INF] * (n + 1)
    dist[start] = 0
    pq = [(0, start)]
    
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            cost = d + w
            if cost < dist[v]:
                dist[v] = cost
                heapq.heappush(pq, (cost, v))
    
    return dist

N, M, X = map(int, input().split())
graph = [[] for _ in range(N + 1)]
reverse_graph = [[] for _ in range(N + 1)]

for _ in range(M):
    a, b, t = map(int, input().split())
    graph[a].append((b, t))
    reverse_graph[b].append((a, t))

go = dijkstra(X, N, reverse_graph)
back = dijkstra(X, N, graph)

print(max(go[i] + back[i] for i in range(1, N + 1)))
```
