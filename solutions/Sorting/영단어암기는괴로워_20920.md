## 흐름
- `Counter`로 **(길이 >= M)** 인 단어만 빈도 집계
- 정렬 기준을 튜플로 만들어 한 번에 정렬  
  - `(-빈도, -길이, 단어)` → 오름차순 정렬로 요구사항 만족
- 정렬된 결과에서 단어만 출력

## 코드
```python
"""
7 4
apple
ant
sand
apple
append
sand
sand

conter 잘 사용하기
M 아래는 삭제
"""

from collections import Counter

import sys

input = sys.stdin.readline

N, M = map(int, input().split())

counter = Counter()
for _ in range(N):
    string = input().strip()

    if(len(string) >= M):
        counter.update([string])

dic = []
for key in counter:
    dic.append((-counter[key], -len(key), key))

dic.sort()

for cur in dic:
    print(cur[2])
```

## 질문 & 실수 정리

### 새로 배운 것
#### Counter로 빈도 집계 후 정렬 키 설계
- **핵심 원리**: `Counter`로 단어별 등장 횟수를 모은 뒤, 정렬 조건(빈도/길이/사전순)을 **튜플 정렬 키**로 한 번에 처리.
- **시간복잡도**: 집계 O(N), 정렬 O(K log K) (K=서로 다른 단어 수)

#### 튜플 정렬에서 내림차순 처리
- **핵심 원리**: 파이썬 기본 정렬은 오름차순이므로, 내림차순이 필요한 값(빈도/길이)은 `-값`으로 변환해 해결.
- **시간복잡도**: 키 계산 O(K)

## AI 코드 리뷰

### 개선할 점
1. **변수명 개선**: `dic`은 실제로 “리스트” 역할이라 `words` / `items` / `sorted_words` 같은 이름이 더 직관적.
2. **items() 활용**: `for key in counter:` + `counter[key]` 대신 `for word, freq in counter.items()`가 더 읽기 쉬움.
3. **출력 최적화(선택)**: 데이터가 많을 때는 `print` 루프 대신 `sys.stdout.write("\n".join(...))`가 조금 더 안정적일 수 있음.

## 수정된 코드
```python
import sys
from collections import Counter

input = sys.stdin.readline

N, M = map(int, input().split())

counter = Counter()
for _ in range(N):
    word = input().rstrip()
    if len(word) >= M:
        counter[word] += 1

items = [(-freq, -len(word), word) for word, freq in counter.items()]
items.sort()

out = "\n".join(word for _, _, word in items)
sys.stdout.write(out)
```
