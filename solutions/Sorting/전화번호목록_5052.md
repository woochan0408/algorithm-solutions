# 백준 5052 📞 전화번호 목록 파이썬

## 느낀점
>
- 시간초과로 실패
- 접두사 정렬 아이디어 새로 배웠다.

---

## 실패한 코드 흐름
1. 모든 전화번호 쌍을 비교하는 O(N²) 브루트포스 접근
2. 두 번호 중 짧은 쪽을 기준으로 한 글자씩 비교하여 접두어 관계 판별
3. 접두어 관계가 하나라도 발견되면 "NO" 반환

## 실패한 코드
```python
import sys
input = sys.stdin.readline
T = int(input())

def hasPrefix(s1, s2):
    if(len(s2) < len(s1)):
        s1, s2 = s2, s1
    result = True
    for i in range(len(s1)):
        if(s1[i] != s2[i]):
            result = False
            break
    return result

def solve(N, arr):
    found = False
    for i in range(N-1):
        for j in range(i+1, N):
            if(hasPrefix(arr[i], arr[j])):
                return 'NO'
    return 'YES'

for i in range(T):
    N = int(input())
    arr = []
    for _ in range(N):
        arr.append(input().strip())
    print(solve(N, arr))
```

**문제점**: N이 최대 10,000이고 테스트케이스가 최대 50개이므로 최악 50 × 10^8 연산. Python에서 O(N²)은 시간 초과.

## 성공한 코드 흐름

1. 전화번호를 사전순(문자열 정렬)으로 정렬
2. 정렬하면 접두어 관계에 있는 번호는 반드시 인접하게 위치
3. 인접한 쌍만 비교하면 O(N)으로 판별 가능

## 성공한 코드
```python
import sys
input = sys.stdin.readline
T = int(input())

# 접두사 비교함수
def hasPrefix(s1, s2):
    # 길이 작은 값을 s1에 저장
    if(len(s2) < len(s1)):
        s1, s2 = s2, s1
    result = True
    for i in range(len(s1)):
        if(s1[i] != s2[i]):
            result = False
            break
    return result

def solve(N, arr):
    found = False
    arr.sort()
    for i in range(N-1):
        if(hasPrefix(arr[i], arr[i+1])):
            return 'NO'
    return 'YES'

for i in range(T):
    N = int(input())
    arr = []
    for _ in range(N):
        # 문자열 형태 저장
        arr.append(input().strip())
    print(solve(N, arr))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 문자열 사전순 정렬과 접두어 관계
문자열을 사전순으로 정렬하면, 접두어 관계에 있는 두 문자열은 반드시 인접한 위치에 놓이게 된다. 예를 들어 "911"과 "91125426"은 정렬 후 바로 붙어 있다. 이 성질 덕분에 모든 쌍을 비교하는 O(N²) 대신 인접 쌍만 비교하는 O(N)으로 줄일 수 있다.
- **핵심 원리**: 사전순 정렬에서 문자열 A가 B의 접두어라면, A와 B 사이에 A를 접두어로 갖지 않는 문자열이 끼어들 수 없음
- **시간복잡도**: O(N log N) 정렬 + O(N) 비교 = O(N log N)

#### Python 시간복잡도 기준
C/C++에서 1초에 약 10^8 연산이 가능한 반면, Python은 약 10^7 연산이 한계이다. 따라서 Python으로 풀 때는 제약 조건을 보고 C++ 기준보다 한 단계 낮은 시간복잡도를 목표로 해야 한다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| N=10,000이면 N²=10^8이라 1초 안에 될 거라고 판단 | Python 기준 10^7이 한계이며, 테스트케이스 수(최대 50)도 곱해야 함 |

## AI 코드 리뷰

### 개선할 점

1. **미사용 변수 제거**: `solve` 함수 내 `found = False`가 선언만 되고 사용되지 않음
2. **`startswith()` 활용**: 직접 구현한 `hasPrefix` 함수 대신 Python 내장 메서드 `str.startswith()`를 사용하면 더 간결하고 C 레벨에서 동작하여 빠름
3. **입력 처리 간소화**: 리스트 컴프리헨션으로 입력을 한 줄로 처리 가능

## 수정된 코드
```python
import sys
input = sys.stdin.readline

T = int(input())

for _ in range(T):
    N = int(input())
    arr = [input().strip() for _ in range(N)]
    arr.sort()

    result = 'YES'
    for i in range(N - 1):
        if arr[i + 1].startswith(arr[i]):
            result = 'NO'
            break

    print(result)
```
