## 실패한 코드 흐름
1. R 명령마다 `lst.reverse()` 호출
2. D 명령은 항상 `popleft()`로 앞에서 제거

## 실패한 코드
```python
import sys
from collections import deque
input = sys.stdin.readline
N = int(input())
for _ in range(N):
    qList = input().strip()
    arrCount = int(input())
    inputStr = input().strip()
    inputStr = inputStr[1:-1]
    if(inputStr != ""):
        lst = deque(map(int, inputStr.split(",")))
    else:
        lst = []
    err = False
    for q in qList:
        if(q == 'R'):
            if(lst):
                lst.reverse()
            else:
                print()
        if(q == 'D'):
            if(lst):
                lst.popleft()
            else:
                err = True
                break
    if(err):
        print('error')
    else:
        result = "["
        for i in lst:
            result += str(i) + ","
        result = result[0:-1] + ']'
        print(result)
```

**문제점**: R마다 `reverse()` O(N) 호출 → R이 10만 번이면 시간초과

## 성공한 코드 흐름

1. **방향 플래그** 사용: R은 실제로 뒤집지 않고 `reversed_flag` 토글만 (O(1))
2. D 명령 시 플래그에 따라 `pop()` 또는 `popleft()` 선택
3. 출력 직전에 플래그가 True면 한 번만 reverse

## 성공한 코드
```python
import sys
from collections import deque
input = sys.stdin.readline
N = int(input())
for _ in range(N):
    qList = input().strip()
    arrCount = int(input())
    inputStr = input().strip()
    inputStr = inputStr[1:-1]
    if(inputStr != ""):
        lst = deque(map(int, inputStr.split(",")))
    else:
        lst = deque()
    
    err = False
    reversed_flag = False
    
    for q in qList:
        if(q == 'R'):
            reversed_flag = not reversed_flag
        elif(q == 'D'):
            if(lst):
                if reversed_flag:
                    lst.pop()
                else:
                    lst.popleft()
            else:
                err = True
                break
    
    if(err):
        print('error')
    else:
        if reversed_flag:
            lst.reverse()
        result = "[" + ",".join(map(str, lst)) + "]"
        print(result)
```

## 질문 & 실수 정리

### 질문했던 내용 (새로 배운 것)

| 질문 | 답변 |
|------|------|
| 방향 플래그가 이해 안 됨 | 실제로 뒤집지 않고 "뒤집힌 상태인지"만 기억. D할 때 방향에 따라 앞/뒤 선택 |

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|----------|
| R마다 `reverse()` O(N) | 플래그 토글 O(1) |
| `if ... if` 구조 | `if ... elif` 구조 |
| 빈 배열 `lst = []` | `lst = deque()` (일관성) |
| 문자열 `+=` 연결 | `",".join()` 사용 |

## AI 코드 리뷰

### 개선할 점

1. **변수명**: `qList` → `commands`, `arrCount` → 사용 안 하므로 `_`로 대체 가능
2. **최적화**: int 변환 없이 문자열 그대로 저장하면 파싱/출력 더 빠름
3. **삼항 연산자**: `if/else` 두 줄을 한 줄로 간결하게

## 수정된 코드
```python
import sys
from collections import deque
input = sys.stdin.readline

T = int(input())
for _ in range(T):
    commands = input().strip()
    n = int(input())
    arr_str = input().strip()[1:-1]
    
    dq = deque(arr_str.split(",")) if n > 0 else deque()
    
    reversed_flag = False
    error = False
    
    for cmd in commands:
        if cmd == 'R':
            reversed_flag = not reversed_flag
        elif cmd == 'D':
            if dq:
                dq.pop() if reversed_flag else dq.popleft()
            else:
                error = True
                break
    
    if error:
        print("error")
    else:
        if reversed_flag:
            dq.reverse()
        print("[" + ",".join(dq) + "]")
```
