## 흐름

1. 테스트 케이스마다 명령어 문자열, 배열 크기, 배열을 입력받음
2. 투 포인터(l, r)로 배열의 유효 범위를 추적
3. R 명령: l과 r을 스왑하여 뒤집힌 효과를 냄
4. D 명령: 빈 배열이면 error, 아니면 l이 r보다 작으면 l+1, 크면 l-1
5. l == r일 때 D가 오면 빈 배열로 전환 (zero 플래그)
6. 최종 출력 시 l < r이면 정방향 슬라이싱, l > r이면 역방향 슬라이싱
7. 역방향 슬라이싱에서 r == 0인 경우 stop을 생략해야 하므로 별도 분기 처리

## 코드

```python
import sys
input = sys.stdin.readline
def solve(req, arr):
    # 빈 배열
    zero = False
    if(len(arr) == 0):
        zero = True
    
    l = 0
    r = len(arr)-1
    for re in req:
        if(re == 'R'):
            l, r = r, l
        elif(re == 'D'):
            if(zero):
                print('error')
                return
            if(l == r):
                zero = True
            elif(l < r):
                l += 1
            else:
                l -= 1
    if(zero):
        print('[]')
    else:
        if(l == r):
            sub = [arr[l]]
        elif(l < r):
            sub = arr[l:r+1]
        else:
            if(r == 0):
                sub = arr[l::-1]
            else:
                sub = arr[l:r-1:-1]
        print('['+','.join(map(str, sub))+']')
        return
    
T = int(input())
for _ in range(T):
    req = input().strip()
    N = int(input())
    string = input().strip()
    string = string[1:-1]
    if(len(string) == 0):
        arr = []
    else:
        arr = list(map(int, string.split(',')))
    solve(req, arr)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 파이썬 역방향 슬라이싱에서 stop이 -1일 때의 함정

파이썬 슬라이싱 `arr[start:stop:step]`에서 step이 음수(역방향)일 때, **stop에 음수 인덱스를 쓰면 의도와 다르게 동작**한다.

예를 들어 `arr = [1, 2, 3]`에서 `arr[1:-1:-1]`은 빈 리스트를 반환한다. `-1`이 마지막 인덱스(`2`)로 변환되어 `arr[1:2:-1]`이 되고, index 1에서 역방향으로 가면서 index 2에 도달할 수 없기 때문이다.

- **핵심 원리**: 역방향 슬라이싱에서 **stop이 0번 인덱스 직전(= 처음까지 포함)**이어야 하면, stop을 `-1`이 아니라 **생략**해야 한다. `arr[start::-1]`처럼 쓰면 index 0까지 포함하여 역순으로 가져온다.

| 의도 | 잘못된 코드 | 올바른 코드 | 결과 |
|------|------------|------------|------|
| index 1→0 역순 | `arr[1:-1:-1]` | `arr[1::-1]` | `[2, 1]` |
| index 2→0 역순 | `arr[2:-1:-1]` | `arr[2::-1]` | `[3, 2, 1]` |


## AI 코드 리뷰

### 개선할 점

1. **변수명 `re` 충돌**: `re`는 파이썬 정규표현식 내장 모듈명이므로 `cmd` 등으로 변경하는 것이 안전하다.

2. **`zero` 플래그 대신 카운트 활용**: 남은 원소 개수를 별도로 관리하면 빈 배열 여부를 플래그 없이 자연스럽게 판단할 수 있다.

3. **deque를 활용한 더 깔끔한 접근**: 방향 플래그 하나로 R은 토글, D는 방향에 따라 `popleft()` / `pop()` 호출로 처리하면 슬라이싱 분기(`r == 0` 예외 처리)가 완전히 사라진다. 시간복잡도는 동일하게 O(N)이지만 코드가 훨씬 단순해진다.

**deque 풀이 흐름:**
1. 입력받은 배열을 deque로 변환
2. `is_front = True` 플래그로 현재 방향 관리
3. R → `is_front` 토글
4. D → `is_front`이면 `popleft()`, 아니면 `pop()`. 비어있으면 error
5. 출력 시 `is_front`가 False면 deque를 뒤집어서 출력

## 수정된 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

def solve(req, arr):
    dq = deque(arr)
    is_front = True  # True: 정방향, False: 역방향

    for cmd in req:
        if cmd == 'R':
            is_front = not is_front
        elif cmd == 'D':
            if not dq:
                print('error')
                return
            if is_front:
                dq.popleft()
            else:
                dq.pop()

    if not is_front:
        dq.reverse()
    print('[' + ','.join(map(str, dq)) + ']')

T = int(input())
for _ in range(T):
    req = input().strip()
    N = int(input())
    string = input().strip()[1:-1]
    if string:
        arr = list(map(int, string.split(',')))
    else:
        arr = []
    solve(req, arr)
```
