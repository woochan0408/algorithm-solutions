# 백준 14719 🌧️ 빗물 파이썬

## 느낀점
>
- 어렵다.. 다시 풀자.

## 흐름

1. 스택에 인덱스를 저장하며 순회
2. 현재 높이가 스택 top보다 높으면 웅덩이 발견
3. 바닥(pop) + 왼쪽벽(peek) + 오른쪽벽(현재)으로 물 계산
4. 너비 × 높이 누적

## 코드

```python
import sys
input = sys.stdin.readline
H, W = map(int, input().split())
world = list(map(int, input().split()))
stack = []
result = 0
for i in range(len(world)):
    cur = world[i]
    # 웅덩이 발견
    while stack and world[stack[-1]] < cur:
        floor = world[stack.pop()]
        if(not stack):
            break
        left = stack[-1]
        result += (min(world[left], cur) - floor) * (i - left - 1)
    stack.append(i)
print(result)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 스택으로 빗물 계산
내려갔다가 다시 올라올 때 웅덩이가 생긴다. 스택에 인덱스를 저장하고, 현재가 스택 top보다 높아지면 물을 계산한다. 세 가지 요소가 필요하다: 바닥(pop한 것), 왼쪽 벽(pop 후 남은 top), 오른쪽 벽(현재 위치).
- **핵심 원리**: `물 = (min(왼쪽벽, 오른쪽벽) - 바닥) × 너비`
- **시간복잡도**: O(N) - 각 원소가 최대 한 번 push, 한 번 pop

#### 너비 공식
양쪽 벽 사이의 칸 수는 `i - left - 1`이다. 벽 자체는 물이 차는 칸이 아니므로 양쪽을 제외해야 한다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---------|----------|
| `stack[-1] < cur` (인덱스와 높이 비교) | `world[stack[-1]] < cur` |
| `left = stack.pop()` (왼쪽 벽 제거) | `left = stack[-1]` (peek) |
| `stack[0]` (스택 바닥) | `stack[-1]` (스택 top) |
| `i - left + 1` | `i - left - 1` |

## AI 코드 리뷰

### 개선할 점

1. **사용하지 않는 변수 제거**: `H`는 사용되지 않음
2. **주석 정리**: 상단 주석이 현재 로직과 맞지 않음
3. **가독성 향상**: `width`, `height` 변수로 분리하면 계산 의도가 명확해짐

## 수정된 코드

```python
import sys
input = sys.stdin.readline

_, W = map(int, input().split())
world = list(map(int, input().split()))

stack = []
result = 0

for i in range(W):
    cur = world[i]
    
    while stack and world[stack[-1]] < cur:
        floor = world[stack.pop()]
        
        if not stack:
            break
        
        left = stack[-1]
        width = i - left - 1
        height = min(world[left], cur) - floor
        result += width * height
    
    stack.append(i)

print(result)
```
