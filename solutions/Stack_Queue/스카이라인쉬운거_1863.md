## 느낀점
>
- 처음 접근은 그리디로 했지만 시간초과가 예상되어 Stop
- 엣지케이스 (중간에 height 0 push하는 경우)를 못 찾았다. 꼭 찾자
- 힌트 맹신하지 말자. (괜히 힌트보고 grid 그려서 풀려하다가 시간낭비)
- 코드 순서 바꾸는 것만으로 손목관절을 보호할 수 있다. (AI 클린코드 참고)
- 요즘 손목이 너무 아프 다 ..

## 흐름

1. 스택을 사용해 현재까지의 건물 높이들을 관리
2. 새로운 높이가 들어올 때:
   - 스택의 top보다 작으면: 더 높았던 건물들은 여기서 끝나므로 pop하며 카운트
   - 같은 높이면: 하나의 건물로 이어질 수 있으므로 무시
   - 더 크면: 새 건물 후보로 push (단, 높이가 0이면 제외)
3. 마지막에 스택에 남은 건물 수도 더해서 출력

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
result = 0
stack = []
for _ in range(N):
    x, h = map(int, input().split())
    
    if not stack:
        if(h != 0):
            stack.append(h)
    elif(stack[-1] < h):
        stack.append(h)
    else:
        while(stack and stack[-1] >= h):
            cur = stack.pop()
            if(cur > h):
                result += 1
        if(h != 0):
            stack.append(h)
print(result + len(stack))
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `result` → `count`가 더 직관적
2. **불필요한 변수 제거**: x 좌표는 사용하지 않으므로 `_`로 받을 수 있음
3. **조건문 통합**: `if not stack`과 `elif stack[-1] < h` 조건을 하나로 합칠 수 있음

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
count = 0
stack = []

for _ in range(N):
    _, h = map(int, input().split())
    
    while stack and stack[-1] > h:
        stack.pop()
        count += 1
    
    if stack and stack[-1] == h:
        continue
    
    if h != 0:
        stack.append(h)

print(count + len(stack))
```
