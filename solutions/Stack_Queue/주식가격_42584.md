# 프로그래머스 42584 📈 주식가격 파이썬

## 느낀점
>
- 스택을 잘 쓰는 편이 아니라 고민하는 시간이 길었다.
- AI 수정 코드를 보니 확실히 어렵게 풀었다.
- 자료구조 문제를 좀 더 풀어보자. 

## 흐름

1. 각 시점의 가격이 떨어지지 않은 기간을 구해야 하므로, 스택에 (가격, 인덱스)를 저장
2. 현재 가격이 스택 top보다 작으면 → 가격이 떨어진 시점이므로, pop하면서 기간 계산
3. 현재 가격이 스택 top 이상이면 → 그대로 push
4. 순회 종료 후 스택에 남은 원소들은 끝까지 가격이 안 떨어진 것이므로, 마지막 인덱스까지의 거리 계산

## 코드
```python
"""
시간을 저장하자.
"""
def solution(prices):
    N = len(prices)
    answer = [0] * N
    stack = []
    
    for i in range(N):
        cur = prices[i]
        
        if(not stack or stack[-1][0] <= cur):
            # 시간과 함께 저장
            stack.append((cur, i))
            continue
        
        # 작은 값이네?
        while stack and stack[-1][0] > cur:
            before = stack.pop()
            answer[before[1]] = i - before[1]
        stack.append((cur, i))
    
    i = N-1
    while stack:
        before = stack.pop()
        answer[before[1]] = i - before[1]
    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### 스택을 활용한 구간 계산 패턴
스택에 값과 인덱스를 튜플로 함께 저장하면, pop 시점에서 인덱스 차이로 구간 길이를 바로 계산할 수 있다. "다음에 조건을 깨는 시점 찾기" 류의 문제에서 자주 등장하는 패턴이다.
- **핵심 원리**: 조건을 만족하는 동안 스택에 쌓고, 조건이 깨지는 순간 pop하며 결과 계산
- **시간복잡도**: O(N) — 각 원소가 최대 한 번 push, 한 번 pop

## AI 코드 리뷰

### 개선할 점

1. **불필요한 분기 제거**: `if/continue` 패턴으로 push 경로와 pop 경로를 나눴지만, `while` 조건이 이미 이를 처리하므로 분기 없이 while → append만으로 충분하다. 조건이 안 맞으면 while이 자연스럽게 skip되기 때문에 코드가 절반으로 줄어든다.

2. **튜플 언패킹 활용**: `before[0]`, `before[1]` 대신 `price, idx = stack.pop()` 형태로 언패킹하면 각 값의 의미가 명확해진다.

3. **잔여 스택 처리 간결화**: `while stack: pop()` 대신 `for price, idx in stack:`으로 순회하면 pop 없이도 깔끔하게 처리할 수 있다.

4. **변수명 개선**: `N` → `n` (파이썬 컨벤션상 대문자는 상수/클래스), `before` → `price, idx` (언패킹), `cur` → 인라인 사용 가능

## 수정된 코드
```python
def solution(prices):
    n = len(prices)
    answer = [0] * n
    stack = []

    for i in range(n):
        while stack and stack[-1][0] > prices[i]:
            price, idx = stack.pop()
            answer[idx] = i - idx
        stack.append((prices[i], i))

    for price, idx in stack:
        answer[idx] = n - 1 - idx

    return answer
```
