(그리디, 투포인터, dp 다 떠오름..)
- 결국 특정 값을 선택할 지 말지는 trade-off 관계라 생각되어 dp로 결정
- 잘 짰다고 생각했는데 시간초과
- 실패 후 새로운 아이디어를 배웠다.

---

## 실패한 코드 흐름
1. N자리 숫자에서 K개를 지우는 문제를 "N-K개를 선택하는 문제"로 변환
2. `dp[i][j]` = i번째 숫자까지 봤을 때 j개를 선택한 최댓값으로 정의
3. 전이: `dp[i][j] = max(dp[i-1][j-1] * 10 + arr[i], dp[i-1][j])`
4. 메모리 최적화를 위해 2차원 배열 대신 1차원 롤링 배열 사용

## 실패한 코드
```python
import sys
input = sys.stdin.readline
def makeNum(a, b):
    return a*10 + b
N, M = map(int, input().split())
# M개 선택하는 문제로 변경
M = N - M
string = input().strip()
arr = []
for c in string:
    arr.append(int(c))
    
prev = [0]*(M+1)
prev[1] = arr[0]
    
for i in range(1, N):
    cur = [0]*(M+1)
    for j in range(1, min(i+1, M+1)):
        cur[j] = max(makeNum(prev[j-1], arr[i]), prev[j])
    prev = cur
print(cur[M])
```

**문제점**: 시간복잡도 O(N × M)으로 최악의 경우 O(N²)이며, 파이썬 큰 정수 연산 비용까지 더해져 N=500,000에서 시간초과 발생

---

## 성공한 코드 흐름

1. 앞에서부터 숫자를 하나씩 스택에 넣는다
2. 넣기 전에, 스택의 top이 현재 숫자보다 작으면 pop (제거 횟수가 K 이하일 때만)
3. 앞자리가 클수록 전체 수가 커지므로, 앞에서 작은 숫자를 제거하는 것이 항상 이득 (그리디)
4. 루프 종료 후 아직 K개를 다 제거하지 못한 경우 (오름차순 등), 뒤에서 잘라낸다

## 성공한 코드
```python
import sys
input = sys.stdin.readline
N, M = map(int, input().split())
count = M
string = input().strip()
stack = []
for c in string:
    while (stack and stack[-1] < c and count > 0):
        count -= 1
        stack.pop()
    stack.append(c)
print("".join(stack[0:N-M]))
```

## 질문 & 실수 정리

### 새로 배운 것

#### 스택 기반 그리디 (Monotone Stack)
숫자에서 K개를 제거해 최댓값을 만드는 문제는 스택을 활용한 그리디로 O(N)에 해결할 수 있다. 앞에서부터 숫자를 순회하며, 스택의 top보다 현재 숫자가 크면 top을 제거하는 방식이다. 각 원소가 스택에 최대 한 번 push, 한 번 pop되므로 전체 연산 횟수가 O(N)이 된다.
- **핵심 원리**: 앞자리가 클수록 전체 수가 커지므로, 앞에 있는 작은 숫자를 우선 제거
- **시간복잡도**: O(N)

#### 파이썬 문자열 비교
파이썬에서 숫자 문자는 `'0' < '1' < ... < '9'` 순서로 비교되므로, 문자를 `int`로 변환하지 않고 문자열 그대로 비교해도 올바르게 동작한다. `int` 변환을 생략하면 성능상 이점이 있다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|DP 접근 (O(N²))|스택 그리디 접근 (O(N))|
|`prev[1]` 초기값 설정 누락|`prev[1] = arr[0]`으로 첫 번째 숫자 반영|
|루프 후 남은 제거 횟수 미처리|`stack[0:N-M]`으로 슬라이싱|
|M을 루프에서 직접 감소시킨 뒤 슬라이싱에도 사용|`count` 변수를 별도로 두어 원본 M 보존|

## AI 코드 리뷰

### 개선할 점

1. **변수명 개선**: `M`이 "제거할 개수"인데, `count`도 같은 값에서 시작하여 역할 구분이 모호하다. `K`(제거 개수)와 `remaining`(남은 제거 횟수)으로 분리하면 가독성이 좋아진다.
2. **리스트 컴프리헨션 활용**: `arr`를 만드는 for 루프 대신 리스트 컴프리헨션을 사용할 수 있지만, 이 코드에서는 `arr` 자체가 불필요하다 (문자열을 직접 순회하므로).
3. **슬라이싱 명확화**: `stack[0:N-M]` 대신 목표 길이를 변수로 저장하면 의도가 더 명확해진다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

N, K = map(int, input().split())
string = input().strip()
target_len = N - K  # 최종 결과의 길이

stack = []
remaining = K  # 남은 제거 횟수
for c in string:
    while stack and stack[-1] < c and remaining > 0:
        remaining -= 1
        stack.pop()
    stack.append(c)

print("".join(stack[:target_len]))
```
