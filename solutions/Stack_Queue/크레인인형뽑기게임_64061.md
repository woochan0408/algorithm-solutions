## 느낀점
>

## 흐름

1. 각 열에 남아 있는 인형의 개수를 `last`에 저장한다.
2. 크레인이 작동할 열을 0부터 시작하는 인덱스로 변환한다.
3. 해당 열에 인형이 남아 있다면 `N - last[move]`로 가장 위 인형의 행을 구한다.
4. 뽑은 인형이 바구니의 가장 위 인형과 같으면 두 인형을 제거하고, 다르면 바구니에 추가한다.
5. 제거된 인형의 총개수를 반환한다.

## 코드

```python
'''
최솟값을 묻는 문제

모든 배열을 스택으로 관리하자.

끝값을 저장해두자.





'''

def solution(board, moves):
    stack = []
    N = len(board)
    last = [N for i in range(N)]
    
    for i in range(N):
        for j in range(N):
            if(board[i][j] == 0):
                last[j] -= 1

    answer = 0
    
    for move in moves:
        move -= 1
        
        
        if(last[move] == 0):
            continue
        

        pivot = board[N - last[move]][move]
        last[move] -= 1
        if(stack and stack[-1] == pivot):
            answer += 2
            stack.pop()
        else:
            stack.append(pivot)

    return answer
```

## 질문 & 실수 정리

### 새로 배운 것

#### 2차원 리스트에서 행과 열을 구분하는 방법

2차원 리스트는 항상 `board[행][열]`, 즉 `board[row][column]` 순서로 접근한다. 첫 번째 인덱스는 위에서 아래로 움직이는 행이고, 두 번째 인덱스는 왼쪽에서 오른쪽으로 움직이는 열이다.

크레인 위치는 특정 **열**을 의미하므로 열 인덱스를 고정하고 행을 위에서 아래로 확인해야 한다.

```python
column = move - 1

for row in range(n):
    doll = board[row][column]
```

헷갈릴 때는 다음 문장을 먼저 적어두면 좋다.

> 크레인은 열을 선택하고, 그 열에서 행을 위에서 아래로 내려간다.

- **핵심 원리**: 특정 열을 탐색할 때는 `column`을 고정하고 `row`만 변화시킨다.
- **시간복잡도**: 모든 칸을 한 번 확인하면 `O(N²)`이다.

#### 열마다 가장 위 인형의 행을 저장하는 포인터

매번 열 전체를 다시 탐색하지 않고, 각 열에서 다음에 뽑을 인형의 행을 저장할 수 있다. 예를 들어 `top_rows[column]`에는 해당 열의 가장 위 인형이 있는 행을 저장한다.

인형을 하나 뽑은 뒤에는 해당 열의 포인터를 한 칸 아래로 이동하면 된다. 이렇게 하면 `N - last[move]`처럼 의미를 다시 계산해야 하는 수식을 줄일 수 있다.

- **핵심 원리**: 각 열의 현재 위치를 따로 저장하고, 인형을 뽑을 때만 갱신한다.
- **시간복잡도**: 초기 위치 탐색 `O(N²)`, 모든 크레인 작동 `O(len(moves))`

#### 바구니를 스택으로 관리하기

바구니에서는 가장 마지막에 들어온 인형만 확인하면 된다. 따라서 리스트의 마지막 원소를 스택의 꼭대기로 사용한다.

```python
if basket and basket[-1] == doll:
    basket.pop()
else:
    basket.append(doll)
```

- **핵심 원리**: 마지막에 들어온 인형은 `basket[-1]`로 확인하고, `append()`와 `pop()`으로 추가·제거한다.
- **시간복잡도**: `append()`와 마지막 원소 `pop()`은 각각 `O(1)`이다.

### 실수했던 부분

| 틀린 것 | 올바른 것 |
|---|---|
| 같은 인형이 만났을 때 `answer += 1` | 터져서 사라지는 인형은 두 개이므로 `answer += 2` |

## AI 코드 리뷰

### 잘한 점

1. **열의 상태를 미리 계산함**: 크레인을 작동할 때마다 열 전체를 다시 탐색하지 않아 효율적이다.
2. **바구니를 스택으로 정확히 표현함**: `stack[-1]`, `append()`, `pop()`을 이용해 문제의 제거 규칙을 간결하게 구현했다.
3. **빈 열을 바로 건너뜀**: `continue`를 사용해 불필요한 중첩을 줄였다.
4. **전체 시간복잡도가 충분히 효율적임**: 전처리 `O(N²)`와 크레인 작동 `O(M)`으로 총 `O(N² + M)`이다.

### 개선할 점

1. **변수명으로 역할 드러내기**: `stack`은 `basket`, `pivot`은 `doll`로 바꾸면 문제 속 대상과 바로 연결된다. `last`는 남은 인형의 개수인지 행 인덱스인지 이름만으로 알기 어려우므로 더 구체적인 이름이 필요하다.
2. **지역 변수는 소문자로 작성하기**: `N`은 보통 변하지 않는 전역 상수에 사용하는 표기이므로 함수 내부에서는 `n`이 자연스럽다.
3. **행 인덱스를 직접 저장하기**: `N - last[move]`는 실행은 정확하지만 의미를 한 번 더 해석해야 한다. 각 열의 가장 위 인형 행을 직접 저장하면 보드 접근 순서가 더 분명해진다.
4. **풀이와 맞지 않는 주석 제거하기**: 이 문제는 최솟값을 구하지 않으며, 현재 코드는 각 열을 별도의 스택으로 변환하지 않는다. 풀이 메모가 실제 구현과 다르면 복습할 때 혼란이 생길 수 있다.
5. **불필요한 리스트 컴프리헨션 변수 제거하기**: `[N for i in range(N)]`에서 `i`를 사용하지 않으므로 `[N] * N`처럼 작성할 수 있다.

## 수정된 코드

각 열에서 다음에 뽑을 인형의 **행 인덱스**를 직접 저장하는 방식이다. `board[row][column]`의 의미가 코드에 그대로 드러나므로 행과 열의 순서를 확인하기 쉽다.

```python
def solution(board, moves):
    n = len(board)
    top_rows = [0] * n

    # 각 열에서 가장 위에 있는 인형의 행을 찾는다.
    for column in range(n):
        while top_rows[column] < n and board[top_rows[column]][column] == 0:
            top_rows[column] += 1

    basket = []
    removed_count = 0

    for move in moves:
        column = move - 1
        row = top_rows[column]

        if row == n:
            continue

        doll = board[row][column]
        top_rows[column] += 1

        if basket and basket[-1] == doll:
            basket.pop()
            removed_count += 2
        else:
            basket.append(doll)

    return removed_count
```
