# 백준 13335 🚚 트럭 파이썬

## 느낀점
>
- 구현이 너무 오래걸렸다.
- 너무 복잡하게 생각했다.
- 간단하게 생각하자.
(popleft 할 때 `time += 1`)
- 시간 남으면 다시 풀어보자.

## 흐름

1. 다리를 길이 W짜리 큐로 모델링 (초기값 0으로 채움)
2. 매 턴마다 큐 앞에서 하나 빼고 (다리에서 나감), 새 트럭을 넣을 수 있으면 넣음
3. 못 넣으면 0을 넣어서 빈 칸으로 채움 → 넣을 수 있을 때까지 반복
4. 모든 트럭이 다리에 올라간 후, 마지막 트럭이 빠져나오려면 W만큼 더 걸림

## 코드

````python
# dp? 그리디?
# dp는 말이 안된다.
# 어짜피 순서는 정해져 있으므로 최대한 보내자.

import sys
from collections import deque
input = sys.stdin.readline
N, W, L = map(int, input().split())
arr = list(map(int, input().split()))
arr = arr[::-1]
sub = [0]*W
dq = deque(sub)
t = 0
# 한 주기는 cur을 태울 때까지로 설정
hap = 0
while(arr):
    cur = arr.pop()
    hap -= dq.popleft()
    # 그냥 추가 가능
    if(hap + cur <= L):
        dq.append(cur)
        hap += cur
        t += 1
        continue
    # 추가 가능할 때까지 반복
    dq.append(0)
    t += 1
    while True:
        hap -= dq.popleft()
        t += 1
        if(hap + cur <= L):
            hap += cur
            dq.append(cur)
            break
        else:
            dq.append(0)
print(t + W)
````

## AI 코드 리뷰

### 개선할 점

1. **변수명 불명확**: `arr`, `hap`, `sub`, `cur` → `trucks`, `bridge_weight`, (제거), `truck`으로 변경하면 의도가 명확해짐
2. **불필요한 역순 변환**: `arr[::-1]` 후 `pop()` 대신 `deque`로 만들어 `popleft()`하면 역순 변환 없이 순서대로 처리 가능
3. **중첩 루프 제거 가능**: 내부 `while True` 루프를 없애고 매 턴 단일 루프로 처리하면 가독성 향상. 트럭을 올릴 수 있으면 올리고, 아니면 0을 넣는 방식으로 단순화
4. **`sub` 변수 불필요**: `deque([0]*W)`로 직접 초기화 가능

## 수정된 코드

```python
import sys
from collections import deque

input = sys.stdin.readline

N, W, L = map(int, input().split())
trucks = deque(map(int, input().split()))
bridge = deque([0] * W)  # 다리를 0으로 초기화 (빈 칸)
bridge_weight = 0
time = 0

while trucks:
    # 매 턴: 다리 앞에서 하나 빠짐
    bridge_weight -= bridge.popleft()
    time += 1

    # 다음 트럭을 올릴 수 있으면 올리기
    if bridge_weight + trucks[0] <= L:
        truck = trucks.popleft()
        bridge.append(truck)
        bridge_weight += truck
    else:
        # 못 올리면 빈 칸 추가
        bridge.append(0)

# 마지막 트럭이 다리를 완전히 건너는 시간
print(time + W)
```
