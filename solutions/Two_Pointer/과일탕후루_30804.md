## 흐름
- 처음에는 **양 끝에서 덩어리 길이를 비교해서 더 짧은 쪽을 제거**하는 그리디로 접근했다.
- 그런데 “끝에서 제거하면 과일 종류 수가 1개 줄어든다”는 가정이 성립하지 않아서(내부에 같은 과일이 또 있을 수 있음) 최적을 보장하지 못했다.
- 이후 문제를 **‘서로 다른 과일이 2종류 이하인 가장 긴 연속 구간’**으로 재해석하고,
  투 포인터/슬라이딩 윈도우로 구간을 확장/축소하며 정답을 갱신하는 방식으로 해결했다.

---

## 실패한 코드 흐름
1. 현재 구간의 서로 다른 과일 종류 수(`curLeft`)가 2가 될 때까지 반복
2. 왼쪽 끝 연속 구간 길이(`lLen`)와 오른쪽 끝 연속 구간 길이(`rLen`)를 계산
3. 더 짧은 덩어리 쪽을 잘라내면 손실이 적다고 가정하고 포인터를 이동
4. 종류 수는 한 번 잘라낼 때마다 1개씩 줄어든다고 가정(`curLeft -= 1`)

**문제점**: 한쪽 끝에서 과일을 제거해도 해당 과일 종류가 **구간 내부에 남아있을 수 있어** 종류 수가 줄지 않으며, “짧은 덩어리 제거” 그리디 선택도 최적을 보장하지 않는다.

## 실패한 코드
```python
"""
9
1 2 3 4 5 6 7 8 9

Greedy?

"""

from collections import Counter

import sys

input = sys.stdin.readline

N = int(input())

arr = list(map(int, input().split()))

l = 0
r = N-1
curLeft = len(set(arr))
while curLeft > 2:
    lLen = 0
    rLen = 0
    li = l
    cur = arr[l]
    while True:
        if(cur != arr[li]):
            break
        li += 1
    lLen = li - l

    ri = r
    cur = arr[r]
    while True:
        if(cur != arr[ri]):
            break
        ri -= 1
    rLen = r - ri

    print(lLen)
    print(rLen)

    if(rLen < lLen):
        r = ri
    else:
        l = li
    curLeft -= 1

print(r - l + 1)
```

## 성공한 코드 흐름
1. 오른쪽 포인터 `r`를 늘리며 과일을 구간에 포함시키고, 과일 종류별 개수를 카운팅한다.
2. 구간 내 서로 다른 종류 수가 3개 이상이 되면, 조건(≤2)을 만족할 때까지 왼쪽 포인터 `l`을 이동하며 카운트를 감소시킨다.
3. 매 스텝에서 `r-l+1`로 구간 길이를 계산해 최댓값을 갱신한다.

## 성공한 코드
```python
"""
5
5 1 1 2 1
"""

import sys

input = sys.stdin.readline


N = int(input())
arr = list(map(int, input().split()))
count = [0 for i in range(11)]
def cal():
    result = 0
    for i in count:
        if(i > 0):
            result += 1
    return result


l = 0
ans = 0
for r in range(N):
    count[arr[r]] += 1
    while cal() > 2:
        count[arr[l]] -= 1
        l += 1
    ans = max(ans, r-l+1)

print(ans)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 슬라이딩 윈도우 (투 포인터)
연속 구간의 조건(여기서는 **서로 다른 과일 종류 ≤ 2**)을 유지하면서, 오른쪽을 확장하고 조건이 깨지면 왼쪽을 줄여 조건을 회복하는 방식.
- **핵심 원리**: “구간이 조건을 만족하면 확장”, “조건을 넘으면 축소”를 반복하면서 **모든 구간을 O(N)**에 탐색한다.
- **시간복잡도**: O(N) (각 원소는 `l`, `r`에 의해 최대 1번씩만 들어오고/나감)

#### 빈도 배열로 종류 수 관리
과일 종류가 1~9로 작기 때문에 딕셔너리 대신 **배열 count**로 카운팅이 가능하다.
- **핵심 원리**: `count[x]`가 0→1로 바뀌면 distinct 증가, 1→0으로 바뀌면 distinct 감소처럼 **종류 수를 상수시간으로 관리**할 수 있다.
- **시간복잡도**: 갱신 O(1)

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|양끝 덩어리 길이로 그리디 결정 → 최적 보장 실패|연속 구간 최댓값 문제로 재해석 → 슬라이딩 윈도우 적용|
|끝에서 제거하면 종류 수가 1 줄어든다고 가정(`curLeft -= 1`)|구간 내부 빈도 기반으로 distinct를 정확히 유지|
|구간 조건 확인을 `set`/재계산에 의존|카운트/종류 수를 업데이트하며 유지(상수시간)|

## AI 코드 리뷰

### 개선할 점

1. **`cal()`을 매번 돌리는 구조**
   - 현재는 `cal()`이 count 배열(길이 11)을 매번 훑어서 distinct를 계산한다.
   - 길이가 작아서 통과는 하지만, 더 깔끔한 방식은 `distinct` 변수를 두고 0↔1 변화에서만 증감시키는 것.

2. **count 배열 크기**
   - 과일 번호가 1~9이므로 `count = [0]*10`(혹은 12)처럼 “의미가 드러나게” 잡는 게 좋다.

3. **함수/변수명**
   - `cal()` → `distinct_count()` 같은 이름이 의도를 더 잘 드러낸다.
   - `ans`, `l`, `r`는 투포인터 관례상 괜찮지만, `count`는 `freq`처럼 의미가 더 명확한 이름도 좋다.

### 수정된 코드
```python
import sys

input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))

freq = [0] * 10  # 1~9 사용
distinct = 0
l = 0
ans = 0

for r in range(N):
    x = arr[r]
    if freq[x] == 0:
        distinct += 1
    freq[x] += 1

    while distinct > 2:
        y = arr[l]
        freq[y] -= 1
        if freq[y] == 0:
            distinct -= 1
        l += 1

    ans = max(ans, r - l + 1)

print(ans)
```
