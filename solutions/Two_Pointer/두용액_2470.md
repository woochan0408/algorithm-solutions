# 백준 2470 🧪 두 용액 파이썬

## 느낀점
>
- 과거 개념 몰라서 틀렸던 문제
- 오답노트 완료
- 슬라이딩 윈도우랑 헷갈리지 말자.

## 흐름

1. 용액 배열을 오름차순 정렬
2. 왼쪽 포인터(최솟값), 오른쪽 포인터(최댓값)에서 시작
3. 두 용액의 합을 계산하고, 절댓값이 현재 최솟값보다 작으면 갱신
4. 합이 0이면 즉시 종료
5. 합이 양수면 오른쪽 포인터를 줄이고, 음수면 왼쪽 포인터를 늘림
6. 저장된 최적 쌍 출력

## 코드

```python
import sys
input = sys.stdin.readline
N = int(input())
arr = list(map(int, input().split()))
arr.sort()
l = 0
r = len(arr)-1
answer = float('inf')
answerL = 0
answerR = 0
while l < r:
    cur = arr[l] + arr[r]
    if(answer > abs(cur)):
        answerL = arr[l]
        answerR = arr[r]
        answer = abs(cur)
        if(cur == 0):
            break
    if(cur > 0):
        r -= 1
    else:
        l += 1
print(answerL, answerR)
```

### 개선할 점

## 수정된 코드

```python
import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))
arr.sort()

l = 0
r = len(arr) - 1
min_diff = float('inf')
best_left = 0
best_right = 0

while l < r:
    pair_sum = arr[l] + arr[r]

    if min_diff > abs(pair_sum):
        best_left = arr[l]
        best_right = arr[r]
        min_diff = abs(pair_sum)
        if pair_sum == 0:
            break

    if pair_sum > 0:
        r -= 1
    else:
        l += 1

print(best_left, best_right)
```
