# 프로그래머스 178870 🔗 연속된 부분 수열의 합 파이썬

## 느낀점
>
- 잘 풀었다.

## 흐름

1. 투포인터(left, right)로 연속 부분 수열 탐색
2. right를 한 칸씩 확장하며 합 누적
3. 합이 k를 초과하면 left를 이동시켜 합 축소
4. 합이 k와 같을 때, 현재 길이가 최소이면 결과 갱신
5. 길이가 같으면 먼저 나온 것이 유지됨 (left→right 순회이므로 자동 보장)

## 코드

```python
def solution(sequence, k):
    l = 0
    hap = 0
    m = float('inf')
    result = []
    for r in range(len(sequence)):
        hap += sequence[r]
        while hap > k:
            hap -= sequence[l]
            l += 1
        if(hap == k and (r - l + 1) < m):
            m = r - l + 1
            result = [l, r]
            
    return result
```

## AI 코드 리뷰

### 개선할 점

1. **변수명 통일**: `hap`, `m`, `l`, `r` 등 축약 변수명을 `current_sum`, `min_len`, `left`, `right`로 변경하면 가독성이 올라간다.

## 수정된 코드

```python
def solution(sequence, k):
    left = 0
    current_sum = 0
    min_len = float('inf')
    result = []

    for right in range(len(sequence)):
        current_sum += sequence[right]

        while current_sum > k:
            current_sum -= sequence[left]
            left += 1

        if current_sum == k and (right - left + 1) < min_len:
            min_len = right - left + 1
            result = [left, right]

    return result
```
