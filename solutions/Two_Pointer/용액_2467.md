## 흐름
1. 배열은 이미 오름차순 정렬되어 있으므로, 양 끝에서 시작하는 두 포인터 `l`, `r`를 둔다.
2. 매 단계에서 `s = arr[l] + arr[r]`를 계산하고, `abs(s)`가 지금까지의 최소값보다 작으면 정답 후보를 갱신한다.
3. `s`의 부호에 따라 0에 가까워지도록 포인터를 이동한다.
   - `s > 0`이면 합이 너무 크므로 `r -= 1`
   - `s < 0`이면 합이 너무 작으므로 `l += 1`
   - `s == 0`이면 더 좋아질 수 없으니 종료한다.
4. 루프 종료 후 저장해둔 정답 쌍을 출력한다.

## 코드
```python
"""
5
-99 -2 -1 4 98
"""


import sys
input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))


l = 0
r = len(arr)-1
answerL = arr[0]
answerR = arr[r]
best = float("inf")


while(l < r):
    s = arr[r] + arr[l]
    if(best > abs(s)):
        best = abs(s)
        answerR = arr[r]
        answerL = arr[l]
    if(s == 0):
        break
    if(s > 0):
        r -= 1
    else:
        l += 1

print(answerL, answerR)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 투 포인터에서 “버려도 되는 경우” 판단(단조성)
정렬된 배열에서 `l`을 오른쪽으로 옮기면 합이 커지고, `r`을 왼쪽으로 옮기면 합이 작아진다.  
따라서 현재 합 `s = arr[l] + arr[r]`가
- **음수**라면 0에 가까워지려면 합을 키워야 하므로 `l`을 늘리는 방향만 의미가 있고,
- **양수**라면 0에 가까워지려면 합을 줄여야 하므로 `r`을 줄이는 방향만 의미가 있다.

이 단조성 덕분에 전체 조합을 다 보지 않아도 최적해를 놓치지 않는다.
- **시간복잡도**: O(N)

#### “마지막 상태가 답”이 아니라 “경로 중 최솟값을 저장”하는 패턴
0이 정확히 존재하면 즉시 종료할 수 있지만, 보통은 `l < r` 동안 끝까지 돌면서 매 단계의 점수(`abs(s)`) 최솟값을 저장해두고, 그 저장값이 정답이 된다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|`abs(answerR - answerL)`처럼 **차이**를 최소화함|문제 목표는 **합이 0에 가까운 것** → `abs(arr[l] + arr[r])`|
|현재 포인터가 아닌 `answerL/answerR`로 점수 계산|점수는 매 단계 **현재 (l,r)** 조합으로 평가|
|`abs(s)`로 부호 정보를 잃어 포인터가 한쪽으로만 움직임|포인터 이동은 **`s`의 부호(+, -)** 기준|

## AI 코드 리뷰

### 개선할 점

1. **인덱스/길이 변수 통일**
   - 이미 `N`을 받았으니 `r = N - 1`처럼 통일하면 더 명확하다.

2. **이름 개선**
   - `answerL/answerR` 대신 `best_pair`(튜플)처럼 묶어두면 관리가 편하다.
   - `best`는 `best_abs`처럼 “절댓값 최소”라는 의미를 드러내면 읽기 쉬워진다.

3. **출력 보장**
   - 현재는 `l < r`에서 시작하므로 `answerL <= answerR`가 보장되지만, 습관적으로 `min/max`로 출력 포맷을 고정해두면 안전하다(특히 로직 변경 시).

## 수정된 코드
```python
import sys

input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))

l, r = 0, N - 1
best_abs = float("inf")
best_pair = (arr[l], arr[r])

while l < r:
    s = arr[l] + arr[r]
    if abs(s) < best_abs:
        best_abs = abs(s)
        best_pair = (arr[l], arr[r])

    if s == 0:
        break
    elif s > 0:
        r -= 1
    else:
        l += 1

a, b = best_pair
if a > b:
    a, b = b, a
print(a, b)
```
