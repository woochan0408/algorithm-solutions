## 실패한 코드 흐름
1. 모든 쌍 `(i, j)`의 합을 구하고, 합이 배열에 존재하면 해당 값의 개수만큼 answer에 더함
2. `results` set으로 중복 카운팅 방지 시도

## 실패한 코드
```python
import sys
from collections import defaultdict

input = sys.stdin.readline

N = int(input())

arr = list(map(int, input().split()))
dic = defaultdict(int)
for cur in arr:
    dic[cur] += 1
results = set()
answer = 0
for i in range(len(arr)-1):
    for j in range(i+1, len(arr)):
        cur = arr[i] + arr[j]
        if(cur in dic and cur not in results):
            results.add(cur)
            answer += dic[cur]

print(answer)
```

**문제점**: `arr[i] + arr[j]`의 결과가 `arr[i]`나 `arr[j]`와 같은 값일 때 자기 자신을 합에 포함시키는 경우를 처리하지 못함. 또한 값 기준으로 한 번만 세고 `dic[cur]`을 더하는 방식으로는 "다른 두 수의 합"이라는 조건을 정확히 판별할 수 없음.

## 성공한 코드 흐름

1. 배열의 각 원소 `num`에 대해 "자신을 제외한 나머지 수들 중 두 수의 합이 `num`인가?"를 판별
2. 자신을 제외한 배열을 정렬한 뒤, 투 포인터(양 끝에서 시작)로 O(N)에 쌍을 탐색
3. 합이 target보다 작으면 `l += 1`, 크면 `r -= 1`, 같으면 "좋은 수"로 카운트

## 성공한 코드
```python
import sys
from collections import defaultdict

input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))
# 각각에 대해서 연산
answer = 0
for num in arr:
    sub = list(arr)
    sub.remove(num)
    sub.sort()

    found = False
    l = 0
    r = len(sub) - 1
    found = False
    while l < r:
        total = sub[l] + sub[r]
        if(total == num):
            found = True
            break
        elif(total < num):
            l += 1
        else:
            r -= 1
    if(found):
        answer += 1
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 투 포인터로 두 수의 합 판별
정렬된 배열에서 특정 target과 같은 합을 가지는 쌍이 존재하는지를 O(N)에 판별하는 기법. 왼쪽 포인터 `l`과 오른쪽 포인터 `r`을 양 끝에 놓고, 합이 작으면 `l`을 오른쪽으로, 크면 `r`을 왼쪽으로 이동한다.
- **핵심 원리**: 정렬된 상태에서 양 끝 포인터가 탐색 공간을 한 번에 하나씩 줄이므로 모든 가능한 쌍을 빠짐없이 확인 가능
- **시간복잡도**: O(N)

#### 자기 자신 제외 처리의 중요성
"다른 두 수의 합"이라는 조건에서, 합을 만드는 두 수에 자기 자신이 포함되면 안 된다. `list.remove(val)`은 첫 번째 등장만 제거하므로, 중복 값이 있어도 정확히 하나만 제거되어 올바르게 동작한다.

### 실수했던 부분

|틀린 것|올바른 것|
|---|---|
|값 기반 dict + set으로 일괄 카운팅|각 원소마다 자신을 제외하고 투 포인터로 판별|
|`set()`으로 중복 제거 (2차 시도) → 같은 값의 다른 수를 구분 불가|`list.remove()`로 자신 하나만 제거|
|O(N³) 브루트포스|투 포인터로 O(N² log N)|
|`found = False` 중복 선언|한 번만 선언|

## AI 코드 리뷰

### 개선할 점

1. **매 반복마다 복사 + 정렬 제거**: 배열을 한 번만 정렬해두고, 투 포인터 탐색 시 자기 인덱스만 건너뛰면 O(N²)으로 최적화 가능 (현재 O(N² log N))
2. **`found = False` 중복 선언**: 같은 변수를 두 번 초기화하고 있음
3. **변수명 개선**: `sub`보다 목적이 드러나는 이름 사용, `num` 대신 `target` 등
4. **불필요한 import 제거**: `defaultdict`를 import하지만 사용하지 않음

## 수정된 코드
```python
import sys

input = sys.stdin.readline

N = int(input())
arr = list(map(int, input().split()))
arr.sort()

answer = 0
for k in range(N):
    target = arr[k]
    l, r = 0, N - 1
    found = False
    while l < r:
        if l == k:
            l += 1
            continue
        if r == k:
            r -= 1
            continue
        total = arr[l] + arr[r]
        if total == target:
            found = True
            break
        elif total < target:
            l += 1
        else:
            r -= 1
    if found:
        answer += 1

print(answer)
```
