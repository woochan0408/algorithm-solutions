## 흐름

1. N개의 수를 입력받아 정렬한다.
2. 각 수 `arr[i]`에 대해, 나머지 수 중 두 개의 합이 `arr[i]`와 같은지 투포인터로 확인한다.
3. 왼쪽 포인터 `l`과 오른쪽 포인터 `r`을 양 끝에서 시작하되, 자기 자신(`i`)은 건너뛴다.
4. 합이 타겟보다 작으면 `l`을 증가, 크면 `r`을 감소, 같으면 "좋은 수"로 카운트한다.

## 코드
```python
import sys
input = sys.stdin.readline
def isgood(i):
    l = 0
    r = N-1
    while l < r:
        hap = arr[l] + arr[r]
        if(l == i):
            l += 1
            continue
        elif(r == i):
            r -= 1
            continue
        elif(hap == arr[i]):
            return 1
        elif(hap < arr[i]):
            l += 1
        else:
            r -= 1
    return 0
        
N = int(input())
arr = list(map(int , input().split()))
arr.sort()
answer = 0
for i in range(len(arr)):
    answer += isgood(i)
print(answer)
```

## 질문 & 실수 정리

### 새로 배운 것

#### 투포인터 VS 이분탐색
정렬된 배열에서 "두 수의 합 = 타겟"을 찾는 문제는 투포인터와 이분탐색 모두 가능하지만 시간복잡도에 차이가 있다.

- **투포인터**: 양 끝에서 좁혀가며 한 번의 순회로 판별. 한 타겟당 O(N), 전체 O(N²)
- **이분탐색**: 한 원소를 고정하고 나머지에서 `타겟 - arr[j]`를 이분탐색. 한 타겟당 O(N log N), 전체 O(N² log N)

| 방식 | 한 타겟당 | 전체 (N개 타겟) | 비고 |
|------|-----------|-----------------|------|
| 투포인터 | O(N) | O(N²) | 정렬 필수, 양 끝에서 좁히기 |
| 이분탐색 | O(N log N) | O(N² log N) | 정렬 필수, 고정+탐색 |

정렬된 배열에서 두 수의 합 문제는 투포인터가 더 효율적이다. 이분탐색은 "하나를 고정하고 나머지 하나를 찾는" 구조일 때 적합하고, 투포인터는 "두 수를 동시에 움직이며 찾는" 구조일 때 적합하다.

#### 자기 자신 제외 처리
투포인터에서 특정 인덱스를 제외해야 할 때, 포인터가 해당 인덱스에 도달하면 건너뛰는 방식으로 처리한다. 합을 계산하기 전에 인덱스 검사를 하면 불필요한 연산을 줄일 수 있다.

## AI 코드 리뷰

### 개선할 점

1. **함수명 snake_case**: `isgood` → `is_good`으로 PEP8 네이밍 컨벤션을 따르는 것이 좋다.
2. **반환값 bool 사용**: `return 1` / `return 0` 대신 `True` / `False`를 반환하면 의미가 명확해진다. (`+=`에서 True는 1로 자동 변환됨)
3. **자기 자신 체크 순서 최적화**: `hap`을 계산하기 전에 `l == i`, `r == i` 검사를 먼저 하면 불필요한 덧셈 연산을 방지할 수 있다.
4. **`len(arr)` 대신 `N` 사용**: 이미 `N`을 선언했으므로 `for i in range(N)`이 더 일관적이다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline

def is_good(i):
    l = 0
    r = N - 1
    while l < r:
        if l == i:
            l += 1
            continue
        if r == i:
            r -= 1
            continue
        hap = arr[l] + arr[r]
        if hap == arr[i]:
            return True
        elif hap < arr[i]:
            l += 1
        else:
            r -= 1
    return False

N = int(input())
arr = list(map(int, input().split()))
arr.sort()
answer = 0
for i in range(N):
    answer += is_good(i)
print(answer)
```
