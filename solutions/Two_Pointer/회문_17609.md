# 백준 17609 🪞 회문 파이썬

## 느낀점
>
- 함수 하나로 해결하려는 시도를 했다.
- 하면 했지만 로직이 한번 꼬여서 그냥 solve, valid 구분해서 풀었다.
- 시험장에서 그러면 뻘짓이다.. 빨리 푸는 것에만 집중하기.

## 흐름

1. 양쪽 끝에서 투 포인터로 문자를 비교하며 안쪽으로 이동
2. 불일치 발생 시, 왼쪽 또는 오른쪽 한 칸을 건너뛴 부분 문자열이 회문인지 검증
3. 검증 통과하면 유사회문(1), 실패하면 일반 문자열(2)
4. 불일치 없이 끝나면 회문(0)

## 코드
```python
"""
회문 vs 유사회문
앞뒤로 포인터 1개씩 가지고 있음
count를 셈
1개까지 봐줌 (유사회문)
두 개부터 break 후 일반 문자열로 출력
한 문자를 삭제한다.. 
 = 피봇 한칸 이동한다.
 - 이동 가능 여부 확인.
 - 같은 지 확인
7
abba
summuus
xabba
xabbay
comcom
comwwmoc
comwwtmoc
"""
def solve(s, l, r, life):
    while l < r:
        # 검증시간
        if(s[l] != s[r]):
            # life 없으면 회문 아닌걸로
            if(not life):
                return 2
            if(life):
                # 피봇 이동 후 (목숨 False) 에도 만족한다면
                if(valid(s, l+1, r) or valid(s, l, r-1)):
                    return 1
                else:
                    return 2
        l += 1
        r -= 1
    if(life):
        return 0
        
def valid(s, l, r):
    while l < r:
        if(s[l] != s[r]):
            return False
        l += 1
        r -= 1
    return True  

    
import sys
input = sys.stdin.readline
N = int(input())
for _ in range(N):
    string = input().strip()
    print(solve(string, 0, len(string)-1, True))
```

## AI 코드 리뷰

### 개선할 점

1. **`life` → `can_delete`로 네이밍 변경**: `life`도 의미는 통하지만, `can_delete`가 "한 글자 삭제 가능 여부"라는 역할을 더 직관적으로 전달한다.

2. **`if(not life)` / `if(life)` → `else`로 간결화**: `not life`를 먼저 체크했으므로 바로 다음 분기는 `else`로 충분하다. 불필요한 조건 검사를 줄여 가독성이 좋아진다.

3. **`solve` 함수 return 누락 방어**: 현재 `solve`는 `life=True`로만 호출되지만, `life=False`로 호출될 경우 while 루프가 정상 종료되면 `None`이 반환된다. `valid` 함수로 분리되어 있어 실제 문제는 없지만, 함수 끝에 기본 return을 두면 더 안전하다.

4. **`import` 위치**: `import sys`를 파일 상단으로 이동하는 것이 파이썬 관례(PEP 8)에 맞다.

## 수정된 코드
```python
import sys
input = sys.stdin.readline


def is_palindrome(s, l, r):
    while l < r:
        if s[l] != s[r]:
            return False
        l += 1
        r -= 1
    return True


def solve(s, l, r, can_delete):
    while l < r:
        if s[l] != s[r]:
            if not can_delete:
                return 2
            else:
                if is_palindrome(s, l + 1, r) or is_palindrome(s, l, r - 1):
                    return 1
                else:
                    return 2
        l += 1
        r -= 1
    return 0


N = int(input())
for _ in range(N):
    string = input().strip()
    print(solve(string, 0, len(string) - 1, True))
```
